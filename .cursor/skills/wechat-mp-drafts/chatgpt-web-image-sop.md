# 原创配图 SOP

2026-11-10 用户更新：撤销默认使用 ChatGPT 网页以及网页失败禁止切换的规定。文件路径保留，避免现有引用失效。

## 适用范围与渠道

- 用于原创小说、栀夏生活分享和用户明确同意原创配图的内容。
- 默认使用当前环境的内置 ImageGen，按图片生成 Skill 执行；不要求用户额外指定 Codex，不默认打开网页，不依赖 ChatGPT 网页登录状态。
- 用户明确指定 ChatGPT 网页或其他渠道时按其要求执行；网页版是可选方式。
- 热点、影视和公共事件的真实图片要求继续按各自专题执行；生成图不得冒充新闻现场、历史照片或演员剧照。

## 分镜与文件

- 先明确主体、动作、场景、光线、构图、比例与禁止项，再生成图片。
- 同组人物图先建立封面或人物母版，后续作为参考保持人物与场景连续性。
- 已有 `codex-image-request.json` 时保留 `slot_id`、`output_path`、`prompt`、`reference_slot_id` 与 `safety_rules`；按实际渠道记录 `generator`，不把旧文件里的 `chatgpt_web` 当作新的用户渠道指定。
- 项目图片保存到工作区，保留提示词、实际渠道与质检记录；不覆盖用户未要求替换的已有图片。

## 质检与恢复

- 检查文件可解码、尺寸与比例符合用途。
- 逐图查看人物脸型、年龄感、体型、手指、服饰、道具、空间关系与组图连续性。
- 检查意外文字、水印、二维码，以及年代图中的现代物件和不合时代的包装。
- 失败时保留已有合格图片，只重试未完成或有缺陷的槽位；无法继续时如实说明，不把缺陷图片插入草稿。
- 需要补图的原命令在补齐后重新运行，确认不再缺图。生成或保存图片不自动授权写草稿或发布。

## ChatGPT 网页可选流程

仅用户明确指定网页版时读取和使用本节：

1. 检查已登录的目标会话，不读取 Cookie、密码或浏览器存储，不尝试自动登录。
2. 网页执行器仍要求请求文件的 `generator=chatgpt_web`、`failure_policy=stop_and_prompt`；这些是该执行器的参数，不是默认渠道规则。
3. 按槽位提交提示词与必要参考图，生成后下载到本地并执行上述质检。
4. 网页不可用时说明原因；用户指定的渠道尚不可用，不冒充已经生成。未明确要求保留网页渠道时，可使用内置 ImageGen 继续。
5. 网页执行器保留为可选工具：`scripts.tools.wechat_mp_chatgpt_images`。完成后保留已有合格图片和续跑记录。
