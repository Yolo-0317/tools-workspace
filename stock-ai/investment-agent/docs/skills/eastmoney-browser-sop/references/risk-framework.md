# 风险评估框架

## 1. 技术面风险

### 1.1 上影线风险
- **现象**：当日留有长上影线（如最高8.50，收8.36）
- **含义**：上方存在抛压，短期可能面临回踩
- **提示**：若上影线超过实体50%以上，需警惕短期震荡

### 1.2 乖离率风险
- **现象**：当前价偏离5日均线过远
- **含义**：短期涨幅过大，有回踩需求
- **提示**：乖离率超过10%时，需提示短期有调整风险

### 1.3 均线压制风险
- **现象**：若价格未能有效突破长期均线（如60日均线）
- **含义**：长期趋势仍未改变，反弹可能受阻
- **提示**：需等待有效突破确认

### 1.4 成交量萎缩风险
- **现象**：涨幅较大但成交量未能同步放量
- **含义**：上涨动力不足，可能难以持续
- **提示**：需观察后续成交量是否能维持

## 2. 基本面风险

### 2.1 财务杠杆风险
- **指标**：负债率、资产负债率
- **特别关注**：电力企业通常负债率较高（50-70%），需评估是否过高
- **提示**：若负债率超过行业平均20%以上，需警惕财务风险

### 2.2 应收账款风险
- **指标**：应收账款周转率、应收账款占比
- **含义**：应收账款过高可能影响现金流
- **提示**：若应收账款占营收比例超过30%，需关注

### 2.3 盈利能力风险
- **指标**：净利率、ROE、毛利率趋势
- **含义**：若盈利能力下滑，估值吸引力下降
- **提示**：若净利率环比下滑超过10%，需警惕

### 2.4 资本开支风险
- **指标**：未来资本开支计划、在建工程
- **含义**：大规模资本开支可能压低现金流和分红
- **提示**：若资本开支占营收比例超过20%，需关注

## 3. 事件风险

### 3.1 传闻风险
- **现象**：上涨与特定传闻相关（如重组、重大投资）
- **风险**：传闻未证实前的波动风险
- **提示**：需明确标注"传闻未证实"，提示波动风险

### 3.2 政策风险
- **现象**：行业政策变化（如电价调整、环保政策）
- **风险**：政策变化可能对公司基本面产生重大影响
- **提示**：需关注政策落地时间和具体影响

### 3.3 成本风险
- **现象**：原材料、燃料成本上升
- **风险**：成本上升可能压低利润
- **提示**：需关注成本变化趋势

### 3.4 竞争风险
- **现象**：行业竞争加剧、市场份额下降
- **风险**：竞争加剧可能压低价格和利润
- **提示**：需关注市场份额和竞争格局变化
