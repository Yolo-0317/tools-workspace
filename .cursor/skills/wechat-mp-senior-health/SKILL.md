# 公众号中老年健康稿

适用于中年、退休前后及老年读者共同关心的日常健康问题。年龄只用于理解生活处境，不用于推断个人疾病。稿件是有来源的健康生活文章，不冒充医生诊疗意见，也不附保健食品、药品或医疗器械的购物卡。

写稿前读 [健康作者卡](../wechat-mp-health-content/author-role-card.md)；需要提炼丁香医生写法时读[已有观察](../wechat-mp-health-content/dxy-writing-study.md)。一般健康事实及商品边界仍以[健康内容 Skill](../wechat-mp-health-content/SKILL.md)为准。只选题时用[健康选题 Skill](../wechat-mp-health-topic-discovery/SKILL.md)；需要起标题时可再用[标题 Skill](../wechat-mp-title-writing/SKILL.md)。

## 近期选题：从丁香医生找问题，再独立写稿

近期新稿默认先人工阅读一篇与中老年生活有关的[丁香医生文章](https://dxy.com/)，记录其 URL、发表日期、读者问的具体问题，以及值得学习的一个写作动作，例如如何在开头呈现两种说法的冲突、何时给出核心判断、怎样用证据推进。再决定本公众号要回答的问题、适用人群和自己的角度。

“仿写”只指学习抽象的提问和论证方法：不复用原文标题、句子、故事、比喻、段落顺序或图片，不逐段同义改写，也不声称拥有丁香医生的身份或审稿背书。遵守[丁香医生用户协议](https://dxy.com/doctor-college/agreement/dxy-doctor.html)，不批量抓取、复制或保存原文。健康结论重新查当前有效的官方指南、公共卫生机构原始资料或高质量研究，并记录资料的日期、对象和适用条件。丁香医生旧文不能证明话题最近热门；若标题或汇报称“近期热议”，另按选题 Skill 核关注信号。

选题前先问：读者看到这篇文章，正准备做什么决定？如“每天散步够不够，为什么起身仍费劲”。用一张内部事实卡写明核心问题、3～5 条关键主张、每条原始证据、适用人群和不能推出的结论。不把这张卡原样写进正文。

取证先查中国权威资料，执行[作者卡的证据工作台](../wechat-mp-health-content/author-role-card.md#证据工作台)。禁止因海外页面更易获取而默认以国外机构为主要来源；国内资料充分时优先采用，确需国外研究补充时在事实卡说明必要性，并核对适用范围。

## 写作与审稿

- 开头让真实的矛盾、疑问或有依据的担忧出现，并在前两段说清作者的基本判断；不能靠暗示患病制造焦虑。
- 围绕读者的选择解释“为什么”：活动或饮食机制、证据观察到什么、哪些条件不同、可以怎样做。重要问题写透；通常以约 1200～1800 个汉字作为起稿检查点，内容充分时可短可长，不靠重复和过渡凑字。
- 执行[作者卡的出处检查](../wechat-mp-health-content/author-role-card.md#禁止用出处代替解释)：禁止拿“某机构解释了这些变化”等指路句替代原因或变化的解释。遮住来源名称和链接后，正文仍须完整回答读者的问题；证据不足时保留边界，不编造机制。
- 用短段落排版，但段落的长短随意思变化。先想清楚本段告诉读者哪件新事，再用日常说法直接讲。逐句核主语、动作、对象和证据，不沿上一句的句式自动补出漂亮却不准确的对仗；删掉“这项研究回答的是”“这里值得注意的是”等只宣布写作动作的壳。
- 可以自然使用“吧、呢、啊”等语气词，但不按字数配给。朗读一遍：别让强行衔接、夸张比喻或免责声明打断解释。结尾给一个普通人能用的判断；确有异常情况时再交代需要专业评估的边界。
- 标题必须与正文核心问题同题。正文通常保留一两处**有证据支撑的关键判断**作蓝色高亮，HTML 使用 `color:#1a5276`，不把整段涂蓝。

## 配图与版式

排版时读[健康稿排版](../wechat-mp-health-content/layout.md)：使用分节标题、克制的蓝色重点、必要的建议清单、贴图图注和文末资料，输出带内联样式的 HTML，并检查手机宽度。不要只给每段套一个普通 `p` 标签。

- 至少准备两张与内容对应的**真实图片**，不得用 AI 生成图补位。可把封面图在正文复用。打开实际图片核对画面，并记录原图页、作者、授权方式、文件路径和使用位置；来源与许可无法核实时继续找图。
- 按最新用户偏好，图源统一放文末“图片来源”，注明对应图片、作者、原图及许可链接；使用比正文小的灰色文字；中老年阅读版优先 14px、较深灰 `#606b73`，普通版可用 `font-size:12px;color:#888`；需要时链接原图和许可。不要把两张图的署名堆在文章末尾。封面裁切时注明“封面经裁切”。
- 结尾可用一句说明本公众号还会分享什么，并自然邀请关注、星标；读者可见文案写“本公众号”，不硬编码旧账号名。示例：“我们以后还会分享更多实用的健康话题，觉得有用的话，欢迎关注并星标本公众号。”不把这句当作每篇必抄模板。

## 草稿与检查

写作完成不自动推送。用户要求推草稿时，按[微信 API 草稿步骤](references/draft-api.md)操作：预检出口、上传正文图和封面、创建或更新原草稿、回读核对。回读失败时先保留 `media_id` 查明原因，不能盲目重建。草稿成功也不等于公开发表；发表仍由用户决定。

交稿或推稿前核对：题目与首段同题；关键判断有原始证据；已先查中国权威资料，国外来源确有补充必要性；遮住引文仍能读懂核心解释；两张真实图及文末对应的小字图源齐备；蓝色高亮数量适中；结尾只出现一次关注句；无商品卡、虚构亲历和未经证实的医疗建议。
