# 唐风三桅客船母版验收清单

资产标识：`tang-three-mast-passenger-ship-v01`。

## 船体与尺度

- [ ] 船体能够读出约22至26米长度、5至6米宽度和约4.3:1至4.8:1长宽比。
- [ ] 船头狭长微翘、船尾较宽，首尾方向清楚。
- [ ] 前甲板、中央一层通高长舱和后甲板三段结构完整。
- [ ] 船身正常吃水，没有弯曲、镜像、腾空或玩具比例。

## 船舱可进入性

- [ ] 中央船舱能够读出约7至9米长度和约2.2至2.5米内部净高。
- [ ] 舱门约1.8至2米高，栀夏可以直立通过，头顶低于门框上沿。
- [ ] 门内具有真实暗部和纵深，不是假门或贴图。
- [ ] 船舱具有窗格、立柱、舱顶和墙板厚度，不是半人高木箱、小亭或双层楼阁。

## 三桅三帆

- [ ] 恰好三根桅杆，沿纵轴前、中、后排列，位置与间距清楚。
- [ ] 主桅高出甲板约12至14米，主帆约7至9米高、4至5米宽。
- [ ] 前帆和后帆面积约为主帆75%和65%，三帆关系接近100:75:65。
- [ ] 三帆相较夸张返图缩小到约60%至70%的视觉面积，不形成白墙。
- [ ] 帆底与甲板、舱顶之间有清楚空隙，人物、船舱和船体没有被遮住。
- [ ] 三帆受同一风向，帆骨、褶皱和少量固定索具真实。

## 人物与材质

- [ ] 只有一个栀夏和一个阿砚，身份与角色卡一致。
- [ ] 阿砚位于前甲板；栀夏直立位于船舱门旁。
- [ ] 深棕硬木、米白帆布、水面反射和接触阴影使用统一光源。
- [ ] 画面保持偏写实东方动画电影风格，没有变成真人、3D或扁平贴图。

## 直接淘汰

出现巨帆小船、船长视觉比例不足22米、7至9米长舱无法读出、2.2至2.5米通高空间不足、1.8至2米舱门无法让栀夏直立通过、半人高木箱船舱、桅杆不是三根、帆面遮住主体、船体镜像、多船或多角色时，母版判定失败，不进入后续单集引用。
