# 公众号摘要 SEO 与 #话题 操作说明

> **账号定位（2026-08）**：热点评论（社会 / 文娱 / 职场 / 公共事件）。  
> 代码真源：`scripts/tools/wechat_mp_seo.py`。推草稿后终端 / 飞书通知会打印 **推荐 #话题**。

## 你需要做什么（人工，约 1 分钟/篇）

API **不能**代勾选原创、也不能代加 `#`（须发布后在后台点）。脚本负责：

1. 摘要嵌入稿型 SEO 词（`enrich_digest`）
2. 标题搜一搜检查（`hotspot` / `tv_review`：**实体标题**为主，不强行加 `A股｜` 前缀）
3. 正文文末（免责声明前）写入一行 `#话题`（`WECHAT_MP_HASHTAG_INLINE=1` 默认开）
4. 终端/飞书打印推荐话题与发布提醒

**发布步骤**：

1. [mp.weixin.qq.com](https://mp.weixin.qq.com) 草稿箱 → 预览  
2. **勾选原创** — 分类选 **社会 / 娱乐 / 资讯**（勿默认财经）  
3. 发布后点 **`#`** → 按通知选 3～5 个（可微调 1 个为 **当日事件实体**，≤8 字）

---

## 话题怎么选（原则）

| 原则 | 说明 |
|------|------|
| **实体优先** | 第 1～2 个用 **案由、片名、事件名**（与标题一致） |
| 再垂直 | `#热点观察` `#社会话题` `#公共事件` 等稿型词 |
| 最多 5 个 | 微信限制；勿凑无关热词 |
| 禁止 | 荐股、牛股、必涨、内幕（`HASHTAG_BANNED`） |
| **勿** | 热点号 **不要 `#A股` 打头** 当主策略 |

动态第 4 个：当日事件实体（如片名、案由关键词），≤8 字。

## 标题搜一搜

### hotspot / tv_review（主稿型）

- **前 15 字**：可搜 **实体**（谁 / 啥事 / 片名 / 案由 / 数字），表意完整  
- **不**自动加 `A股｜` 前缀  
- traffic 清单：`title_search_seo` = 前 15 字 ≥8 字且表意完整（见 `sousou-content-rules.md`）

### 财经稿（仅手动）

| kind | 标题池优先词 | 缺省时前缀 |
|------|--------------|------------|
| sector | A股、行业、产业链 | `A股行业｜` |
| market close | A股、收盘复盘 | `A股收盘｜` |
| top5 | A股、观察、结构 | `A股观察｜` |
| dragons | A股、龙头、情绪 | `A股龙头｜` |
| news | A股、快讯 | `A股快讯｜` |

`wechat_mp_traffic_checklist.py` 检查 `title_search_seo`。

## 正文话题行（自动）

免责声明**上一行**，例如：

```text
#热点观察 #社会话题 #公共事件
```

关闭：`WECHAT_MP_HASHTAG_INLINE=0`
