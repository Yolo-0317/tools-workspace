# 去 AI 味（anti-ai-voice）

引流节奏、开篇钩子、站队问句 → [traffic-copy-craft.md](traffic-copy-craft.md)。社会稿形态 → [social-commentary-voice.md](social-commentary-voice.md)。

浓缩自 `wechat-mp-drafts/writing-guide.md` · `researcher-voice.md` · `wechat_mp_eval` 罚分项。

## 口吻定位

本页的研究员词表和下面的财经 checklist 只用于财经稿。用户主动热点的写法先见 [essay-commentary-craft.md](essay-commentary-craft.md)；本页在收稿后识别编审说明、机械重复和空泛套话，不作为初稿提纲。词汇命中先看语境，不能仅为消灭某个词而删除政策适用范围、当事方归属或其他必要限定。

**研究员笔记**：有数字、有出处、有判断边界；不是券商研报腔，也不是聊天灌水。

- 用：**收盘、涨跌幅、板块、情绪、龙头、连板、成交额**
- 少用：**显著、持续、深度、全面、助力、赋能**

## 财经深稿：改句不丢信息

行业与公司深稿出现问答腔、假口语或压缩句时，先写出原段承担的事实和解释，再重写整段；不能只删掉被指出的句子。改写后逐项核对：公司和业务环节、发生的动作、财务科目、报告期与比较期、数字单位、来源、必要的因果边界，原稿中有的关键信息必须保留。缺少来源的公司特定结论应缩小到有证据的事实，不能用泛泛的推测补位。

- 禁止把正文写成答题过程：`看它的收入，实际上是在看……`、`后续能否……还要看……`、`这说明了什么`、`为什么……`。把机制写成陈述句，明确谁采购、谁交付、哪一项进入报表；判断后面接对应数字或报告原文。
- 禁止为去 AI 味删除业务机制。比如设备企业的订单和收入不是同一口径，应说明订单、交付、收入确认分别指什么，再写报告中已确认的收入；若没有订单数据，就不推断订单规模或验收进度。
- 禁止省掉读者需要的时间和对象。首次写同比时给出年份和报告期；跨到行情日期时写清交易日与财报覆盖期。`这些财务数据截至6月30日，与10月8日相隔三个多月`应展开为完整的年度、报告期间和交易日关系。
- 财经深稿不能停在指标清单。每组关键数据后写出一条由数字和来源支持的经营判断，说明变化落在哪个业务或利润口径；末段给出跨公司或跨环节的主结论，并写清结论只覆盖哪个报告期。判断不能复述数字，也不能把单日股价写成财报变化的原因或未来走势。
- 新增的判断段与原稿一起接受全文审校，不能只检查被用户点名的旧句。优先把判断接在对应证据段内；另起一段时必须增加新的因果解释或跨公司比较，不能把上段数字再念一遍。逐句查空泛评语（如“这是最明确的变化”“提供了可核查的解释”）、没有报告依据的经营断言和把“不能……”写成连续答题提示；命中时用具体财务关系重写。
- 避免把作者的工作流程写进文章：`我翻了四份半年报`、`再往下读一行`。直接写公司披露的数字及其关系。
- 改稿后做一次信息守恒检查：逐段对照原稿和新稿，列出被删除的事实或解释；凡是支撑论点的内容，补成有主语、有依据、完整表达的句子。朗读时若像在回应读者提问，继续改写，不靠删句通过检查。

## 机械连接词（eval 扣分）

删除或改写：

- 综上所述、值得注意的是、与此同时、不仅如此
- 一方面…另一方面、总而言之、不可否认
- 在此背景下、随着…的不断发展

## 禁词与模板句（eval + 合规）

| 类型 | 示例 |
|------|------|
| AI 套话 | 感谢您的阅读、希望对您有帮助、点赞让我知道 |
| 财经合规 | 怎么玩、还在榜、领衔、100倍、稳赚 |
| 标题党 | 震惊、重磅、突发（`BANNED_TITLE_WORDS`） |

## 对称句式

避免成对排比：「不仅 X，而且 Y」「既 A，又 B」连用。改为一短句 + 数据。

## 具体感 checklist

- [ ] 正文含 **阿拉伯数字**（涨跌幅、家数、板数）
- [ ] 至少 1 处 **可验证名词**（东财、Tushare、板块名、股名）
- [ ] 段落 ≤3 行（移动端）；过长段拆开
- [ ] 2+ 分块标题（`>` 引用或 `一、`）
- [ ] **标题表意完整**（搜一搜路牌：读者不看正文也懂主题；禁止「返…」「暂…」半句）→ [sousou-content-rules.md](sousou-content-rules.md)

## 普通非虚构公众号稿

文风、语气与句法统一进入[基座随笔写作](../../../docs/writing/中文写作基座.md#公众号随笔写作)，不执行此前的口语替换表、首段金样或影视词语零命中要求。上面的研究员与财经检查只适用于其金融专题。机器模式提示不能替代事实及文体验收，检查与修改轮次沿用公共审稿，不无限改到某个分数。
