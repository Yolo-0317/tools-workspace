## 模块详解

---

### 1️⃣ 技术面（6大指标）

| 指标 | 参数 | 正常区间 | 超买信号 | 超卖信号 |
|------|------|---------|---------|---------|
| RSI | 14日 | 40-70 | >70 | <30 |
| WR（威廉）| 14日 | 20-80 | <20 | >80 |
| MACD | 12/26/9 | 快线在零轴上 | DIF>DEA红柱 | DIF<DEA绿柱 |
| BOLL（布林带）| 20日/2σ | 中轨附近 | 触及上轨 | 触及下轨 |
| DMI | 14日 | ADX>25确认趋势 | +DI>-DI | -DI>+DI |
| 乖离率 | MA20对比 | ±5%以内 | >+10%偏高 | <-10%低估 |

**额外记录：**
- MA5 / MA10 / MA20 / MA60 的数值和排列（多头/空头/纠缠）
- 量比（当日成交量/20日均量）：>2倍=放量，<0.5倍=缩量

---

### 2️⃣ 资金面（主力行为）

**数据来源：** 东方财富 `push2.eastmoney.com` → `/api/qt/stock/fflow/daykline/get`

**资金分级：**
- 超大单：>100万元/笔，主力行为
- 大单：>20万元/笔，机构行为
- 中单：散户游资
- 小单：散户

**核心指标：主力净流入 = 超大单 + 大单**

| 日期 | 超大单 | 大单 | 主力净 | 信号 |
|------|--------|------|--------|------|
| （填入） | | | | ✅吸筹 / ❌出货 / ➡️观望 |

**判断标准：**
- 连续2日主力净流入 > 5000万 = 主力建仓信号
- 连续2日主力净流出 > 5000万 = 主力出货信号
- 放量大涨日 + 主力净流入 = 确认上涨
- 放量大跌日 + 主力净流出 = 确认下跌

### 3️⃣ 形态识别

**自动识别以下K线形态：**

| 形态 | 看多信号 | 看空信号 |
|------|---------|---------|
| 锤子线 | ✅ 底部锤子（下影线≥实体2倍）| — |
| 吞没形态 | ✅ 阳包阴（第二根阳线吞没前一根阴线实体）| ⚠️ 阴包阳 |
| 早晨之星 | ✅ 三日底部反转 | — |
| 乌云盖顶 | — | ⚠️ 顶部反转 |
| 跳空缺口 | ✅ 突破缺口（放量+跳空）| ⚠️ 衰竭缺口（高位+缩量） |
| 头肩底/顶 | ✅ 底 | ⚠️ 顶 |
| 大阳/大阴线 | ✅ >5%阳线 | ⚠️ >5%阴线 |

**输出格式：**
```
近10日K线形态：
  日期    价格    形态            信号
  4/22    9.97   锤子线          ✅ 底部反转
  4/21    10.97  阳包阴          ✅ 多头反攻
  4/20    10.79  阴包阳          ⚠️ 空头压制
```

### 4️⃣ 基本面

| 维度 | 数据 | 来源 |
|------|------|------|
| 总市值 | （亿元） | f116 |
| 流通市值 | （亿元） | f162 |
| 市盈率(PE) | 正常10-30倍 | 东财 |
| 市净率(PB) | 正常1-5倍 | f167 |
| 股息率 | >3%=高股息 | f173 |
| 52周最高/最低 | 参考支撑压力 | f168/f169 |
| 净利润增速（YoY）| 持续>15%=成长 | f184 |
| 营收增速（YoY）| 持续正增长 | f185 |
| 行业属性 | 赛道+政策+周期 | 手动 |

**判断标准：**
- PE < 15 + 净利润增速 > 20% = 低估成长
- PE > 40 + 增速 < 10% = 高估风险
- 股息率 > 4% = 防御收息股
- 营收/净利润增速连续2季度下滑 = 基本面恶化

### 6️⃣ 综合评分（6维度）

每个维度 1-5分，汇总后/6得出综合评分

| 维度 | 权重 | 评分标准 |
|------|------|---------|
| 技术超卖/超买 | 20% | RSI<30/WR>80=5分，极度超买=0分 |
| 资金主力 | 20% | 主力连续净买入=5分，连续净卖出=0分 |
| K线形态 | 15% | 底部形态=5分，顶部形态=0分 |
| 基本面 | 20% | 业绩持续增长=5分，暴雷=0分 |
| 趋势结构 | 15% | 均线多头=5分，均线空头=0分 |
| 估值 | 10% | PEG<0.5=5分，PE>40=0分 |

**评分等级：**
- 4.5-5.0：⭐⭐⭐⭐⭐ 强烈推荐操作
- 3.5-4.4：⭐⭐⭐⭐ 积极关注
- 2.5-3.4：⭐⭐⭐ 中性，等待信号
- 1.5-2.4：⭐⭐ 谨慎，轻仓或观望
- 1.0-1.4：⭐ 高风险，建议回避

---

### 7️⃣ 操作矩阵（分情况应对）

| 情况 | 触发条件 | 操作 | 仓位 |
|------|---------|------|------|
| 🟢 **反弹确认** | 突破MA10（短期均线）且放量 | 减仓50% | 先卖 |
| 🟡 **横盘整理** | 在支撑-压力之间震荡 | 持有不动，不加仓不割肉 | 观望 |
| 🔴 **二次探底** | 跌破近期最低支撑 | 全部清仓/止损 | 止损 |
| 🔵 **暴涨信号** | 涨停/连涨3天+巨量 | 剩余仓位分批止盈 | 止盈 |
| 🟣 **加仓机会** | 回踩关键支撑位且缩量 | 可加仓（≤原仓位50%） | 买入 |

**标准止损规则：**
- 短线（持有<1个月）：止损8-10%
- 中线（1-3个月）：止损15-20%
- 长线（>3个月）：止损25-30%
- 跌破融资爆仓线：无条件清仓

**标准止盈规则：**
- 分批止盈：涨20%卖1/3，涨30%卖1/3，涨50%清仓
- RSI>75 + KDJ-J>90：减仓信号

### 8️⃣ 预测路径（三种情景）

```
乐观情景：
  条件：（技术+资金+形态+基本面的组合触发）
  目标价：XX元
  时间预期：X-X周
  操作：持有/加仓

中性情景：
  条件：（无明显催化剂，震荡为主）
  区间：XX-XX元震荡
  时间预期：X-X周
  操作：高抛低吸/持有不动

悲观情景：
  条件：（基本面恶化/系统性风险）
  止损位：XX元（跌破即走）
  最大亏损：XX%（按持仓计算）
  操作：无条件止损
```

**最大概率判断：**
基于上述7个模块的综合证据，判断当前最大概率情景，给出"一句话结论"。

## 数据获取脚本（Python）

```python
import urllib.request, json

def api(url):
    req = urllib.request.Request(url, headers={'User-Agent': 'Mozilla/5.0'})
    with urllib.request.urlopen(req, timeout=10) as r:
        return json.loads(r.read())

secid = "1.600873"  # 改为个股代码

# K线 + 均线 + MACD + BOLL
kl_url = (f"https://push2his.eastmoney.com/api/qt/stock/kline/get"
          f"?secid={secid}&fields1=f1,f2,f3,f4,f5"
          f"&fields2=f51,f52,f53,f54,f55,f56"
          f"&klt=101&fqt=1&beg=20250101&end=20260424&lmt=80")
klines = api(kl_url)['data']['klines']
dates  = [k.split(',')[0] for k in klines]
closes = [float(k.split(',')[2]) for k in klines]
opens  = [float(k.split(',')[1]) for k in klines]
highs  = [float(k.split(',')[3]) for k in klines]
lows   = [float(k.split(',')[4]) for k in klines]
vols   = [float(k.split(',')[5]) for k in klines]

# 资金流（日级别）
mf_url = (f"https://push2.eastmoney.com/api/qt/stock/fflow/daykline/get"
          f"?lmt=0&klt=1&secid={secid}&fields1=f1,f2,f3,f4"
          f"&fields2=f51,f52,f53,f54,f55,f56,f57,f58,f59,f60,f61,f62,f63")
mf = api(mf_url)

# 估值数据
fields = "f43,f57,f58,f107,f116,f162,f167,f168,f169,f173,f184,f185"
qt_url = f"https://push2.eastmoney.com/api/qt/stock/get?secid={secid}&fields={fields}"
qt = api(qt_url)['data']
```
