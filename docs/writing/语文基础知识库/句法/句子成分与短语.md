# 句子成分与短语

## 先看核心关系

在常见主谓句里，主语是陈述的对象，谓语说明这个对象怎样、是什么或做了什么。主语不等于施事，谓语不等于一个动词。

“小林认真地读完了这本书。”可以先分成主语“小林”和谓语“认真地读完了这本书”。再分析谓语内部：动语中心是“读”，“完”表示结果，“这本书”是宾语，“认真地”说明读的方式。不同层次分别分析，不能一边把整个谓语当一个成分，一边要求它与内部的宾语互不重叠。

“这本书已经寄出了。”的主语是“这本书”，它是动作涉及的对象；句子没有交代谁寄，不能为了补施事擅自加一个人。“小林很认真。”的谓语说明状态，并不缺一个动作。

## 六种基本成分

| 成分 | 作用与位置线索 | 自编例子 |
| --- | --- | --- |
| 主语 | 被陈述的对象，常在谓语前；可以是词或短语 | **这本书**很薄。**每天散步**有益于保持活动量。 |
| 谓语 | 对主语作陈述；可由动词性、形容词性等成分承担 | 小林**读完了这本书**。天气**很冷**。 |
| 宾语 | 与动语发生支配或涉及关系，不限于“被动作伤害的人或物” | 他读**书**。他喜欢**读书**。 |
| 定语 | 修饰、限制名词性中心语，说明所属、范围、数量、性质等 | **小林的**书、**三本**书、**新买的**书。 |
| 状语 | 常在动词或形容词等中心语前，说明时间、方式、程度、范围等 | 他**昨天**回来。他**认真地**读。屋里**很**安静。 |
| 补语 | 在动词、形容词等中心语后补充结果、趋向、程度、数量等 | 写**完**、走**进去**、读得**认真**、看了**三遍**。 |

这些是基本识别线索，不是见位置就能自动套用的公式。前置的时间、地点成分可能作状语，也可能是全句陈述的对象，要结合整个结构判断。“幸好、果然、确实”等还可能涉及整句的评价或判断，不能全解释成动作方式。

六种成分不要求每句齐备。呼语、插说等独立成分也不宜硬塞进主谓宾定状补：“小林，你先读。”中的“小林”是呼语。省略句和非主谓句见[省略指代与复句](省略指代与复句.md)。

## 同一个词，功能会变

“认真的学生”中，“认真”在修饰名词；“认真地读书”中，它在说明读书的方式；“读得认真”中，它补充说明读的状态。不能因为它常表示性质，就在每句都标成定语。

“他喜欢读书”中，“读书”内部是动宾关系，整个短语又作“喜欢”的宾语。分析短语内部和分析它在句中的功能，是两个层次。

## 常见短语关系

| 关系 | 怎样组合 | 自编例子及边界 |
| --- | --- | --- |
| 主谓 | 陈述对象＋对它的陈述 | 天气转凉；可单独成句，也可嵌入更大的句子。 |
| 动宾 | 动作或心理活动等＋涉及对象 | 看书、喜欢安静；不是相邻两个词就有支配关系。 |
| 偏正：定中 | 修饰限制＋名词性中心 | 新买的书；中心是“书”。 |
| 偏正：状中 | 修饰限制＋动词或形容词等中心 | 慢慢走、十分安静。 |
| 述补（中补） | 中心＋补充说明 | 写完、站稳、累得出汗；不必都有“得”。 |
| 并列（联合） | 两项或多项处于并列关系 | 纸和笔、认真而耐心；并列项的关系和层级应相当。 |
| 介宾 | 介词＋它涉及的对象 | 在屋里、向老师；整个短语的句中功能另判。 |
| 同位（复指） | 两个成分指向同一对象 | 我们的班长小林；不是两个不同人物。 |
| 的字短语 | 修饰成分＋“的”，整体具有名词性用途 | 新来的已经到了；指谁须由上下文交代。 |
| 连谓、兼语 | 多个谓词之间有特定的主体关系 | 拿着书朗读、请学生朗读；区别见[常用句式](常用句式.md)。 |

数量、方位等结构还有各自特点；本表列写作中常用的分析入口，并未穷尽短语类型。

## 看组合层级，不能只看词的先后

“老师推荐的书”先由“老师推荐的”修饰“书”，整个短语可作宾语：“我买了老师推荐的书。”这里“老师”不是全句主语。

“我知道小林来了。”中，“小林来了”作为整体交代知道的内容；不能因为“知道”后有个人名，就把“小林”直接当成“知道”的单独宾语，再判兼语。
