# 《登高》视频号发布文案设计

## 目标

为《登高》10 秒成片提供可直接用于视频号发布的标题、正文、话题和置顶评论。文案延续“栀夏飞花令”原创国风诗词 IP 定位，不写成 AI 工具教学或制作复盘。

## 文案方向

- 采用用户确认的“诗境抓眼”方向。
- 第一段从一片落叶领镜切入，呼应成片第一秒的贴地运镜。
- 第二段用栀夏回身与大江展开连接两句诗，不逐镜解释技术。
- 原诗固定为：`无边落木萧萧下，不尽长江滚滚来。`
- 结尾使用一个低门槛、与画面感受直接相关的问题，引导观众留言。

## 发布结构

1. 标题：突出落叶、大江和杜甫《登高》，避免标题党和制作术语。
2. 正文：三至五个短段落，先给画面，再落原诗，最后提问。
3. 身份说明：固定写明 `《栀夏飞花令·登高》` 与 `原创虚构动画｜AI辅助制作`。
4. 话题：控制在六个以内，只保留栏目、篇名、作者、古诗词、国风动画和东方美学。
5. 置顶评论：问题必须容易直接回答，不要求观众掌握诗词知识。

## 语气与限制

- 清透、克制、具有画面感；不用营销腔、教学腔或过度抒情的长句。
- 可以提到阿砚追叶、栀夏回身，但不展开角色设定说明。
- 不夸大为真人实拍，不隐藏 AI 辅助制作属性。
- 不使用 emoji，不加入下载、关注、转发或私信等强引导。
- 不写模型名称、提示词、生成次数、运镜编号或制作成本。

## 交付

- 一条推荐标题。
- 一份可直接粘贴的发布正文。
- 一组不超过六个的话题标签。
- 一条推荐置顶评论。
