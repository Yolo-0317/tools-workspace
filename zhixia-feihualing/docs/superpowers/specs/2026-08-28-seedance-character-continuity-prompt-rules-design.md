# Seedance 远景角色连续性提示词规则设计

## 目标

修复通用提示词规范中的一个结构性漏洞：角色设定虽然在提示词开头完整出现，但角色进入远景、快速运动、遮挡或复杂景观揭示后，模型可能降低角色参考权重，把原创角色重绘成近似的普通人物或动物。

本次只更新通用规范，不修改已经完成的《登高》单集提示词或成片。

## 问题归因

- 全局身份描述不能替代关键时间段的局部约束。模型在复杂运镜和大景揭示中会重新分配注意力，小面积角色的身份、物种和材质容易衰减。
- 单纯使用“不得漂移”“不得普通动物化”等负面措辞不够稳定。关键节点需要重复少量、可见、可验证的正向识别特征。
- 现有门禁关注“角色是否仍在画面中”，但没有要求检查远景里的核心轮廓、比例与材质是否仍然成立。
- 环境提示词若只描述目标氛围而不排除相邻视觉语义，可能生成并不存在的叙事物体。例如“滚滚江流”的高亮水纹可能被模型解释成船迹或尾流。

## 规则设计

### 1. 不可让渡的角色优先级

角色身份、物种结构、肢体与附属物数量、相对比例、固定标记和核心材质，优先级始终高于运镜、景别、景观、粒子和其他特效。当角色稳定性与壮阔景观发生竞争时，应缩减环境复杂度、降低运镜幅度或调整构图，不得牺牲角色身份。

### 2. 风险节点局部重锚

提示词开头保留完整角色定义；时间轴中只在高风险节点重复最短必要的正向身份锚点。以下任一情况出现时必须局部重锚：

- 角色从近景或中景进入全景、大全景。
- 角色画面高度或可见面积明显下降。
- 角色经历快速位移、显著运动模糊、长时间遮挡或重新显露。
- 镜头发生方向变化、空间转换、尺度变化或大景揭示。
- 同时出现多个角色、复杂流体、粒子或高信息量背景。

局部重锚只写当前画面能够观察的核心特征，不机械复制整段角色母版。栀夏优先重锚脸部关系、固定发型发冠、服装轮廓与配色；阿砚优先重锚成年猫尺度、笔锋双耳、朱砂额印、纸墨身体、暖金纹样和唯一黑灰飞白开放式 S 形墨尾。

### 3. 角色占比与可辨识度

- 时间轴必须写明角色在每个关键节点的景别、画面区域和最低可辨识状态，不能只写“角色仍在画面中”。
- 大景揭示中如需保留原创角色，构图必须让核心轮廓和至少三项固定识别特征可见；无法做到时，应改为侧后方清晰轮廓或让角色退出叙事职责，不要求模型在极小面积中生成精细正脸。
- 双角色同框时分别描述两者的可见性和稳定项，不使用含糊的“二人保持一致”。

### 4. 环境相邻语义排除

自然环境除正向材质和运动描述外，还要检查是否存在容易被误解为其他叙事物体的相邻视觉语义。若某种纹理可能暗示不存在的物体，必须在对应时间段就地排除，而不是只放在末尾禁止项。

例如无船江面应写为不规则、连续、宽尺度的自然水势，并明确不形成 V 形尾流、平行白线、规则航迹或多条船迹状高光。类似规则也适用于云层中的道路状结构、雾中的人形轮廓、墨迹中的额外尾巴和粒子形成的文字。

## 提示词编写顺序

1. 开头定义原创虚构角色、参考图职责和不可让渡的身份结构。
2. 写明本片唯一核心运镜、视觉承接物及角色与景观的优先级。
3. 在分段时间轴内标注风险节点，并就地加入最短必要的角色正向重锚与环境相邻语义排除。
4. 末尾禁止项只做全局兜底，不承担关键节点的主要约束职责。

## 生成前检查

- 是否识别了景别扩大、遮挡、快速运动、方向变化、空间转换和大景揭示等风险节点。
- 每个风险节点是否都有简短、正向、画面可验证的角色身份锚点。
- 是否分别写明每位角色的景别、画面位置、相对尺度和关键可见特征。
- 是否明确角色身份优先于景观和特效；复杂度冲突时有可删除或可降级的环境元素。
- 自然水体、云雾、墨迹、粒子等是否完成相邻视觉语义检查。
- 核心限制是否写在对应时间段，而不是全部堆在提示词末尾。

## 生成后抽检

至少抽检第一帧、每次景别或方向变化前后、角色遮挡后重新出现时、高潮揭示和最后一帧。除角色是否存在外，还必须检查：

- 身份、物种、数量、比例与固定标记。
- 发型、服装轮廓、耳形、尾形等远景识别轮廓。
- 核心材质是否从纸墨、丝织或幻想生物降级成普通人物、宠物或塑料模型。
- 环境纹理是否暗示提示词中不存在的船只、道路、额外角色、文字或其他叙事物体。

若偏差只出现在可接受的非叙事细节，可进入后期；若原创角色身份、物种结构或核心标记发生漂移，应记入通用规则复盘。是否重生成由当集发布标准决定，不自动触发生成或素材修改。
