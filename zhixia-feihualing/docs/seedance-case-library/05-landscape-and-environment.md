# 风景与环境

收录山水、森林、花海、天气、沙漠、海洋、建筑、室内和城市空间案例。

案例按统一 `CASE-xxx` 字段登记；重点记录空间层次、尺度参照和环境变化。

## CASE-033 雾山升空揭示城堡

- **来源：** [SeedanceTips 50+ Prompt Library](https://seedancetips.com/prompts/seedance-prompt-library/)
- **访问日期：** 2026-08-28
- **证据等级：** C
- **模型版本：** 页面声称 Seedance 2.0，未见逐例结果证明。
- **输入方式：** 纯文字，10 秒。
- **中文结构化改写：** 日出时摄影机从雾山低处升起，越过前景山脊后缓慢下倾，揭示悬崖城堡；体积雾和金色侧光分开近中远层次。
- **可复用写法：** 让升空跨越真实遮挡物，再用俯倾揭示目标，避免无参照的空中漂移。
- **失败风险：** 城堡结构可能随揭示变形；纯文字来源没有逐例成片证据。
- **栀夏适用性：** 适合诗境由局部山石展开为全景。

## CASE-034 珊瑚礁水下滑行

- **访问日期：** 2026-08-28
- **证据等级：** C

- **输入方式：** 纯文字，12 秒。
