# 热点深评事实与编辑判断门禁

本文件用于当前 Agent 起稿的事实核验与审稿，以及外部初稿的核实编辑。写稿默认入口以 [通用 Skill](../wechat-mp-article/SKILL.md) 和 [热点专题](hotspot-deep-review.md) 的2026-10-12更新为准；用户指定 DeepSeek 时保留其交接。不改变配图与推送授权。

## 先分清每句话是什么

在内部核验清单中，将影响标题、核心判断和家庭决策的表述分为五类：

| 类型 | 处理 |
|---|---|
| 可核事实 | 核对原始来源、时间、地区、对象和口径后使用 |
| 当事方说法 | 写明是谁回应、通报或主张；不自动当成中立结论 |
| 解释性判断 | 说明它由哪些事实推出，保留适用条件 |
| 作者观点 | 必须能被正文证据支撑，不能冒充政策结论 |
| 暂不可核实 | 不作确定事实；仅当本篇确需交代该未决事实时写明待调查或未公布，不因资料缺项自动添审校备注 |

这些标签只用于内部审校，不得以“事实标签”“待核项”“审校结论”等形式进入公开正文。研究时核实材料，起稿时按[公共Skill的交接](../wechat-mp-article/references/drafting-loop.md#协调者整理本篇委托)给主笔所需事实与条件；本页分类表、交付字段及审校意见不整包转成起稿提纲。

## 来源怎样使用

- 政策名称、发布日期、生效时间、金额、计算公式、适用地区、学段、园校性质、对象和例外，优先回到政府、主管部门、法院文书或发布单位原文。
- 一份权威原始文件可以直接证明其中的政策条文，不为凑数机械寻找三个转载来源。整篇成稿仍执行既有来源域要求。 来源域和字数是工程入口的要求，不能反过来决定材料取舍：不得塞入无关评论、重复政策或空泛分析补数。内容不足先补主线所需事实；仍不满足工程门禁时如实标记未满足，不绕过代码或将文字审定等同可推送。
- 新闻事件优先核对首发报道、原始材料和主管部门回应。争议相关机构的情况说明，只能证明该机构公开作出了这一表述；除非有独立调查结果，不写成争议已经查清。
- 多个网页如果都转述同一份通知、同一段采访或同一条视频，只算一个原始信源。不同域名不自动等于独立印证。
- 风格样本只用于观察开头、节奏和措辞，不能为数字、引语、政策范围或因果关系提供证据。
- 信息冲突时先检查发布时间、适用年份、地区、学段、收费类别和定义口径；仍无法解释时保留不确定性，不替来源强行统一。

### 用户主动热点的关键主张交付

在内部 `editorial_handoff.json` 中逐项登记标题和导语的前提、关键数字、企业或政策动作、结论依赖的事实；不要求把每句常识写成台账。每项写明原文主张、原始来源链接、来源发布日期、所述事件或数据的时期、实际核对时间、适用范围，以及正文中能找到的原句。区分 `source_fact`（原始事实）、`reported_snapshot`（报道时的页面快照）、`party_statement`（当事方说法）和 `author_inference`（作者推断）。这份记录是内部交付物，不进入公开正文。

`editorial_review` 与 `paragraph_progression` 在实际成稿审校后据实填写，不要求主笔先填字段再把正文写成字段说明。同一交付记录还须写 `editorial_review`，先注明本篇文体和目标读者。随笔记录 `narrative_focus`（实际写到的人和事）、重要事实锚点和实际相邻关系；记录用于成稿核对，不将“形成认识”另设为主笔绩效，不强制填写读者疑问、唯一结论或反方。论证稿才登记主要主张、证据锚点及确实涉及的异议；存在主张就核依据，但不强制所有文章成为可反驳命题。

`paragraph_progression` 只保留一份，按[结构验收格式](../wechat-mp-article/references/review.md#结构验收与放行记录)记实际内容和联系，不登记每段应产生什么道理。随笔事实可靠、表达与承接成立即可据实放行，不因缺少中心论点拒收。`review.md`引用版本与处理，不重复结构表。旧工程若仍强制论点或提问字段，记录兼容缺口；不得造一个判断塞入正文或伪造验收，亦不从文档调整推导修改程序、绕过推送门禁的权限。

房源、商品价格或库存等页面快照，要在正文中说出“报道时／页面当时显示”及相应日期；不能把旧截图写成当前仍可买到的价格。企业动作若来自媒体转述，正文和交付记录都注明报道主体，不写成企业自己宣布。作者推断单独归属，不冒充报告结论。关键主张回不到原始出处时，先改稿或删句，不用更多转载链接填满来源域。

## 教育费用稿重点核对

逐项核对：谁适用、收费或减免项目、金额单位、按月或按学期、实际天数或自然日、是否自愿、退费触发条件、例外、执行时间和办理主体。

测算必须写明假设。保教费、伙食费、住宿费、托管费、校车费和代办费不得互相套用退费规则。备案上限、学校执行价、政府购买或补助金额、家庭实缴额不得混成一个数字。

## 语言审稿独立于事实核验

本页只得出事实结论，文体按[基座](../../../docs/writing/中文写作基座.md#修改依据与语义保护)与[四角色审稿](../wechat-mp-article/references/review.md#事实和文体分别放行)另核，不重复执行一套语言检查。

## 编辑时检查信息增量

随笔核选材与叙述联系，不逐段要求观点或意义增量；论证稿核主要主张是否有依据，是否漏掉会改变判断的事实或真实异议。两者均不为造冲突、凑篇幅或填字段重复解释。记录字段使用本页“关键主张交付”，实际段落及相邻关系使用公众号审稿，避免双份登记。

## 事实边界怎样写进正文

只将影响本篇判断的对象、金额、时间、条件、归属及现实后果写清，不逐句追加防误解说明。取舍统一按[基座](../../../docs/writing/中文写作基座.md#防御性表达与必要事实条件)：

- 可用：`这项减免只覆盖保教费，伙食费仍按实际就餐结算。`
- 可用：`校方作出了解释，是否存在捆绑收费仍待教育部门核查。`
- 禁用：`为了避免读者误解，这篇文章并不是要否定学校。`
- 禁用：`本文不能被理解为对所有民办学校的批评。`

正文讨论事件和规则，不讨论“本文、本稿、这篇文章应该怎样被理解”。删除审稿说明后，如果事实边界随之消失，就把适用范围和实际后果直接补回正文。

## 交付前人工复核

核验记录中逐项确认关键主张已有原始来源，类型、时点、适用范围及计费口径无错配；存在判断时未删去已有配套来制造冲突。对内部台账与公开正文分别核对，不把字段齐全或三个域名当作独立印证和事实通过。

语言、段落、标题、图文、轮次与公开稿检查由通用 Skill 统一处理；推送按用户授权和工程门禁执行。

本页来源方法沿用既有编辑记录，不依赖或执行外部事实核验脚本。
