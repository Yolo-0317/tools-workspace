# 15秒诗镜电影级特效库设计

## 目标

为《栀夏飞花令》的15秒诗镜建立一套可复用的电影级特效库。特效库服务于“电影级全写实角色外观＋超现实镜头舞蹈＋15秒梦境长镜头”，让每条视频用一个主特效和最多一个辅助特效持续吸引观众，同时保持栀夏与阿砚的形象清楚、稳定、可识别。

特效库不追求堆叠数量，也不把粒子、辉光或魔法光束等同于高级感。每个特效必须承担钩子、牵引、转场、揭示或落点中的一个明确职责，并与摄影机路径、角色运动和诗句意象共同设计。

## 核心原则

一条15秒诗镜的特效上限固定为：

> 一个生成期主特效＋最多一个生成期辅助特效＋少量后期增强。

- 主特效负责改变空间、尺度、材质状态或观看关系，是本集唯一的视觉奇观。
- 辅助特效负责显示空气、深度、速度或环境响应，不与主特效争夺注意力。
- 后期增强只修饰可控的光、雾、颗粒、景深、字幕和调色，不重新设计人物或诗境。
- 角色卡只锁定身份设计；最终栀夏与阿砚保持电影级全写实外观。
- 人物和镜头运动可以不遵循现实物理，但面部、骨骼、服装、毛发、阿砚物种结构和材质必须逐帧稳定。
- 特效必须与人物和环境发生前后景、遮挡、反射、折射、风场或光照交互，不能像贴纸一样覆盖画面。
- 特效不能连续遮挡栀夏或阿砚的脸部超过0.5秒，也不能让两位角色在关键形象展示段缩成无法识别的小点。

## 库的组织方式

特效库以“镜头功能”为一级分类，以“材质”和“制作阶段”为标签。这样写单集提示词时先回答特效为何出现，再选择它由水、雾、光、布料、墨迹或粒子表现。

### 一级功能分类

1. 钩子特效：0至2秒制造异常视角、材质状态或空间误判。
2. 牵引特效：2至7秒引导摄影机、栀夏与阿砚共同移动。
3. 转场特效：5至10秒通过连续材质或物象变化进入下一层诗境。
4. 揭示特效：9至12秒完成本集最大尺度或最完整诗境的出现。
5. 落点特效：12至15秒减速、收束并承接两句诗朗诵和字幕。

同一主特效可以覆盖相邻功能，例如“灯火领舞并生成世界”可以同时承担牵引、转场与揭示；但每条视频仍只登记一个主特效。

### 材质标签

- 水与液体：水面、波纹、薄膜、飞沫、泡沫、雾、倒影和折射。
- 云雾与体积：云海、烟雾、体积光、空气湿度和空间深度。
- 布料与毛发：栀夏衣袖、裙摆、发丝和阿砚毛发、墨尾。
- 颗粒与群体：雪、沙、落叶、花瓣、尘埃、墨粒和萤光微粒。
- 光与光学：月光、灯火、焦散、辉光、光晕、折射和焦外光斑。
- 墨与书写：墨迹、飞白、笔画、宣纸纤维和文字形态转化。
- 地貌与环境：山体、竹林、江面、星空、季节和昼夜转换。

### 制作阶段标签

- `generation-hero`：必须在视频生成阶段完成的主特效，负责角色、镜头与空间的共同运动。
- `generation-support`：在生成阶段完成的辅助特效，负责环境响应和空间层次。
- `post-enhancement`：在后期可精确控制的增强特效，不承担核心叙事。

## 生成期主特效范围

首批主特效库至少包含以下方向：

1. 水面弯折成天空，人物与摄影机沿弯折水面进入下一层空间。
2. 瀑布反向升入银河，真实水体连续转化为星河而不退化为发光光束。
3. 栀夏衣袖延展成云海、江水、月光或雪幕，摄影机沿衣料弧线穿越。
4. 阿砚唯一墨尾延展成墨迹、山脉、竹影或夜空，角色与镜头沿同一引导线移动。
5. 灯火、月光、落叶、花瓣、雪或笛声纹理作为唯一领舞元素，经过之处生成完整诗境。
6. 眼睛反光、灯芯、水滴、花蕊或叶脉内部展开宏大写实空间，并保持角色可识别比例。
7. 环境在摄影机经过时发生季节、昼夜、尺度或地貌的连续变化。
8. 写实颗粒聚合为人物所在的场景，再沿镜头方向自然散开并揭示下一层空间。

每个主特效条目必须记录：功能、材质、适用诗意、建议运镜、15秒时间位置、视觉承接物、角色共舞方式、全写实提示词、禁止项、身份漂移风险和4至5秒测试方案。

## 生成期辅助特效范围

辅助特效只增强主特效，不改变故事结构。首批包含：

- 体积雾、云气和克制体积光束。
- 水雾、飞沫、薄膜水滴和空气湿度。
- 稀疏雪粒、落叶、花瓣、尘埃或墨粒。
- 水面焦散、倒影波纹和折射扰动。
- 灯火或月光的局部辉光与环境反射。
- 衣料、发丝、毛发和墨尾对梦境风场的响应。
- 用于显示摄影机轨迹的少量粒子或雾线。

辅助特效必须保持稀疏、具有明确来源，并服从同一运动方向。禁止同时使用两种以上群体粒子，也禁止让辅助特效占据人物面部安全区。

## 后期增强范围

后期增强用于修饰生成结果并确保文字准确：

- 克制辉光、高光扩散和光晕。
- 局部体积雾、深度雾和空气透视。
- 有限景深、轻微运动模糊和焦外光斑。
- 统一电影颗粒、暗角、黑位和色彩关系。
- 诗句字幕淡入、逐句高光和准确作者署名。
- 使用局部遮罩调整特效前后层级，避免遮挡栀夏和阿砚。

后期不得修补已经发生的换脸、阿砚物种漂移、骨骼畸变、服装变化或空间断裂。出现这些问题时，原片必须退回视频生成阶段。

## 特效等级

### S级：空间与材质共同转化

角色、镜头、材质和空间在同一连续动作中发生变化，可作为整条15秒诗镜的核心。必须先制作起始、转折和结尾三张状态卡，并做4至5秒低成本测试。

### A级：单一元素牵引或环境响应

灯火、月光、落叶、水纹、衣袖或墨尾承担明确的运动引导，空间结构基本稳定。适合大多数正式生成。

### B级：氛围与光学增强

体积雾、焦散、飞沫、稀疏粒子、辉光和焦外光斑，只作为辅助或后期修饰，不单独承担一条视频的视觉钩子。

### 禁用效果

- 无来源的全屏粒子雨。
- 仙侠式魔法阵、能量环和持续光柱。
- 动漫速度线、分身残影和夸张拖影。
- RGB故障、数字毛刺、随机色散和短视频模板转场。
- 大面积闪白、爆光或频闪。
- 同时出现雪、花瓣、萤火虫、墨粒和光点。
- 只在背景循环、与镜头和人物没有交互的装饰特效。
- 覆盖人物脸部、改变栀夏五官或让阿砚变成普通猫的效果。

## 15秒特效节奏

| 时间 | 特效职责 | 画面要求 |
| --- | --- | --- |
| 0—2秒 | 钩子 | 主特效立即出现异常状态或引导物，角色同时进入运动 |
| 2—7秒 | 牵引 | 主特效带动镜头、栀夏与阿砚共同移动，保持形象展示 |
| 7—10秒 | 转化 | 材质或空间连续变化，使用唯一视觉承接物 |
| 10—12秒 | 揭示 | 主特效达到最大尺度或完整形态，然后开始减速 |
| 12—15秒 | 落点 | 主特效保留轻微运动，辅助特效减弱，朗诵两句诗并后期叠加字幕 |

## 单集选型数据

每条诗镜在写视频提示词前填写一张特效选型卡：

| 字段 | 内容 |
| --- | --- |
| 诗句 | 两句固定原诗 |
| 核心意象 | 本集唯一主导物象 |
| 主特效 | 一个 `generation-hero` 条目 |
| 辅助特效 | 零个或一个 `generation-support` 条目 |
| 后期增强 | 必要的 `post-enhancement` 条目 |
| 核心运镜 | 运镜库中的一个S级、A级或B级模板 |
| 视觉承接物 | 连接空间转化的唯一物象 |
| 角色共舞 | 栀夏与阿砚如何随镜头和特效运动 |
| 形象展示 | 两位角色同时清楚可辨的时间段与景别 |
| 遮挡门槛 | 特效经过人物脸部的最长时间，不超过0.5秒 |
| 三张状态卡 | 起始、转折、结尾场景卡路径 |
| 测试方案 | 4至5秒测试段及通过标准 |

选型卡中主特效超过一个、辅助特效超过一个、没有视觉承接物或没有角色形象展示段时，不得进入提示词编写和付费生成。

## 失败处理

- 风格动漫化：停止增加负面词，先检查场景卡是否达到电影级全写实，再缩减特效任务。
- 角色被特效遮挡：降低特效密度、缩短前景经过时间或改变摄影机轨迹，不用后期锐化抢救。
- 空间转化断裂：保留一种材质和一个运动方向，删除第二套转场机关。
- 粒子廉价：减少数量，增加来源、尺度差、景深、碰撞和环境光响应。
- 特效像贴纸：补充前后景遮挡、反射、折射、风场、碰撞或局部光照交互。
- 画面过满：先删除辅助特效，再降低主特效覆盖面积，始终优先保留角色和核心诗境。
- 中文字幕错误：移除模型生成文字，保留干净画面、音乐和朗诵，字幕后期准确叠加。

## 验收顺序

1. 栀夏与阿砚的身份、数量、全写实材质和可识别度。
2. 主特效是否只有一个，是否服务诗句与核心运镜。
3. 特效、人物和摄影机之间是否存在清楚的视觉连续性。
4. 空间或材质转化是否连续，没有随机瞬移或材质突变。
5. 特效是否与人物、环境产生遮挡、反射、折射、风场或光照交互。
6. 辅助特效是否不超过一个，且没有遮挡人物脸部。
7. 12至15秒是否完成减速、两句诗朗诵和字幕安全区保留。
8. 整体是否保持电影级全写实，而非动漫、游戏CG或短视频模板质感。
