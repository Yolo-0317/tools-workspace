# 栀夏固定声音身份设计

## 目标

为栀夏建立后续诗镜、对白、朗诵和半吟半唱统一使用的声音身份。以后不再把“清冷女声”“知性女声”或其他临时音色名称当作角色声音定义；具体剧集只改变情绪、力度、速度和气息，不更换栀夏的基础年龄感与声线人格。

## 固定声音身份

栀夏固定使用18岁东方少女的自然声线：清透、轻盈、明亮，带少量克制气声和自然书卷气。声音年轻、有灵气、有真实呼吸，不幼态、不甜腻、不故作成熟；吐字清楚但没有播音主持感，情绪从人物当下体验自然产生，不使用统一的“古风朗诵腔”。

固定听感关键词：

- 18岁少女年龄感。
- 清透、轻盈、明亮。
- 少量气声，但辅音与诗句字音保持清楚。
- 温柔、聪慧、克制，允许出现好奇和轻微惊喜。
- 自然说话与自然读诗，不端着，不表演腔。

## 单集允许变化

每首诗可以按照意境调整以下表演参数，但不能改变基础声线身份：

- 情绪：惊叹、温暖、孤寂、顽皮、安静、坚定或怅惘。
- 音量：根据距离、环境和剧情自然变化。
- 语速：以自然可懂为前提小幅调整，不用强制变速填满时长。
- 气息：高山、奔跑、寒冷、低声耳语等情境允许增加少量真实呼吸反馈。
- 句尾：可上扬、平收或轻落，由诗意决定，不固定成一种腔调。

不得因情绪变化而切换成另一位演员般的音色、明显改变年龄、突然变得冰冷成熟或甜腻幼态。

## 固定禁用方向

- 清冷御姐音、成熟艳丽女声。
- 幼童音、萝莉音、甜腻夹子音。
- 新闻播报、广告配音、朗诵比赛和字正腔圆的主持腔。
- 机械匀速、每字等长、句句同一重音。
- 戏曲腔、仙侠配音腔、过度古装腔。
- 过量气声、耳语到字音不可辨或刻意拖长尾音。
- 为制造情绪而大喊、哭腔泛滥或使用夸张颤音。

## 《夜宿山寺》本集表演

本集使用固定声音身份下的“轻盈惊叹”状态。栀夏像第一次站到云海之上的百尺古楼，既敬畏又惊喜；她下意识压低声音，仿佛怕惊动寂静星空，但声音里仍藏着明亮笑意。

朗诵文本：

> 危楼高百尺，手可摘星辰。

表演节奏：

- “危楼高百尺”稍慢，视线仰望，重心放在“高”与“百尺”，表现高度带来的敬畏，不夸张拖腔。
- 两句之间自然停顿约0.3秒。
- “手可摘星辰”语气轻轻上扬，带一点笑意和不可思议；“摘”清楚但不重砸。
- “星辰”柔和收束，最后一个字与镜头减速同时结束，不额外补气声尾巴。

可直接用于TTS或配音导演的文本提示：

> 18岁东方少女栀夏的自然声音，清透、轻盈、明亮，带少量高山空气感与克制气声；不是清冷御姐，也不是甜美幼童。她仿佛第一次站在云海之上的古寺高楼，既敬畏又惊喜，为了不惊动寂静夜空而自然压低音量。“危楼高百尺”稍慢、微微仰望，表现高度带来的震撼；停顿约0.3秒后，“手可摘星辰”语气轻轻上扬，带一点笑意和不可思议；“星辰”柔和收束。吐字清楚但不使用播音腔，不做夸张古风吟诵，不拖腔。

## 落库边界

- `docs/character-bible.md`记录栀夏固定声音身份和禁用方向，作为长期人读事实源。
- `docs/production-workflow.md`记录“固定基础声线＋单集情绪表演层”的生产规则。
- `config/voices.json`继续保存实际TTS供应商映射；当前栀夏speaker暂不因文字设计直接更换，只有试听确认新speaker更符合本设计时才更新技术映射。
- 单集文档只记录本集表演状态、朗诵文本、停顿和重音，不重复改写固定声音身份。
- 现有已经生成的历史音频不追溯替换；后续新生成内容统一遵循本设计。

## 验收标准

1. 不看画面时，听感仍像同一个18岁栀夏，而不是每集换一位配音演员。
2. 能听出不同诗境的情绪变化，但年龄、明亮度、轻盈感和自然书卷气不变。
3. 诗句每个字清楚，气声不影响可懂度。
4. 没有清冷御姐、幼童甜腻、播音主持或古装表演腔。
5. 《夜宿山寺》的第二句比第一句更有惊喜，但整体保持压低音量的高山静夜感。
