# 牛马也智能 · 标题写作

## 先读稿，再起标题

读完整篇正文和首段，提取三件事：写给谁、正文实际回答什么问题、读者读完会得到什么具体信息。已有正文时不能只凭选题或商品名起标题。若用户要求的标题角度在正文中没有答案，先指出错位；用户授权改正文时再同步修改。

## 标题要同时有线索和悬念

标题让读者识别具体主题，并留下正文能展开的信息，不固定分成前半句给场景、后半句留原因的模板。可以暂不展开品牌名或结论，但不能连对象也藏掉，形成读者无法判断主题的空悬念。默认用自然、完整的叙述语气；用户明确指定疑问标题时沿用，并核正文兑现。具体取舍统一见下文当前标题偏好。

商品稿的悬念应落在可核实的购买判断上，例如版本、规格、适用条件、到手成本或使用场景，不编造功效、亲测、限时机会和群体焦虑。健康商品广告标题不能暗示人人缺某种营养、服用后会改善症状，或把独立广告伪装成医疗科普；具体证据边界读 [wechat-mp-health-content](../wechat-mp-health-content/SKILL.md)。

用户明确要求女性健康、素人语气、疑问式或不出现品牌名时，将这些作为本篇约束，同时保留正文主题。不要为了满足一个形式要求丢掉其他信息。

## 当前标题偏好（2026-10-09）

后续公众号标题优先采用“自然地把话留一半”：给出读者熟悉、能够识别的具体场景或事情，再留下正文能够补齐的信息。句子读起来顺，信息尚未说尽；不是故意把语法截断。读者知道文章在谈什么，同时想知道具体是哪几种情况、后来发生了什么或其中的原因。

用户确认的例子：**半夜去趟卫生间，最容易忽略的是这几种情况**。前半句明确夜间如厕场景，后半句暂不列出具体情况，由正文展开。这说明“这几种情况”“这件事”等指代表达不能按词表一律禁用：前文已有明确场景、后文有具体内容承接时可以用；没有对象、仅说“背后不简单”才是空悬念。此例用于理解方法，不要求所有文章套“最容易忽略的是……”模板；“最、都、一定”等词仍要核对是否形成未经支持的比较或绝对结论。

起标题时先选正文中值得继续了解的一项信息，确定标题交代什么、暂时不展开什么，再组织自然的句子。不把所有正文要点或最终结论列进标题，不只给“要留心、不能大意”等泛提醒，也不以风险提示本身代替打开理由。真实认知差异可以使用，但不是每篇的必备结构；不强套“灯亮了也会……”“还不是……”“反而……”制造反差。不把核心问题直接改成疑问句，也不靠问号、连续追问或省略号凑悬念。

悬念必须有明确主题和正文依据。不要把原因全部揭完，也不要退化成没有具体对象和正文承接的空话；不固定套用“恰恰是”“反而是”“原来是”等转折句式。健康标题不虚构患者结局，不用未核实的严重后果或确定诊断制造焦虑。用户明确要求疑问式时按本次要求处理。

财经盘后稿的悬念优先落在读者真正要弄清的差异上，例如指数跌幅与个股、持仓表现可能不同。用一项已核实的盘面事实让读者知道在谈哪一天、哪件事，把解释留给正文；不要把几个指数和板块的涨跌幅排成标题，也不要只用“还有一关”“先别看点位”制造空缺。用户明确要求问句时，也须提出具体、正文能回答的问题；不暗示已掌握读者的真实持仓或收益。标题实验对问句效果并无一致结论，不能把问号当成点击率保证。

## 小标题

小标题说明本节具体内容，不把内部分类或审核动作当作正文标题。执行[小标题从提纲转成文章](../wechat-mp-article/references/editorial-language.md#小标题也要从提纲转成文章)的单读、接首段读、整组连读；仅与正文对应或没有问答语气不足以通过。必要行动提醒保持清楚。

## 出候选与选择

先写 3—5 个不同角度的候选，避免只替换同一句中的几个词。逐个问：

1. 不看正文，读者知道大致在讲什么吗？
2. 标题暗示的问题，首段 50 字内是否出现，正文是否真正回答？
3. 标题有没有提前泄露全部结论，或反过来藏得过空？
   明确读者打开后具体想知道哪项信息；只剩泛提醒或刻意反差时，重新起标题。指代表达结合场景判断，不机械删词。
4. 朗读是否像正常人说话，有没有把「健康需求」和「版本差异」等两层问题硬接成一句的痕迹？
5. 是否含未经核实的效果、数字、比较、身份或稀缺性？

选一个最贴合正文的标题，并简短说明它对应正文哪一段；不要把所有候选都留给用户替你做判断。用户只要求改标题时，直接更新稿件标题，不擅自重写正文。

## 标题自动修订循环

起候选 → 检查自然程度、信息缺口及正文兑现 → 重写有问题的候选 → 连着首段复读 → 选定一个标题。这个循环由 Agent 在当前写作请求中主动执行，不能把第一批候选直接交给用户来完成审稿。

单独起标题或改标题时，集中检查与修改最多三轮，达到要求或没有具体问题就提前结束。作为整篇健康稿流程的一部分时，与正文及图中文字共享[完整流程](../wechat-mp-health-content/final-delivery-workflow.md)规定的三轮上限，不另计三轮，不因换角度或重新起候选重置。连续两轮同类问题未改善，剩余轮次换角度重写，不继续替换近义词。第三轮仍不理想时保留事实准确且较自然的候选，说明具体不足，不强称达标或启动第四轮。

每轮内部记清：已给出的场景或对象、暂未展开的信息、正文对应段落。只写“有悬念”不算检查；需要明确读者打开后想知道什么。只剩“留点心、不能大意”的泛提醒，或风险已经说尽却没有待展开的信息时，换角度起标题。读起来故意绕一句“还不是……”或硬加反差时，回到直接的日常说法。

用户确认的“半夜去趟卫生间，最容易忽略的是这几种情况”是口吻参照，不是所有题目的固定句模。新标题保留同样的自然信息缺口，具体句式随正文变化，不规定每篇都分前后两半。

没有具体问题且主题、自然表达、信息缺口、正文兑现和事实边界均成立时停止。已有自然的标题不为多跑一轮强行润色；修改后更绕或更空就恢复清楚的版本。此循环不授权推草稿，也不暗示已部署标题评分程序。

## 平台门禁

按 [搜一搜内容规则](../wechat-mp-writing/sousou-content-rules.md) 核对标题完整度、前 15 字的信息、≤32 字、截断后语义及禁词；按 [引流写法](../wechat-mp-writing/traffic-copy-craft.md) 核对标题与开篇同题。两处是持续维护的规则真源，本 Skill 只负责标题判断，不复制其分稿型硬禁表。

用户要求强悬念时，也不能用标题与正文无关、夸大或隐瞒关键信息的写法。无法同时满足时，说明冲突并给出最接近其偏好的合格标题。
