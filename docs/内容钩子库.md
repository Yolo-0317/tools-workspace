# 内容钩子库

更新：2026-10-21。用户要求：先建立大型钩子库，覆盖标题、文案、封面，以及关注、评论、点赞等互动；以后每次选题必须参考钩子类型。

适用：水边酉杯酒、历史小人书及本工作区后续小红书内容。账号定位、事实边界和已确认文案仍分别维护，钩子不改变事实。这里是可扩充的模板库，不声称穷尽全部类型，也不把模板当已验证的增长规律。

当前共 **240个可检索条目**：48个标题类型、24个开头、24个正文推进、24个封面结构、24个关注引导、36个评论引导、18个点赞引导、18个收藏引导、12个分享引导、12个历史叙事模板。条目包含结构与话术示例，不代表240种独立心理机制。

## 每次选题必须执行

1. 先写读者的具体问题或故事中的动作、冲突与结果。说不清内容，就不先堆钩子。
2. 定一个主要目标：点开、读完、收藏、评论、关注中选一个；可有一个次要目标。曝光入口、阅读过程和结尾各司其职。
3. 从T库选择一个主钩子，可再配一个副钩子。标题至少写三种不同类型的候选，不能只换同义词。
4. 从O、P、V选适合的开头、正文推进和封面结构，写清“标题提出什么、正文哪一页兑现”。故事选题同时看H库。
5. 从F/C/L/S/R中只挑符合当前内容的一项主要引导；确有需要才加一个次要引导。不默认每篇都写“点赞收藏关注”。
6. 提交选题时附简短钩子卡，列ID、目标、对应页和互动句。完整文案确认后再生成媒体，延续原制作顺序。
7. 发布后按同一观察时长记录可见结果，再决定复用或修改。模板编号只方便回查，不代表效果排名。

2026-10-21用户新增：每期正式定稿前，通过浏览器到小红书找同话题高赞、高评论图文；记录真实链接与可见数据，拆解标题、封面、开头、正文和评论问题。把同题观察与本库类型对应后，再定本篇表达。未找到、缺数据、未读评论需如实写，不能把自写模板说成平台爆款。

## 读者动机和互动目标分开选

| 读者为什么停下 | 适合的入口 | 能提供的实际价值 |
| --- | --- | --- |
| 想知道答案 | 问题、悬念、细节、身份线索 | 清楚的解释或有依据的揭秘 |
| 怕理解错 | 错读、定义、条件、对照 | 纠正具体理解，给可用方法 |
| 面临选择 | 场景、步骤、比较、优先顺序 | 说明比较维度与适用情境 |
| 想省时间 | 清单、速查、地图、流程 | 真正可回看的图卡 |
| 有相似经历 | 熟悉困境、地方叫法、具体场景 | 让人能补充自己的经验 |
| 有情绪想表达 | 具体冲突、反差、对白、选择 | 说中处境并解释经过 |
| 想看故事往下走 | 动作、物件、后果、反转 | 完整经过与可收束结尾 |
| 喜欢一种表达 | 审美、器物、画面、系列识别 | 持续稳定的内容形式 |

情绪强度可以提高：用短句、现场动作、具体代价和鲜明选择。不要把无依据的“所有人”“没人知道”“震惊全场”当情绪来源。数字、价格、稀缺、绝对优劣和争议性结论，先有可支撑材料再写进成稿。

## 标题、封面、文案如何配合

- 笔记标题：具体对象加一个看点，离开封面仍能理解。
- 封面：一个主看点配一个可见物件或动作；副标题补背景，避免在封面写完整摘要。主副标题、底条共用一个核心疑问，别同时开三处谜。
- 开头：立即接标题的问题，或落到标题里的现场。
- 正文：逐段提供新信息；能直接回答的问题先回答，再解释，不拖到末页。
- 结尾：给答案、工具卡或具体结果，再决定是否邀请互动。
- 关注：依靠明确的下一篇、系列范围或持续表达方式。
- 评论：给读者一个能回答的具体问题，可以选、可以补、可以讲经历。
- 点赞：用于表达认可、共鸣或对讲法的反馈，语气自然，可省略。
- 收藏：需要确实有复用价值的图卡、流程、清单或来源。
- 分享：给出谁可能需要、为什么有用，避免给读者派转发任务。

## O库：24个开头

开头负责让读者进入本篇。知识图文前两页应兑现初步答案；故事先给场面，再交代必要背景。

- **O01** 这瓶酒的名字你可能认识，背面这行字却未必读过。
- **O02** 先把两张标签放在一起看，差别就在标出的地方。
- **O03** 先看这个数字：[数字]。它量的到底是什么？
- **O04** 你在酒柜前犹豫的时候，可能先卡在了一个词上。
- **O05** 先做一道小题：[A]和[B]，说的是同一件事吗？
- **O06** 先看这张图，答案藏在两条流程分开的地方。
- **O07** “[常见说法]。”这句话究竟能用到哪一步？
- **O08** 同样叫[A]，两个例子里的意思却需要分开读。
- **O09** 先认一个实物：[对象]。名字熟，样子未必见过。
- **O10** 把镜头拉近，这个平常略过的小字才是本篇要讲的。
- **O11** 今天只解决一个问题：[具体问题]。
- **O12** 酒瓶上[A]写得很大，旁边的解释我们放大来看。
- **O13** 先别背术语，看看这件东西是怎么做出来的。
- **O14** 从[起点]到[结果]，关键变化发生在这一环。
- **O15** 这一页可以先留着，后面我们用它对照两个例子。
- **O16** 你家乡叫它[A]，换个地方，名字可能又变了。
- **O17** 看起来差不多的两件东西，先按同一个维度比较。
- **O18** 先把能看到的现象，和想下的结论分开。
- **O19** 今天先读清瓶身写的意思，口感留给真实体验。
- **O20** 故事先从[时间地点]的[具体动作]讲起。
- **O21** 所有人都在[动作]，只有[人物]留下做了另一件事。
- **O22** [人物]手里拿着的[物件]，后来成了解释这件事的线索。
- **O23** 结局先放在这里：[有依据的结果]。往前看，事情怎样走到这一步？
- **O24** 上一期提到了[A]，评论里有人问[B]。这篇专门回答它。仅在确有该评论时使用。

## P库：24个正文推进与收束

只有后面确有对应内容时才用预告句。能用图直接解释的，不用“更惊人的还在后面”拖延。

- **P01** 先给答案：[一句结论]。接下来用两个例子说明。
- **P02** 读到这里，先记住[A]；它和后面的[B]要分开。
- **P03** 把刚才的术语换回这张标签，就容易找到位置了。
- **P04** 同一个比较维度，再看第二个例子。
- **P05** 两条路线到这里还相同，从下一步开始分开。
- **P06** 这张图只解释[范围]，换成另一种工艺，步骤需要重新核对。
- **P07** 看见[A]，还不能直接得出[B]；缺的是[具体信息]。
- **P08** 前面解决“是什么”，下一页看“怎么用”。
- **P09** 先暂停一下，用刚才的方法读一遍这张示例图。
- **P10** 如果只留一张图，留下一页的对照卡。
- **P11** 看一下标出的这行字，它会改变刚才的理解。
- **P12** 现在回到开头的问题，用这三个条件逐项判断。
- **P13** 这个词在日常聊天和标签上，读法需要分别说明。
- **P14** 你刚才看到的是现象，这一页解释可能影响它的条件。
- **P15** 先把这两个容易混淆的名字并排放好。
- **P16** 这一页给直接答案，补充出处放在最后。
- **P17** 第一个线索指向[A]，第二个线索才能说明[B]。
- **P18** 事情到这里看似结束，材料里还记着一段后续。
- **P19** 他接下来做的动作，让前面的疑问有了落点。
- **P20** 这个选择改变了什么，结尾用一个具体结果交代。
- **P21** 回看开头的[物件/原话]，此时它的意思清楚了。
- **P22** 答案就在图里的[位置]，不用再记另一套口诀。
- **P23** 把这页和第[页码]页对照，区别会更明显。
- **P24** 最后把边界补齐：[适用条件]。超出这个范围，不能照搬。

## 交稿检查

标题有明确对象；封面一眼能认主题；开头承接封面；正文有答案；结尾不突然；互动与本篇内容相接。删掉无法兑现的最大、唯一、必看、保证、内部秘密等词。知识稿不故意留半个答案换评论，故事稿不靠杜撰反应增添刺激。

不写“评论某字领资料”除非资料与真实交付方式已经准备好且属于用户授权范围；不做虚构抽奖、关注解锁、转发奖励、假共识或恐吓。正常的表达可以有力度，依据来自真实困境、可见细节和明确结果。

## 持续维护

新增有效结构先补ID、例句和使用条件，避免只收集口号。已用钩子记到具体期次选题卡；下次先查本库和本账号近期已用组合，再决定是否重复。账号选题规划、标题候选、发布文案与封面策划都引用本库。

指标用于比较不同内容和表达，不预设某类型必然获得高赞。复盘先看作品是否兑现承诺，再看互动句是否可答，最后再尝试更换钩子类型。
