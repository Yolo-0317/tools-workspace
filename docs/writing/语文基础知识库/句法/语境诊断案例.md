# 语境诊断案例

这里区分语法问题、语义歧义与语境不合。改法依赖已知意思，不能在材料不足时挑一句顺口的话替换。除第一例注明的用户原句外，均为自编教学例子。

## 1. 成分没有丢，叙述顺序仍不合当前语境

- 用户指出的原句：读书写字跟着罗先生学。
- 用户给出的改句：跟着罗先生学读书写字。
- 当前语境：普通介绍人物的学习经历，前文没有把“读书写字”提成对比话题。
- 问题：原句前置学习内容，普通叙述多绕一步。改句按“跟谁学什么”展开，更符合这一处的自然表达。补足分析用主语是“程砚秋跟着罗先生学读书写字”，正文是否写出主语取决于前文，不能一律补齐。
- 边界：若正在对比不同内容向谁学习，内容前置可以成立。这个修改不是“宾语永远不能前置”的语法禁令；“跟着罗先生”的术语归类也不必强定为唯一一种。

## 2. 两个短语都通顺，放一起却换了动作主体

- 语境：材料明确写老师接书后朗读。
- 待改：小林把书递给老师，读了起来。
- 问题：后一个动作容易继续由小林承担，与材料不符。
- 可改：小林把书递给老师，老师读了起来。
- 边界：如果本来就是小林读，原句不因此有错。没有材料时不能自行决定朗读者。

## 3. 修饰关系含混，不能擅自固定数字

- 语境：只知道涉及三位学生，没有家长人数。
- 待改：三位学生的家长到场了。
- 判断：这句话不必然有语病，但不能据此转述为“三名家长到场”。数字修饰对象变了。
- 可改：若读者容易误会，可写“这三位学生的家长到场了”；准确人数仍须另核。
- 边界：表意准确的原句可以保留，不能为了展示修改而添家长人数。

## 4. “把”后交代不完整，补结果仍要依据

- 语境：独立陈述；材料说材料已按类别整理完毕。
- 待改：他把材料整理。
- 问题：这一处处置过程悬着，句意未收住。
- 可改：他把材料整理好了。
- 边界：如果材料只说开始整理，就不能补“好了”；也不能归纳为所有把字句必须加“了”。

## 5. 为了短而压坏动词搭配

- 语境：给学生安排课程。
- 待改：老师安排他课程。
- 问题：“安排”不能在这里照“送他一本书”的关系直接带这两项。
- 可改：老师给他安排课程。
- 边界：“老师安排他参加课程”表达另一种关系，不是原句可以无依据替换的同义说法。

## 6. 句子顺了，否定范围却被改了

- 原意：并非每个人都同意。
- 错改：大家都不同意。
- 问题：从否定全称变成全体否定，改变了结论。
- 保留：并非所有人都同意。
- 边界：“大家不都同意”在适当口语语境可表达原意；是否改得更明确，取决于读者和歧义风险。

## 7. 把先后补成因果

- 语境：材料只记载他离开，后来演出取消。
- 待改：他走了，因此演出取消了。
- 问题：“因此”增加了原材料没有证明的因果。
- 可改：他离开后，演出取消了。
- 边界：这仍须原材料证明先后；如果连先后都不明确，应分别陈述并核时间。不能靠删连接词完成事实核验。

## 8. 都能成立的表达，不为了统一模板而改

“他认真读书”和“他认真地读书”均可自然成立；“门口站着两个人”无需补一个人称主语；“小林拿出书，翻到第三页”不必在后半句重复主语。只有具体语境出现歧义、缺项或不合口吻时才改，不能把检查项当成必改项。
