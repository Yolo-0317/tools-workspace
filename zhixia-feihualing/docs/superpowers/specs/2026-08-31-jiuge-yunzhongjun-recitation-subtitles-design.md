# 《九歌·云中君》缓慢朗诵字幕成片设计

## 目标

将用户确认直接使用的 15.093 秒《九歌·云中君》Seedance 原片制作成一份无字幕朗诵试听版和一份正式字幕版。画面、舞蹈、镜头、原片音乐与环境声内容不重生成；后期只增加栀夏固定女声的两句缓慢画外朗诵、逐句竖排字幕、必要的轻度音乐避让和保真高清输出。

## 输入与输出

- 原片：`episodes/jiuge-yunzhongjun-15s/assets/video/content-raw-v01.mp4`。
- 原片规格：496×864、24 fps、H.264；AAC 44.1 kHz 双声道；15.093 秒。
- 无字幕试听版：`exports/jiuge-yunzhongjun-15s-voiced-v01.mp4`。
- 正式字幕版：`exports/jiuge-yunzhongjun-15s-subtitled-v01.mp4`。
- 两份输出均为 1080×1920、24 fps、H.264、48 kHz 双声道 AAC，时长保持约 15.093 秒。
- 保留原片右下角“AI生成”标识，不遮挡、不裁掉。

## 朗诵内容

全片只由栀夏画外朗诵《楚辞·九歌·云中君》两句，不念题目、作者、篇名或其他旁白，不要求画中人物对口型：

1. 灵皇皇兮既降。
2. 猋远举兮云中。

采用两句分开慢诵，不拆成四个短单元，也不把两句连续赶读。第一句对应云神降临和云门显现，第二句对应横向旋转、远游与目送。

## 声音表演与缓慢语速门禁

- 使用栀夏既有固定女声：年轻、清透、克制、低甜度、有书卷气和高天空间感，不换成成熟御姐、幼童、主持人、仙侠旁白或神谕声线。
- 自然说诗，不使用朗诵比赛腔、戏曲腔、吟唱、耳语、拖字或刻意神秘化表演。
- “缓慢”必须体现在单句内部的字间节奏、气息推进和句尾留韵，不能只依靠句间空白。
- 第一行目标时间窗为 1.000—6.200 秒，有效人声目标约 4.300—4.700 秒。
- 第二行目标时间窗为 7.700—13.500 秒，有效人声目标约 4.800—5.200 秒。
- 两句之间保留约 1.500 秒云风、音乐和舞蹈呼吸；第二句结束后保留约 1.593 秒画面与音乐余韵。
- 每句有效人声至少占自身时间窗的 82%，原则上不超过 90%；低于 80%必须试听复核。若生成结果仍显得偏快，优先按同一声线重生；必要时只做不变调轻度减速，不以明显机械拉伸交付。
- “猋”按“biāo”读，必须复核读音；不得误读为“犬”“飙”的其他声调或省略该字。

## 字幕设计

- 字幕使用两张透明竖排诗句卡，随对应朗诵逐句出现。
- 第一行“灵皇皇兮既降”位于画面右侧，并附较小题署“屈原《九歌·云中君》节选”。
- 第二行“猋远举兮云中”位于画面左侧，不重复题署。
- 字体沿用九歌正式字幕体系：暖象牙白主字、低反射暗金细描边、玄黑柔影；风格克制，不使用发光字、霓虹、卷轴边框或装饰性法阵。
- 字幕位置必须避开栀夏脸部、双手、主要袖缘轨迹和身体中轴；同时避开右下角原片“AI生成”标识。
- 第一张字幕在约 1.000 秒淡入，随第一句结束后淡出；第二张在约 7.700 秒淡入，随第二句结束后淡出。具体消失时间允许依据最终有效语音边界在目标窗内微调。

## 混音设计

- 原片音乐、风声、衣料声和落脚声保持原有时间结构，不替换音乐、不重新配器。
- 栀夏人声居中，保留适度远近感，不做贴脸广播式响度；两句音色、距离和空间感保持一致。
- 人声期间对原片音乐做约 3 dB 的平滑轻度避让，使用缓慢起落，避免明显泵动；非人声区间恢复原片音量。
- 第一行开始前保留约 1 秒原片开场，句间与片尾保留完整环境声和音乐呼吸。
- 最终总线无削波、爆音或明显底噪突变，真峰值不高于 −1.0 dBTP；不得为了追求固定响度破坏原片动态。

## 实现边界

- 建立本集独立的 `voice-lines.json`、`subtitle-plan.json`、透明字幕卡、构建脚本和验证脚本。
- 使用现有豆包 TTS 生成流程及栀夏固定音色，逐句生成，保留可恢复的独立音频文件。
- 先输出无字幕试听版，检查声线、读音、单句内部速度、句尾留韵和音乐关系；通过同一套已验收音轨再输出正式字幕版。
- 画面只做适配 1080×1920 的保真放大，不重绘、不插帧、不改变人物比例，不裁掉右下角原有标识。

## 验收标准

1. 两句文本准确，只有栀夏画外朗诵，无新增对白、题目朗读、作者朗读、吟唱或画中口型要求。
2. “猋”正确读作“biāo”；两句保持同一声线、同一距离和同一高天空间感。
3. 单句内部明显舒缓，句尾有自然留韵；有效人声占各自时间窗 82%—90%，听感不赶、不拖、不机械。
4. 第一行落在 1.000—6.200 秒，第二行落在 7.700—13.500 秒，句间和片尾均保留可感知的音乐余韵。
5. 两张竖排字幕分别位于右侧和左侧，不遮脸、双手、主要袖缘轨迹、身体中轴或“AI生成”标识。
6. 原片音乐只在人声期间平滑轻压约 3 dB，无明显泵动；最终无削波、爆音和突然音量跳变。
7. 无字幕试听版和正式字幕版均可播放，规格为 1080×1920、24 fps、H.264、48 kHz 双声道 AAC，时长与原片一致。

## 版本决策

本次采用用户确认的 A 方案：两句分开慢诵。当前原片画面保持不变，已记录的云门、圆台、动作和景别偏差不在本次后期中修复，只用于后续生成优化。
