# 《凉州词》15 秒双角色飞天诗境

## 诗文

王之涣《凉州词》：

> 黄河远上白云间，一片孤城万仞山。
>
> 羌笛何须怨杨柳，春风不度玉门关。

## 成片形式

- Seedance 2.0，15 秒，9:16 竖屏，电影级高写实东方幻想 CG，一镜到底。
- 输入仅使用栀夏和阿砚两张原创虚拟角色母版，不上传首帧图、场景图、动作分镜或舞蹈参考视频。
- 原片已由用户确认可用；地面古典舞、栀夏飞天、阿砚同向伴飞和黄河关城揭示均生成成功。
- 已接受但不作为新默认的偏差见[QA复盘](qa-notes.md)。

## 后期朗诵与字幕

全诗四句由栀夏使用固定清透声线分别朗诵，不增加阿砚对白、标题口播、作者口播或额外旁白。有效朗诵与字幕区间为：

- “黄河远上白云间”：0.279—2.534 秒，附“唐·王之涣”题署。
- “一片孤城万仞山”：3.650—5.856 秒。
- “羌笛何须怨杨柳”：6.850—9.315 秒。
- “春风不度玉门关”：11.750—14.219 秒。

字幕采用项目现有米白色行楷竖排样式，每句随实际人声出现。第四句字幕比其他句向左移动80像素，避让低位伴飞的阿砚。原片音乐和环境声完整保留，人声区间通过平滑侧链压缩压低原声。
