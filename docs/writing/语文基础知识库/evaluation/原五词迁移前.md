# 持续与转折词语

本页收录现代中文写作中常见的五个词。释义依据页末词典；“语境与替换”是根据释义编写的编辑参考，不能当作词典原话或不可违反的语法定律。例句为自编示例，不能移作文章事实。

## 还

这里读 hái，不讨论“归还”的 huán。

**常用意义**：状态延续；尚未发生或完成；另有补充；程度更深；在某些句子里也能表示意外。一个“还”不只承担一种关系。[词典依据：还](https://dict.concised.moe.edu.tw/dictView.jsp?ID=19234&la=0&powerMode=0)

| 用法 | 自编例句 | 语境与替换 |
| --- | --- | --- |
| 尚未完成 | 他还没看完这本书。 | 说到当前，阅读没有完成。“没看完”保留未完成事实；“还”强调截至当前的状态，不凭一个词推断阅读拖延。 |
| 状态持续 | 晚饭后，他还在看书。 | 延续先前的动作。“仍然在看书”也能成立，不因“还”更短就必须替换。 |
| 增加内容 | 除了课本，他还带了一本字典。 | 前文已有一项，再补一项。不能换成表示状态持续的“仍然”。 |
| 比较程度 | 这条路比那条还远。 | 有明确比较对象，表达“更远”；不是单纯持续。 |
| 意外或赞叹 | 这个办法还真管用。 | 可能含意外或赞叹；新闻转述不能随手加进原作者没有表达的态度。 |

**回读重点**：先辨认本句的义项，不把所有“还”都展开为“还是”。“还在”“还有”“还没”本来就可以是完整自然的说法。

## 还是

**常用意义**：仍旧；在选择中连接选项；表示经过考虑后倾向某种做法。词典另列强调补充的用法，不能因为词形相同就把它们混为一种。[词典依据：还是](https://dict.concised.moe.edu.tw/dictView.jsp?ID=19237&la=0&powerMode=0)

| 用法 | 自编例句 | 所需语境与风险 |
| --- | --- | --- |
| 先前状态未变 | 又读了一遍，他还是没看懂。 | 前文交代再次阅读，后面说结果依旧。不能凭空补出“又读了一遍”给“还是”找依据。 |
| 选择 | 周末坐车去还是走过去，要看天气。 | 连接两种选项；这里不能换成“仍然”。词本身不等于问答文体。 |
| 倾向或建议 | 路上可能堵车，还是早点出发吧。 | 提出比较倾向的做法。不是客观宣布必须如此；不能用它软化硬性要求。 |

**语境与替换**：“读过一遍了，还没看懂”和“读过一遍了，还是没看懂”都可能成立。后一种更显出尝试之后结果未变的意味；具体口吻仍取决于前后文，不用字数判断优劣。

本次改稿中，用户偏好“还是写不出这样流畅的句子”，这只确认了局部措辞，不证明对应学生的真实能力。原材料若只说“表现有些脱节”，不能为了套用这个句式，就把判断改成完全“写不出”。

## 仍然

**常用意义**：先前的状态没有改变。[词典依据：仍然](https://dict.concised.moe.edu.tw/dictView.jsp?ID=36310&la=0&powerMode=0)

**自编例句**：“调整作息以后，他晚上仍然很晚才睡。”前面有改变作息这一背景，后面说明晚睡状态未变；调整不等于改善已经成功。

**语境与替换**：表达持续时，“仍然”和“还是”有交集。编辑时有时会觉得“仍然”较偏平稳的陈述，“还是”更贴近当下说话的口吻；这是语境判断，不是“仍然只能用于书面语”的规定。正式叙述也不必避用“还是”。

**回读重点**：“仍然”通常把读者引向先前的状态或预期变化，背景可以来自上文或明确情境，不必每句重述。只有当前状态依据时，不靠它补出一段未经证实的持续历史。“仍然可能发生”也仍是可能性，不能改成“仍然发生”。

## 但是

**常用意义**：连接有转折关系的内容。[词典依据：但是](https://dict.concised.moe.edu.tw/dictView.jsp?ID=7966)

**自编例句**：“她想把设备收起来，但是孩子查资料时还需要用。”前面是意愿，后面是与之有牵制的需要。转折不要求两句字面完全相反。

**语境与替换**：可以在合适语境中与“不过、可是”比较选择，但不能据此认定三者处处等价。是否写出“虽然”、用“但”还是“但是”，须看完整句子；不为句式整齐补一组关联词。

**误用线索**：“孩子在写作文，但是家长在看书。”若上下文只是在分别说两人的活动，没有相反预期，转折关系不足；若上文明确家长原答应陪孩子写，则可能存在转折。不能只凭孤立句式判错，也不能借一个“但是”替文章编出冲突。

## 不过

**常用意义**：转折；仅仅。它也可出现在“比不过”等动词后结构，或“再合适不过了”等程度表达里，不能都按连接句子的词处理。[词典依据：不过](https://dict.concised.moe.edu.tw/dictView.jsp?ID=2027&la=0&powerMode=0)

| 用法 | 自编例句 | 替换边界 |
| --- | --- | --- |
| 转折或补充限制 | 地方不远，不过周末人多。 | 前后在同一出行语境中，后一事实限制前面的便利。若无依据说人多，不能为了转折编出来。 |
| 数量限制 | 从家走过去不过十分钟。 | 带“仅仅”的意味，不是“但是”。在真实文章里，时间须有依据，也要留意是否替读者判断“很短”。 |
| 动词后结构 | 这场比赛，他跑不过对方。 | 关系由整组动词结构表达，不能把“不 过”中的字拆出来换成转折词。 |
| 程度表达 | 这个尺寸再合适不过了。 | 整体表达程度很高；不是补充一个例外。商品、健康等写作不能借自然语气加强未经支持的效果判断。 |

**语境与替换**：转折用法中，“不过”有时像接着补一句限制，“但是”有时更突出两面牵制；不是固定的强弱等级。将全文“但是”替成“不过”不能自动使口吻自然。

## 替换对照与边界

以下为编辑诊断示例，不是统一改写模板。

| 原表达或关系 | 看似顺口的修改 | 须核对的变化 |
| --- | --- | --- |
| 作文和以往表现有些脱节 | 他还是写不出这样的句子 | 从不一致推成能力不足，又可能带入状态延续；词顺口不证明推断成立。 |
| 两个活动分别发生 | 用“但是”连接 | 是否确有相反预期或牵制；没有就保持并列或分别叙述。 |
| “不过十分钟”的数量限制 | 把“不过”替成“但是” | 义项已换，不能直接替换。 |
| 当前尚未完成 | 统一把“还没”改为“仍然没” | 是否需要强调先前状态一直未变；原来已自然时不强改。 |

使用时先读懂整句和上下文，确定要表达的关系，再比较候选词。定义可以帮助排除误用，具体口吻仍需把改句放回整段。没有语病但太正式时，也可能需要改主语、动作和信息安排，不能指望只换关联词解决。
