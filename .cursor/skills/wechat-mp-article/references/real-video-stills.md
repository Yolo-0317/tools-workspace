# 真实视频截图配图

用于公众号文章的真实资料图：查找视频、下载必要素材、核对画面，再截取封面或正文图。用户指定已有视频或另一条聊天时先复用材料，不重新找同一份视频。只写文案且无需真实图时不启动下载；本分支不制作口播、配音、进度条或完整视频，也不自动上传。

用户选择和已确认授权优先，专题仍负责事实来源与发布流程。专题默认只看搜索卡片时，不能自行扩展到播放下载；用户明确指定视频截帧的，执行其选择并记录，不再用默认艺术图或卡片图替换。

## 1. 按正文找素材

先读成熟正文，每张图明确对应段落和用途，例如事件现场、人物、设备、历史会面或演化示意。缺图时按缺少的对象查找，不先下载大量素材再让文章迁就画面。数量随信息变化，合格图够用就停止；不为凑数量重复截取同一个镜头。

用户给了聊天链接，读取对应聊天中的稿件、来源与文件路径；长记录按页查找有关条目，不通篇打印工具输出。阅读不授权向另一条聊天发消息。找到本地目录后，先查 `research.md`、素材清单、原视频和现有截图，再补缺项。

在工作区先用 `rg --files` 定位素材、用 `rg` 查主题；先核对清单，不把旧目录的事件、年代、使用权直接复制到本篇。优先原始报道视频，避免从带配音、角色或二次字幕的成片反截。

## 2. 搜索与获取原视频

中文报道优先查新华社、央视、国际在线和发布机构官网；科学成果查研究机构，历史题材查档案馆、博物馆、官方纪录片及逐文件注明来源的档案平台。通用实拍可用许可明确的素材库，但只能说明环境，不能冒充指定人物或事件。外文原始材料按需要补核，不机械要求来源数量。

检索词组合对象、事件、地点、年份及“视频／现场／资料／会谈”等画面任务。先读原报道页，核机构、标题、发布日期与所述事件日期，再查看视频。搜索结果标题、封面和播放器入口仅是线索，不代表已观看或身份已核定。

通过公开播放器、页面数据或现有下载工具获取实际媒体地址；HTTP视频、HLS等按当前工具能力处理。优先复用本地脚本，必要时用已有 FFmpeg 或下载工具，不假设环境有固定CLI或私人密钥。不绕过登录、付费、DRM或访问限制；失败时记录原因，改找同题原始来源或可用照片，不无限重试。

只下载本篇需要的素材，保存原件、原报道页地址和下载时间。临时媒体链接失效后可回原页面定位；含签名或鉴权参数的链接留在必要的本地记录，不写进公开正文或日志输出。下载供截图和内容核对，不为绕过工具显示限制而下载。

## 3. 核对画面，再截帧

先按[交付规则](delivery.md#正文版式)筛掉9:16竖屏长图和整张或几乎整张都是文字、缺少实际画面信息的候选。带字幕、标题或说明文字的实景画面正常选用，不因有字就排除或裁掉文字；纯文字卡片不能仅凭来源权威或内容相关而放行。竖屏原视频能否裁切，须核对真实主体和必要标记，不能仅改输出尺寸。

用 `ffprobe` 查尺寸、时长与编码。先在多个时间点抽帧，覆盖候选区间、镜头切换和字幕变化；需要时播放相关区间。实际查看地名、人物、建筑、日期、台标、原字幕、“资料”与“AI生成”等标记。抽帧只记抽帧核对，不能记成完整观看或独立核实事件。

同一条新闻可能混入历史镜头、其他地点、动画和机构标志。报道发布得新，不代表画面拍摄得新。为每个采用区间分别判断：本次现场、同地点资料、历史资料、通用实拍、动画示意、影视演绎或AI生成；没有足够依据就保留未知，不把画面升级成现场证据。

下列情况换帧或换来源：地点或年代不符；原字幕与正文矛盾；只有标志没有所需对象；运动模糊；主体遮挡；混入其他战区或事件。机构发布的AI动画仍是AI示意，不能因为来自官网就记成实拍。烟雾、爆炸、军用装备等通用画面不能证明某一次袭击、武器型号或责任方。

选画面清楚、动作稳定、正文对象明确的帧，不自动取视频第一帧。封面与正文可以复用同一张合格图；其他图应增加新的信息。保留台标、署名、资料和AI标记。裁切、缩放可适应版式，但不能删掉身份标记后改称实拍，不增加原片没有的人物、设施或事件细节。

已有 FFmpeg 时可按实际文件和时间点截取，例如：

```bash
ffprobe -v error -show_entries format=duration:stream=codec_name,width,height -of json "/absolute/path/source.mp4"
ffmpeg -hide_banner -loglevel error -ss 00:00:10 -i "/absolute/path/source.mp4" -frames:v 1 "/absolute/path/images/01-scene.jpg"
```

时间点只是例子，选帧仍要实际查看。已存在输出先保留或换版本名，不盲目覆盖。截图从视频提取，不必调用 imagegen；不要用生成图补成真实新闻画面。

## 4. 看图、配文与有限修正

逐张打开实际截图，再看约390px手机宽度下的效果。核主体、清晰度、原字幕是否完整、台标与必要标记是否可读，封面横幅及方形裁切是否损伤主体。图片说明默认省略，具体按[交付规则](delivery.md#图片说明默认省略)安排必要身份与署名。半截字幕、无关滚动新闻明显干扰时优先换帧，不能靠说明掩盖画面矛盾。

用户明确要求图注时，只保留内容、来源与理解所需的年代，例如：

- `利雅得机场，央视新闻画面。`
- `2023年萨那停火谈判资料画面，来源：新华社。`
- `三体系统示意，来源：中科院视频，AI生成。`

不在图注写“截自已下载视频第10秒”、完整下载文件名或核验过程。现场图不必机械堆日期，历史图须防止被看成本次现场。署名、许可要求及必要事实限定照常保留，不能为简短删掉。

图像身份和用户要求的图注并入[统一审稿](review.md)。画面不合格就针对问题换帧或补找来源，最多两轮集中选图修正；仍无合格图时减少图片或交付无图稿并说明缺项，不伪造配图成功。

## 5. 内部台账与交付

本篇保存 `images/` 和 `figure_sources.json`，已有素材清单可补充复用，不复制一份过期信息。每个采用图至少记录：

| 字段 | 内容 |
| --- | --- |
| 用途 | 图号、对应正文位置、封面或正文用途 |
| 来源 | 原报道页、作者或机构、原视频路径、下载时间 |
| 时空与性质 | 发布日期、能确认的拍摄日期与地点、画面性质；未知写未知 |
| 截取 | 采用视频时间点或区间、截图文件路径、裁切缩放情况 |
| 核对 | 实际观看或抽帧范围、画面描述、核对时间、通过或排除理由 |
| 使用条件 | 具体许可或转载依据；未确认就如实记录，不因官方发布而写可自由使用 |
| 交付状态 | 本地、已上传或已回读；只有实际执行后更新 |

将“内容已核对”“已经下载”“使用权已确认”分开记录。已有用户授权的正常截图和草稿操作不重复请求确认；公开使用仍按具体许可与专题要求执行，不把公开可见等同于可自由转载，也不把写稿授权当成发表授权。

截图插在对应段落附近，封面与正文保持同一身份说明。用户要求推草稿时走既有工程流程，回读核正文、图片顺序、图注与历史／示意标记；取证台账和详细截取信息不搬进公开文章。
