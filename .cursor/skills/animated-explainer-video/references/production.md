# 制作与时序

## 接续现有资源

识别最新方案、视觉源、角色素材、字幕、音频缓存与导出。检查工具、字体与环境，已有引擎可用就继续。art-motion 提供方法及代码参考，FFmpeg 负责编码、混音和合成，不会凭空生成分层动画。

代码动画可不增加视频模型；新位图需要图像能力，配音需要 TTS，采用上游自动竞品分析流程另需 Gemini API。不假设所有 API 已配置，缺失时具体说明并完成可做部分。

单集保存方案、素材、视觉源、音频、时间轴、导出和 QA；目录沿用项目习惯，文件可定位、可恢复即可。

## 可定位时间的代码动画

使用 Canvas、SVG、Three.js 或现有代码引擎时，让同一时间对应同一帧：渲染由绝对时间或帧号驱动，不依赖预览播放了多久。具体接口、随机过程、预检与导出方法见 [代码动画案例与适配](code-animation-examples.md#代码渲染约定)。优先适配原引擎，不为满足某条上游提示词重写系统或新增模型。

## 无声版本与真实对白

未授权声音时以朗读估算、字幕草案构建视觉版，保留可延展区间、动作锚点及完整文案，不提前把所有可调整动画烘焙成固定短片。

配音前核对全文、speaker 映射、声线、发音与授权，沿用现有豆包配置，不输出凭证。现有入口有付费门禁就按规则执行；已授权生成可作为授权依据，不能跳过工具强制门禁。

历史系列使用 [历史片长场景与统一配音](history-visual-and-voice.md) 的固定视频口播语气提示；全部分段、补句和重试复用同一提示与声音参数，人名读音另列。风格提示计入缓存标识，禁止根据段落内容临时换情绪提示。

分段缓存原声及回执，保存文本、声线、参数与缓存标识。文本或声线改变时使旧缓存失效，不因文件同名误用。失败不覆盖成功段；结果不明先查产物与回执，避免重复付费。

实测说话起止、停顿与可用词时序。自然语速决定时间预算，再调整视觉进入、解释、停留和转场。离线变速只作有限修整，保留原声并重新算时序，不为旧时长持续加速。

## 一条最终时间轴

动画、字幕和嘴型共同使用最终时间轴，格式适配已有引擎。可用 JSON 记录：

- 分辨率、fps、采样率与总时长。
- 场景起止、源视觉映射及关键动作锚点。
- 完整文本、speaker、音频路径、最终偏移与实测发言起止。
- 可用词时序、字幕显示区间。
- 最终处理后音频包络与嘴型开闭区间。

服务端时序经过剪头、变速、加偏移必须映射到最终时间。改语速后不能沿用原声包络。

固定帧率镜头按帧对齐，音频按采样数补足或剪掉明确的纯静音尾；记录舍入，不累积成长片漂移。检查编码后起点与时长，不仅检查合成前 WAV。

## 身体固定与嘴型

当前系列只改嘴部区域，不加呼吸缩放、点头、眨眼和手势。镜头切换可换主持人构图，同一镜头不把身体抖动当嘴型。

嘴型同时满足该角色正在发言、当前有有效声音；旁听、静音、换气和话尾闭嘴。三态开合和 RMS 包络可作基础，但不是准确音素嘴型，音量驱动不保证每个发音匹配唇形。

加入适合声线的平滑、迟滞，抽检噪声触发与快速乱抖。嘴层保持遮罩、锚点、尺寸和透明度，不盖脸部轮廓，不留补丁。

## 字幕、重点与混音

字幕来自最终全文，跟真实发言对齐，重点词在实际念到时出现。自然语义断行，按真实分辨率与字体检查遮挡、超框和可读性，不用字符数代替布局检查。

SRT 与烧入字幕可有不同话尾停留策略，写明理由；文本、段落与起点一致。SRT 检查通过不代表烧入字幕已检查。

背景音服从对白清晰度。按项目与平台需要检查响度、峰值和削波，不把旧片数值当平台硬要求。最终台词完整，不切尾音。

## 合成与恢复

FFmpeg 参数从可用流程和当前文档核对，不直接复制旧集路径运行。输出新版本，验证后标最终。格式服从用户；本系列基线是 1080×1620、30fps、H.264 与 AAC。

完整解码并检查流起点、时长，抽检首尾、转场、重点词和口型。完整动作及主观听感需要实际播放；技术数据不能证明已完整观看、听验。
