# Seedance 2.0 公开案例导向的诗境提示词重建设计

## 目标

依据 Seedance 2.0 官方提示词指南、官方示例和公开带成片案例，重新建立栀夏诗境的视频提示词结构。新版必须从可观察的画面因果关系出发，不继承旧版的项目内部镜头框架、逐毫秒音频时间轴或抽象特效机关。

首个落地对象为《白雪歌送武判官归京》10 秒诗境。完成后，这套结构成为后续尚未生成诗境的默认提示词规范。

## 已确认输入与边界

- 模型：Seedance 2.0。
- 画幅与时长：9:16 竖屏，10 秒，一镜到底。
- 参考素材：只上传栀夏与阿砚两张原创角色母版。
- 两张母版只锁定角色身份、外形、结构、材质和比例，不作为首帧或场景构图。
- 不上传状态卡、首帧图、场景图或动作参考视频。
- 提示词第一句固定声明两名角色均为本项目原创虚构数字角色，并立即完成参考图映射。
- 栀夏是第一视觉主体，并产生开场第一个清楚可见的动作。
- 阿砚足底至耳尖约 40 厘米，保持双耳、四足、单尾、朱砂额印与纸墨材质。
- 舞蹈只限定：`中国古典舞身韵、轻盈克制、连续自然、不遮脸`；具体动作、连接与收势由 Seedance 自由发挥。
- 对白、诗句、字幕与精确口型均不交给视频模型，后期完成声音和文字合成。

## 采用方案

采用“单一视觉事件 + 三段自然过程 + 一条摄影机路径”。

这比旧版的精密时间轴更适合当前输入条件：两张角色母版可以帮助锁定人物，但不能同时保证精确口型、复杂特效、多个景别变化与严格舞蹈节点。新版主动减少竞争目标，把十秒集中在栀夏形象、自然起舞和由雪产生的诗意联想上。

不采用以下两种方案：

- 多镜头分镜方案：节奏更强，但会增加角色跳变，不符合当前一镜到底要求。
- 精确控制方案：需要增加场景图或动作参考视频，与当前“仅两张角色母版”的输入决定冲突。

## 新版提示词结构

最终可复制正文只由六个连续部分组成：

1. 原创虚拟角色声明与两张参考图映射。
2. 十秒竖屏、一镜到底、雪林时间与光线等基础画面条件。
3. 三段自然事件，不出现九段毫秒级拆分。
4. 一条连续摄影机路径。
5. 最短必要的角色稳定与物理真实性约束。
6. 声音边界与少量高风险禁止项。

输入说明、生产状态、文件路径和验收清单保留在 Markdown 正文之外，不复制进提交给 Seedance 的提示词。

## 三段自然事件

### 第一段：栀夏钩子

开场立即看见栀夏的正面偏侧中景。她先自然转身或抬眼，衣袖随动作产生真实惯性，迅速建立角色形象。阿砚位于她身侧雪地，比例清楚但不抢第一视觉注意。

这一段不出现空镜、雪花微距、阿砚单独开场、口型任务或独立特效。

### 第二段：动作引发雪落

栀夏自然进入舞蹈。她经过积雪松枝附近时，衣袖带起的轻风或脚步造成的细微震动使枝头粉雪落下。雪的运动必须来自人物动作与环境接触关系，不能凭空出现图形化雪花或魔法爆发。

阿砚只做抬头、转耳、注视等低复杂度反应，不跳跃、不参与舞蹈、不承担口型。

### 第三段：梨花意象与收束

逆光穿过自然落雪，远近覆雪枝梢在景深中呈现近似梨花盛开的视觉联想。画面始终是冬季雪景，不生成真实梨花、花瓣、绿叶或季节转换。栀夏完成自然收势，面部保持可见；阿砚仍在同一空间关系中。

## 摄影机设计

- 全片只有一条主路径：摄影机始终位于栀夏正面偏侧，平滑侧向跟随，并在同一运动中逐渐增加与人物的距离。
- 摄影机不绕到栀夏背后，不脱离人物追逐雪粒，不升空，不突然改变方向。
- 开场以栀夏中景快速建立形象，结尾自然扩展到能看清两名角色与覆雪树林的较宽画面。
- 正文使用平台可理解的普通摄影语言，不出现任何 Mxx、Hxx、Dxx、Sxx、状态卡编号、资产路径、版本号或项目任务名。

## 角色与画面优先级

当生成目标发生竞争时，按以下顺序取舍：

1. 栀夏固定身份、面部与完整身体。
2. 阿砚 40 厘米尺度、原创结构与纸墨材质。
3. 舞蹈连续、轻盈且不遮脸。
4. 摄影机连续跟随。
5. 枝雪落下和梨花般的冬季意象。
6. 背景树林层次、辅助雪粒和其他装饰。

不再使用一长串重复负面提示。只保留已在失败成片中实际发生、且会直接破坏核心结果的风险：换脸换装、肢体增生、阿砚普通猫化或比例缩小、摄影机绕到背后、图形化巨大雪花、真实梨花与文字水印。

## 声音与后期

- Seedance 只负责自然冬日环境声、轻微衣料声和克制的无人声音乐。
- 不要求模型生成“梨花？”“是新雪。”或诗句，也不要求任何精确无声口型。
- 对白、诗句、字幕及其精确时间点继续以后期音频与字幕文件为事实源。
- 视频提示词中的三个时间段只用于画面节奏，不与每句 TTS 的毫秒长度硬绑定。

## 白雪诗境的因果主线

白雪最终提示词只表达这一条主线：

> 栀夏先动建立形象；她在覆雪松林中自然起舞，动作带落枝头粉雪；逆光把自然落雪和覆雪枝梢连成梨花初开的错觉；她在正面偏侧完成收束，阿砚安静见证。

“梨花？”与“是新雪。”由后期声音完成，而不是让画面承担精确对话表演。

## 验收标准

- 最终提示词只引用两张原创角色母版。
- 可复制正文的第一句完成原创虚拟角色声明，随后完成图片映射。
- 正文只有三个宽时间段，或采用三个自然段表达同等顺序；不得恢复逐毫秒音频节点。
- 栀夏在开场立即可见并产生第一个动作。
- 阿砚明确为约 40 厘米，并保留双耳、四足、单尾、朱砂额印和纸墨材质。
- 舞蹈限定完整且只保留固定四项，具体舞蹈由 Seedance 自由发挥。
- 雪由栀夏动作带动枝头积雪自然落下，并仅形成梨花般联想。
- 摄影机只有一条正面偏侧连续跟随路径，不绕到背后。
- 正文不含内部代码、资产路径、状态卡术语、唯一引导雪花、精确口型或台词诗句。
- 提示词长度和重复度明显低于旧版；每项约束只在最需要的位置出现一次。
- 相关静态检查和文本格式检查全部通过。

## 生成门禁

本次只更新设计、规范和文字提示词，不调用 Seedance，不生成图片、视频或付费素材。正式生成仍需单独确认模型、时长、分辨率、生成数量与预计费用。
