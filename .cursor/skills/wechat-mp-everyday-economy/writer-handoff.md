# 交给写稿流程

研究包用五部分：主题与新闻发生地；一句可被证据支持的核心判断；已核事实、日期、口径和原始链接；算账输入、公式、适用人群与遗漏成本；当事方说法及尚待核实的信息。只把已核事实列为确定陈述。

交给写稿时另用一句话说明主要读者是谁、他看到这些事实后最想问或最想说什么。它是文章的观察角度，不算第六类事实，也不能伪装成真实采访或所有人的共同意见。

手工提示词保留可替换的五栏：

```text
主题：【事件、地点、日期】
核心判断：【可检验的一句话】
已核事实与来源：【事实、口径、日期、原始链接】
算账输入、公式和未计成本：【无则写“本题不做测算”；假设须明示】
当事方说法与待核信息：【主体、说法、缺口；无则写“无”】
```

这五栏只构成研究底稿；完整文章要求仍用现有 DeepSeek SOP 的热点提示词交付，不能把本页五栏单独当成完整提示词。

用户确认写稿后，按 [现有 DeepSeek 写稿 SOP](../wechat-mp-writing/deepseek-writer-sop.md)制作提示词并由用户手动调用。要求标题不超过32字、正文900—1100字、纯段落；从真新闻走到普通人的收入、支出、时间或选择，再作有证据的个人判断。可以有散文式节奏和作者立场，不写成问答卡、政策 FAQ 或机械三段式；不虚构作者见闻、家庭故事、报价、回报率或群体心声。

用户贴回稿件后，走现有事实、文学性、图片与草稿门禁。公开事实不因写得动人而免核；测算应重新核算。只有用户再确认，才可能写入新的公众号草稿，不能覆盖既有草稿。

先手动试写六篇：家庭账单、消费现象、热点解释各两篇。复盘仅用公众号后台真实的24小时与7天阅读、分享、评论等可得数据，结合来源与题材差异判断；不宣布“爆款规律”，不把单篇表现当因果证明。
