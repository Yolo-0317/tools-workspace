## 分清三个层次

词类说一个词在当前用法中是什么，如名词、动词、副词；短语结构说几个词怎样组合；句子成分说这个词或短语在当前句中承担什么功能。三者不能互相代替。名词不总作主语，动词也不总单独作谓语。

本层采用便于写作检查的常见教学术语。同一句话可能有不同的语法分析；遇到分类争议，先写清对象、动作、修饰和分句关系，不用一个术语标签代替判断。例句除明确标明用户原句外均为自编，不充当历史材料或用户认可的文风正例。

## 检索与维护

这些页面手工维护，未进入词库的JSON索引。现有`kb.py query --mode sentence`只召回词形，不分析句法。可在工作区用：

```bash
rg -n '兼语|主语|修饰范围' docs/writing/语文基础知识库/句法
```

新增知识先核来源，再写自己的解释与有语境的例子。每个修改例子说明具体问题和适用边界；自然但不适合当前语境的表达，不标成普遍语病。新增共通执行要求改基座，不在本目录另立一套审稿流程。
