# 牛马也智能 · 健康题材独立写法

适用：用户要求规划、研究、撰写或修改健康生活、营养、保健品相关公众号内容。现有 [小商品单品稿](../wechat-mp-writing/product-feature.md) 保持独立；本 Skill 不复用其选品门槛、素人推荐措辞、商品卡写入或草稿槽位。选题与选品可以分别研究，不强制把商品配给文章。

用户要求从最近的网络关注中挑健康话题时，先用 [健康话题选题 Skill](../wechat-mp-health-topic-discovery/SKILL.md)；确定题目后再回到本 Skill 写作。

面向中老年读者的健康知识稿，使用[中老年健康稿 Skill](../wechat-mp-senior-health/SKILL.md)承接近期丁香医生选题参考、真实配图、版式与手动草稿；本 Skill 继续提供共用的健康事实和商品边界。

撰写或修改健康知识稿时，先读 [健康生活作者卡](author-role-card.md)，用其确定作者视角、资料使用方式和全文节奏；本文件仍负责事实、商品与发布边界。

需要参照丁香医生科普写法时，再读[首轮写法观察](dxy-writing-study.md)。只借鉴问题切入、证据解释和段落推进，不复用原文句子、医疗身份或旧文结论；最终语气以本号作者卡和用户改稿反馈为准。

需要美化或渲染健康稿时，读[健康公众号排版](layout.md)，先做手机预览，再交付带内联样式的正文 HTML。

## 先确定交付物

- **健康知识稿**：回答一个读者问题，引用可回查的原始资料，不给个人诊断、用药或补充剂方案；不在同页放相关保健食品、药品、医疗器械、特殊医学用途配方食品的购物链接。
- **商品研究表**：只读调用现有 Select 接口发现候选，记录采样词、页码、时间、商品身份、价格、来源平台销量提示和预计佣金。平台销量不是本号转化或全网排名。商品候选不等于可推广资格。
- **保健食品广告素材**：仅在产品身份、注册/备案、标签、广告批准文件与平台要求均已核对时另行研究；依已批准内容处理，不借健康科普作导购，也不擅自改写获批广告。本 Skill 不授权发布、挂卡或创建草稿。

《互联网广告管理办法》第八条和[自媒体医疗科普通知](https://www.cac.gov.cn/2025-08/01/c_1755764425442686.htm)限制健康养生知识同页出现相关保健食品等购物链接；[广告审查办法](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/fgs/art/2023/art_4ca076ac0eeb4a9e9204e0cee26e359b.html)限制保健食品功效、成分、适宜人群等广告表述。发布界面的「健康医疗分享」声明不是医疗资质或广告批准。商品与正文弱关联也不能用来推定同页可挂卡。遇到材料缺失时，输出缺口和可做的知识稿，不生成带货草稿。

## 研究读者与选题

按具体生活问题分组，不把年龄当成诊断：年轻人可查作息、久坐和外食标签；中年人可查体重、膳食与活动；老年人可查食物多样性、肌力与骨骼健康。每个候选写清「谁在什么场景遇到什么问题」「权威资料实际支持什么」「什么需要就医或个体评估」。这些只是初始研究方向；要称热门，另查近期搜索、讨论和本号数据。

资料优先取[国家卫健委健康素养 66 条](https://www.nhc.gov.cn/xcs/c100123/202405/73a4927142f34152abed875634a3c13b.shtml)、[成人食养指南](https://www.nhc.gov.cn/sps/c100088/202301/f01895a06c5349ef999f25da833c166d.shtml)、[老年营养改善行动](https://www.nhc.gov.cn/lljks/c100158/202210/8a11962d784540d7a61ef883948f768e.shtml)等原始文件，再查当前有效版本。注明来源和发布日期；不从产品营销页倒推健康结论。未经医疗资质认证，不生产专业诊疗科普；引用专业资料时清楚标注来源和 AI 生成标识要求。

## 写稿流程

标题说出具体生活问题，不暗示一种产品人人需要。开头用可核实的日常选择或常见误区进入问题，不渲染患病恐惧，不编造亲测、病例或医生背书。内部可以安排问题、事实、解释和适用边界，但这些是作者的工作顺序，不是正文的固定段落模板。

1. 写前按[作者卡](author-role-card.md#证据工作台)核好事实，再为每个拟写段落记一句**读者会得到的具体信息**。写「实验把参与者的睡觉时间统一定在十一点」，不写「解释研究局限」。若一句话只描述作者下一步要做什么，先补充事实，不开始写那段正文。
2. 起稿时从这句具体信息往下写：读者还需要知道哪个条件、原因、数字或生活选择，就把它说出来。把研究笔记转成正文前，再用一句话说清「谁在什么时候做了什么，出现了什么变化」；研究里的「早进食组」「晚吃阶段」「参与者出现饥饿感」不能未经转换就进入叙述。研究人数、对照条件和测量方式仍要交代，可放在相邻句。不要先生成「这里值得留意的是」「研究回答的是」「对于普通人」等结构提示，再往后填内容；这些是症状示例，不是禁用词表。有实际语义作用的转折可以保留。
3. 按下方小循环写正文，当前段落组通过后再写下一组。没有通过时回到段落要点或事实资料重写，不只替换几个词。
4. 核心问题得到充分解释后再收尾。若篇幅不足，查读者还有哪些问题没得到解释、哪些证据条件没说清，再补有来源支持的内容；不要用过渡、重复结论或空泛生活场景凑字。短段落是排版方式，不能把一个重要问题压成摘要。

### 正文小循环

每次处理相邻的两三段；论证需要较长解释时可按一个完整意思处理，不为凑段数强行截断。

1. **起稿**：写出当前段落组，不预先填「转折句」「总结句」等占位内容。
2. **停笔核对**：这几段各让读者多知道了什么？关键句的主语、动作、时间和适用条件是否清楚，能否回到已查资料？研究语言是否直接混进了正文？读出声时，是否像作者在说一件事，还是在报告写作步骤？
3. **修正或继续**：信息缺失就补查资料或重想段落要点；事实越界就收窄判断；语言生硬就从「谁做了什么」重新说。若只是宣布转折、复述上一段或预告建议，让后面的具体内容直接开头。通过后再写下一组，段落可以停在事实或判断上。

循环到读者的核心疑问已得到解释，重要条件也已说清；若资料不足以回答，明确收窄文章主张，不反复试写同一句。成稿后再通读两遍：第一遍逐句核关键事实、主语和适用范围，第二遍朗读语气及段落节奏。任何语言修改只要改变事实含义，就回到第一遍重核。

成分科普要区分成分本身的研究、一般膳食建议与某款产品获批的功能，不能把前两者直接写成该商品的功效。用自然口语解释数字与标签；结尾给读者一条可执行的非购买判断。

## 商品证据门槛

先把候选分为普通食品、保健食品、药品、医疗器械或特殊医学用途配方食品。普通食品不得声称保健或治疗功能；保健食品核对注册/备案、获批功能、成分含量、适宜与不适宜人群、食用量及有效广告批准材料，不超出说明书和审查通过的广告内容。无法确认分类、资质或批准内容时停止商品广告方向。不得沿用小商品稿的「我挺推荐」「常备必买」等保健食品推荐句式。

研究输出分别列出选题证据、商品证据和不可使用的主张。若后续确需独立草稿流程，先另行设计 `kind`、槽位和验证，不修改或绕过 `product_feature`。
