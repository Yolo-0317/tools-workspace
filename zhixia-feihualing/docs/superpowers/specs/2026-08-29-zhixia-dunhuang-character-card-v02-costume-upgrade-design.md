# 栀夏敦煌角色卡 v02 服化道升级设计

## 目标

在不改变栀夏身份、角色卡信息结构和敦煌十六舞“一套固定服装”原则的前提下，参考三张敦煌舞台造型照片，升级服装质感、配色、妆发与配饰。新版需要比 v01 更华丽、更有敦煌乐舞辨识度，同时保持三视图可读、配件可拆解和 Seedance 视频复现稳定。

## 参考图使用边界

- 参考图一用于提取孔雀蓝、琥珀橙与象牙白的配色关系，以及璎珞、腰链和金属乐舞道具的层次。
- 参考图二用于提取胸衣、分层裙片、臂带与长飘带构成，以及蓝橙色在全身轮廓中的分布。
- 参考图三用于提取织锦质感、上臂臂钏、成组手镯、额心花钿和敦煌高髻氛围。
- 参考图只提供服化道语言，不复制照片人物身份、脸部、姿态、背景、水印或具体道具造型。

## 选择的造型路线

采用“舞台写实敦煌”路线：在壁画矿物色与现代舞台服装结构之间取得平衡。服装比文物复原更轻盈醒目，比神女幻想风更克制，避免满身宝石、巨大冠饰和过多独立飘带造成生成变形。

## 角色不变项

1. 角色仍为 18 岁的栀夏，保留现版清秀东方脸型、琥珀棕眼睛、自然纤长体态和约七头身比例。
2. 保留六组表情：平静、轻微微笑、专注、惊讶、敬畏、含蓄喜悦；六格必须在眼神、眉形和嘴形上明显可辨。
3. 保留高写实 CG 角色设定图质感、暖白背景、细朱砂线框与中英双语栏目。
4. 保留一页纵向角色卡，以及正面、右侧、背面三视图；三视图必须是同一套服装、同一发型、同一配饰。
5. 不改变“敦煌十六舞固定造型”定位，不增加第二套服装。

## 色彩系统

新版将 v01 的大面积朱砂红降为点缀，确立以下层级：

- 主色一：孔雀石青蓝，用于胸衣织锦、外层裙片和局部飘带，承担角色识别。
- 主色二：琥珀橙，用于不对称裙片与外层飘带，提供暖色动势。
- 基底色：象牙白，用于胸衣底色和内层长裙，保持轻盈与人物轮廓。
- 金属色：温润旧金，用于织纹、冠饰、璎珞、臂钏、手镯、腰链和鞋面细节。
- 点缀色：少量朱砂红与宝石红，只用于额心花钿、冠饰中心、胸衣纹样和极少数流苏。
- 辅助色：极少量浅青绿，用于玉石坠饰，不与孔雀蓝争夺主次。

全身蓝、橙、白的视觉面积保持约 4:3:3；旧金只勾勒结构与配饰，不覆盖大片布面。

## 服装结构

### 上装

- 修身短胸衣，长度停在自然腰线上方，露出适量腰腹以符合敦煌舞台服装，但不做低胸或暴露设计。
- 象牙白丝缎作为底层，孔雀蓝织锦覆盖胸前主要区域。
- 胸口使用对称莲花、忍冬纹与小型卷草纹，金线刺绣中嵌少量朱砂红和浅青绿细节。
- 肩部使用清楚、稳定的细肩带，不采用容易漂移的无肩带结构。
- 胸衣下缘加入一圈窄旧金织边与小型珠坠，珠坠数量克制、左右对称。

### 下装

- 内层为象牙白哑光乔其纱长裙，垂坠柔软但不透明，不出现高开衩。
- 外层由孔雀蓝与琥珀橙的不对称织锦裙片交叠，形成前中、两侧和背后的清楚结构。
- 裙片边缘使用窄旧金滚边，局部加入莲花与卷草纹，纹样密度集中在腰部和下摆，避免全身等密度铺满。
- 裙摆具有足够幅度供旋转、翻身和腾跃，但三视图静态状态下不夸张蓬起。

### 飘带

- 只使用一组双层长飘带：外层琥珀橙，内层浅青蓝，均为轻薄半透明丝绢。
- 左右两端固定在上臂后外侧的臂钏下方，从手臂外侧自然垂落；不缠腰、不横挂背部、不从腋下穿过。
- 正面能看见飘带从双臂外侧下垂；侧面能看见固定点；背面能看见两侧独立垂落，中背保持无遮挡。
- 三视图中的固定点、长度、颜色顺序和垂落方向必须完全一致。

## 材质与工艺

- 胸衣和外层裙片：有重量、有细密经纬纹理的丝绸织锦，金线为织入式或刺绣式，不能呈塑料印花。
- 内裙：哑光象牙白乔其纱，柔软垂坠，层间有轻微透光但保持遮蔽。
- 飘带：更薄、更通透的丝绢，边缘有极细金线，不使用厚重纱幔。
- 金属：统一为温润旧金，保留细微锤揲与磨砂质感，不使用高亮塑料金。
- 宝石：红玉与浅青玉只作为小面积嵌饰，具有半透明石材感，不做大颗钻石或现代水晶。

## 妆发设计

- 发型保留敦煌高髻，但从单一环髻升级为左右对称的双环望仙髻与中央高髻组合，轮廓向上舒展，背面结构清楚。
- 冠饰采用轻量莲焰形旧金冠，中央一枚小型朱砂红宝石，左右配小型金叶与垂珠，不使用巨大满头冠。
- 额心使用精致朱砂莲瓣花钿，眼尾增加赭红渐层与极细金色点饰。
- 唇色使用哑光赤陶红，脸部保留栀夏原有年轻、清透和温柔感，不做浓重戏曲妆。

## 固定配饰组

全身固定为六组配饰，三视图与拆解栏逐一对应：

1. 莲焰旧金冠与配套小型发簪。
2. 细长旧金流苏耳坠，末端各一枚浅青玉坠。
3. 双层璎珞项链：上层贴颈细链，下层莲瓣短坠链。
4. 左右对称旧金上臂臂钏，同时作为飘带固定点。
5. 左右手腕各一组成组细手镯，数量固定、不过肘。
6. 旧金腰链与短流苏腰饰，垂坠集中在腰部两侧和前中，不超过膝部。

不增加鼻饰、面链、现代耳夹、夸张指甲、大颗钻石或密集全身珠串。

## 道具设计

角色卡拆解区单独展示一件“圆形莲纹金色乐舞法器”作为可选道具，提取参考图一的金属乐舞氛围，但使用原创莲花、日轮与卷云纹构成，不复制参考图具体形状。

三视图不持握该道具，避免遮挡胸衣、腰链和手部结构。道具不属于角色固定身体配饰，后续只有相应舞蹈需要时才上传或描述。

## 角色卡版式

- 沿用 v01 纵向角色设定卡布局与暖白纸张感，不改成海报或场景照。
- 顶部保留：`ZHI XIA`、`栀夏`、`敦煌十六舞固定造型`、`DUNHUANG DANCE COSTUME`、`No. 01`、`CHARACTER PROFILE`。
- 主区左侧为正面、右侧、背面三视图，人物从头到脚完整入画，脚下仅有极淡接触阴影。
- 主区右侧为六个统一构图的肩部以上表情格。
- 下部依次包含服装拆解、饰品与结构、细节特写、色彩材质和纹样参考。
- 服装拆解必须分别展示胸衣、内裙、孔雀蓝裙片、琥珀橙裙片、双层飘带和舞鞋。
- 饰品区必须逐一展示六组固定配饰和可选乐舞法器。
- 细节区重点展示眼妆、唇妆、双环高髻背面、织锦经纬、金线刺绣、旧金锤揲和玉石坠饰。

## 生成方式

使用 Codex 内置图片生成工具，以现版 v01 正式角色卡为身份、版式和三视图一致性参考，以三张用户照片作为服化道参考，生成新的完整角色卡，而不是对照片人物换脸或直接拼贴。

输入图片角色分工：

- 现版 v01：编辑目标与身份、版式、表情、人物比例参考。
- 参考图一：配色、珠宝层次与金属道具参考。
- 参考图二：服装结构、飘带和全身色块参考。
- 参考图三：织锦、臂钏、手镯、额饰与发型氛围参考。

生成后先作为 v02 候选版供用户确认，不覆盖 v01。确认后再制作 Seedance 高清版与上传版，并更新角色固定说明与资产清单。

## 禁止项

- 不改变栀夏脸型、年龄感、身高比例或东方身份。
- 不复制参考照片人物的面部、姿态、场景或水印。
- 不生成影楼写真、月亮背景、洞窟背景或舞蹈海报。
- 不把朱砂红继续作为最大面积主色。
- 不出现塑料亮片、现代水钻、廉价印花、厚重窗帘式飘带或全身高反光金属。
- 不让飘带在三视图中改变固定位置、颜色顺序或数量。
- 不让配饰遮挡脸部、胸衣结构、手腕或腿部轮廓。
- 不在三视图中持握道具，不增加第二套服装。

## 验收标准

1. 第一眼仍能认出是现版栀夏，而不是参考图中的人物。
2. 蓝、橙、白、旧金层级清楚，朱砂红只承担点睛。
3. 三视图的胸衣、裙片、飘带固定点、发型与六组配饰完全一致。
4. 织锦、乔其纱、丝绢、旧金和玉石能在细节格中被清楚区分。
5. 全身配饰丰富但不拥挤，舞蹈时不会显著限制肩、腕、腰和腿部动作。
6. 六个表情在眼神、眉形和嘴形上明显不同。
7. 角色卡信息完整、人物无遮挡、无照片水印、无多余肢体、无乱码式大标题。
8. 可选乐舞法器只出现在拆解区，不影响固定角色造型的一致性。
