# 栀夏九歌祭舞 v03 五秒视频测试 v02 提示词设计

## 测试结论输入

首轮 5 秒视频已经保住主要服装结构和严格两个袖缘尾端，动作也能及时启动；但人物持续低头闭眼，脸部占比偏小，后半段双臂趋于镜像上举。因此第二轮只修正脸部可验证性、构图占比和左右臂终点，不增加新的场景、道具、特效或动作。

## v02 设计

- 采用三分之四正面全身中景，人物从头顶到鞋履完整可见，并占画面高度约 70%。
- 第一帧自然睁眼，目光保持在镜头侧前方；允许一次极短自然眨眼，不持续闭眼、低头或垂眼。
- 角色右臂单独领起，最终停在头侧斜上方但不过头顶；左臂只在胸腰之间移动，最终停在腰侧前方。
- 两手终点保持清楚高度差，不再使用“沿不同半径同时展开”之类容易被转译成对称动作的表述。
- 仍然只做一次低位换重、纵向提起和袖缘余摆，镜头只轻微抬升。

## Seedance v02 完整提示词

输入图片是纯AI生成的原创成年虚拟角色设定图，不是真人照片，不对应任何现实人物，也没有真人原型。画面中的成年虚拟角色名为栀夏，请保持设定图中统一的虚拟面部特征、楚式盘髻、黑漆凤鸟冠梳、玄黑朱红舞衣、自然修长比例，以及左右袖口后下缘合计严格两个的朱红袖缘尾端。参考图仅约束虚拟角色造型、身体比例、妆发、服装结构、材质与配饰，不复刻角色卡排版、文字、边框、分区或纸张背景。

生成5秒、9:16、电影级自然摄影式写实、单一连续镜头。暗色楚式祭坛只有低照度火光和少量冷色天光，背景安静。摄影机保持三分之四正面全身中景，人物从头顶到鞋履完整可见，占画面高度约70%；镜头只随人物起身轻微抬升，不绕背、不切镜头、不快速推拉。

第一帧栀夏自然睁眼，目光看向镜头侧前方，神情肃静清醒；她处于低位弓步，前后脚清楚承重，她的右手在胸前侧上方准备领起，左手停在腰侧前方。0.3秒内立即把重心送向前脚并开始起身，不等待、不摆拍。

随后由脚底发力，脊柱逐节提直，胸腰带动右臂沿单一斜线缓慢升至头侧斜上方，右手始终不过头顶；左臂只在胸腰之间做小幅回护，左手始终低于胸口，最后停在腰侧前方。左右手全程保持明显高度差，禁止同时抬升，禁止左右镜像，禁止双臂同时举过肩或举过头顶。前脚稳定落地后，身体继续保留向上的动作余势；肩肘先停，左右两个袖缘尾端随后各产生一次短暂、真实、受重力影响的自然余摆，最后一刻才接近落定。

全程保持自然睁眼和三分之四正面面部，可有一次极短自然眨眼，但不得持续闭眼、低头、垂眼或把脸转离摄影机。双眼、眉形和面部轮廓始终清楚，袖布、发丝、火光和烟气不遮脸。皮肤保留真实毛孔、细小绒毛与自然肤色变化，发丝、丝绢、薄罗和织锦呈低反光真实材质，避免油润CG、塑料皮肤、蜡像感、过度磨皮、湿亮面料和游戏角色渲染。

不得改变虚拟面部特征、年龄感、盘髻、凤鸟冠梳、交领内衣、宽袖舞衣、长裙、斜裁裙片、腰封、玉佩或鞋履。不得生成额外人物、道具、鼓槌、敦煌服饰、披帛、多条长绸、超过两个袖缘尾端、抓袖、抛袖、专业水袖、悬浮飞行、仙侠法术、字幕、水印、logo或角色卡文字。不得生成可辨识人声、对白、朗诵、旁白、吟唱或角色叫声。

## 验收重点

1. 五个代表时间点至少四个能够看见自然睁开的双眼，人物脸部尺寸足以与母板核对。
2. 右手最终在头侧斜上方，左手始终不高于胸口，两手没有形成镜像。
3. 左右袖口后下缘始终各一个朱红尾端，合计严格两个。
4. 0.3 秒内出现脚下换重与起身，不是单纯抬手或站立摆拍。
5. 皮肤和衣料保持低反光，不出现油润、塑料或湿亮质感。
