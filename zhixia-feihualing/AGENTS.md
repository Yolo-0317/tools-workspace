# 栀夏飞花令项目执行要求

继承工作区规则。用户可见内容使用中文，不使用 emoji。

## Seedance 提示词门禁

- 新写、修改、审查或交付本项目任何 Seedance 提示词前，必须读取并执行 [官方提示词交付门禁](docs/seedance-official-prompt-gate.md)。只在聊天中给提示词也适用。
- 先区分本次栏目和用户最新确认，不将文化诗舞的角色尺度、声音模式、精确舞蹈时间轴直接套入天宫喜剧。
- 门禁是语义审查，不是生成成功保证或自动 API 拦截。未解决拦截项不得交付为可直接提交；素材提醒按门禁记录，不擅自更换用户已确认角色卡。
- 审查结论、来源日期和风险留在模型正文外。实际提交前核对平台真实素材绑定；付费生成仍须按生产流程取得授权。
- 遇到新型号或官方更新，回源核验正文，不把旧经验或社区建议标成官方强制规定。
