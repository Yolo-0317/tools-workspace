# 北上广深择校文章与门禁设计

## 背景

“牛马也智能”近期聚焦教育政策、招生考试和升学规则。现有热点深评规则已经覆盖全国教育政策和高讨论度地方新政，但尚未单独处理择校文章。择校内容具有较高的搜索价值和家庭决策价值，同时也容易混淆城市、区县、学段和年份，或滑向学校排名、学区房承诺和招生中介软文。

本次将择校正式纳入教育垂类，首期只覆盖北京、上海、广州、深圳的义务教育与高中选校。大学志愿继续归入高考政策与志愿填报，不进入本专题。

## 目标

1. 让 Agent 能稳定筛选北上广深有现实决策价值的择校政策热点。
2. 将择校文章写成政策解释和家庭决策支持，而不是学校排行榜或招生承诺。
3. 明确城市、区县、学段、年度、政策状态和适用家庭，防止地方规则跨区域外推。
4. 对高风险承诺设置硬门禁，同时保留对骗局、违规招生和相关说法进行批评报道的空间。
5. 沿用用户主动热点的 DeepSeek 手工交接、Agent 核实编辑、抖音真实配图和双确认流程。

## 非目标

- 不建立学校排名数据库或“梯队表”。
- 不自动预测个人录取概率。
- 不提供学区房投资建议、房产推荐或价格判断。
- 不采集学校升学率、在校生成绩或未成年人个人信息。
- 不建设自动抓取四城全部招生数据的长期系统。
- 不覆盖大学志愿、留学择校和国际学校商业推荐。

## 参考文章与可迁移写法

### 官方问答型

北京与上海的年度招生政策解读，把复杂规则拆成家长真实会问的问题，再回答适用条件、办理时间、选择后果和兜底安排。可迁移的不是问答排版本身，而是“先回答家庭会失去或获得什么选择，再解释政策术语”的顺序。

- 北京市政府《2026年北京义务教育阶段入学政策发布》：https://www.beijing.gov.cn/zhengce/zcjd/202604/t20260417_4589532.html
- 上海市政府《2026年上海市义务教育阶段学校招生入学工作实施意见及问答》：https://www.shanghai.gov.cn/xbhygq/20260327/ed6e6cd11bbd4fafa263d6e6dcedc45a.html

### 家庭决策型

广州市高中报考指南明确提示，应结合兴趣、性格、招生范围、住宿条件和升学路径，不应只按学校名气或一个分数排序。可迁移原则是：比较维度必须与家庭选择有关，历史数据只能作为带年份的参考，不能直接推导学校质量或未来录取结果。

- 广州市招生考试委员会办公室《2026年广州市高中阶段学校招生报考指南》：https://gzzk.gz.gov.cn/attachment/8/8027/8027351/10816553.pdf

### 城市与区级规则型

深圳市级文件规定免试就近、积分入学和公民同招等总体原则，各区再制定积分项目和实施细则。广州义务教育同样以区为主实施，区级文件可能规定“人户一致”、学位占用或具体招生范围。可迁移原则是：市级原则、区级细则和学校安排必须分层引用，不能用一个区的规定概括整座城市。

- 深圳市政府《深圳市教育局关于做好2026年普通中小学招生入学工作的通知》：https://www.sz.gov.cn/cn/xxgk/zfxxgj/tzgg/content/post_12819389.html
- 广州市海珠区政府《2026年广州市海珠区义务教育学校招生工作实施细则政策解读》：https://www.haizhu.gov.cn/gzhzjy/gkmlpt/content/10/10791/post_10791352.html

### 新闻深评型

优秀择校深评通常采用“政策变化—家庭具体不确定性—官方规则—实际选择成本—制度根因”的推进方式。旧报道可以学习结构，但涉及划片、入学和招录的事实不得跨年度复用。

- 光明日报《中小学入学新政新在哪儿》：https://edu.people.com.cn/n1/2019/0418/c1006-31036679.html

## 方案

采用“独立专题规则 + 现有热点路由 + 两层门禁”。

### 独立专题规则

新增 `.cursor/skills/wechat-mp-writing/school-choice-policy.md`，仅当主题涉及北上广深的幼升小、小升初或高中选校时读取。文件包含：

- 选题范围与排除项；
- 四城规则层级与易错点；
- 来源优先级和年度核验要求；
- 选题评分和文章结构；
- 学校比较允许维度；
- 硬门禁、编辑门禁和发布前清单。

现有 `hotspot-deep-review.md` 只增加简短路由和稳定偏好，不复制专题细节，避免主文件继续膨胀。

### 两层门禁

第一层是专题写作门禁，由 Agent 在选题、提示词、核实编辑和发布前执行。它负责必须理解语境的风险，例如：区级规则是否被外推、历史分数是否混用、学校宣传是否经过交叉核验。

第二层是自动高置信度检查，只拦截明确的招生承诺或中介营销表达，例如“买房必上”“百分百录取”“内部名额”“花钱保录取”“保证进名校”。自动检查必须识别否定和批评语境，允许“不能承诺买房必上”“警方查处百分百录取骗局”等正常表述。模糊的价值判断不进入正则硬拦截，避免误伤。

## 选题规则

候选优先覆盖：

- 当年义务教育招生政策变化；
- 单校划片、多校划片、电脑派位、积分入学；
- 公民同招、民办摇号和未录取后的安排；
- 指标到校、名额分配和高中招生范围；
- 随迁子女、跨区入学、回户籍地入学和转学；
- 学位预警、人户一致、住房或租赁材料要求；
- 多孩子女同校、长幼随学；
- 民办收费、住宿、通勤和招生计划变化；
- 专家提出且已形成公开讨论的择校建议，但必须与正式政策分开。

每个候选至少说明：城市、区县或市级范围、学段、入学年度、政策发布主体、政策状态、受影响家庭、家庭成本、当前热度、争议点和事实风险。

同一事件按“热度、家庭相关性、政策确定性、可核验性、决策价值”综合排序。标题更焦虑不构成加分项。

## 来源层级

1. 当年教育行政部门、考试院、区政府和招生平台的正式文件。
2. 与正式文件配套的官方政策问答、流程图和报考指南。
3. 学校经主管部门备案或公开发布的当年招生简章，只用于说明该校自述、计划、收费和课程安排。
4. 新华社、人民日报、光明日报、中国教育报等媒体的采访和深度报道。
5. 家长经验、论坛、中介、房产平台和培训机构只能作为待核线索，不能单独支撑政策结论或学校评价。

涉及当前入学资格、材料、日期、招生范围、积分、批次、学费和计划时，必须回到当年官方原文。搜索摘要、旧文章和媒体转述不能代替原文。

## 城市专项边界

### 北京

区分市级原则与各区实施细则。重点核对登记入学、单校或多校划片、房产取得时间、学位占用、跨区或回户籍入学等条件。某一区的“六年一学位”、购房日期或派位规则不得写成全北京统一规定。

### 上海

重点核对公民同招、民办摇号、一贯制直升、未被民办录取后的公办安排及各区排序规则。市级问答和区级细则不得混为一层；“报名民办失败后的安排”必须写完整，不能只制造失去公办学位的恐慌。

### 广州

广州义务教育以区为主实施。重点核对各区“人户一致”、实际居住、学位占用、统筹安排和相对就近等具体口径。某区规定的距离、年限或排序不得外推全市。高中选校应核对招生范围、批次、户籍或学籍条件、外区计划、随迁子女计划、学费和住宿。

### 深圳

深圳各区积分入学细则不同。户籍、住房、租赁、居住时间、社保、大学区或共享学区的计分方式不得写成全市统一积分表。每年必须核对区级细则、学位预警和材料截止日期；历史积分线只能标注为往年结果，不能当作当年录取线。

## 学校比较边界

允许比较的项目仅限可核验事实：

- 招生范围和招生计划；
- 公办、民办等办学性质；
- 学费及经批准的住宿等费用；
- 住宿条件和通勤距离；
- 课程、选科和特色项目的官方安排；
- 指标到校、名额分配或特殊类型招生资格；
- 标明年份的历史录取分数、计划和录取结果。

不得直接制作“最好学校”“名校梯队”或以单一录取分数、升学率评价学校质量。学校官网、开放日和招生简章只证明学校如何自述，涉及办学成果和教学效果时至少需要一个独立可靠来源或明确标注为校方说法。

## 硬门禁

- 区级规则不得写成全市规则，四座城市的规则不得互相套用。
- 往年分数线、计划、积分和划片办法必须标注年份，不得冒充当年规则。
- 不得宣称学区房、落户、租房、缴纳社保或购买课程可以保证学位。
- 不得传播“内部名额”“关系入学”“花钱保录取”等服务信息；作为诈骗或违规招生报道时必须有警方、教育部门或可靠媒体来源，并明确其不合法或不可信。
- 不得根据学校名气、录取分数或未经核验的升学率制作排行榜、梯队表或确定性推荐。
- 不得替具体家庭确认入学资格或给出确定录取概率；应提示以当年主管部门审核和正式录取结果为准。
- 不得把征求意见稿、专家建议、媒体预测或学校口头答复写成已实施政策。
- 不得收集、展示或推断未成年人姓名、住址、学籍、成绩和家庭财产等可识别信息。
- 不得贬低普通学校、职业教育、民办学校、特定城区或其中的学生与家庭。
- 不得接受学校、房产中介、培训机构或择校咨询机构的宣传材料作为独立评价，不得植入未披露的商业推荐。
- 标题不得使用“选错毁一生”“学区房白买了”“不买就没学上”等无法由正文和政策直接证明的恐吓表达。

## 正文结构

择校热点深评保持900—1100字纯段落，推荐节奏为：

1. 用一个可核验的政策变化或家庭选择后果开场。
2. 在前五分之一交代城市、区县、学段、入学年度和受影响家庭。
3. 解释规则如何运转，尤其是报名某一选项后会失去、保留或新增什么选择。
4. 比较家庭实际成本，包括住房、租赁、通勤、住宿、学费、材料和时间，但不作投资建议。
5. 明确尚未公布或不能确定的部分，不替主管部门作判断。
6. 落到制度透明、教育公平和适配性，而不是简单告诉家长追逐名校。
7. 结尾只问一个具体、可回答的问题。

成稿不强制使用编号或问答体；以上只是信息顺序，不改变热点深评的纯段落要求。

## 自动检查设计

在现有热点公开文案门禁中增加择校高风险承诺扫描。实现应满足：

- 只在标题、摘要或正文出现择校、学区、入学、派位、积分入学、录取等上下文时启用。
- 拦截明确肯定或营销式承诺，不因单独出现“内部名额”“百分百录取”等词就拒稿。
- 对“不存在内部名额”“不能保证录取”“警方查处百分百录取骗局”等否定、引用和批评语境放行。
- 返回具体命中的句子和修改方向，不笼统提示“内容违规”。
- stage 与 push 前均执行，保持与现有公开文案门禁一致。

不自动判断区级规则是否被全市化，也不自动判定数据是否为当年版本。这两项依赖语境和外部事实，继续由专题门禁和 Agent 回源核验完成。

## 测试

新增测试覆盖：

- “买房必上某小学”“内部名额保证录取”等肯定承诺被拒绝；
- “买学区房也不能保证入学”“警方查处百分百录取骗局”等否定或批评语境通过；
- 普通招生政策讨论不被误伤；
- 既有社会热点、教育政策和非择校稿不受新规则影响；
- 专题文档可从 `hotspot-deep-review.md` 被准确发现。

验证运行最相关的公众号热点质量门禁、原创性和浏览器写稿工作流单元测试，并检查文档链接与 Git 差异。
