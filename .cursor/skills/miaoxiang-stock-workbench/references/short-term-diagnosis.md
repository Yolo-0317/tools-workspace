# 短线诊股：覆盖与核验

短线个股分析加载本页，并优先遵循 [唯一来源规则](skill-only-data.md)。保留V3公式，新增事实不加减技术分。验证基于2026-09-20查询华天科技、行情2026-09-18；单案例支持不代表所有市场、日期和字段保证可用。

## 默认分析顺序

1. 市场和板块环境：同日指数涨跌/成交、市场涨跌家数和涨跌停数量；解释个股走强是否有板块支持。
2. 板块内位置：使用定义清楚的行业/概念集合、同日指标和实际筛选条件。不把宽概念成员当同业务同行，也不把成交额第一自动叫龙头。
3. V3技术：仅mx-data日线；先验证输入适配与完整性，当前适配待验证则标记V3未完成。不能复用旧Tushare分数。结论区分短期突破与中期趋势。
4. 资金和交易结构：主力资金与融资分开；有龙虎榜才解析席位，无有效返回标记未核实。连板、竞价属于补充信息。
5. 催化、基本面与近期风险：事实时间、报告期、减持/解禁/业绩日程/监管/重组分项核验。宏观和财务不重复拉已核验缓存。
6. 观察条件与缺项：区分证据、推断和未知；不输出未经回测的胜率，也不自动生成交易或发帖。

## 查询模板与调用预算

沿用每轮最多8次、串行的流程预算；不是程序自动限流。先复用同日市场、公告、财务和已有龙虎榜，缺项才查。预算不足时交付部分覆盖，不为凑齐栏目自动开启下一轮。

- 市场：`查询{日期}上证、深证、创业板及{行业/概念}涨跌幅与成交额；全部A股上涨下跌家数、涨跌停数量，标明日期单位和口径。`
- 排名：`{板块}概念A股，{日期}成交额排名前10名。` 只描述筛选与排序；所需额外指标对返回代码另用mx-data补查。
- 交易结构：`{名称代码}{日期}连续涨停天数、开收盘集合竞价成交量额、融资余额与净买入；注明日期单位。` 只将实际返回字段纳入报告。
- 风险：每次一个具体主题，例如`{公司}{时间范围}减持计划及进展公告`、`{公司}未来30天限售股解禁公告`、`{公司}{重组对象}注册批复或交割实施公告`。预算不够则将未查项标记未覆盖，不能用一轮泛搜索当完整风险排除。

## 筛选语义门禁

检查原始responseConditionList、totalCondition、日期、排序、返回数量与totalRecordCount，逐项对照用户条件。日期/范围/排序不匹配或多出条件即拒绝作为目标排名。

实测：问句附带“连续涨停天数”被解读成连续涨停大于0；“不要筛选涨停”又被解读为排除涨停，两次均不符合请求。最简正向问句成功。不要在纠正请求里反复堆否定语句；具体追加条件不能由模型默许。该门禁目前是Skill执行核对要求，未实现通用自动语义比较器。

## 同名字段与龙虎榜读取

mx-data通用展示器按中文标签写字典，会覆盖同名字段。实测包括两个“机构专用”卖方，以及股东人数/人均股数的两个“较上期变化”。金融事实以rawTable原始字段ID、nameMap、fieldSet及时间为准；不能直接依赖展示字典。展示器本身保留上游版本，不声称全局已修复。

龙虎榜用工作台工具，按table_id + side + rank + seat_id保留记录，优先rawTable原精度：

```bash
/Users/huan.yu/dev/tools-workspace/stock-ai/.venv/bin/python /Users/huan.yu/dev/tools-workspace/.cursor/skills/miaoxiang-stock-workbench/scripts/billboard_input.py /绝对路径/龙虎榜原始响应.json --code 002185.SZ --date 2026-09-18
```

此工具只适配已验证的单日、单侧前五金额表。输出top5_complete并校验代码、日期、金额和单位；业务失败/空表不得解释为未上榜。它不提供机构总净额，不把两个同名机构合并，不保证同名席位身份相同，亦不推断隐含反向交易。连续三日榜、同日多上榜原因需要分表独立核验，不能混合累加。

## 证据与时点

- 所有字段标记已验证、部分覆盖、未返回或尚未测试。请求日期不等于返回日期，季度数据必须写真实报告期。
- 新闻内引用的“获批后”“交易完成后”不等于获批或已经完成；须找确定公告正文与发布日期。
- 风险排查不完整不能写“无减持/无解禁/无监管风险”。
