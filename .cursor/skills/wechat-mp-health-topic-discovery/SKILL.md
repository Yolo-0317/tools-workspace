# 公众号健康话题选题

本 Skill 只负责选题。读者可以是任何年龄；按他们正在问的问题找题，不预设年轻人、中年人、老年人的配额。确定题目后，中老年健康知识稿进入[中老年健康稿 Skill](../wechat-mp-senior-health/SKILL.md)；其他健康题材进入[健康题材 Skill](../wechat-mp-health-content/SKILL.md)及其作者卡。

## 什么算值得写

一个合格题目同时具备：近期有人关心的可见证据、一个普通读者能说出口的具体疑问、足够可靠的原始资料，以及本号能清楚回答的角度。热度本身不证明健康说法正确；官方新发布一份资料，也不自动证明大众正在讨论它。

优先寻找有真实张力的问题：两种流行建议相互矛盾、常见做法的效果被夸大、读者面临具体选择，或一条新消息改变了原来的判断。标题方向应透露问题，不提前把疾病风险扣到读者身上。

## 每次选题怎么查

1. 记录检索日期。默认先人工阅读[丁香医生健康科普](https://dxy.com/)以发现读者问题；用户给出的[女性健康专题](https://dxy.com/baike/category/24821?tag_id=0)是其中一个入口，不把选题限制为女性或医疗疾病。允许一组选题都从丁香医生找到线索，但只记录人工形成的题目、来源链接、发布日期、读者疑问和本号能写的生活角度；遵守[站点协议](https://dxy.com/doctor-college/agreement/dxy-doctor.html)，未经书面许可不批量抓取或保存其文章原文。
2. 再看近 7 天的讨论和搜索；持续性问题可扩到近 30 天。分开记录事件发生、丁香医生文章发布和实际查阅的日期。旧内容今天被搜索到，不算今天的新热点。
3. 从公开可回查的关注信号核对候选：如[百度热搜榜](https://top.baidu.com/board?tab=realtime)、公开社交平台话题与评论、平台搜索联想、本号近期搜索与阅读数据。选用当时实际可访问的渠道；丁香医生的一篇文章只是选题线索，不算独立的近期关注信号；不把媒体转发数、商业营销声量当作公众需求。
4. 每个声称“近期热门”的候选，至少核对两个相互独立的关注信号，并保存词条或页面链接、显示时间、可见热度依据及读者原本在问什么。若只有一个信号，标为“观察候选”；若只有权威资料而缺少关注信号，标为“常青候选”。不编造搜索量、排名和全网热度。
5. 为候选找能直接回答问题的原始资料。中国适用的建议和规则先查国家卫健委、疾控机构、国家药监局等现行资料；具体营养素可查[美国国立卫生研究院膳食补充剂办公室](https://ods.od.nih.gov/factsheets/list-VitaminsMinerals/)等原始资料，并明确适用国家、人群和日期。丁香医生文章可以提示检索方向，不能代替当前原始证据。
6. 判断能否由当前账号写成一般健康生活知识稿。涉及诊断、处方、治疗、检查结果解读或专业医疗科普资质的，只有在账号资质与专业审核路径清楚时才列为可写；否则说明为何暂缓，不把它包装成生活建议。合规边界见[健康题材 Skill](../wechat-mp-health-content/SKILL.md)。

## 排序与去重

先剔除事实无从核验、靠疾病恐惧传播、权威资料不足或账号不适合回答的题目。其余候选按四项说明排序理由：

- **关注度**：有多少独立且近期的读者问题，而不是发布者说它“很火”。
- **可答性**：资料能否回答核心疑问；若证据有争议，能否把争议讲清。
- **读者收益**：读完能否改变一个具体判断或行动。
- **账号新意**：与本号近 30 天选题是否重复，能否提出更准确的问题。

不因年龄、性别或商品佣金加分。季节性话题要核对地域和当季实际风险；突发健康新闻要核对事件日期与官方回应，不从一个个案推演普遍风险。

## 交付格式

通常给出 3～5 个候选，并明确首选；证据不足时宁可少给。每个候选写明：

| 字段 | 需要交代什么 |
| --- | --- |
| 读者正在问 | 用一句正常人会说的话表达，不用学科分类替代问题 |
| 近期关注证据 | 两个独立信号的链接、显示时间和可见依据；不足时标注观察或常青 |
| 权威解答入口 | 原始资料链接、发布日期、适用人群，以及它能回答到哪里 |
| 作者角度 | 核心判断、可形成的冲突或悬念、读者读完能获得的具体判断 |
| 暂不写什么 | 未证实说法、超出资质的医疗建议、容易造成误解的标题 |

结尾说明为什么首选比其他候选更值得先写，并列出本次检索日期。选题结果不自动生成正文、调用商品接口、创建草稿或安排定时发布；用户要求写稿时再进入作者卡和事实核验。
