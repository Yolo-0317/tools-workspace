# 牛马也智能：需求切入的返佣单品稿型设计

日期：2026-09-26。状态：用户已审阅并批准，已按此设计实现手动稿型。

## 目标与范围

新增 `product_feature` 手动独立稿型。每次运行从现有公众号返佣商品 Select 接口寻找热门且预计单笔佣金较高的商品，围绕一个真实消费需求写一篇单品推荐稿，写入「牛马也智能」独立草稿槽位。`--kind all`、晚间批次和定时任务均不包含它；API 写入的目标只是草稿箱，发表仍由用户处理。

本文不复活已搁置的「简选小电」，也不改变普通长文禁止自动插返佣商品的规则。`product_feature` 是普通 CPS 商品卡的唯一新增白名单稿型。默认一篇只推荐一件商品、插入一张商品卡。

## 方案选择

选择接入现有 `wechat_mp_draft --kind product_feature` 与 `wechat_mp_draft_slots`，复用草稿接口、封面和质检入口，新增独立选品、成稿及验证模块。旧 `wechat-mp-commerce-drafts` 的品牌和文件映射已经过期，不能作为新稿型运行入口；逐篇临时手写则无法沉淀可重复的选品与验证规则。

## 选品数据流

1. 使用现有 `wechat_mp_product.search_daihuo_products`，按与本号读者生活相关的需求词搜索。首次词池聚焦办公桌面、通勤充电、家庭小电器；每词最多读前两页、每页 30 件，词池可配置，每次查询记录关键词、时间、页码和返回数。该接口是关键词搜索，不是全站热榜。
2. 将同一商品去重，提取商品名、平台、品类、当前报价、预计单笔佣金、佣金比例及销量提示。销量提示只用作热度近似值，不写成累计销量或全站排名。所有价格与佣金注明查询时间，草稿写入前重新查询。
3. 先排除没有明确需求场景、商品身份不清、价格或佣金缺失、销量提示不足，以及医疗功效、投资收益等不适合本号核验的候选。销量门槛初始为 1000；低于门槛时明确停止选品，不以佣金高为由绕过。
4. 在合格候选中综合需求贴合度、销量提示、预计单笔佣金金额及价格合理性排序；佣金比例只作辅助。若商品报价乘佣金比例与预计单笔佣金的差额大于 1 元且超过预计值的 20%，标记异常并排除。候选报告至少列前三名及淘汰原因，由 Agent 确认最能写出真实需求的一件。
5. 从品牌官网、品牌官方店商品页或销售平台当前商品页逐项核对正文要用的参数、适用条件、售后和价格；Select 的商品标题只是线索。商品卡在预览及草稿回读时验证 `data-pid` 对应同一商品。商品 ID 与草稿卡 ID 无法匹配、商品下架、价格变化超过 10% 或预计单笔佣金变化超过 20% 时停止写入，返回选品阶段。

## 文章结构与表达

文章先回答「谁在什么场景里遇到什么麻烦」，再给出选择标准和可行替代办法，最后解释本商品满足了哪些标准、有什么限制、适合谁与不适合谁。场景须来自可核事实或清楚标记为一般情境，不编造作者使用、采访、购买或效果体验。推荐理由用经过核实的功能、尺寸、价格和使用约束支撑，不用「必买」「全网最低」或未经证明的功效断言。

标题以需求和商品品类为主，不以佣金、夸张收益或虚假稀缺性引流。正文允许自然段落，不套固定四段式广告模板；需要一段真正有用的选购判断，即使读者不买这件商品也能带走方法。只在商品解决方案已经讲清之后插入一张 CPS 卡。广告关系以紧贴商品卡的独立「广告」标识呈现，不在正文里念「本文含广告推广」或「下方是一张返佣商品卡」；预计佣金仅用于内部选品。摘要与正文的商品身份、价格口径一致。封面与正文配图不得冒充实测图；无合格图时使用与品类相符的既有公共素材，并在商品入口旁标明其示意属性。

## 手动工作流与安全门禁

`--kind product_feature --dry-run` 只读查询并输出候选、选品理由、产品事实清单和写作请求，不上传图片、不写选品缓存、不更新草稿槽位。Agent 据此撰写结构化终稿；终稿保存商品标识、查询时间、证据链接、标题、摘要、正文及选品理由。带 `--codex-draft` 的预检验证全文、来源、商品卡和推广标识，显示最终预览。用户明确要求写入草稿后，命令才更新 `product_feature` 槽位；同槽更新应提示将覆盖的旧标题。运行失败保留原槽位。

质量门禁包括：商品与需求相符；关键产品参数可回源；标题和摘要兑现正文；推荐理由与商品卡为同一件；至少交代一个限制或不适合的人群；不得虚构亲测；单篇恰好一张普通 CPS 卡且没有短剧组件；普通 `hotspot`、`silver`、`news` 等稿型仍拒绝普通 CPS 卡。无合格候选或核验失败时不生成或写入草稿。

## 验证与观察

实现时先写有意义的单元测试，覆盖排序门槛、异常佣金、去重、无候选停止、商品身份一致、唯一商品卡、独立槽位和 `--kind all` 隔离。再用接口只读查询和 `--dry-run` 检查一次完整请求；草稿写入后回读卡片并核对商品。发布后按文章阅读、卡片点击、成交与实际确认佣金复盘，不能把预计佣金当收入承诺。

## 研究依据

- [微信广告流量主成长营：返佣商品广告](https://training.tencentads.com/uploads/202406/44FVgzA9_zjy5jV.pdf)：相关性、点击率、转化率和佣金比例共同影响效果；佣金比例高不等于转化好。
- [京东内容原创平台帮助文档](https://wq.360buyimg.com/data/ppms/movie/neirongyuanchuangpingtai-help-20170303.1.pdf)：围绕面条制作引出工具、围绕厚蛋烧引出锅具，以及单品文案要具体说明价值。
- [有赞「慈怀读书」案例](https://www.youzan.com/anli/76439)：从阅读场景、痛点和解决方案组织推文，并按点击与下单数据复盘。其业绩数字属于商家自述，不作为本号收益预测。
