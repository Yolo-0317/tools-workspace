# 文化诗舞合集后续方向

## 定位

本文件记录《栀夏飞花令》在《栀夏·敦煌十六舞》之后可继续发展的“文化符号＋舞蹈＋诗词”合集方向。它是长期选题池，不改变当前制作优先级，也不代表这些系列已经进入制作。

候选主题必须同时具备：

- 能形成稳定、清楚且不同于其他系列的文化视觉符号。
- 能提供足够丰富的身体动作、空间路线和舞蹈高潮，不能只靠换背景与服装区分。
- 有原作或高度匹配的诗词文本，诗词不是后贴的装饰。
- 能用统一角色母板连续生产，同时允许单集通过环境、动作、道具与色彩产生差异。

## 建议优先顺序

1. 《栀夏·敦煌十六舞》：当前已规划系列，建立华丽、强动作的文化诗舞认知。
2. 《栀夏·九歌祭舞》：首选后续方向，以《楚辞·九歌》建立神秘、叙事化的楚地神话体系。
3. 《栀夏·宋词十二境》：发展细腻情绪、空间调度与克制镜头语言。
4. 《栀夏·华夏神女十二章》：在前述系列稳定后，再发展人物型神话合集。

其他候选方向：盛唐乐舞、山水名楼、二十四节气、东方器物、花神与草木。它们保留在选题池中，进入制作前需重新评估与敦煌、九歌的视觉和动作重复度。

## 《九歌祭舞》统一角色母板原则

《九歌祭舞》可以并且应当使用一张统一的栀夏专属角色母板。推荐叙事身份是“同一位楚地祭舞者进入十个神境，以祭舞迎请、追随并送别诸神”，而不是栀夏逐集扮演不同性别和身份的神祇。

### 母板固定项

- 固定栀夏的脸、18岁年龄感、身材比例、三视图和六种表情。
- 固定高而窄的单体楚式盘髻与小型黑漆凤鸟冠梳，避免大型神女仙冠。
- 固定玄黑、朱红为主色，辅以少量暗金和象牙白；整体取楚漆器般幽深、庄重的色感。
- 固定交领右衽内衣、朱红玄黑一体式宽袖舞衣、多层长裙、清楚腰线与可见舞履；左右袖口后下缘各连续延伸一个朱红尾端，合计严格两个末端。
- 凤鸟、云雷、龙蛇与香草纹只作局部纹样，不堆叠为盔甲或满身装饰。
- 角色母板中默认手中无道具，避免单一道具绑定全部篇章。

### 单集可变项

每集只通过神境、单一道具或自然承接物、局部光色和动作语汇表达篇章差异，不更换栀夏的脸、发型、头冠或整套服装。

| 东皇太一 | 神坛、星空、鼓或无道具 | 庄严祭舞、纵向提沉 |
| 云中君 | 云海、高天、长袖 | 升腾、倾身穿云 |
| 湘君 | 湘水、兰舟、兰草 | 寻觅、临水回望 |

### 与敦煌系列的区隔

- 敦煌使用孔雀蓝、琥珀橙、象牙白与旧金，强调莲焰冠、华丽乐舞和双层长飘带。
- 九歌使用玄黑、朱红、暗金和象牙白，强调黑漆凤鸟冠梳、楚漆器色感、一体式袖缘尾端与祭祀氛围。
- 九歌不得复用敦煌妆发、莲焰冠、蓝橙双层飘带和飞天定式，避免成为“敦煌换背景版”。
