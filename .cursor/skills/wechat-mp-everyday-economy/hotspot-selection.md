# 选题：新变化与普通人的关联

以北京时间确定检索窗口。优先找过去 72 小时发生或公布的新变化；不足时扩至七天。更旧事件只有出现新的数据、裁判、执行结果或明确后续，才作为“新”候选。报道刊发日、事件发生日、政策施行日分别记录，不混用。

选题时先逐一核查微博、百度、小红书、抖音、豆瓣、知乎的当日公开热榜或热门讨论页，以及上海、深圳、广州可获得的当地榜单；记录查看时间、榜单原始链接、候选词条、名次或可见互动。平台原榜优先，镜像和归档须注明来源与快照时间。平台不提供公开榜单、需要登录或页面无法读取时标“未取得”，不能把搜索命中、旧快照、直播销售榜或当地媒体首页冒充当日热榜。六个平台和三地都应有核查状态，缺口在候选交付时公开，不以“逐榜核查完成”概括未取得的部分。

再查政府、监管、法院、统计机构、企业或机构原始公告及有采访和明确出处的媒体报道，核实榜上议题的事实。榜单和评论只判断讨论范围，不代替事实来源。搜索结果数、同源转载数和 A 股市场热点，不是社会讨论热度的精确量尺；单个平台上榜也不能直接推断跨平台热度。

硬门槛：事件、日期、地点、可核验来源、受影响的人群，以及一个能解释收入、支出、时间或选择的新增信息。缺一项就标记证据缺口，不为了凑满三条而补题。

优先级由可见讨论信号、生活相关度、证据完整度、解释空间共同决定。费用只是生活相关度的一种，不天然高于劳动、住房、交通、消费或公共服务。教育选题仍须遵守现有公众号选题地域约束及用户最新选择；本 Skill 不另造城市白名单。

每组最多三项、推荐一项。每项用简短字段交代：事件、事件日期、地点、原始来源链接、受影响人群、钱或选择怎样变化、可见讨论信号、读者可能转给谁、可讨论的问题、仍缺什么证据。不可计算的“热度指数”不写数字。若只有一项合格，就只给一项。

交付前附一行覆盖记录：微博、百度、小红书、抖音、豆瓣、知乎和上海、深圳、广州当地榜，分别标“原榜已查／有时间戳的镜像或热门页／未取得”。只有媒体首页时注明“本地新闻扫描，非当地热榜”。若覆盖不全或某题无可见讨论信号，只称“近期可研究议题”，不称“热榜筛出”或“高热度”。

用户选定后再转入 [证据与算账](evidence-and-accounting.md)。用户直接要求写已点名事件时，不必重复候选环节。
