# 写作范式库

更新：2026-10-27。首批建立掌故短篇、历史奇案、人物对照三类。范式说明怎样依据材料组织文章，不提供万能句式，不承诺传播效果。共通表达和实际回读以[中文写作基座](../中文写作基座.md)为准，事实来源、平台格式和制作授权继续走当前专题。

## 使用入口

| 当前任务 | 读取 | 选择前提 |
| --- | --- | --- |
| 用一件事呈现人物处境或关系 | [掌故短篇](掌故短篇.md) | 有相对完整的一件事，不只剩一句传闻或评价。 |
| 讲异常事件、处置经过或追查过程 | [历史奇案](历史奇案.md) | 至少能区分事件经过、当时说法与后来的查证。 |
| 把两个人的具体经历放在同一维度比较 | [人物对照](人物对照.md) | 两边均有相应材料，差别不是靠删掉一边的背景造出来。 |
| 查原12个模板的条件、风险及归属 | [十二类选题检查](../../小人书选题与身份揭秘模板.md) | 保留H01—H12编号；它们是选题特征，不能代替本库的文章组织。 |
| 看本轮参考了哪些稿件、改稿意见与检查 | [建设与核对记录](建设与核对记录.md) | 案例用于结构学习，历史事实进入新稿仍须回源。 |

先读基座和本次命中的专题，再按需要查看适配案例；不要求每篇选定一类范式，不默认把三类和十二个标签全套一遍。

## 起稿时怎样使用

确有借鉴时，在已有结构稿中简记借鉴之处及本篇依据，不照抄参考文章的段落顺序、句式或结尾。用户只要求正文时，不把这些内部说明一并交付。

结构交代主要内容及其关系，不为每个段落预设固定功能，也不以“制造反转”等效果词替代内容。页数、字数和画面数由材料及当前载体决定，不从范式反推必须凑满几段。无匹配范式时按材料另排结构，不硬归类。

原十二类可以作为一个或多个选题标签。例如一封遗嘱可对应H12，但正文未必需要临终现场；一段人生转折可对应H10，但不必藏到最后揭晓。人物对照也不必领取一个H编号才成立。

## 扩充与维护

先收真实改稿，再归纳可复用的方法。案例注明版本、具体问题、修改理由、事实状态和不能推广之处；只有用户明确认可的文字才记作用户正例。交付过、文件名写“已确认”和审稿通过，均不能证明每一句都可无条件复用。

新范式需要有不同于现有三类的文章任务，并有足够材料演示完整展开。换一个题材、开头或钩子，不自动算一种新范式。共同要求改基座，专题差异留专题，选题标签细节留原十二类文件。
