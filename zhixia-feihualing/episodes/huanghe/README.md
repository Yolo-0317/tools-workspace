# 《黄河之水天上来》10 秒舞蹈诗境

## 取句

- 李白《将进酒》：黄河之水天上来，奔流到海不复回。
- 形式：Seedance 2.0，10 秒，9:16 竖屏，电影级高写实 CG，一镜到底。

## 诗境与舞蹈

高山峡谷、赭黄色层理河滩、金褐色黄河、云间落差与逆光河雾构成真实诗景。栀夏在第一秒内完成强起势，沿河岸横向疾行，以两次换重、跨步翻身、行进旋转、跨步提身和持续推进发展中国古典舞身韵；长袖扫过近岸浪花，带起真实河雾与逆光水滴弧线。

摄影机贴近水面沿一条侧向平行跟拍主路径运动，在行进旋转时沿原方向短暂加速，在高潮时顺河抬升拉开，揭示云间高山与奔涌黄河。本集采用无定式结尾：9.700 秒前栀夏始终保持清楚主动作，最后一帧仍在舞动与镜头运动中直接结束。

阿砚位于侧后方安全岩石，不参与舞蹈、不安排特写；每次出现均保持足底至耳尖约 40 厘米、笔锋双耳、四足、单尾、朱砂额印、暖金纹样和向外呲出的纸纤维毛束。
