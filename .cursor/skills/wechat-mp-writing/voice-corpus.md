# 写稿语料库（默认加载，勿每次翻外链）

> **定位**：账号级 **用词、语气、句型** 真源。写/改 `hotspot`、`discussion`、`tv_review` 讨论稿时 **先读本文件**，再读稿型补充（如 [voice-corpus-dianji.md](voice-corpus-dianji.md)）。
> **不必** 每次写稿读 `reference-reading-sop` 或 `sources.json`；那些只在 **扩容语料库**（季度/你丢新对标文）时用。
> 禁词硬表仍见 [anti-ai-voice.md](anti-ai-voice.md) · [social-commentary-voice.md](social-commentary-voice.md)。

## 一、口吻一句话

**刚看完、跟朋友说「戏里/新闻里到底怎么回事」** — 有细节、有判断，不像通稿、不像观后感、不像上课。

人格边界：[account-role-card.md](account-role-card.md)

---

## 二、句长与段

| 规则 | 做法 |
|------|------|
| 段长 | 多数 **1～3 行**；关键事实可 **单句成段** |
| 句长 | 单句尽量 **≤35 字**；摆事实链可用一句稍长，下一句立刻缩短 |
| 节奏 | **短短长**：两个短句后接一个稍长事实句，禁止连续四句同长 |
| 空行 | 场景换、人物换、时间跳 → 空一行 |
| 禁止 | `>` 小标题、`一、二、三`、连续 5 段同样句长 |

---

## 三、开头（首段 50～80 字）

**公式**：`时间/场合` + `谁` + `一个可见动作或结果` — 不要先讲节目立意。

| 可用句型（仿结构，勿整句照抄） | 示例骨架 |
|-------------------------------|----------|
| 播出锚点 | `{月日}，{平台}播了《…》第一集，讲的是《…》。` |
| 镜头先入 | `开头没先讲{课文/背诵}，一上来就是{人}在{做什么}。` |
| 冷事实 | `{谁}在{地名}待了{多久}，只为把{物件}留下来。` |

**开口就用（口语）**：一上来、开头没先、片头还在、报道里、史料里、网上有人提
**开口禁用**：节目旨在、正片还没、列篇目、戏里先出来的是、镜头先落到、刷到这条、值得注意的是

---

## 四、中段：事实怎么写

1. **数字落地**：用阿拉伯数字（2021年、28篇、6年），禁「二十八」「二〇二一」
2. **地名人名**：章丘、咸阳、国图 — 一次出现就够，不堆履历
3. **引语**：戏里台词或嘉宾一句，**≤30 字**，不连成专家课
4. **转述来源**：`报道里写`、`史料里记`、`蒙曼在访谈里提过` — 禁「专家指出」「据悉」连发
5. **代价**：写 **动作**（不让烧、掘墙取出、走不动路），不写「舍命护书的史诗感」

---

## 五、收束（末段 1～2 句）

| 类型 | 骨架 | 禁用 |
|------|------|------|
| 物件停笔 | `{物件}后来在{地点/柜子/课本}里。` | 读者你选择、值得深思 |
| 生活账 | `和平年月{小事}，顶多{具体代价}；和{古人}比，账已经轻/重了。` | 问心无愧、强烈推荐 |
| 留白 | 一个画面停住，不总结全文意义 | 总而言之、综上所述 |

## 六、用词表（写稿时默查）

### 6.1 叙述层 — 多用

| 类别 | 词/短语 |
|------|---------|
| 时间 | 大年初一、当晚、乱世里、天下平定后 |
| 动作 | 塞进、掘出、口传、整理、护着、走不动 |
| 来源 | 戏里、报道里、史料里、访谈里、网上有人提 |
| 画面 | 玻璃柜、手机屏、竹简、残卷、土墙 |
| 轻判断 | 离不开、绕不开、顶多多花、说白了（**至多一处**） |

### 6.2 叙述层 — 禁用（通稿/AI/观后感）

| 类别 | 禁词/禁句 |
|------|-----------|
| 煽情 | 鼻头一酸、泪流满面、热泪盈眶、震撼、直击心灵 |
| 通稿 | 旨在、呈现、彰显、诠释、声情并茂、创新之处 |
| 观后感 | 强烈推荐、值得一看、问心无愧、太精彩了、演活了 |
| 抬格 | 史诗感、厚重感、文化火炬、精神内核、弦歌不辍 |
| 元叙述 | 节目告诉我们、它想让你、这集想让你感到、深度所在 |
| 作文 | 一方面…另一方面、不仅…而且…（连用）、总而言之 |
| 行业报告 | 风向松绑、与其说不如说、一拨另一拨、对X来说 |

### 6.3 剧评腔 — 少用或换

| 少用 | 改用 |
|------|------|
| 戏眼、意象 | 重点在、留到最后的画面 |
| 耳目一新 | 算新鲜、少见 |
| 拍得很直 | 演出来了、立住了 |

## 七、节奏金样（学句长，勿抄内容）

> **说明**：下面是 **4 种写法芯片**（冷事实 / 镜头开头 / 代价链 / 物件收束），不是「一篇只能写 4 段」。
> 典籍专栏等短札正文见 [voice-corpus-dianji.md](voice-corpus-dianji.md) **5 段骨架 + 5 段金样**；社会热点深评通常 **6～9 段**。

### 金样 A · 冷事实连打（社会/话题）

```text
前天，青岛大学死了一个人。
是一个宿管大爷，热死的。
```

### 金样 B · 播出+镜头（文化短札）

```text
2021年大年初一，央视播了《典籍里的中国》第一集。
开头没先讲怎么背，一上来就是伏生护书。
```

### 金样 C · 代价链（事实句长短交错）

```text
天冷想烧简取暖，妻子不让。
儿子为护书丢了命。
天下平定后他掘墙取出竹简，损毁过半，整理得二十八篇。
```

### 金样 D · 物件收束

```text
墙里掏出来的竹简，后来在国图玻璃柜里。
```

## 八、写后自检（30 秒，全文 grep）

1. 首段 50 字内是否 **人+事/镜头**？有无「旨在」「值得注意的是」？
2. 全文「不仅/而且/一方面/另一方面」≥2 次？删改。
3. §6.2 禁词任一条命中？改。
4. 末段是否在 **说教或升华**？改物件或生活账。
5. 读出声像不像 **微信群转述**？不像就改。
