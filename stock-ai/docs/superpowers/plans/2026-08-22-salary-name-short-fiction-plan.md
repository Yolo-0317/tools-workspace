# 《工资到账后，多了一个人的名字》写作计划

> **For agentic workers:** 按作品设计逐场完成正文；本任务由当前 Agent 内联执行，不分派子任务。

**Goal:** 完成一篇约 3000—4500 字、可直接用于公众号的原创都市现实轻悬疑单篇小说。

**Architecture:** 九场线性有限视角叙事。工资摘要制造谜面，两次反转分别改写款项来源与周岚动机，最终以林澄主动告知当事人并提交书面异议回答核心行动问题。

**Tech Stack:** 中文短篇小说；公众号短段落排版；人工一致性与悬念公平性检查。

## Global Constraints

- 开篇明确标注“原创虚构”。
- 前 100 字出现异常与风险。
- 不影射真实企业，不使用超出人物能力的取证手段。
- 两次反转均须有前置线索。
- 结局解决事件，不解决所有人的人生。

---

### Task 1: 完成开篇谜面与第一次调查

**Deliverable:** 从工资到账写到林澄确认周岚的名字仍存在于工资与审批记录。

- [ ] 用工资短信、转账摘要和退款动作建立异常。
- [ ] 通过周岚的警告增加职业风险。
- [ ] 插入两人因异常考勤证明决裂的必要旧事。

### Task 2: 完成两次反转与核心选择

**Deliverable:** 揭开身份拆分成本、临时帮助老员工及安排失控的完整因果。

- [ ] 第一次反转解释钱并非周岚私人转入。
- [ ] 第二次反转解释周岚最初参与的动机。
- [ ] 让受影响员工表达与林澄不同的现实利益。

### Task 3: 完成后果与全文质检

**Deliverable:** 林澄作出选择，事件获得处理，关系与生计留下余波。

- [ ] 林澄先告知当事人，再提交异议与离职。
- [ ] 不安排所有人理解或感谢她。
- [ ] 检查人物信息权限、金额、时间和线索回收。
- [ ] 删除作者议论、连续金句和解释性对白。
