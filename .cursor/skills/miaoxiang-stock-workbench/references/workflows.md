# 妙想六技能研究工作流

## 每日选股

1. 默认使用 [V3五因子规则](v3-rules.md)：[预算与缓存检查](call-efficiency.md) → 妙想预筛 → mx-data日线及完整性核验 → 仅在输入适配已验证时执行原V3计算（当前适配待验证） → 资讯/财务复核。此前成交额Top5查询只是接口测试，不是默认策略。
2. 确认已完成交易日和数据截止时间；V3默认规则无需重复询问持有周期。用户明确自定义筛选时按原意执行，并与V3结果分开标注。
3. 按V3数据协议核对单位、复权、历史覆盖和字段日期。缺项列待核验，不虚构分数，不用同名平台指标替代公式。未计算全预筛集合时明确只是局部复核。
4. 对通过技术条件的重点标的，用查数与资讯检查财务和事件风险。专项按用户意图调用，复核结果不擅自加减V3技术分。
5. 输出V3技术条件通过、待核验与未通过项；明确筛选范围、五项分数、原排序依据及风险。允许零候选。这不是交易资格或收益验证。

## 个股分析

短线综合诊股必须按 [短线覆盖与核验](short-term-diagnosis.md) 检查市场、板块、资金龙虎榜和事件风险；优先复用已核验缓存，未返回项目不强行补齐。

- 先确认名称、代码、市场；基础数据和资讯检索形成事实层，不调用本地 diagnose_stock 或 OpenCLI；所有研究数据遵循[唯一来源规则](skill-only-data.md)，不读MySQL或直接抓取网页。
- 单项行情、估值、财务、资金数值用 `mx-data`；新闻、公告、政策和研报用 `mx-search`。
- 综合分析先读数据和资讯，再按用户关注维度分析，不强制查询每一维度。
- 资金分析核对资金口径和日期；消息分析区分已发布事实与影响推断；机构观点标明机构、报告日期、预测期和分歧，不把目标价当成确定预测。
- 财报解读先确认已发布报告期，使用 mx-data 取同口径数据、mx-search 核对原公告。指定期间不存在就标记缺失，不暗中回退。
- 技术指标仅基于Skill返回数据；V3须先完成mx-data输入适配及完整性验证，当前未完成，不复用旧来源得分。各专项结论由工作台基于事实生成，不冒充已卸载技能的原始报告。

## 板块研究

用 mx-search 检索当前事件和政策，用 mx-xuangu 查询板块成分，用 mx-data 比较同期行情与财务指标。市场热点需要明确时间范围和来源，不能把一次搜索结果称为全市场热度排名。缺少同口径数据就不做强弱排序。

## 自选与模拟组合

- “查看我的自选”：mx-zixuan 查询，展示返回数量、行情日期和完整名单；不添加或删除。
- “分析我的自选”：先查询清单，再以这些代码作为研究范围；可以复用同日已保存清单，明确时间。V3结果只代表自选范围，不是全市场筛选。
- 自选接口没有持仓成本和数量。明确查询模拟持仓/资金/委托时使用 mx-moni 只读端点，账户未绑定时报告原因；不将模拟持仓当实盘。
- 明确要求增删自选、模拟交易或撤单时，先核对对象、方向、数量、价格等请求参数，缺少关键参数再询问，不由V3候选推导交易授权。

## 社区

mx-poster 面向东方财富社区。只在用户要求社区内容/账号操作时加载；公众号写作不自动路由为社区发布。研究结果不触发自动发帖、点赞、评论。发布或互动必须是用户明确要求的动作，使用前核对内容及上游自动互动选项。

## 证据质量与降级

- 记录来源、实体、指标口径、报告期间/事件日期、采集时间和原文链接；采集时间不能代替数据时间。
- 核对事件日期与发布时间。历史回顾作背景；正文将历史事件误写为当前时，标记“时间冲突 / 待核验”，不能作为当日催化。用妙想资讯搜索追溯原始来源；不能核实就排除该证据。
- 同源转载及同一公告去重；资讯、热点和专项重复引用同一事件不算多份独立证据。未提供原始出处的模型报告只能作为外部解读。
- 当前热点/报告不得用于历史回测；不宣称具备历史时点完整性。过期行情不作现价，财务数据标记对应季度或年度。
- 新发现重大风险但尚未核实时，标记风险待复核，不给肯定性执行建议。
- 退出码为零仍检查正文非空、实体、时间与业务错误。鉴权失效停止该依赖，不输出 Key；网络异常最多重试一次，业务拒绝不重复请求。
- 依赖缺失或失败时报告未完成项；没有妙想结果就不伪造名单，不回退旧股票 Skill。
