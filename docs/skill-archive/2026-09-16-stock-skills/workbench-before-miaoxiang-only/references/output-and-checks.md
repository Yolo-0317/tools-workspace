# 输出契约与验收

## 每日选股报告

1. **结论**：目标交易日、数据截止日、规则版本、运行模式、正式候选数量。零候选是有效结果。
2. **市场与板块**：本地 ALLOW/LIMITED/FREEZE 等实际状态、妙想热点背景；区分结构化事实和外部解读。
3. **正式候选 / 准备中观察 / 影子研究 / 妙想补充观察名单**：原样保持本地分层。列名称、代码、形态、入选或拒绝原因、主要风险和证据时间。不得把影子结果改称正式候选。
4. **条件计划**：仅展示本地已返回且符合其权限的触发价、入场上限、失效价、目标和最大股数；字段缺失写未提供，不自行估算。条件计划不等于成交。
5. **缺失与冲突**：数据过期、鉴权失败、正文为空、未核实公告、来源价格不一致。
6. **来源**：本地原始输出、妙想原文报告、核验原始公告链接。保留独立源文件，汇总不能替换原文。

## 个股分析报告

- 一句话结论，写明本地诊断是否完成、是否仅研究观察。
- 价格与时间：最近完整收盘、最新价及其时间、财报期间分别列出。
- 本地结构与计划：形态、风险门禁、已有冻结计划及其状态。
- 用户要求的专项：资金、消息、业绩、机构观点；标记已完成、缺失或不适用。
- 反证与风险：不只列利好；解释来源冲突，未经核实不写确定因果。
- 用户可检查的下一步条件及原始报告链接。

专项子 Skill 要求原文交付时保留原文主体/独立原文附件；工作台结论单列为“本地规则核对”，不得冒充上游结论。上游报告不能合成为新的未经验证胜率或买入评分。持仓任务如有项目专用投顾交付格式，结合其当前阶段呈现，但不扩大私人数据外发。

## 验收场景

| 用户请求或异常 | 预期行为 |
|---|---|
| 今天选股 | 当前完整日 + V1.3 + 一次热点 + 重点标的查数/资讯；不启动旧 combined 兜底 |
| 当前价是多少 | 直接 mx-finance-data，不运行全市场或读取账户 |
| 分析东方财富的买点、资金和公告 | 本地单股诊断 + 明确资金/消息专项，不跑宏观或全市场 |
| 综合分析东方财富 | 本地诊断 + 行情/资讯；不伪造明确机构或财报意图 |
| 看最新一期业绩 | 实体识别 → 已发布报告期列表 → 点评，未发布期间停止 |
| 两个板块谁强 | 本地轮动事实对比；妙想行业报告各自保留，不根据报告主观排序 |
| 妙想推荐股票但本地 SHADOW/FREEZE | 研究观察，不能升级 LIVE、股数或买入许可 |
| 本地零候选 | 如实报告零；补充观察名单不得填进正式候选 |
| 新监管风险与本地通过冲突 | 标记风险待复核、暂缓执行建议，保留原本地输出 |
| 本地日线/点时/账户缺失 | 列出缺项；外部研究不得补造正式资格或持仓仓位 |
| 妙想退出码零但空正文/业务错误 | 判定该项失败，不引用旧报告冒充成功 |
| 热点表时间为今日、正文事件年份相互矛盾 | 标记时间冲突并排除当日催化，原文核验前不采信 |
| 回放上月选股 | 只用当时可用的历史数据，不调用当前热点作为历史证据 |
| 每天都这样选 | 先明确是日度使用还是确实要求调度；不因 Skill 名称自动创建定时任务 |

## 验证边界

安装时验证结构、命令帮助、依赖和脱敏，并以公共查询检查连接。未运行全量选股、私有持仓诊断或完整十接口时必须明确说明；不把文档走查表述为已执行的真实交易链路测试。
