# 阿砚 Seedance 角色母板设计

日期：2026-08-28

## 目标

基于现有正式主卡 `assets/characters/阿砚角色卡高写实CG-v01.png`，制作一张可长期随 Seedance 视频上传的阿砚角色母板。母板与栀夏最终母板使用相同的档案卡结构，但采用阿砚专属的宣纸白、墨黑、暖金和朱砂红视觉体系。

母板负责锁定阿砚的全角度结构、表情范围、固定标记、纸墨材质和色彩，不承担具体视频场景或镜头构图的定义。

## 最终交付

- `assets/characters/阿砚角色母板高写实CG-v01-最终版.png`
- `assets/characters/阿砚角色母板-v01-Seedance固定说明.md`
- 更新 `docs/character-bible.md`
- 更新 `assets/inventory.csv`

母板采用单张竖版档案卡，分辨率不低于 1024×1536。生成图中的人物与结构由图像模型完成，所有中英文文字、标签和色值均由本地排版写入。

## 视觉体系

- 背景：温润宣纸白，保持干净留白。
- 标题与框线：浓墨黑为主，哑光暖金为辅，少量朱砂红用于强调。
- 角色材质：柔软细腻的宣纸纤维与纸墨绒羽，高写实 CG，不做硬质纸雕、陶瓷或塑料。
- 饱和度：比旧灰白稿更清透，琥珀眼、暖金纹和朱砂印具有清晰色彩分离，但不得使用霓虹色或高亮发光。
- 版式：严格复用栀夏母板的身份区、信息区、三视图、六表情、拆解区、细节区、色板和底部档案区层级。

## 母板分区

### 顶部身份区

- 主标题：`A YAN`
- 中文名：`阿砚`
- 副句：`墨痕落纸，它便从诗里醒来。`
- 英文副句：`WHEN INK TOUCHES PAPER, IT AWAKENS FROM POETRY.`
- 右上角：`No. 02 / CHARACTER PROFILE / 栀夏飞花令`

### 基础信息

- 角色名：阿砚 / Ayan
- 身份：原创东方墨灵
- 高度：约 9cm
- 结构：一头一躯干、两只笔锋耳、严格四足、唯一开放式 S 形墨尾
- 眼睛：暖琥珀色
- 固定标记：额间朱砂印、肩胸平面暖金云纹
- 性格关键词：聪明、独立、克制、好奇、试探顽皮

### 三视图

- 正面、严格右侧、背面。
- 三个视图同高、同尺度、脚底齐平。
- 每个视图必须保持双耳、四足、单尾。
- 侧视图清楚展示尾根与躯干的唯一连接点。
- 背面展示耳部淡墨过渡和墨尾飞白，不新增背部装饰。

### 六种表情

- 平静 / NEUTRAL
- 好奇 / CURIOUS
- 警觉 / ALERT
- 得意 / PROUD
- 惊讶 / SURPRISED
- 顽皮 / PLAYFUL

所有表情使用同一头部比例、眼型、额间朱砂印和耳部轮廓。不得生成星星眼、极端大头、普通猫式卖萌或人类嘴型。

### 结构拆解

- 头部与躯干轮廓。
- 两只笔锋耳。
- 两条前肢与两条后肢。
- 唯一开放式 S 形墨尾。
- 四足爪部与尾根连接关系。

拆解图必须是同一角色的结构参考，不得把阿砚拆成机械零件、折纸组件或玩具模型。

### 固定标记

- 额间固定形态朱砂红印记。
- 肩胸交界处平面暖金回旋云纹。
- 明确标记无铃铛、无项圈、无胸针、无悬挂饰品。

### 细节特写

- 暖琥珀眼。
- 额间朱砂印。
- 笔锋耳尖的宣纸白至深墨渐变。
- 纸墨绒羽与宣纸纤维。
- 暖金云纹。
- 墨尾浓墨、淡墨和飞白过渡。

### 色彩材质

- 宣纸白 `#F2EEE5`
- 淡墨灰 `#A9A5A0`
- 浓墨黑 `#252525`
- 哑光暖金 `#B99A5D`
- 朱砂红 `#B54432`

色板只负责建立色彩基准，不要求视频镜头中出现色板或母板排版。

### 底部档案区

- 角色介绍：阿砚是从墨痕与诗句间醒来的东方墨灵。它聪明、独立而克制，面对未知先观察、再试探，偶尔露出一点顽皮。
- 关键词：聪明独立、纸墨灵性、克制敏锐、试探好奇、守护诗句、轻巧灵动。
- 签名：`阿砚`，搭配一枚小型朱砂爪印。

## Seedance 输入规则

1. 默认第一张上传 `阿砚角色卡高写实CG-v01.png`，负责锁定整体身份。
2. 默认第二张上传最终母板，负责锁定全角度、结构、表情、材质与色彩。
3. 若平台只允许上传一张图，使用主卡；母板用于人工核对。
4. 视频提示词必须声明上传图片是原创虚构数字角色，只参考身份、结构与材质，不复刻档案卡布局。
5. Seedance 生成阶段永久禁止任何可辨识人声；对白、朗诵、字幕和标题全部后期制作。

## 严格禁止

- 多腿、多耳、多尾、分叉尾、断尾、尾巴与身体多点连接或肢体残影。
- 漂移为普通猫、兔子、狐狸、鹿或其他现实动物。
- 极端大头萌宠、星星眼、夸张卡通表情或人类嘴型。
- 黑脸、熊猫斑、整体纯黑、硬质纸雕、折纸、陶瓷或塑料。
- 铃铛、项圈、胸针、金属圆饰、悬挂结构或额外装饰。
- 朱砂印发光、变成宝石、火焰、花朵或复杂图腾。
- 动漫、二维插画、低清灰雾、霓虹色、文字乱码、水印和 logo。

## 验收标准

- 版式层级与栀夏最终母板一致。
- 三视图同高、脚底齐平，严格双耳、四足、单尾。
- 六种表情仍能识别为同一只阿砚。
- 主卡、三视图、表情和细节中的额间朱砂印形态一致。
- 无铃铛、项圈、胸针或其他未定义配件。
- 中文、英文、色值和标签无错字、无重影、无遮挡。
- 图像可正常解码，角色资产清单和角色母版文档引用正确。
