## 拍摄角度库

每条贴图先选择 `A编号`，写入行程连续性卡和每张图的提示词。前置自拍手机在画面外；镜前自拍才允许出现手机或倒影。角度变化不得改变脸型、五官比例或体态。

| 编号 | 镜头设计 | 使用边界 |
|---|---|---|
| `A01` | 正面微俯的前置半身自拍，视线看镜头 | 适合作为首图；脸部正面清晰，不做侧脸 |
| `A02` | 左侧 30° 三分之二侧脸，视线落向镜头外 | 每组最多一张；必须与 `A03` 或 `A01` 搭配 |
| `A03` | 右侧 30° 三分之二侧脸，回头看镜头 | 每组最多一张；与左侧镜头保持平衡 |
| `A04` | 镜前正面半身或全身自拍 | 同组可用一张；画面中可见手机，不用遮脸 |
| `A05` | 第三视角全身走路或站立，脸部朝前或轻转 15° | 适合展示完整穿搭；不做背影充数 |
| `A06` | 坐姿阅读或桌边半身，脸部 15° 正面偏转 | 适合物品与日常细节；不得重复 `A02/A03` 的侧脸构图 |

## 使用门禁

- 同一条贴图只用一个 `look_id`；跨天或明确换装时才选择第二套，并在文案中交代时间点。
- 新发内容不得重复最近 8 条贴图的 `look_id`，续集和“同一周末”除外；续集必须在文案中说明复用原因。
- 同一 `look_id` 的领型、颜色、材质、外搭、下装、鞋和主配饰必须一致。母图中的红色开衫、蓝色上衣不属于默认穿搭。
- 季节转换时新增一张胶囊衣橱表，再启用相应 `look_id`；禁止用厚针织或大衣混入夏季场景。
- 每条图文先在脚本中记录 `look_id + HA编号 + E编号 + J编号 + B编号 + S编号`，再写进生成提示词。相同服装可以通过不同包、鞋和主饰品变成不同的场景搭配，但不得在同一条里无理由跳变。
- 每组必须至少包含 1 张 `A01`、`A04` 或 `A05` 的正面构图；`A02`、`A03` 合计最多 2 张，且不得连续出现同一侧脸。最近 3 条贴图的首图角度不得重复。
- 每条再记录 `P编号 + 鞋编号 + 拍摄方式`。未交代换装时鞋履不得改变；书、包、杯子、防晒用品等已出现的物件必须延续颜色、尺寸和使用状态。首图与末图至少共享一个可辨识的物件或场景锚点。
- 瑜伽裤 Look 只用于拉伸、普拉提、步行、瑜伽馆往返或恢复场景；镜头展示动作、瑜伽垫和运动装备，不使用臀部/裆部特写、低机位仰拍或以身材为主题的文案。
- 先讲场景和搭配思路，再出现对应商品；产品没有真实信息或合作披露时，只展示风格灵感，不写亲测、回购或购买引导。
