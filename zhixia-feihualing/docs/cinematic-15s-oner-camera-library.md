# 15秒诗镜电影级一镜到底运镜库

## 目的

本库用于为每条15秒诗镜挑选一个独立的核心运镜母题。默认成片方向为“电影级全写实外观＋超现实镜头舞蹈＋15秒梦境长镜头”。目标不是模拟现实摄影器材，而是让观众从第一帧开始跟随镜头，在运动中不断获得新空间、新人物关系或新诗意信息，直到最后两句诗朗诵结束。

所有模板默认遵守：

- 栀夏与阿砚保留角色卡的身份设计，但最终使用电影级全写实外观，不复制角色卡的半写实渲染。
- 环境保持电影级写实摄影、自然镜头光学、真实材质与真实动态范围。
- 全片只有一个主要运镜逻辑，不堆叠多个互相竞争的视觉机关。
- 0至2秒建立视觉钩子，2至10秒持续推进，10至12秒完成空间揭示，12至15秒减速朗诵两句诗。
- 人物和摄影机的运动可以不遵循现实物理。栀夏与阿砚可以跟随镜头滑行、悬浮、踏光、借风上升或穿越诗境，但身份、形体、服装、毛发和材质必须逐帧稳定。
- 镜头轨迹必须清楚，空间变化必须具有视觉连续性。极致视觉效果来自镜头、人物、诗意元素与梦境空间的连续共舞，不以动漫化、严重运动模糊或廉价魔法特效制造刺激。

## 电影长镜头的可复用原则

ARRI对《1917》摄影系统的解析指出，稳定器的价值不只是平稳跟拍，而是让镜头在同一条运动中从低机位升到人物背后，再绕到人物正面；镜头因此能不断改变观众与人物的关系。ARRI还强调《1917》的运动始终服务于把观众带进人物旅程，而不是单独展示器材技巧。

美国电影摄影师协会对《人类之子》的回顾记录了另一种重要方法：镜头大体由人物行动驱动，但也可以暂时形成自己的路径，在人物之间、空间前后和新事件之间主动寻找信息。对15秒诗镜而言，这意味着镜头不能只是机械跟在栀夏身后，而要在运动中主动发现诗境。

《爱乐之城》的长镜头经验说明，演员运动与摄影机运动需要预先共同排练；《One Shot with Ed Sheeran》的摄影复盘进一步强调，真正的一镜到底依靠精确编排与少量清楚的视角扩展，镜头短暂离开人物是为了展示环境尺度，随后仍要回到人物情绪。

## 通用15秒节奏

| 时间 | 镜头职责 | 运动要求 |
| --- | --- | --- |
| 0—2秒 | 第一秒视觉钩子 | 从异常机位、强前景或运动中的物体直接开始，不使用建立性空镜 |
| 2—6秒 | 绑定人物行动 | 摄影机与栀夏、阿砚建立同向或反向运动关系，形成第一层视差 |
| 6—10秒 | 改变观看关系 | 至少改变一次高度、方向或人物前后关系，出现新的诗境信息 |
| 10—12秒 | 核心空间揭示 | 完成唯一一次高价值揭示，并从高速逐步减速 |
| 12—15秒 | 诗句落点 | 保留小幅滑行、升降或弧线，清冷女声朗诵两句诗，字幕后期叠加 |

## S级：超现实镜头舞蹈

S级模板是后续15秒诗镜的主方向。它们保留电影级全写实角色和环境材质，但主动解除现实重力、地理和摄影器材限制，让栀夏、阿砚与摄影机共同完成一段连续的梦境舞蹈。

### S1 镜头牵引—角色共舞—诗境展开

**梦境动作：** 摄影机沿一条清楚的三维曲线高速移动，栀夏与阿砚不靠真实步行追赶，而是像被镜头的运动势能牵引一样同步滑行、旋转、升降和改变站位。两者始终围绕镜头构图移动，镜头到哪里，角色与诗境便在哪里展开。

**15秒路径：**

- 0—2秒：摄影机从极近的诗意物象旁冲出，栀夏与阿砚已处于运动中，没有站立准备过程。
- 2—6秒：摄影机贴地或贴水前进，阿砚踏着水光、墨迹或落叶同步滑行，栀夏衣袖和裙摆形成第二条运动弧线。
- 6—10秒：摄影机连续升高并绕向人物正面；栀夏无需真实起跳，直接随衣袖、风或光线被托起，阿砚沿另一条弧线升到与她同一构图层。
- 10—12秒：镜头、栀夏和阿砚同时完成一次方向转换，完整诗境在三者运动间展开。
- 12—15秒：人物随镜头缓慢悬停或滑行，保持中近景与远景诗境同框，朗诵两句诗。

**角色展示：** 2至6秒展示运动中的全身与服装，6至10秒展示两者正面或三分之四正面，12至15秒兼顾角色与完整诗境。

**优势：** 角色不是被摄影机追赶的对象，而是镜头运动本身的一部分，最符合AI角色灵动、非物理的特点。

**风险：** 必须锁定栀夏与阿砚相对镜头的位置变化，禁止人物像贴纸一样固定在画面坐标上，也禁止滑行时脚部和身体被拉长。

### S2 衣袖与墨尾接力—空间连续变形

**梦境动作：** 栀夏衣袖和阿砚唯一墨尾轮流成为视觉承接物。镜头沿衣袖弧线进入第一层诗境，再沿墨尾延展出的墨迹转入第二层空间；每次空间变化都在同一运动方向上完成，不切镜。

**15秒路径：**

- 0—2秒：栀夏衣袖贴近镜头扬起，半透明丝织纹理后方已经出现正在移动的阿砚。
- 2—6秒：摄影机沿衣袖弧线绕过栀夏，衣料边缘自然延展成云、水、雾或月光，环境在写实材质中连续变形。
- 6—10秒：阿砚从变化后的空间中跃出，唯一墨尾贴近镜头形成第二条引导曲线；摄影机沿墨尾方向快速追随，墨色转化为山、竹影、江面或夜空。
- 10—12秒：栀夏从新空间另一侧随镜头重新进入构图，与阿砚共同完成诗境揭示。
- 12—15秒：衣袖和墨尾分别落在画面两侧形成框景，两位角色与诗境主体同时清楚可辨，朗诵两句诗。

**优势：** 每次转化都有角色自身元素承接，既展示形象，又让空间变化具有视觉连续性。

**风险：** 衣袖不能完全遮黑画面；墨尾必须始终只有一条，不能变成烟雾团、多条触手或普通猫尾。

### S3 微观物象—尺度跃迁—角色始终同构图

**梦境动作：** 从眼睛反光、灯芯、水滴、花蕊或叶脉的微观世界出发，摄影机连续拉开到巨大诗境；栀夏与阿砚不按现实比例缩小，而是随镜头完成优雅的尺度适配，始终保持可识别的画面占比。

**15秒路径：**

- 0—2秒：极近微观物象内同时包含栀夏与阿砚的倒影、剪影或真实身影，第一帧即建立身份。
- 2—6秒：摄影机快速后撤，微观纹理扩展成写实山川、江面、星空或林海；角色随镜头滑出物象，并保持中景比例。
- 6—10秒：摄影机沿空间纵深继续跃迁，角色踏着光线、云层或水纹与镜头同步移动，环境尺度不断扩大。
- 10—12秒：大全景达到最大尺度，但镜头通过弧线回靠让栀夏与阿砚重新占据画面三分之一以上。
- 12—15秒：角色与宏大诗境同框，清冷女声朗诵两句诗。

**优势：** 能在15秒内呈现极强的尺度惊喜，同时避免角色在大全景中彻底消失。

**风险：** 尺度变化必须由同一纹理或光线连续变形完成，禁止直接从眼睛跳切到航拍风景。

### S4 诗意元素领舞—角色追随—世界随之生成

**梦境动作：** 选择一个与诗句直接相关的元素作为领舞者，例如灯火、月光、落叶、雪、水、花瓣、笛声纹理或墨字笔画。摄影机跟随该元素移动，栀夏与阿砚灵动追随；元素经过之处，完整写实诗境实时生成或转化。

**15秒路径：**

- 0—2秒：诗意元素从镜头前高速掠过，摄影机立即被其带走。
- 2—6秒：元素穿过栀夏与阿砚之间，两位角色同时转身并以悬浮、滑行或踏光方式加入运动。
- 6—10秒：摄影机、元素和角色保持三角关系前进；元素经过之处连续长出竹林、江面、山川、雪地或灯火。
- 10—12秒：元素抵达最终诗境主体，镜头快速绕过它并反向面对栀夏与阿砚，完成最大揭示。
- 12—15秒：元素在角色身旁缓慢悬停，环境继续轻微生成或流动，朗诵两句诗。

**优势：** 诗句内容直接决定镜头运动，视觉奇观与诗意不会分离。

**风险：** 每集只能选择一个领舞元素；禁止同时让落叶、花瓣、月光、墨迹和灯火抢夺注意力。

## A级：优先用于正式生成

### A1 贴地追随—升至越肩—绕到正面

**电影动作：** 摄影机从人物脚边或阿砚视线高度开始，与人物同向快速移动；中段连续升到栀夏腰部、肩部，再从背后沿弧线来到两人侧前方；结尾由人物正面或三分之四正面揭示远处诗境。

**抓眼原因：** 15秒内连续改变高度、景别和人物关系，观众会自然等待“镜头升起来以后会看见什么”。

**15秒路径：**

- 0—2秒：贴地掠过落叶、水面、花瓣、雪或石阶。
- 2—6秒：低位追随阿砚与栀夏前进，前景形成高速视差。
- 6—10秒：镜头升至越肩高度，同时从背后绕向侧前方。
- 10—12秒：人物停步或转头，镜头越过肩线揭示诗境主体。
- 12—15秒：镜头继续做小幅弧线滑动，朗诵两句诗。

**适用：** 行路、寻声、追灯、登高、过桥、入林、临水。

**AI稳定性：** 高。运动始终围绕角色，不要求穿透实体，也不要求长时间遮挡角色。

**主要风险：** 升高太快会把低机位追随变成无人机升空；绕到正面时必须限制在90至140度，避免整圈旋转。

### A2 强前景穿出—绕角—纵深揭示

**电影动作：** 第一帧被巨大的真实前景占据，例如梧桐叶、门帘、岩壁、船帆、竹竿或飞雪；摄影机迅速从前景边缘冲出，贴着实体边界前进，在转角处改变方向，最终看到前方人物与完整诗境。

**抓眼原因：** 第一秒先隐藏空间，再突然释放画面；观众会跟着镜头寻找前景后面是什么。

**15秒路径：**

- 0—1.5秒：巨大前景擦近镜头，画面只露出局部光线和材质。
- 1.5—5秒：镜头从前景侧面冲出，栀夏与阿砚进入中近景。
- 5—9秒：镜头沿墙、竹篱、山石或门廊快速前进并绕过转角。
- 9—12秒：转角后出现此前被遮挡的灯火、江面、瀑布、月色或人物事件。
- 12—15秒：镜头沿空间纵深缓慢推进，朗诵两句诗。

**适用：** 发现型诗境、门后世界、山路转弯、竹篱寻声、洞口出景。

**AI稳定性：** 高。前景遮挡时间短，镜头路径容易用三张状态卡锁定。

**主要风险：** 不允许前景完全遮黑超过0.3秒，否则模型容易制造假切镜或重置角色。

### A3 正面倒退伴行—侧向脱离—回归人物

**电影动作：** 摄影机面对人物倒退移动，保持栀夏与阿砚正面表演；中段从人物前方斜向脱离，主动进入侧面诗境，再沿另一条弧线回到人物肩侧，完成新的空间关系。

**抓眼原因：** 观众先被人物表情绑定，镜头突然离开人物去寻找异常，随后又回到人物反应，信息持续更新。

**15秒路径：**

- 0—4秒：正面低位倒退，人物向镜头方向前进。
- 4—8秒：镜头横向脱离人物，贴近异常物体或诗境线索。
- 8—11秒：镜头绕过线索，从侧后方重新找到栀夏与阿砚。
- 11—12秒：人物视线与远处主体形成对应。
- 12—15秒：小幅向前滑行并朗诵两句诗。

**适用：** 对话开场、发现异常、风吹花落、月影、水声、灯火。

**AI稳定性：** 中高。角色在前段和后段都清楚出现，中间脱离时间不超过4秒。

**主要风险：** 镜头回归时容易生成第二组人物；必须通过中段场景卡锁定同一空间与人物位置。

## B级：通过短测试后使用

### B1 倒影起镜—贴水翻正—低位追随

**电影动作：** 从水面倒影或铜镜反射开始，借真实水波、镜面边缘或人物动作确认反射关系；摄影机沿反射平面翻正，随后贴水追随人物。

**抓眼原因：** 第一秒产生世界倒置的视觉误判。

**AI稳定性：** 中。必须先有精确首帧和翻正后的第二状态卡，否则容易把倒影复制成第二组实体角色。

**限制：** 只允许一次90至180度翻正，后续不得再叠加大环绕、升空和穿越。翻正过程控制在2秒内。

### B2 垂直俯冲—地面贴行—反向抬升

**电影动作：** 镜头从树冠、楼檐、船帆或山石上方快速下降，接近地面后转成水平贴行，最后沿人物动作重新抬升。

**抓眼原因：** 高度变化强烈，空间规模在短时间内被压缩并重新展开。

**AI稳定性：** 中。适合人物以背面或侧面出现；不适合俯冲中持续保持正脸。

**限制：** 俯冲段不超过2秒，落到地面后必须立即稳定；禁止从极高航拍直接冲到面部特写。

### B3 物体领航—人物接棒—诗境接棒

**电影动作：** 摄影机首先跟随一个真实运动物体，例如落叶、灯影、纸鸢、花瓣、流水或飞鸟；该物体经过栀夏与阿砚时，摄影机把注意力交给人物；人物再通过视线或动作把镜头引向最终诗境。

**抓眼原因：** 画面连续发生三次主体交接，观众会自然跟随视觉线索。

**AI稳定性：** 中。领航物必须形状简单、运动方向唯一，不能要求长时间保持精细小道具结构。

**限制：** 每次接棒都通过同框完成，不能让旧主体完全消失后凭空生成新主体。

## C级：实验性运镜

### C1 单次滚转环绕

摄影机沿人物外侧弧线移动时完成小于90度的滚转，并在2秒内恢复水平。视觉冲击强，但容易造成空间失重、角色畸变和动漫化，只适合无正脸或背影段落。

### C2 极近微观—快速拉远大全景

从眼睛、灯芯、水滴或叶脉极近景迅速拉到环境大全景。视觉差异极强，但AI模型容易在跨越多个景别时重新生成角色，只能通过已确认的首尾场景卡做4至5秒测试，不直接进入15秒正式生成。

### C3 多次遮挡接力

镜头连续穿过门框、树干、人物衣袖和其他遮挡物，模拟摄影机接力。真实电影可通过器材与人员交接完成，但AI视频容易在每次遮挡后重置人物与环境，因此不作为栀夏诗镜默认方案。

## 明确淘汰的伪高级运镜

- 无意义360度连续旋转。
- 从人物面部瞬间拉到极高航拍。
- 反复甩镜、闪白、黑场或完全遮挡制造假一镜到底。
- 摄影机没有任何视觉转化或承接便直接穿过人物身体、实体墙壁、竹竿或灯笼。
- 同时使用倒影翻转、贴地追踪、环绕、俯冲和升空。
- 全程匀速平移或缓慢推拉，却只靠“电影感”文字包装。
- 用廉价魔法粒子、速度线、动漫残影、无意义光束爆发或严重运动模糊代替镜头舞蹈和连续空间转化。

## 每集选型卡

正式写视频提示词前，先填写。运镜模板决定摄影机路径，[电影级特效提示词库](cinematic-vfx-library.md)决定空间与材质怎样变化；两者必须共享同一个视觉承接物，不得各自设置互相竞争的视觉机关。

| 项目 | 内容 |
| --- | --- |
| 本集诗句 | 两句固定原诗 |
| 核心运镜母题 | 优先填写S1、S2、S3或S4；写实动作型内容可填写A1、A2、A3、B1、B2或B3中的一个 |
| 主特效 | 特效库中的一个 Hxx |
| 辅助特效 | 零个或一个 Sxx |
| 后期增强 | 必要的 Pxx |
| 第一秒钩子 | 第一帧具体看到什么、镜头正向哪里移动 |
| 主运动路径 | 摄影机相对人物和场景的连续轨迹 |
| 角色共舞方式 | 栀夏和阿砚如何随镜头滑行、悬浮、踏光、升降或改变站位 |
| 视觉连续性 | 用衣袖、墨尾、灯火、月光、水面或其他唯一元素承接空间转化 |
| 唯一方向变化 | 在第几秒、因什么信息改变方向 |
| 唯一景别变化 | 从什么景别变到什么景别 |
| 核心揭示 | 10至12秒新出现的诗境信息 |
| 诗句落点 | 12至15秒的构图、轻微运动和朗诵节奏 |
| 角色稳定策略 | 哪些时段看正脸，哪些时段只看背面或侧面 |
| 三张状态卡 | 起始卡、转折卡、结尾卡的文件路径 |

没有完成选型卡和三张状态卡时，不进入正式15秒付费生成。
