# “一字三诗·风”视频设计

## 目标

制作《栀夏飞花令》第二条“一字三诗”短视频，以“风”为题，延续EP01“花”已经跑通的约20秒竖屏模板，同时增加角色逐步进入诗境的变化。

## 诗句

1. 沾衣欲湿杏花雨，吹面不寒杨柳风。
2. 风急天高猿啸哀，渚清沙白鸟飞回。
3. 长风破浪会有时，直挂云帆济沧海。

## 时间轴

| 时间 | 内容 |
| --- | --- |
| 0—2.5秒 | 栀夏与阿砚同框片头；阿砚报题“今日飞花令，风。” |
| 2.5—7秒 | 第一首诗；纯江南杏花雨与杨柳诗境，不出现角色 |
| 7—11.5秒 | 第二首诗；秋江峡谷，栀夏以中远景进入并抬头看逆风白鸟 |
| 11.5—16秒 | 第三首诗；沧海云帆，阿砚从墨色风纹中加入，与栀夏同框 |
| 16—20秒 | 新版片尾；风翻书页，阿砚说“风停了，诗还没停。第四句，你来接。” |

## 15秒主内容

主内容采用三段各约4.5秒的全屏诗境，加首尾过渡。变化顺序固定为：

1. 纯诗境抓人。
2. 栀夏进入诗境，动作明确但克制。
3. 阿砚加入，栀夏与阿砚同框，再制造一次视觉变化。

第二、三段仍以环境大景为主体。角色使用中远景，不遮挡峡谷、飞鸟、沧海和云帆，不退回书中微缩景观。

## 动作与转场

- 第一段：镜头穿过带雨杏花进入青石小径；细雨斜落，柳枝拂过水面。
- 第一至第二段：杏花雨被增强的风吹散，花瓣和水雾转为秋江薄雾。
- 第二段：栀夏站在临江高崖，向前半步，抬头看白鸟；衣袖和马尾受风轻动。
- 第二至第三段：白鸟掠过镜头形成遮挡转场，羽翼亮部化为海面反光。
- 第三段：栀夏扶船舷，阿砚从墨色风纹中显现并落在她身旁或船舷上；两者望向云层打开后的天光。
- 结尾：镜头追随风越过船帆，海雾化成水墨留白，方便衔接片尾。

## 视觉与连续性

- 9:16竖屏，720P，15秒。
- 清雅细腻的东方二维动画电影质感，明亮清透、低饱和。
- 风必须通过雨丝、柳条、衣袖、马尾、芦苇、白鸟、浪涛和船帆表现，避免抽象特效堆叠。
- 栀夏和阿砚严格遵循角色母版及上传参考图。
- 栀夏不正脸对镜、不做口型、不夸张表演。
- 阿砚从墨色风纹自然显现，不凭空闪现，不改变体型、颜色和结构。
- 不生成文字、字幕、水印、书本、书页、桌面、相框或画中画。

## 声音与字幕

- Seedance主内容不生成对白、旁白、吟诗或歌词，只允许自然环境声。
- TTS沿用固定音色：第一、第三句为栀夏“甜美娇俏2.0”，第二句及片头片尾为阿砚“假小子2.0”。
- 字幕沿用左上角双列竖排行楷；纯白实色；所有“风”字使用亮朱红；无背景色。

## 验收标准

- 2.5—7秒为纯诗境，不出现角色。
- 7—11.5秒只有栀夏进入，不提前出现阿砚。
- 11.5—16秒栀夏和阿砚同框，角色为中远景。
- 三段都是全屏诗境，没有书中微缩景观。
- 三段风力和空间尺度逐步增强。
- 转场连续，无硬切、闪白、人物瞬移和角色变形。
- 生成后根据实际TTS时长重新对齐场景，不直接假设提示词秒数精确。
