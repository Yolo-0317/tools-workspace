# 《凉州词》15 秒朗诵字幕成片设计

## 目标

将用户已验收为可用的《凉州词》15.093 秒 Seedance 原片制作为正式朗诵字幕成片。全片只由栀夏朗诵王之涣《凉州词》全诗，不增加阿砚对白、标题朗读、作者朗读或额外旁白。

## 输入与输出

- 原片：`/Users/huan.yu/Downloads/c1a9b75a-ca60-4dc8-aebe-b29ad8b4c7b0.mp4`。
- 单集目录：`episodes/liangzhouci-15s/`。
- 配音输出：`assets/audio/liangzhouci-15s-paced-v01/`，保留四句独立原始配音与合成元数据。
- 正式成片：`exports/liangzhouci-15s-subtitled-v01.mp4`。
- 成片保持原片15.093 秒、9:16 竖屏、24fps和现有“AI生成”画面标识；输出放大为1080×1920，不裁掉角色、黄河、关城或原有标识。

## 朗诵内容与表演

四句分别生成，使用栀夏角色母版中的固定音色。基础声线为18岁东方少女，清透、轻盈、明亮，带少量自然气声和书卷气；本集表演层增加苍茫、开阔和轻微坚定，但不改变成成熟女声、播音腔、戏曲腔或夸张古风吟诵。

1. `黄河远上白云间。`：起声自然，“黄河远上”舒展，“白云间”略向远景放开，不拖长。
2. `一片孤城万仞山。`：保持同一声线，“孤城”有空间感，“万仞山”稳定落下，不刻意悲情。
3. `羌笛何须怨杨柳。`：情绪略向内收，“何须怨”是温和劝解而非反问呵斥，不夸张拖腔。
4. `春风不度玉门关。`：随双角色飞起与关城揭示增加开阔和坚定感，“玉门关”清楚收住，不额外补话。

## 目标时间结构

采用四句独立生成、按有效人声边界裁切、句间留白后合成的方式。下列是目标窗口，实际起止以配音波形和听感复核为准，可在相邻留白内微调，不改变句序：

| 句子 | 目标窗口 | 画面关系 |
| --- | --- | --- |
| 黄河远上白云间 | 0.25—2.70 秒 | 栀夏开场起势，黄河和夕阳建立 |
| 一片孤城万仞山 | 3.60—6.00 秒 | 地面古典舞展开，山脊和关城可读 |
| 羌笛何须怨杨柳 | 6.90—9.60 秒 | 地面舞句后段和沙风蓄力 |
| 春风不度玉门关 | 10.70—14.40 秒 | 栀夏与阿砚飞起，玉门关揭示 |

若某句原始TTS明显超出目标窗口，先以清楚可懂为优先，再对单句做轻微时长调整；不通过压缩到赶字或大幅拉长来强行卡死时间码。第四句必须在14.6秒前完整结束，为成片尾部保留自然余韵。

## 字幕设计

- 沿用已验证的15秒全诗成片竖排诗句样式，不增加弹幕、对白气泡或横排说话字幕。
- 四句诗按实际有效人声时间分段出现，标点不进入画面。
- 第一句同时附“唐·王之涣”题署，后三句不重复题署。
- 字幕避让栀夏面部、主要舞姿、阿砚、黄河主河道和关城；结合实际帧面确定左右安全区，同一句不在显示期间跳位。
- 字体、颜色、描边、阴影和字号复用现有正式诗句字幕模板，确保在夕阳、山体和后段蓝天上都能清楚阅读。

## 混音

- 原片音乐和环境声完整保留。
- 仅在四段有效人声区间将原声平滑压低约5dB，句间留白恢复原声，压低与恢复使用短淡变，避免音量抽动。
- 人声居中，保持清楚但不压过配乐；最终成片不削波，整体峰值不高于 -1dBFS。
- 不改变原片时长，不删除原有沙风、衣袖与飞行环境声。

## 验收标准

1. 全诗四句文字、句序和归属准确，只有栀夏一个人声。
2. 朗诵从开场分布至结尾飞天段，句间有可感知留白，不赶字，不超出视频。
3. 四段字幕与实际人声边界对齐，第一句含“唐·王之涣”，不遮挡角色与关键景物。
4. 原片画面不被重绘或裁掉，结果为1080×1920、24fps、约15.093秒的可播放H.264/AAC视频。
5. 人声清楚，原片音乐和环境声仍可感知，人声区间压音平滑，最终音频无削波。

## 执行边界

本设计只覆盖原片归档、栀夏四句全诗配音、字幕时间轴、混音和正式字幕成片。不重新生成 Seedance 视频，不修复原片已接受的飞行偏晚、天光跳变、关城变形、阿砚细节简化和发光沙轨，不制作封面或发布文案。
