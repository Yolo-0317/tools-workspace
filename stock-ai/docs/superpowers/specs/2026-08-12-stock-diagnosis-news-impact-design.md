# 个股诊断消息面影响设计

日期：2026-08-12

## 1. 目标与范围

为现有个股诊断增加统一的消息面影响层，同时服务以下两个入口：

1. 用户在聊天中点名股票时触发的单股诊断；
2. `scripts/analysis/analyze_holdings_v2.py` 运行的 MySQL 批量持仓诊断。

消息层负责采集、标准化、去重、时效判断、来源分级、产业链映射、影响评分、重大利空否决和三路径概率修正。它不替代技术面、资金、筹码、盘口、组合与风险门禁，也不得根据单一利好直接生成交易结论。

本期不实施短线选股双池。已确认的后续方案为：技术面候选池与重大新闻事件池并行，最终合并评分；该方案在个股诊断消息层完成后另行设计和实施。

## 2. 核心原则

- 两个诊断入口使用同一个消息影响服务，同一事件和股票必须得到相同结果。
- 利好有限加分，利空优先控制风险。
- 消息只能在限定范围内修正强、中、弱三路径概率。
- 经权威来源核实的重大利空可以否决新交易，但不能阻止已有持仓执行保护性减仓或退出。
- 固定产业链映射打底，AI只补充未知映射；所有AI补充必须保留证据、置信度和失效时间。
- 盘前、盘中未收盘的海外涨幅只视为半确认信号。
- 消息数据缺失时继续完成原诊断，并明确披露覆盖不足，不用模型常识补齐事实。
- 任何消息结论都必须带数据截止时间和来源。

## 3. 分层时效

| 消息类型 | 默认有效期 | 说明 |
|---|---:|---|
| 海外市场及公司事件 | 24小时 | 包括美股、韩国和日本公司的财报、指引、订单及股价共振 |
| 国内外政策及产业催化 | 3天 | 包括行业政策、资本开支、供需、价格和产业事故 |
| A股公告、业绩及监管事件 | 7天 | 重大持续性事件可由事件记录显式延长，但必须给出依据 |

超过有效期的事件不参与评分和概率修正，可在历史复盘中保留。

## 4. 数据流

```text
单股代码 / 全部持仓
        ↓
读取公司行业、概念和固定产业链映射
        ↓
按股票或合并主题获取候选消息
        ↓
去重、时效过滤、来源分级和事实核验
        ↓
标准化事件
        ↓
海外公司/产业 → A股板块 → 具体个股映射
        ↓
影响评分、否决检查和概率修正
        ↓
消息影响卡 / 批量影响摘要
```

批量诊断先合并持仓主题，再按主题采集一次并分发到相关股票，避免逐股重复搜索和同一事件重复计分。

## 5. 数据来源与降级

### 5.1 初期自动来源

- MySQL `macro_news_items` 中已有的财经快讯；
- 东财 OpenCLI 财经快讯；
- 东财 OpenCLI 国际指数，现有美股、恒生、日经基础上补充韩国主要指数；
- A股公司公告和可验证的公司级公开材料。

### 5.2 补充来源

- 聊天诊断期间通过联网搜索获得的官方公司、交易所、监管和投资者关系材料；
- 用户提供的文章正文或链接，经核验后转换为标准事件；
- 外部来源产生的标准事件写入事件缓存，供同日后续单股和批量诊断复用。

### 5.3 降级规则

- 自动海外公司新闻不可用时，输出“海外公司新闻覆盖不足”，该部分不评分；
- 只有标题、没有正文或发布时间的事件不参与正向加分；
- 未证实传闻可以作为待核验风险展示，但得分为零；
- 任一消息提供方失败不得阻断技术诊断；
- 后续海外公司定时监控作为独立增量，不阻塞本期共用评分与映射模块。

## 6. 标准事件模型

每条标准事件包含：

| 字段 | 含义 |
|---|---|
| `event_id` | 去重后的稳定标识 |
| `title` / `summary` | 标题与事实摘要 |
| `published_at` / `observed_at` | 发布时间与系统观察时间 |
| `source_url` / `source_name` | 原始链接与来源名称 |
| `source_tier` | 监管/公告、公司官方、权威媒体、普通转载、传闻 |
| `market` / `country` | A股、美股、韩国、日本及所属国家 |
| `subjects` | CoreWeave、Nebius、三星电子等事件主体 |
| `event_type` | 财报、指引、订单、资本开支、涨价、政策、监管、事故等 |
| `direction` | 正向、负向或中性 |
| `confirmation_state` | 已收盘/正式披露、盘前/盘中、待核验 |
| `valid_until` | 评分失效时间 |
| `evidence` | 评分与映射所依据的事实 |

标准事件映射到股票后生成：

| 字段 | 含义 |
|---|---|
| `transmission_type` | 直接供应、海外同业、需求验证、宏观联想 |
| `mapped_sectors` | 对应A股板块 |
| `relevance` | 高、中、低或无关 |
| `confidence` | 映射置信度 |
| `base_score` / `weighted_score` | 基础分与系数调整后得分 |
| `mapping_evidence` | 产业链关系证据 |
| `mapping_source` | 固定映射或AI补充 |

## 7. 来源分级

来源优先级从高到低为：

1. 交易所公告、监管文件和法定披露；
2. 公司官网、财报和投资者关系材料；
3. 权威财经媒体；
4. 普通媒体转载；
5. 社交媒体和未证实传闻。

对应来源系数：官方及法定披露 `1.0`，权威媒体 `0.8`，普通转载 `0.5`，传闻 `0`。

## 8. 固定映射与AI补充

固定映射保存在独立配置文件中，首批覆盖：

- AI算力、服务器、光模块、液冷、数据中心供配电；
- 半导体设计、制造、设备、材料和存储；
- 韩国存储芯片、面板和动力电池；
- 日本半导体设备、机器人和汽车；
- 原油、黄金、有色金属、航运和出口链；
- 电力、电网和储能；
- 医药及主要政策敏感行业。

固定映射需要支持海外公司、海外行业、A股板块和A股股票四级关系。AI补充仅在固定映射未覆盖时启用，并遵守：

- 必须输出传导链和原始证据；
- 置信度低于中等时不得参与正向评分；
- 不得把概念相似当成客户或供应商关系；
- AI补充结果进入当次事件缓存，不自动永久写入固定映射；
- 永久映射必须人工审阅后加入配置。

## 9. 评分规则

### 9.1 基础分

| 传导关系 | 单条基础分 |
|---|---:|
| 已确认的直接客户、供应商或重大订单 | ±8 |
| 两家以上海外同业共同验证 | ±5 |
| 行业需求、资本开支或价格趋势验证 | ±4 |
| 政策和宏观联想 | ±2 |
| 无证据的概念关联 | 0 |

加权分计算：

```text
加权分 = 基础分 × 来源系数 × 时点系数 × 相关度系数
```

时点系数：正式披露或相关市场收盘确认 `1.0`，盘前或盘中未确认 `0.5`，待核验 `0`。

相关度系数：高 `1.0`，中 `0.6`，低 `0.3`，无关 `0`。

### 9.2 去重与累计

- 相同事件的转载只保留最高等级来源；
- 同一事实被多家公司共同验证时可以构成同业共振，但不能把转载篇数当成验证数量；
- 同方向事件递减累计，避免新闻数量放大分值；
- 单股消息总分上限 `+12`，下限 `-20`。

## 10. 三路径概率修正

技术面、资金、板块、筹码和盘口先生成基础概率，消息层仅做修正：

| 消息总分 | 修正范围 |
|---:|---|
| +8至+12 | 强势路径最多增加10个百分点 |
| +3至+7 | 强势路径增加3至6个百分点 |
| -3至-7 | 弱势路径增加5至8个百分点 |
| -8以下 | 弱势路径增加10至15个百分点 |
| -2至+2 | 不调整或最多调整2个百分点 |

调整必须满足：

- 强、中、弱最终概率合计100%；
- 输出基础概率、逐路径调整量和最终概率；
- 不改变已有硬风险门禁；
- 正向消息不能把“禁止试错”直接升级为“可人工试错”；
- 盘前海外事件只能修改开盘预期，盘中动作仍需A股板块、量价和承接确认。

## 11. 重大利空否决

以下事件经法定披露、监管或公司官方来源核实后，可以将新交易结论降为“禁止试错”：

- 立案调查、财务造假或重大违法风险；
- 退市、停牌或交易资格风险；
- 重大合同终止或核心客户流失；
- 严重业绩暴雷或大额减值；
- 控股股东重大风险或债务违约；
- 产品安全事故或核心业务被禁止。

对已有持仓，否决结果转为保护性减仓或退出评估，不产生“因风险过大所以不操作”的错误冻结。

## 12. 输出契约

### 12.1 单股诊断消息卡

```text
【消息面影响】+6，中等偏利好，24小时内有效

核心事件 → 海外/行业传导 → A股板块 → 目标个股相关度

基础概率：强35% / 中45% / 弱20%
消息修正：强+5 / 中-2 / 弱-3
最终概率：强40% / 中43% / 弱17%

失效条件：相关海外股票收盘回落，或A股对应板块竞价、开盘不跟。
数据截止：时间；来源：链接或来源名称。
```

正文最多展示三条高相关事件，其他事件合并，避免增加执行负担。

### 12.2 批量持仓摘要

| 股票 | 消息分 | 方向 | 最相关事件 | 概率变化 | 有效期 |
|---|---:|---|---|---|---|
| 示例股票 | +6 | 中等偏利好 | 海外同业共振 | 强势+5个百分点 | 24小时 |

每只股票的详细部分引用对应消息卡，不重复列出整个新闻池。

## 14. 错误处理与可观测性

- 每个提供方独立记录成功、失败、采集时间和覆盖范围；
- 事件保留原始来源，不允许只有AI摘要而没有证据；
- 评分结果保留逐项计算明细，支持解释和复盘；
- 数据库不可用时允许单股诊断使用当次内存事件，但批量报告必须标注未缓存；
- 映射冲突时优先固定映射；AI结果仅作补充并降低置信度；
- 时间无法解析时不参与正向评分；重大风险进入待核验列表。

## 15. 测试与验收

单元测试至少覆盖：

1. 三类时效边界及过期过滤；
2. 标题不同但事实相同的转载去重；
3. 来源、时点和相关度系数计算；
4. 得分上下限及同方向递减累计；
5. 传闻正向得分为零；
6. 概率修正后合计100%；
7. 单一利好不能突破风险门禁；
8. 官方重大利空否决新交易；
9. 已有持仓仍允许保护性退出；
10. 无消息时原概率和原结论不变；
11. 单股与批量入口对同一输入结果一致；
12. 批量主题只采集一次并正确分发。

集成验收使用至少三组固定样例：

- CoreWeave、Nebius、超微电脑共同上涨映射国内AI算力链；
- 韩国存储厂商事件映射国内存储芯片链；
- 日本半导体设备厂商事件映射国内设备链。

每组均验证直接供应、同业验证、需求验证和宏观联想不会混淆，并验证盘前与收盘状态产生不同权重。

## 16. 非目标

- 不自动下单；
- 不以消息替代盘口二次确认；
- 不在本期构建完整产业知识图谱；
- 不在本期实施短线选股双池；
- 不因海外指数普涨自动给所有A股持仓加分；
- 不永久保存未经人工复核的AI产业链关系。
