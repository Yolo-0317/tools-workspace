# 公众号生活化返佣文案 Skill 设计

日期：2026-09-26。依据：用户认可洗洁精试稿的生活场景、轻包袱和口语节奏，要求沉淀为专门 Skill。

## 范围

新增 `wechat-mp-native-ad-writing`，负责「牛马也智能」返佣单品稿的正文写作和改稿，当前选品范围为零食与日用小百货。它不负责旧「简选小电」、自动选品、插入商品卡、写草稿或发表；这些环节由现有 `product_feature` 和公众号工程处理。

## 核心写法

先用一个读者能认出的生活小麻烦开场，让笑点从动作、物件或预期落差里长出来；让文章继续推进到可用的选择办法，再自然引出商品。商品推荐要明确，同时说明推荐所依赖的可核实规格与适用人群。结尾可回扣开头，但不为押笑点牺牲判断。篇幅随问题展开，避免短到只有四段广告，也避免用重复段落凑长。

口语靠句式与停顿，语气助词只在朗读时自然的位置出现，不按数量添加。第一人称可表达选品判断，不能伪装购买、使用或测试经历。轻包袱不嘲笑读者，不虚构人物引语、商品效果、价格优势或稀缺性。

## 衔接和验证

从 `wechat-mp-writing` 与 `wechat-mp-drafts` 路由到新 Skill；`product-feature.md` 保留选品、事实、结构化 JSON、独立广告标识和草稿门禁，并指向新 Skill 的写法。验证 Skill 格式、路由链接、与本次洗洁精稿的事实和文案门禁相容。
