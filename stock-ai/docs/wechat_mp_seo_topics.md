# 公众号摘要 SEO 与 #话题 操作说明

代码真源：`scripts/tools/wechat_mp_seo.py`。推草稿后终端 / 微信·飞书通知会打印 **推荐 #话题**。

## 你需要做什么（人工，约 1 分钟/篇）

API **不能**代勾选原创、也不能代加 `#`（须发布后在后台点）。脚本负责：

1. 摘要里自动嵌入搜一搜词（`enrich_digest`）
2. **标题**前 15 字嵌入稿型词（`enrich_title_for_search`，真源 `TITLE_SEO_*`）
3. **正文文末**（免责声明前）直接写入一行 `#A股 #收盘复盘 …`（`WECHAT_MP_HASHTAG_INLINE=1` 默认开，兼容 `WECHAT_MP_HASHTAG_FOOTER`）
4. 终端/飞书通知仍打印推荐话题（无「发布后加话题」说明段）

**你的步骤**（每篇发布时）：

1. 打开 [mp.weixin.qq.com](https://mp.weixin.qq.com) 草稿箱 → 预览
2. 点「发布」→ **勾选原创**（分类选 **财经**）
3. 发布成功后 → 文章右侧 **`#`** → 按通知/终端里的推荐，**原样选 3～5 个**（可微调 1 个为当日主线，见下表）

无需改 `.env`；定时批次推送后，飞书/微信消息里会带 `#话题` 行。

## 话题怎么选（原则）

| 原则 | 说明 |
|------|------|
| 先大后小 | 第 1 个尽量是 **`#A股`**，拉搜一搜大盘流量 |
| 再垂直 | 第 2～3 个用稿型词（收盘复盘 / 龙头战法 / 财经快讯） |
| 最多 5 个 | 微信限制；不要凑满无关热词 |
| 禁止 | 荐股、牛股推荐、必涨、内幕等（代码 `HASHTAG_BANNED` 会过滤） |
| 动态 1 个 | 龙头稿可把 **当日主线**（如电力、半导体）作为第 4 个，≤8 字 |

## 按稿型默认推荐（脚本输出）

| kind | 时段/槽 | 推荐 #话题（按顺序点） |
|------|---------|------------------------|
| `sector` | 收盘 `close` | `#A股` `#行业研究` `#产业链`（可选当日主线 ≤8 字） |
| `market` | 盘前 `pre` | `#A股` `#盘前观察` `#外围市场` |
| `market` | 午间 `midday` | `#A股` `#午间复盘` `#盘面速览` |
| `market` | 收盘 `close` | `#A股` `#收盘复盘` `#结构分析` |
| `news` | — | `#A股` `#财经快讯` `#宏观解读` |
| `top5` | — | `#A股` `#选股观察` `#技术面` |
| `dragons` | 盘中 `intraday` | `#A股` `#盘中龙头` `#情绪周期` |
| `dragons` | 收盘 `eod` | `#A股` `#收盘龙头` `#连板梯队` + 可选主线名 |
| `workspace` | — | `#开发者工具` `#量化自动化` `#个人项目` |

**交易日 19:00** 批次为 `sector` + `top5` + `dragons(eod)`；**休市日（周日/节假日）** 定时 `news` 一篇（72h、个股优先）；**周六** 不推。`market` / `workspace` / `temp` 手动；话题见上表。

## 摘要 SEO 词（自动写入，一般不用改）

| kind | 核心词 | 长尾短语 |
|------|--------|----------|
| sector | A股、行业研究 | 热点行业产业链与量价观察 |
| market | A股、收盘复盘 | 指数外围与结构判断 |
| news | A股、财经快讯 | Top10要闻逐条解读 |
| top5 | A股、选股观察 | 收盘信号与结构拆解 |
| dragons | A股、龙头复盘 | 情绪周期与龙头梯队 |
| workspace | 工具工作区、量化自动化 | 收盘入库到草稿的一条龙 |

## 标题搜一搜（自动，前 15 字）

| kind | 标题池优先词 | 缺省时前缀 |
|------|--------------|------------|
| sector | A股、行业、产业链、怎么拆/怎么跟 | `A股行业｜` |
| market close | A股、收盘复盘 | `A股收盘｜` |
| top5 | A股、选股、领衔、收盘信号、明日盯 | `{Top1}领衔N只！收盘信号出炉，明日盯啥？` |
| dragons | A股、龙头、情绪、怎么玩、还在榜 | `{情绪阶段}怎么玩？{龙头}{N}板还在榜` |
| news | A股、快讯 | `A股快讯｜` |

阅读量清单会检查 `title_search_seo`（`wechat_mp_traffic_checklist.py`）。

## 正文话题行（自动）

免责声明**上一行**，仅话题、无说明文字，例如：

```text
#A股 #收盘复盘 #结构分析
```

关闭：`WECHAT_MP_HASHTAG_INLINE=0`
