# 正常人怎么说（写后必跑，不是让你逐句改）

> **定位**：Agent 成稿后的 **自动改写层**，模拟「跟朋友发微信讲刚看的节目」。
> **不是** 让用户一句句抠；是 **你写完初稿 → 全文过本表 → 输出第二版**。
> 典籍专栏写前仍读 [voice-corpus-dianji.md](voice-corpus-dianji.md)；本文件管 **怎么把 AI/剧评腔整段翻成人话**。

## 一、改写算法（全文一遍，禁止只改用户点名的一句）

```text
1. 朗读测试：每段默读，像不会在群里说的话 → 整段重写
2. 主语换口语：戏里/正片/列篇目 → 节目里/电视里/那段演的是/没先讲课文
3. 删掉摄像头：镜头、呈现出来、让观众感受到 → 删掉或改成具体画面
4. 删掉当老师：节目旨在、这一集想、它先把…摆出来 → 删
5. 事实保留：数字、地名、人名、台词不动
6. **主语写清**：谁想烧、谁拦、谁死了——禁「妻子不让」悬空（读者不知道跟谁有关）
7. **禁对称连打**：「A不让；B死了」像作文排比 → 改成讲故事的一句接一句
8. 收束检查：末段禁「读者你选择」「把代价摊开」；用物件或一句生活账停笔
```

## 二、剧评腔 → 正常人（对照表，写后全文替换）

| Agent/剧评常写 | 正常人会说 |
|----------------|------------|
| 正片还没列篇目 | 没先讲课文 / 没大段背古文 / 开头没讲哪一篇 |
| 戏里先出来的是伏生 | 先讲的是伏生 / 一上来是伏生护书 |
| 镜头先落到伏生身上 | 删；直接写伏生做了什么 |
| 节目旨在… | 删整句 |
| 戏里演了 | 节目里演到 / 有一段演 |
| 古今对话是亮点 | 删；写撒贝宁带他去国图那段 |
| 倪大红将…演绎到极致 | 倪大红演得… / 倪大红把老头演得很真 |
| 让观众沉浸在… | 删 |
| 值得一提的是 | 删 |
| 据史料记载 | 史书写 / 《史记》里写 |
| 传递了…精神 | 删；写具体动作 |
| 这一集想让你感到 | 删 |
| 它先把代价摆出来 | 删；直接写下雪不烧简 |
| 天冷想烧竹简取暖，妻子不让 | 路上冷得厉害，一家人为取暖几乎动到竹简，妻子拦下来（**勿写伏生手痒想烧**——护书人设冲突） |
| 伏生手痒想把竹简烧了取暖 | **禁**；改：冻得受不了时妻子搂住竹简不让碰火 / 差点烧了简是妻子拦的 |
| 妻子不让；儿子为护书，死在兵乱里 | 禁对称连打；改成：伏生想烧取暖，妻子不干；后来兵乱里儿子护书，人没了 |
| 只是把代价摊开了 | 删；直接写具体场面 |

## 三、从好稿学的节奏（不是抄句子）

**《铁拳教育》金样**（`teach_you_a_lesson.body_core.md`）：
- 第一句给 **反差**（爽 vs 发虚）
- 每节一个判断，下面跟 **具体场面**
- 不用「节目旨在」

**《史记·儒林列传》伏生段**：
- 短句摆因果：藏壁 → 战乱出走 → 回家掘壁 → 失几十篇 → 齐鲁教授 → 晁错往学
- **无形容词堆叠**

**观后感/澎湃稿**（反例）：
- 鼻头一酸、史诗感、真的太精彩 → **禁止学**

## 四、典籍短札 5 段 · 正常人版金样（尚书，可仿节奏）

```text
大年初一，《典籍里的中国》播了第一集，讲《尚书》。很多人冲着撒贝宁、倪大红去的，不料先被伏生拽住：秦火烧书，他把竹简塞进土墙；天下大乱，背着书跑，老婆孩子都没护住，倒是护住了书。

伏生这名字，以前顶多出现在课本脚注里。节目把他这一辈子摊开讲：少时学《书》，秦末带着老婆孩子和竹简逃。路上冷得不行，伏生手痒想把竹简烧了取暖，妻子不干，说破了也不能动这批书。后来兵乱里，儿子还在护书，人没了。仗打完他回老家，从墙里挖出竹简，烂掉大半，理出来只剩二十八篇。汉文帝听说还有人懂《书》，想召他进京，伏生腿脚走不动了，朝廷派晁错到章丘，坐家里听他把《书》一句句口传。今天我们能读到的今文《尚书》，就是这一趟留下来的。

中间还演了大禹治水、武王牧野，古装大戏一通演。常被引用的那句「民惟邦本，本固邦宁」也出来了——邦国以百姓为本，本稳固了，邦国才安宁，大白话就是这样。蒙曼在节目里补了一句，「民本」这词，很早就见于这些篇章。不用背部名，听见这句也会愣一下：几千年前的竹简上，已经在问百姓算不算根本。

节目另一段，撒贝宁带伏生到国家图书馆。玻璃柜里是《尚书》，手机里也能搜到今文读本。伏生望了一会儿，说：书有了你们的传承，我放心了。史书爱写权力和战争；这一集问的是另一件事：字能不能传下去。

《尚书》出了名的难读，第一集也没让人当场背。下雪逃难那会儿，伏生宁肯冻着也不烧竹简——这事儿节目里讲得很细。如今弄懂几页古文，顶多花半小时；伏生那时是用老婆孩子的命换来的。
```
