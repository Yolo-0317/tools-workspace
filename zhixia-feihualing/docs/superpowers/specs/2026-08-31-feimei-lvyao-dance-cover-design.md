# 《飞袂绿腰》舞蹈封面设计

## 目标

为《栀夏·敦煌十六舞》07《飞袂绿腰》制作一张 1080×1920 竖屏正式封面。封面直接取自已完成的无字幕高清朗诵版，不调用图片生成模型，不重绘人物、服装、飘带或庭院场景。

## 底图

- 视频：`exports/feimei-lvyao-15s-voiced-v01.mp4`。
- 固定取帧时间：13.000 秒。
- 画面内容：第三高潮后的斜向深侧弓定格；栀夏位于画面中部，左臂横向舒展、右臂斜向高举，脸部三分之四侧面可辨，蓝橙飞袂形成一横一纵的大开幅线条。
- 青绿帷幔、暖金流苏、石质舞坪与秋叶保持原片冷暖层次，人物服装的孔雀蓝、琥珀橙、象牙白和旧金配饰清楚可读。
- 直接从 1080×1920 无字幕朗诵版精确截帧，不改变人物比例、构图、光影或色彩，不修复肢体、飘带连接和背景细节。
- 保留右下角原片已有“AI生成”标识。

## 文字层级与排版

- 左侧第一列小字竖排“栀夏”，作为系列角色识别。
- 左侧第二列主标题竖排“飞袂绿腰”，作为缩略图第一阅读信息。
- 左侧第三列小号题署竖排“唐·李群玉《长沙九日登东楼观舞》”。
- 主标题使用项目既有行楷字体，角色名与题署使用楷体。
- 主标题使用暖象牙白，角色名与题署使用稍暗的柔和旧金色；统一添加克制深色柔影。
- 字号、字距、列距和起始高度延续《雪袖白纻》《莲台天乐》的敦煌十六舞封面体系。

## 安全区

- 三列文字集中在画面左侧暗部，不遮挡栀夏眼睛、鼻口、头冠主体和躯干中心。
- 主标题允许覆盖少量左侧外围飞袂或横展手臂，以保证缩略图辨识度，但不得切断手掌轮廓。
- 题署不得进入人物脸部、承重腿、蓝橙飞袂交汇中心或右下角已有标识区域。
- 不增加横排副标题、英文、完整诗句、印章、边框、平台图标或额外装饰。

## 制作方式

1. 使用 FFmpeg 从无字幕朗诵版 13.000 秒精确提取一张 1080×1920 原帧。
2. 使用本地 Swift/AppKit 确定性渲染器叠加三列准确中文。
3. 输出 PNG，并检查尺寸、色彩模式、文字、人物可读性和右下角标识。
4. 将封面路径、取帧时间和制作方式登记到单集 README 与素材清单。

## 输出

- 正式封面：`exports/feimei-lvyao-dance-cover-v01.png`。
- 构建入口：`scripts/build_feimei_lvyao_dance_cover.sh`。
- 渲染器：`scripts/render_feimei_lvyao_dance_cover.swift`。
- 验收门禁：`tests/test_feimei_lvyao_dance_cover.sh`。

## 验收标准

1. 输出恰为 1080×1920、RGB 或 RGBA PNG，可正常解码。
2. 底图来自无字幕高清朗诵版 13.000 秒，人物姿势、比例、光影和场景与源帧一致。
3. 三列文字依次为“栀夏”“飞袂绿腰”“唐·李群玉《长沙九日登东楼观舞》”，无错字、乱码、截断或相互重叠。
4. 栀夏脸部、头冠、躯干、深侧弓和飞袂大开幅清楚；文字不遮挡五官和躯干中心。
5. 主标题在缩略图状态下清楚可读，允许覆盖少量左侧手臂或外围飞袂，但不切断手掌轮廓。
6. 右下角已有“AI生成”标识保留；不新增水印、边框、特效、装饰或平台元素。
7. 制作过程不调用图片生成模型，不重绘、补画、美化或修改栀夏与庭院场景。

## 不在本次范围

- 不修改朗诵字幕正式视频。
- 不制作横版封面、动态图封面或多套视觉方向。
- 不制作视频号发布文案。
