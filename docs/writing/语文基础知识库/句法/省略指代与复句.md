# 省略、指代与复句

## 省略：可以恢复，才有依据不说

“小林拿出书，翻到第三页，开始朗读。”三个动作由同一个人完成，不必重复三次“小林”。“谁来读？”“小林。”也能借上文恢复意思。这些省略不会自动造成成分残缺。

主体发生变化时，要给读者线索。例如只有“小林把书交给老师，读了起来”，读者容易把后一个动作接到小林身上。若材料说朗读者是老师，应明确为“小林把书交给老师，老师读了起来”；若材料没有交代谁读，应查材料，不能凭语感选一个人。

不能把所有短句都视为省略。“下雨了”作为非主谓句独立成立，并不需要从前文寻找一个被删掉的主语。

## 指代：找得到对象，还要排除竞争对象

“小林告诉小周，他明天来”中的“他”可能指两个人。上下文若已明确就不必改；若正需区分，可按材料在后半句直接写“小林明天来”或“小周明天来”，也可连同前后文重组。“自己”在复杂句中也可能需要辨明所指，不能当作消除歧义的通用替换词。

“这、那、此事、因此”可能指上一件事、一个判断或整段内容。回读时应能说出它实际指什么。两件事并列后只说“这让他很难过”，须核究竟是其中一件还是两件共同造成影响，不凭距离最近就认定所指。

“也”通常需要可对应的另一项，“又”常关联重复或追加，“仍然”关联状态延续。这种承接可以在上文，也可以由共同语境提供，不必每次另加一句铺垫。没有可恢复的承接时，才考虑删去或改写，不能统一禁用。

## 复句：先判关系，再选连接词

多个分句可以不用连接词，也能靠内容建立关系。选连接词是在明确原有关系，不能借它补造事实。

| 关系 | 自编例子 | 容易混淆的地方 |
| --- | --- | --- |
| 并列 | 小林整理书，小周整理信。 | 两项并列不自动表示先后。 |
| 顺承 | 他拆开信，读了起来。 | 先发生不一定是后事的原因。 |
| 递进 | 他读完了，还做了笔记。 | 必须确有追加信息，不能为节奏硬添“更”。 |
| 转折 | 雨很大，他还是出门了。 | 须有语境中的预期差异，不是任意两件事都用“但是”。 |
| 解说 | 他只带了一样东西：一本旧书。 | 后项说明前项，不必再补因果。 |
| 因果 | 因为道路封闭，车辆改道。 | 须有因果依据；同时发生或先后发生不够。 |
| 假设 | 如果明天下雨，活动就改期。 | 设想条件，不把假设改成已经发生。 |
| 条件 | 只有核对原件，才能确认这一处字迹。 | 必要条件不保证单靠它就足够。 |
| 目的 | 他把字写大一些，好让后排看清。 | 表达目的，不保证实际达成。 |

“只要A就B”通常把A表述为足以推出B的条件；“只有A才B”通常把A表述为B所必需的条件。两者不是仅有口吻差异，改换前必须核条件强弱。

“虽然……但是……”与“不但……而且……”组织的关系不同，不能为了避免重复随意轮换。不出现成对关联词也不一定有语病；要看关系是否清楚，是否有另一半悬空或范围错接。

## 分句层级和关联词的位置

“因为A，所以B；但C”可以是先建立A与B的因果，再让C与前面的判断转折。不要把一串分句看成每句只与最近一句相连，修改时可先用括号标出实际范围。

同一主体下，“小林虽然很累，还是读完了”容易连读；不同主体下，“虽然小林很累，小周还是让他读完了”更明确。常见位置规律服务于范围识别，不能只凭“虽然”在主语前后就宣布语病；应核整句表达了什么。

## 跨句承接

段落中可以延续人物、时间、处所或同一话题。若同时换人、换时间又换地点，只省略其中几个要素，读者可能错误地沿用上一句背景。补足必要变化即可，不需要把每句写成独立新闻导语。
