# 热点深评约 1000 字门禁设计

## 目标

将用户主动热点深评从 1800—2200 字调整为约 1000 字，减少为满足长度而重复论证，同时保留事实、争议、规则和普通人影响的完整闭环。

## 适用范围

仅调整用户主动 `hotspot` 的 DeepSeek 手工交接与 Agent 编辑终稿：

- DeepSeek 提示词目标改为 900—1100 字。
- Agent 编辑终稿正文去空白后至少 850 字。
- 超过 1100 字不直接拒绝；信息完整时允许保留，编辑阶段应优先精简。
- `hot_business`、影视、银发稿和暂停使用的旧自动热点生成链路保持原规则。

## 门禁与文档

统一修改以下真源，避免提示词与运行门禁互相冲突：

1. `wechat_mp_hotspot_article.py`：用户主动 Codex 热点默认最小正文长度降为 850，环境变量仍允许在安全范围内覆盖。
2. `wechat_mp_originality.py`：原创性评估使用同一 850 字默认下限，不再硬编码 1800 字。
3. `deepseek-writer-sop.md`、`hotspot-deep-review.md`、`wechat-mp-drafts/SKILL.md`：统一写明目标 900—1100 字、硬门禁 850 字。
4. 保持至少三个来源域、原创核心判断、双确认、抖音优先真实图片和禁止生成图等门禁不变。

## 验证

- 先补回归测试：849 字拒绝，850 字通过长度门禁。
- 验证原创性报告使用相同下限。
- 运行热点相关单元测试和 Skill 快速校验。
- 检查仓库差异，仅纳入本次字数门禁相关修改，不覆盖现有未提交改动。

## 非目标

- 不改变文章结构、配图数量、来源多样性或发布确认流程。
- 不修改热点商业稿及其他公众号稿型的篇幅。
- 不为满足 900 字而删减必要的事实限定或风险说明。
