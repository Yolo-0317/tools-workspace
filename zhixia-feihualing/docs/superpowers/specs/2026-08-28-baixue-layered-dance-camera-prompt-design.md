# 《白雪歌》层次舞蹈与动作触发运镜提示词设计

## 目标

重写《白雪歌送武判官归京》10 秒 Seedance 2.0 最终提示词，在只上传栀夏与阿砚两张原创角色母版的前提下，解决旧版舞蹈退化为左右挥臂、摄影机只有简单侧移的问题。诗句保持“忽如一夜春风来，千树万树梨花开”，互动保持阿砚“梨花？”、栀夏“是新雪。”，对白、朗诵和字幕仍由后期完成。

## 输入与稳定边界

- 采用基础级输入：图片1为栀夏角色母版，图片2为阿砚角色母版；不上传状态卡、场景图或动作参考视频。
- 提示词第一句声明两名角色均为本项目原创虚构数字角色，并立即完成图片映射。
- 栀夏首帧可辨认，0.5 秒内产生全片第一个清楚动作；面部保持正面或三分之四正面，不被衣袖和落雪遮挡。
- 阿砚保持约 40 厘米成年猫尺度、双耳四足单尾、朱砂额印、暖琥珀眼、暖金纹样与纸墨纤维结构，只作低复杂度回应。

## 舞蹈设计

采用层次版中国古典舞身韵短句，不写 Dxx、剧目名称、逐拍编舞或精确角度：

1. 起势：栀夏从稳定站姿开始，沿小弧线迈步，重心由后脚平滑移向前脚；目光先抬起，脊柱和胸腔随呼吸舒展。
2. 发展：她继续侧向弧移并完成第二次换重，身体由微沉进入提起，再转向覆雪松枝；双臂形成高低错落的连续圆弧，不在原地左右对称挥动。
3. 环境结果：身体转向和衣袖惯性带起轻风，低垂松枝释放真实粉雪；衣袖、裙摆和高马尾延迟响应，不主动制造魔法粒子。
4. 收势：栀夏向较高层次舒展后稳定落回双脚支撑，保持三分之四正面，双眼清楚，手臂形成不遮脸的不对称轮廓。

具体连接由模型在上述移动、重心、方向、高低层次、上肢与衣料反馈、起止状态内自然完成。

## 摄影机设计

全片只有一条侧向贴身跟随并逐渐拉开的主路径，允许两次由可见动作触发的小幅反应：

1. 开场以正面偏侧中全景建立栀夏脸部与完整身体，近处覆雪松针形成前景视差，阿砚位于她侧后方雪地。
2. 栀夏微沉并完成第一次换重时，摄影机同步小幅降低，保持脸、手臂、脚下落点同时可读；这是第一次动作触发反应。
3. 栀夏转向松枝、粉雪开始落下时，摄影机沿原主路径向侧后方有限弧移并逐渐拉开，让近景松针快速掠过、人物和远处雪林形成多层视差；这是第二次动作触发反应。
4. 结尾停在较宽的三分之四正面双角色构图，栀夏仍是主体，阿砚和覆雪树林清楚可辨，落雪只形成“梨花初开”的联想。

摄影机不绕到人物背后、不追逐雪粒、不无原因升空、不突然反向，也不把两次反应写成独立竞争运镜。

## 画面与声音

- 冬季清晨覆雪松林，侧后方暖金阳光、雪地冷色反光、真实积雪重量与接触阴影。
- 主体动作、松枝受风、粉雪落下和逆光显现形成自然因果；不出现真实梨花、巨大图形雪花、春季绿叶或魔法爆发。
- Seedance 只生成无人声音乐和环境声；不生成对白、朗诵、吟唱、字幕或精确说话口型。

## 验收标准

- 前 0.5 秒已建立栀夏形象和首动作。
- 舞蹈含弧线移动、两次换重、一次清楚的高低层次变化及稳定收势，不退化为原地左右挥臂。
- 摄影机主路径连续，两次反应均由画面内动作触发，存在清楚前中后景视差。
- 栀夏不换脸、不遮脸、不滑步；阿砚保持约 40 厘米原创结构，不变成普通白猫或幼猫。
- 全片始终是雪景，梨花只作为诗意联想。
