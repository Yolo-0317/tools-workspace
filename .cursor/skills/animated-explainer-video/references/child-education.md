# 儿童教育专题

用于儿童学习、绘本、语言、情绪、自控、游戏、习惯与亲子互动。默认面向家长时，讲清孩子行为及大人能做的事；儿童直接观看时另按年龄调整词汇、画面和信息量。儿童教育题材不代表观众一定是儿童。

## 选题与取证

优先具体家庭场景：反复读同一本书、玩同一种游戏、离开熟悉的人、听见了却没开始做事。吸引力来自准确指出熟悉但未理解的现象，不先给孩子贴标签。

每条关键主张记录：

| 字段 | 要回答的问题 |
|---|---|
| 主张 | 口播准备说什么？ |
| 来源及阅读范围 | 原研究、机构指南还是转述？读过全文还是摘要？ |
| 对象 | 年龄、样本规模、是否特定群体？未报告的写未报告。 |
| 条件与比较 | 实验任务、干预条件和对照是什么？ |
| 结果 | 实际测到了什么，持续多久？ |
| 限制 | 能否推到家庭场景？相关是否被讲成因果？ |
| 画面 | 如何展示，不增加来源未证明的机制？ |

年代早不代表经典研究失效；需要现行建议时核对当前机构指南。健康、诊断、用药、营养和安全问题按医疗专题取证，不用教育模板替代专业依据。

## 表达边界

- 区分可观察行为、研究结果与可能解释。保留“可能”等必要限定，不以去 AI 味为由删掉。
- 不把小样本学习任务推广为“提高智商”“开发大脑”“某年龄决定一生”，不让动画给未证实的机制背书。
- 年龄范围是适用条件，不是每个孩子必须准时达标的倒计时。避免“再不做就晚了”的焦虑开头。
- 不把单个行为诊断为某种障碍，不从动画故事推断真实孩子病因。需要专业评估的迹象按可靠指南描述，不提供自诊断量表。
- 可虚构说明用的家庭场景，不能声称是本人育儿经历、真实病例或真实实验。
- 建议与证据相称，给出可观察行动，不承诺照做就见效。不把“允许重复阅读”讲成“只读同一本最有效”。

## 示例：重复读绘本

《同一本绘本，孩子为什么总让你再读一遍？》可作为选题示例；调用 Skill 不等于批准制作此集。

- Horst 等，2011：[Getting the story straight](https://www.frontiersin.org/journals/psychology/articles/10.3389/fpsyg.2011.00017/full)。已有检索显示对象为三岁儿童；实际写稿时重读设计与结果，核对词语接触次数及比较条件。
- 作者面向公众的解释：[Read It Again!](https://kids.frontiersin.org/articles/10.3389/frym.2017.00030)。其中对熟悉情节与注意力的解释须与实测结果区分。

可以在相同书页中逐步突出词语与物件，表现重复和熟悉；不能画假脑扫描并宣称某脑区被激活。实际阅读建议另核对应指南，不能由一项词汇实验推出全部育儿做法。
