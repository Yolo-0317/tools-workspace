## 一、为什么卡在 ~80

| 因素 | 说明 |
|------|------|
| 三篇同批 | 一次通知内分流；单篇 127（周日 news）> 三篇合计 80 是结构常态 |
| 清单型财经 | sector/dragons/news 分享欲弱；难像情感号破圈 |
| 无推送红利 | 公众号消息 ~4%；必须优化 **标题（搜一搜）** 与 **头条完读（流量主）** |
| 粉丝基数 | 慢涨；阅读不会仅靠「坚持发」线性翻倍 |

**结论**：下一阶不是换赛道，是 **80 → 90–100** 的慢爬坡 + **每月 2–4 次 market 冲高**。

## 二、三档目标与动作

### 档 A：稳住 75–85（当前，1–2 周）

| 动作 | 负责 |
|------|------|
| evening 三篇照常；18:20 launchd | 自动 |
| news 标题 **热股名前置**（勿泛化「A股必读？」） | draft-ops |
| dragons 情绪词跟 eod（启动/高潮/退潮 + 还在榜） | 自动 + 人工扫标题 |
| sector 主线行业名 +「产业链怎么拆」 | sector-discovery |
| **每周只改一类**（标题 OR 开篇 OR sector 选题） | 运营官 |

**成功标准**：连续 5 个交易日阅读 **≥75**；流量主概览 **≥¥1.0/日**。

### 档 B：突破 90–100（1–2 月）

| 动作 | 预期贡献 |
|------|----------|
| 搜一搜：标题前 15 字含 **当日 Top 热股/板块名** | +5–15 读/日 |
| 头条 news 开篇 **2 句结论**（非快讯堆叠） | 完读↑ → 流量主曝光↑ |
| **大行情日** 同批加 1 篇 `market --edition close` | 单批 +20–40 读（偶发） |
| 搜一搜看板：对齐高点击搜索词 | 见 sousou-analytics-sop |

**成功标准**：周均阅读 **≥90**；概览入账 **≥¥1.5/日**。

### 档 C：冲高 130+（偶发，不作 KPI）

- 外部叙事日（油价、地缘、重磅政策）+ **market 复盘**
- 或 **Controlled** 群聊转发（321 模式）— 不可每日复制
- workspace/英语 **≤1/周**，作破圈补充，非主轴

## 三、大行情日识别（何时加 market）

**不是「等大 A 涨」**；满足 **≥2 条** 可在 **同一次群发** 加 market（仍 1 次通知）：

1. 上证/创业板 **|涨跌幅| ≥1%** 或明显放量  
2. 涨跌家数/涨跌停 **极端**（看 dragons eod 炸板率、涨跌比）  
3. sector **Top1 行业断层**领先  
4. 快讯 **≥1 条** 可写进标题的宏观/地缘事件  

**频率**：每周 **0–1 篇** market；每月 **2–4 篇** 足够。

```bash
cd stock-ai
uv run python -m scripts.tools.wechat_mp_draft --kind market --edition close
# 与 evening 三篇同批群发：market 放次条或替换最弱一篇，勿第二次通知
```

## 四、渠道分工

| 渠道 | 占比（近期） | 运营动作 |
|------|--------------|----------|
| 朋友圈 | ~31% | 标题可转发感；财经弱，勿强求 |
| 搜一搜 | ~27% | **热股名、板块名、情绪词**；weekly 看板 |
| 聊天 | ~25% | 正常；321 式群发仅作 **已知 outlier** |
| 推送 | ~4% | 忽略；优化搜一搜与头条 |

## 五、本周只调一类（防全改）

| 现象 | 只调 |
|------|------|
| 阅读 <75 三日 | news 标题模板（热股前置） |
| 阅读 OK、流量主低 | 头条开篇 + 段长（完读） |
| 搜一搜占比升、某 kind 搜索词集中 | 该 kind 标题句式 |
| sector 长期 ~50 | sector-discovery 权重 |
| 三篇都低 | 考虑同批加 market（大行情日） |

## 六、不该做的

- 错开发表（个人号做不到）  
- 用 321 读当模板或 KPI  
- 日更加篇（推荐衰减）  
- 改情感号 / 堆非财经  
- 用明细行收入否定概览入账  

## 七、与变现的关系

阅读台阶与流量主 **强相关但非 1:1**（结算滞后）。档 A→B 阅读 +15% 时，入账常见 **+20–40%**。详见 [revenue-model.md](revenue-model.md)。
