# 《月照反弹琵琶》朗诵字幕成片设计

## 目标

将用户确认可用的 15.104 秒《月照反弹琵琶》无道具舞蹈原片制作成可发布的 1080×1920 竖屏成片。全片只增加栀夏固定声线的四句诗画外朗诵和逐句竖排字幕，不改变现有舞蹈、镜头、背景音乐、环境声与动作节奏。

源视频：

`/Users/huan.yu/Downloads/45b803cd-530c-4ae0-850c-ce84cf069d4d.mp4`

源视频经检查为 496×864、24fps、15.104 秒，含 H.264 视频与 32kHz 双声道 AAC 原声。原下载文件保持不变，制作时先复制到项目单集资产目录。

## 朗诵内容与声音身份

全片只使用栀夏画外朗诵，不增加角色对白，不要求画中人物对口型：

```text
琵琶起舞换新声，
总是关山旧别情。
撩乱边愁听不尽，
高高秋月照长城。
```

- 作者与篇名：唐·王昌龄《从军行七首·其二》。
- 使用项目中已经确认的栀夏固定音色 `ICL_uranus_zh_female_tianmeihuopo_tob`，与《鼓催柘枝》成片保持同一声音身份。
- 声线保持 18 岁东方少女的清透、轻盈、明亮与书卷气；情绪清冷而坚定，带边塞辽阔感，不使用播音腔、朗诵比赛腔、戏曲腔、吟唱或过度悲情表演。
- 四句保持相近语速和响度，句内自然停连，句末完整收韵，句间保留短呼吸，不赶字、不吞字、不补充标题、作者或其他台词。

## 时间结构

朗诵从开场动作后 0.250 秒进入，第四句主体在 14.400 秒前结束，留下约 0.7 秒音乐与动作余势。目标时间窗如下；实际合成可依据生成音频时长在各自时间窗内微调不超过 0.200 秒：

| 诗句 | 目标进入 | 目标结束 | 画面关系 |
| --- | ---: | ---: | --- |
| 琵琶起舞换新声 | 0.250 秒 | 3.100 秒 | 对应开场高腿反弓与第一高潮余势 |
| 总是关山旧别情 | 3.550 秒 | 6.400 秒 | 对应换重、宽弓和第二高潮 |
| 撩乱边愁听不尽 | 6.900 秒 | 9.800 秒 | 对应中段横向舞句与纵深蓄势 |
| 高高秋月照长城 | 10.350 秒 | 14.400 秒 | 对应后段沉提、扬带与月下长城收束 |

句间保留约 0.45—0.55 秒呼吸。字幕与朗诵使用同一时间窗，淡入淡出计入时间窗内。第四句不得延伸到画面结束之后。

## 字幕设计

- 四句逐句出现，同一时间只显示当前一句，不把全诗同时铺满画面。
- 沿用《鼓催柘枝》已经确认的暖象牙白竖排诗句样式：克制深色描边或柔和阴影、适量字距、无底板、无发光、无卡拉 OK 高亮。
- 第一句附小号题署“唐·王昌龄《从军行七首·其二》”，后三句不重复题署。
- 字幕主体优先位于画面右侧安全区的上中部，避开中央舞者、面部、主要手势、腿部与蓝橙飘带；题署放在正文内侧，视觉层级低于正文。
- 字幕进入与退出使用约 0.120 秒淡入淡出，不逐字跳出，不使用现代花字或转场特效。
- 原片右下角已有的 AI 生成标识保留，不遮挡、不裁除；字幕最低点不得进入右下角标识区域。

## 原声零衰减混音

本片采用用户确认的“原声零衰减叠加”，与《鼓催柘枝》的背景闪避方案不同：

- 原片背景音乐、琵琶重音、羯鼓、脚步、衣料和环境声从头到尾保持原始增益 `1.0`，即 0 dB。
- 不使用 sidechain compression、ducking、动态音量包络或在人声时间窗内降低原声。
- 不对原声单独做响度归一化、频段削减或重新均衡；只重采样到最终输出所需的 48kHz 双声道。
- 四句人声单独去除过长头尾静音、轻度压缩并规范到约 −21 LUFS，使朗诵清楚但不形成贴脸广播感。
- 人声居中叠加，保持干净近声，只允许极轻空间感；不使用明显大厅混响。
- 混合使用 `amix normalize=0`，保证原声进入混音前后增益不变。最终只在混合总线上使用透明峰值限制器防止叠加爆音，不通过整体响度归一化回拉背景音乐。
- 原片实测约 −15.86 LUFS、真峰值约 −1.22 dBTP。最终目标不强制追求固定综合 LUFS，只要求无削波、无爆音，输出真峰值不高于 −1.0 dBTP，且主观听感中背景音乐与未加朗诵原片保持同等强度。

## 画质处理

采用保真高清处理，不进行生成式人物重绘：

1. 将 496×864 原片按比例放大至高度 1920，再居中轻裁左右边缘，输出 1080×1920，不拉伸人物。
2. 使用 Lanczos 高质量缩放、轻度时空降噪和克制锐化，改善脸部边缘、服装纹样、金饰、飘带和城墙纹理。
3. 只做轻微对比度与饱和度稳定，不改变深蓝月夜、孔雀蓝、琥珀橙、象牙白和烽火暖光的关系。
4. 不补帧、不改变 24fps、不改速、不裁动作、不生成式超分、不磨皮、不重绘面部、不移除 AI 标识。
5. 保持完整 15.104 秒和现有运镜。

## 输出与归档

- 原片项目内归档副本，内容与下载源文件一致，不覆盖下载目录文件。
- 无字幕配音试听版：1080×1920，保留原声 0 dB，叠加四句朗诵，用于检查声音与时间轴。
- 最终字幕版：1080×1920、24fps、H.264 高质量视频、48kHz 双声道 AAC 192kbps、快速起播标记。
- 四条独立朗诵音频、声音生成清单、字幕时间轴、四张透明字幕卡、专用构建脚本与验证脚本。
- 单集 README 与资产清单同步记录源片、语音、试听版和最终版。

## 验收标准

1. 四句文字、顺序和读音正确，第一句约 0.250 秒进入，第四句及尾韵在 14.400 秒前完成。
2. 全片只有栀夏画外朗诵，无阿砚对白、额外旁白、吟唱或新增画中口型。
3. 原片背景音乐全程保持 0 dB，无侧链、无闪避、无人声时间窗音量包络、无可闻突降或回升。
4. 朗诵清楚但不过分贴脸；混合无削波、爆音或明显泵动，最终真峰值不高于 −1.0 dBTP。
5. 四句暖象牙白竖排字幕逐句出现，第一句带正确题署；无错字、乱码、截断、重叠或超出画面。
6. 字幕不遮挡脸、主要手势、腿部、蓝橙飘带或右下角 AI 标识。
7. 输出为 1080×1920、24fps、约 15.104 秒；人物比例未拉伸，脸与服装未被重绘，原有 AI 标识保留。
8. 原下载文件未覆盖；无字幕试听版和最终字幕版均可独立播放、音画同步并支持快速起播。

## 与既有规范的关系

本设计沿用《鼓催柘枝》的栀夏固定音色、逐句竖排字幕样式、保真高清处理和双版本交付方式，但明确覆盖其“朗诵期间压低背景音乐”的混音做法。本片必须始终执行原声 0 dB、无闪避的独立混音规则。
