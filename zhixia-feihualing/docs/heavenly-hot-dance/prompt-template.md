# 《天宫热舞》Seedance 精简提示词模板

## 使用前准备

1. 先选单人或双人。
2. 再从卡点摇、轻街舞、现代舞、拉丁中只选一个主舞种。
3. 拉丁继续只选恰恰、桑巴或牛仔之一。
4. 上传素材后，在 Seedance 输入框中插入实际生成的 `@素材标签`，再替换模板示例标签。
5. 每轮只生成一条候选，外部付费生成前取得用户当次明确确认。

## 素材组合

| 组合 | 素材 | 适用场景 |
|---|---|---|
| 单角色图＋文字 | 1 张角色图 | 单人低成本动作测试 |
| 双角色图＋文字 | 2 张角色图 | 双人关系与简单换位测试 |
| 角色图＋动作视频 | 1–2 张角色图＋1 段自有或获授权动作视频 | 需要稳定舞种、动作密度和队形 |
| 角色图＋动作视频＋纯音乐 | 1–2 张角色图＋1 段合法动作视频＋1 段 10 秒纯音乐 | 需要同时控制身份、动作和卡点 |

不要为了凑齐素材而上传来源不明的视频。多模态参考提高控制力，但不保证逐帧复刻。

## 六段模板

### 1. 素材职责

```text
{角色A}参考{角色A实际图片标签}，该图片只负责{角色A}的面容、成年年龄、身高体态、妆发和服装。
{双人时：角色B参考角色B实际图片标签，该图片只负责角色B的面容、成年年龄、身高体态、妆发和服装。}
{有动作视频时：动作参考实际视频标签，只参考舞步、动作密度、身体节奏和双人关系，不参考原人物、服装、场景、色彩和镜头。}
{有音频时：音乐参考实际音频标签，只参考拍速、重拍、能量变化和结束点，不参考人声。}
```

### 2. 角色关系

```text
{单人：角色A是全片唯一舞者，完整全身持续可见。}
{双人：角色A担任主舞并先发动作；角色B担任陪舞，以晚半拍、镜像方向、较小幅度或高低层次回应。两人保持清楚身份差异，不换脸、不融合，也不从头到尾机械复制。}
```

### 3. 单一舞种

只从下列文件粘贴一个“可复制动作段”：

- 卡点摇：`modules/beat-dance.md`
- 轻街舞：`modules/light-hiphop.md`
- 现代舞：`modules/modern-dance.md`
- 拉丁：`modules/latin-dance.md`，并只选恰恰、桑巴或牛仔。

```text
本片只跳{主舞种}。{粘贴所选模块的一组或两组连续动作正文}

舞者不是沿天阶走向镜头，不进行模特台步、仙女巡游或连续展示姿势。除一次短促换位外，双脚始终执行有节奏的踏点、侧步、交叉换重或弹步；手臂动作必须与肩、胸、髋和脚步的重拍同时发生。
```

### 4. 五段时间线

```text
0–2 秒：第一帧直接进入第一组连续舞步，脚步换重和上身重拍同时开始。
2–4 秒：完成第一组并进入第二组，通过方向或身体层次变化提高动作密度。
4–6 秒：{双人：保持脚步完成全片唯一一次短互动或换位，接触完成立即恢复舞步。单人：继续第三组动作，不停顿摆姿。}
6–8 秒：全片最高能量段，连续脚步和身体重拍最清楚。
8–10 秒：保持与最高能量段相同的动作密度，人物运动持续至最后约 0.2 秒，最后一拍完成动作，不提前站定。
```

### 5. 场景镜头

```text
9:16竖屏，10秒，写实电影感仙境，单一连续镜头。角色位于前景白玉天阶，身后是恢宏天门、层叠宫阙与云海纵深。人物约占画面高度65%–75%，从头饰到鞋底完整可见。摄影机保持正面偏四分之三的稳定全身景，只做克制轻微推进或小幅横向跟随；不切特写、不环绕、不高速甩镜。飘带只在身体动作后自然延迟，不能遮挡脸和脚步。
```

阿砚出场时追加：

```text
阿砚始终保持成年女性人形、严格两只笔锋猫耳和唯一一条从尾骨连接的开放S形墨尾。墨尾保持自然粗细和柔和锥形末端，只做低幅度滞后摆动，不逐拍甩动，不变成粗大问号、圆环或独立书法笔画。
```

### 6. 精简约束

```text
不走秀、不巡游、不用走路、举臂、慢转或摆姿代替跳舞；不提前停舞；不换脸、不融合人物；不增加人物、肢体、猫耳、墨尾或飘带；不穿模、不浮脚、不让鞋底滑行；不使用地板动作、大跳、连续高速旋转、危险托举、低俗或性暗示动作。画面不出现角色卡排版、文字、水印或标志。
```

## 有动作视频

- 使用页面实际插入的动作视频标签。
- 文字只定义“参考什么”和“排除什么”，不逐拍复述参考视频中的全部动作。
- 参考视频人物数量、镜头距离、服装活动范围和目标视频应尽量相近。
- 动作视频必须为自有或已获授权素材。

推荐映射句：

```text
动作参考@视频1，只参考其完整舞步顺序、动作密度、重拍、队形和身体节奏；把原人物替换为本片角色，把原场景替换为天宫。不参考原视频的人脸、服装、背景、色彩、文字和标志。
```

## 无动作视频

- 必须完整粘贴一个舞种模块的两组连续动作。
- 不只写“热烈起舞”“跳得有节奏”或“自由发挥”。
- 文字动作优先写脚步换重、身体重拍和动作顺序，少写抽象气质形容词。

## 有音频

- 上传恰好 10 秒的纯器乐音频，并使用页面实际插入的音频标签。
- 让第一拍、最高能量段和最后一拍对应音频，不再另外指定冲突的 BPM。
- 如果音频含歌词、口号或可辨识人声，先制作纯器乐版本再上传。

推荐映射句：

```text
音乐参考@音频1，只参考拍速、重拍、能量变化和结束点。第一帧动作踩中第一拍，6–10秒连续强拍，最后动作与音频最后一拍同时结束。
```

## 无音频

- 指定一个与舞种相符的拍速范围，不要求模型同时生成另一种节奏。
- 固定写明 0 秒落拍、6–8 秒最高能量、8–10 秒保持密度、最后一拍结束。
- 生成画面后再配置节奏一致的独立纯音乐。

## 双人卡点摇示例

以下示例假定平台已生成 `@图片1` 和 `@图片2` 两个实际引用标签；若页面标签不同，必须替换。

```text
栀夏参考@图片1，@图片1只负责栀夏的面容、168cm成年舞者体态、仙家妆发和月白淡金服装。阿砚参考@图片2，@图片2只负责阿砚的短圆成年面容、162cm体态、两只笔锋猫耳、白墨服装和唯一开放S形墨尾。栀夏担任主舞并先发动作；阿砚担任灵动陪舞，以晚半拍、镜像方向和较小幅度回应。两人保持清楚身份差异，不换脸、不融合，不从头到尾机械复制。

本片只跳轻快利落的卡点摇。第一组连续完成侧向弹步四拍、肩部左右顿点两拍、胸腔收放两拍和反方向前臂切线四拍；第二组连续完成交叉换重四拍、髋部左右切换两拍、手腕甩点两拍，再以快速回弹改变朝向并继续四拍侧向踏点。脚底真实着地，肩、胸、髋、手臂和脚步同时踩中重拍。

0–2秒：第一帧两人直接进入侧向弹步，栀夏先发，阿砚晚半拍镜像回应。2–4秒：完成肩胸卡点和反方向前臂切线，双脚持续换重。4–6秒：两人保持踏点完成全片唯一一次短换位，接触后立即分开并恢复舞步。6–8秒：并排进入交叉换重、髋部切换和手腕甩点的最高能量段。8–10秒：继续侧向踏点、肩部顿点和快速回弹，保持同等动作密度至最后约0.2秒，最后一拍才完成动作。

9:16竖屏，10秒，写实电影感仙境，单一连续镜头。两人位于前景白玉天阶，身后是恢宏天门、层叠宫阙和云海纵深。人物约占画面高度70%，头饰到鞋底完整可见。摄影机保持稳定的四分之三正面全身景，只做克制轻微推进，不切特写、不环绕、不高速甩镜。宽飘带只在身体动作后自然延迟，不遮挡脸和脚步。阿砚墨尾保持自然粗细和柔和锥形末端，只做低幅度滞后摆动，不逐拍甩动。

舞者不是沿天阶走向镜头，不进行模特台步、仙女巡游或连续展示姿势。除一次短换位外，双脚始终执行有节奏的踏点、侧步、交叉换重或弹步；不提前停舞，不换脸、不融合人物，不增加人物、肢体、猫耳、墨尾或飘带，不穿模、不浮脚，不使用地板动作、大跳、连续高速旋转、危险托举、低俗或性暗示动作。画面不出现角色卡排版、文字、水印或标志。
```
