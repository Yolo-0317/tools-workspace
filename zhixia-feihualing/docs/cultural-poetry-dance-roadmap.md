# 文化诗舞合集后续方向

## 定位

本文件记录《栀夏飞花令》在《栀夏·敦煌十六舞》之后可继续发展的“文化符号＋舞蹈＋诗词”合集方向。它是长期选题池，不改变当前制作优先级，也不代表这些系列已经进入制作。

候选主题必须同时具备：

- 能形成稳定、清楚且不同于其他系列的文化视觉符号。
- 能提供足够丰富的身体动作、空间路线和舞蹈高潮，不能只靠换背景与服装区分。
- 有原作或高度匹配的诗词文本，诗词不是后贴的装饰。
- 能用统一角色母板连续生产，同时允许单集通过环境、动作、光影承接物与色彩产生差异。

## 建议优先顺序

1. 《栀夏·敦煌十六舞》：当前已规划系列，建立华丽、强动作的文化诗舞认知。
2. 《栀夏·九歌祭舞》：首选后续方向，以《楚辞·九歌》建立神秘、叙事化的楚地神话体系。
3. 《栀夏·宋词十二境》：发展细腻情绪、空间调度与克制镜头语言。
4. 《栀夏·华夏神女十二章》：在前述系列稳定后，再发展人物型神话合集。

六个候选系列按建议开发顺序明确为：

1. 《栀夏·名楼十二望》：以楼阁、江河、月色、风雨与题咏空间组织舞蹈。
2. 《栀夏·廿四节气舞》：以气候、物候、地貌与光色反馈表现节气。
3. 《栀夏·器物十二章》：器物作为环境主角或构图锚点，栀夏围绕其空间与光影起舞。
4. 《栀夏·盛唐十二乐舞》：以盛唐乐舞气象、舞台空间与远景乐声形成系列辨识度。
5. 《栀夏·十二花神》：以花木、花影、花瓣与季相色彩回应动作。
6. 《栀夏·草木十二笺》：以草木群落、叶影、风向、露水与季相变化叙事。

六个系列仍属于候选池，不改变“敦煌十六舞 → 九歌祭舞 → 宋词十二境 → 华夏神女十二章”的当前主线顺序。进入制作前仍需重新评估与敦煌、九歌的视觉和动作重复度。

## 神性审美生效边界

- 敦煌十六舞从第六支开始执行，九歌祭舞从第二篇开始执行。
- 已生成、已确认或已发布的成片不返工；已完成但尚未发布的成片不因本规则重新生成。
- 去网红感，不去人物感：视频中的栀夏默认不直视镜头，视线指向神境、祭坛、同行对象、自然承接物或诗中事件；表情服从篇章关系，不把栀夏统一处理成无情绪神像。
- 神性来自人物与神境之间的迎请、追随、等待、回护、悼念和送别关系，不由金光、悬浮、法阵、符文或粒子堆叠代替舞蹈。
- 角色卡中的正面平视只承担身份锁定，不代表视频中的表演视线。

## 敦煌十六舞分型

敦煌单集先判断文化与表演类型，再确定神性强度，不使用一套宗教化表情覆盖全部舞种：

1. 飞天、供养舞与礼佛空间可以使用下视、遥望、回身散花、长裙与飘带迎风等庄严或超逸表达。
2. 柘枝、胡旋、白纻等乐舞以华丽、矫健、含蓄和舞台气韵为主，不强制肃穆悲悯。
3. 诗境型原创舞的表情和视线服从诗句，不因“敦煌”标签统一改成神像表情。

默认开头继续使用全身强起势，第一帧保持头顶至鞋履可见，并在 1.000 秒内进入主体舞句。局部特写钩子只允许选择一支未生成敦煌单集做可回退的单变量测试：0.000—0.500 秒使用冠饰、璎珞、指尖或袖缘动态细节，0.800 秒前拉开至完整全身。若人物身份、脚下承重或主体舞句受损，立即回退到全身强起势；该结构不得连续复用。

## 诚实命名与发布边界

作品继续定位为原创文化诗舞、原创敦煌乐舞意象或《九歌》现代祭舞转译。没有明确参考链时，不得将作品正向宣传为“复原”“还原”“AI活化文物”“数字敦煌复原”，不得虚构洞窟编号、临摹者、研究者、文物出处或大师参考关系。

- 确有来源时只写“灵感参考莫高窟第57窟飞天”等与实际使用范围一致的表述，并在内部设计稿中保留来源。
- 标题、字幕和发布文案不得暗示项目属于敦煌研究院、数字敦煌官方项目、非遗传承项目或专业古舞复原。
- 搜索标签优先使用准确实体词，如“敦煌舞、飞天、楚辞、九歌、山鬼、中国古典舞、国风舞蹈”。“AI辅助制作”可以作为透明声明，但不作为每条标题的第一传播信息。

## 后续系列继承边界

宋词、名楼、节气、器物、花神和草木系列只继承诚实考据、去网红感、视线对象、情绪弧线与环境因果，不继承统一的肃穆表情、黑金色板、祭坛或低沉男声。《宋词十二境》优先保留人间情绪与日常空间；《华夏神女十二章》进入制作前逐人物建立身份、出处和视觉边界。

## 全系列无手持器物规则

栀夏进行舞蹈时双手始终不持任何器物。器物只能作为地面、祭坛、背景、远景或光影承接物，通过环境反馈参与叙事，不进入手部持握关系。

- 乐器只作远景演奏、舞台陈设或声源暗示，栀夏不演奏、不持乐器。
- 花木只生长于环境中，或以花影、花瓣、风向和光色回应动作；栀夏不采摘、不持花枝。
- 剑、扇、伞、农具和其他器物只能静置于地面、台座、祭坛或中远景，不被拿取、挥舞或传递。
- 《栀夏·器物十二章》仍以器物为视觉主题，但栀夏只围绕器物及其空间、倒影和光影反馈起舞，绝不操控器物。

## 《九歌祭舞》统一角色母板原则

《九歌祭舞》可以并且应当使用一张统一的栀夏专属角色母板。推荐叙事身份是“同一位楚地祭舞者进入十个神境，以祭舞迎请、追随并送别诸神”，而不是栀夏逐集扮演不同性别和身份的神祇。

### 母板固定项

- 固定栀夏的脸、18岁年龄感、身材比例、三视图和六种表情。
- 固定高而窄的单体楚式盘髻与小型黑漆凤鸟冠梳，避免大型神女仙冠。
- 固定玄黑、朱红为主色，辅以少量暗金和象牙白；整体取楚漆器般幽深、庄重的色感。
- 固定交领右衽内衣、朱红玄黑一体式宽袖舞衣、多层长裙、清楚腰线与可见舞履；左右袖口后下缘各连续延伸一个朱红尾端，合计严格两个末端。
- 凤鸟、云雷、龙蛇与香草纹只作局部纹样，不堆叠为盔甲或满身装饰。
- 角色母板与所有单集均执行全系列无手持器物规则，双手始终空着。

### 单集可变项

每集只通过神境、自然或器物环境承接物、局部光色和动作语汇表达篇章差异，不更换栀夏的脸、发型、头冠或整套服装。

### 与敦煌系列的区隔

- 敦煌使用孔雀蓝、琥珀橙、象牙白与旧金，强调莲焰冠、华丽乐舞和双层长飘带。
- 九歌使用玄黑、朱红、暗金和象牙白，强调黑漆凤鸟冠梳、楚漆器色感、一体式袖缘尾端与祭祀氛围。
- 九歌不得复用敦煌妆发、莲焰冠、蓝橙双层飘带和飞天定式，避免成为“敦煌换背景版”。
