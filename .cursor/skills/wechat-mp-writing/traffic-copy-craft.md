> **分工**：本文件 = **怎么让人点开、划下去、转出去、顺手关注**；形态与禁词见 [social-commentary-voice.md](social-commentary-voice.md) · [anti-ai-voice.md](anti-ai-voice.md)；稿末转化见 [follow-growth-copy.md](../wechat-mp-growth-ops/follow-growth-copy.md)；标题路牌见 [sousou-content-rules.md](sousou-content-rules.md)。

## 一、引流稿要优化什么

订阅号 **推送弱、推荐流强**（陌生读者占比高）。一篇稿同时服务三个指标：

| 指标 | 读者行为 | 写作对应 |
|------|----------|----------|
| **点开** | 列表里停 1 秒 | 标题路牌完整 + 情绪温差（禁震惊体） |
| **完读** | 划到文末 | 短段、节奏钩子、好奇回路不断档 |
| **转化** | 关注 / 转发群聊 | 可转述的细节 + 站队问句 + 稿末星标句 |

**内部策略**（勿写进正文）：争议选题、讨论度、双榜——只给 Agent 用；读者只见「摆事实、摆说法」。

**完读与收入**：完读低 → 流量主曝光少 → 推荐池权重也吃亏。引流不是标题党，是 **前 3 句留住 + 中段不塌 + 结尾有落点**。

## 二、标题：合规内的「想点」

搜一搜 **路牌完整** 优先于悬念（见 sousou §一）。在路牌完整前提下，用下面手法抬点击，**禁止**震惊 / 100 倍 / 半句话截断。

### 2.1 六种有效结构（热点号）

| 结构 | 模板 | 示例 |
|------|------|------|
| **事实 + 问号** | `{谁/啥事} + {反常结果}？` | `儿子病逝留 87 个游戏号，遗产该归谁？` |
| **声明 vs 反击** | `{一方说法}，{另一方}气吐了？` | `婚外试管丈夫发声明，患癌妻子气吐了？` |
| **续篇感** | 标题可带「又」「再」「声明之后」 | `婚外试管丈夫发声明患癌妻子气吐了？`（正文开篇交代写过一版） |
| **数字锚** | 具体数字前置或紧跟主语 | `87 个号` `58 岁` `四十集上限` |
| **身份标签** | 读者能代入的角色（一句内） | `宿管大爷` `原配` `游戏玩家家属` |
| **公共议题压缩** | 个案 + 一句社会问 | `没有空调的值班室，算工伤吗？` |

### 2.2 标题禁用（引流也禁）

- 平台名 + 词条连读：`百度把…送上热搜` `微博#…#`  
- 内部编审：`候选五条` `相较另一标题`  
- 空悬念：路牌残缺（`返…` `暂…`）  
- 情绪过载：`震惊` `三观震碎` `天都塌了`

### 2.3 标题与开篇必须「同题」

标题承诺的事件，**首段 50 字内**要落地。否则推荐流读者觉得被骗，完读断崖。

### 2.4 合成情境只作引子

没有公开可核验个案时，可用一两句合成情境让读者先看见普通人的处境；首段须明确它“不对应具体当事人”，80 字内回到可核验事件。不得编造聊天记录、私信、机构答复、名额、薪资、采访或未公开材料。

## 三、开篇：前 80 字定生死

推荐流读者 **先滑再看**。开篇任务：让人觉得「这事跟我有关 / 这事有蹊跷」。

### 3.1 优先入口（与 social-commentary 一致）

**A. 冷事实连打**（默认）

```text
前天，青岛大学死了一个人。
是一个宿管大爷，热死的。
```

**B. 续篇入口**（写过同题时）

```text
这事儿我们写过一版了。
朱女士、假结婚证、上海中山医院冻着的婚外胚胎——前几天稿里讲过她告丈夫、第三者、医院。
8 月 3 日又有新动静。
```

**C. 温差一句即止**（慎用，立刻回事实）

```text
空调房里打字的人，和六平米值班室里转小风扇的人，中间隔着一份语焉不详的通报。
张培生，58 岁，倒在入夏后最热的那几天。
```

### 3.2 好奇回路（open loop）

开篇可 **先抛结果、后倒叙**，但 2 段内必须补可核对事实：

```text
丈夫在电话里发了段「挺通情达理」的声明。
隔天凌晨，妻子四个字怼回来：避重就轻。
```

读者想知道：声明说了啥、为啥气——下一段给。

### 3.3 开篇禁用

| 禁用 | 改用 |
|------|------|
| 刷到这条热搜 | 直接写谁发生了什么 |
| 值得注意的是 | 删掉 |
| 公开报道里有一条 | 直接写事实 |
| 双榜 / 热度破亿 | 写大家在吵什么 |

## 四、中段：防划走的节奏

### 4.0 热点长图文完读硬约束

以下是阅读节奏检查项，用户主动 `hotspot` 的文章写法先以 [essay-commentary-craft.md](essay-commentary-craft.md) 为准；`hot_business` 与其他长图文仍遵守各自篇幅和结构。标题与首段同题、Markdown 星号禁用、真实配图等硬要求不因写法调整而放松。

- 首段 80 字内交代事件、变化和读者利益点。
- 尽早让真实事实与文章核心问题出现；不为凑悬念拖延必要信息。
- 按论证推进提供信息增量，不按固定字数埋钩子。
- 检查是否有值得转述的事实或判断，不设置数量硬指标；具体见 §6.5。
- 段落多数为 1 至 3 行，避免连续五段同句长。
- 正文配图均匀分布，承担滚动阅读换气，不集中堆在开头。
- 文末只留一个具体互动问题，关注和推荐提示交给现有流水线。

自动门禁继续检查标题与首段同题、开篇数字、超长段落和文末问句。信息增量、可转述颗粒与配图节奏由干跑时人工复核，不用关键词数量替代内容判断。

### 4.1 移动端排版（硬约束）

| 手法 | 参数 | 作用 |
|------|------|------|
| **一句一段** | `\n\n` 分段；discussion 走 `finalize_discussion_body` | 屏上像「弹幕流」，不累 |
| **段间距** | HTML `margin:0 0 14px` | 视觉呼吸 |
| **强调** | 禁止 `**`；判断句可单句成段，也可留在自然段 | 节奏服从内容 |
| **引用块** | 通报 / 原话 / 留言 | 节奏重置，像换频道 |
| **配图** | 均匀分布，勿堆首段 | 划动时有视觉停顿 |

**禁止**：连续 5 段同句长；满篇小标题目录体。

### 4.2 节奏变化（按内容需要使用）

任选一种，**不要堆满篇**：

1. **短句落锤**：`听着好像挺通情达理？`  
2. **对照一句**：`通报里六个字。学生心里是一个会溜猫的爷爷。`  
3. **数字突变**：`八个月没发工资。`  
4. **原话引用**：`原话就四个字：避重就轻。`  
5. **轻问句**：`那胚胎到底算谁的？`（不替读者判案）

### 4.3 信息递进（默认曲线）

```text
冷事实 → 可核对细节（物件立人）→ 制度/通报 vs 民间记忆 → 同类扩面（≤2 段）→ 收束
```

感情曲线见 social-commentary §四；引流版强调：**温之前先冷**，愤怒来自事实对照，不是形容词。

### 4.4 中段禁用（引流视角）

| 禁用 | 原因 |
|------|------|
| 长段背景综述 | 陌生读者直接划走 |
| 行业展望句 | `后面陆续会有…` 无钩子 |
| 作文结构 | `一拨…另一拨…` `与其说…不如说…` |
| 重复标题信息 | 开篇已说过的声明，中段勿再导语复述 |

## 五、语气人设：群里转述，不是上公开课

### 5.1 人设一句话

**刚看完热搜、在群里跟朋友说这事的人**——有态度但克制，摆事实、摆吵架点，不替平台、不替法院、不替行业总结风向。

### 5.2 语气刻度

| 档位 | 什么时候用 | 句式 |
|------|------------|------|
| **冷** | 通报、时间线、数字 | 短句。句号。不连形容词。 |
| **温** | 立人、学生留言、邻居回忆 | 具体物件 + 行为 |
| **张力** | 对照段 | 一句通报、一句民间，中间不解释 |
| **收束** | 结尾 | 名字 + 事实，或一句问句 |

### 5.3 「你」怎么用

- **偶尔**拉读者站位：`若站在父亲那一方` `试想六平米没空调`  
- 全篇 **≤2 次**；勿连续 `你觉得` `你是否`  
- 站队问句放 **稿末倒数段**（与关注句分工，见 follow-growth-copy §4.3）

### 5.4 口吻对照表

| 像引流自媒体（可用） | 像 AI / 研报（禁用） |
|----------------------|----------------------|
| 气吐了、怼回来、避重就轻 | 引发广泛关注、值得深思 |
| 网上也在吵 | 舆论场呈现分化态势 |
| 有帖子拿…举例 | 有人举那种…论证 |
| 证还没下来 | 播出许可、外部条件 |
| 钱回不来戏上不了 | 库存去化、沉没库存 |
| 妆发还是几年前的样子 | 服化道一眼五年前 |

## 六、用词与语气工具箱

### 6.1 情绪动词（克制版）

优先 **看得见的行为**，少用空感叹：

| 场景 | 可用 | 不用 |
|------|------|------|
| 愤怒 | 怼、回呛、不认、气吐 | 震怒、痛心疾首 |
| 惋惜 | 没了、倒了、没撑过 | 令人痛心、泪如雨下 |
| 质疑 | 语焉不详、说不清、没回应 | 存在诸多疑点 |
| 讽刺（轻） | 听着挺…？隔天就… | 何其讽刺 |

### 6.2 连接与过渡（口语导流）

| 避免（书面 / AI） | 改用（口语） |
|-------------------|--------------|
| 与此同时 | 同一天 / 隔天 / 另一边 |
| 在此背景下 | 删掉，直接写下一句事实 |
| 值得注意的是 | 删掉 |
| 据悉 / 记者了解到 | 通报写的是 / 记者电话里听到 |
| 引发热议 | 网上也在吵 / 评论区吵翻了 |
| 综上所述 | 删掉；用名字或问句收 |

### 6.3 站队问句模板（稿末互动）

**一句即可**，勿连环三问：

```text
你觉得声明算有担当，还是避重就轻？
若是你，会接受销毁胚胎吗？
这类外包岗，空调该不该算基本配置？
```

禁止：`点赞让我知道` `关注不迷路`（关注句单独由代码注入）。

### 6.4 读者共鸣与讨论度软提示（非阻断）

`hotspot`、`hot_business`、`tv_review`、`silver` 建议保持：

- 前 150 字给出人物/角色和处境动作；
- 正文三分之一内写清现实代价；
- 写清不同需求与实际张力，不人为制造对立；
- 末段问“如果是你…会怎么选？”而不是空泛“你怎么看？”。

未达成时给出提示，不作为推稿硬拦。

### 6.5 转述价值：给读者有用的信息与可复述的判断

用户于2026-09-07确认：通过信息增量、具体处境和清晰判断改善分享意愿，不靠制造焦虑。对热点深评，本节优先于本文件其他位置的固定钩子数量、间隔和站队建议。

- **信息增量**：优先在前1/3解释一个影响读者选择、容易误解的政策细节；不强行反常识，不把普通常识包装成独家发现。
- **具体处境**：说明谁承担时间、费用、接送或举证成本。事实需有来源；风险和假设要显式限定，不用假设场景暗示当地已经发生问题，不省略已有配套来制造矛盾。
- **清晰判断**：在论据充分处提炼一句可独立转述的结论，结尾前可自然收束；脱离上下文后仍须准确，保留地区、条件等必要限定。不为了表态制造对立，不替读者声称“大家都这么想”。
- **不机械埋钩子**：不要求每篇至少两个钩子或每隔固定字数设悬念。已有好句优先保留或前移，避免叠加同义金句、重复结论。短句可独立成段，高亮总量继续遵守稿型规范。
- **事实优先**：禁止虚构采访、心理、名额不足、收费上涨、投诉或实施失败；不把编辑指令、传播策略和“认知钩子”等术语写进正文。不加入“转给家长群”“不转就吃亏”等分享催促，不以奖励、恐惧诱导转发。
- **适度验证**：先作少量试写。按相同发布后观察窗口记录转发人数/阅读人数，并结合完读、来源渠道、题材与样本量判断。人数和次数不混用；后台未提供的指标标记不可得。单篇涨跌不是因果证明，不承诺转发率、推荐量或eCPM上涨。

例：春秋假可写“放假日期告诉家长哪天不上课，托管安排才告诉无法休假的家庭怎么办”，同时保留当地已有托管的事实；不以“请不了假、托管报不上名，那是谁的假期”暗示未经核实的服务失败。示例用于说明边界，不要求每篇照抄句式。

编辑自检：读者能带走哪条具体信息或判断？有无失去限定后容易误传的短句？是否重复？没有合适的传播句时，不以凑句为由阻断合格稿件。此项为人工编辑检查，不声称已实现自动检测。

## 七、稿型差异（同一套引流，力度不同）

| 稿型 / 时段 | 引流侧重 | 语气 |
|-------------|----------|------|
| `discussion` 11:00 | 更短、更克制；钩子靠事实 | 少升华，多多方说法 |
| `hotspot` 15:00 | 可加深一层公共议题 | 仍禁小标题清单体 |
| `tv_review` / evening 18:00 | 滚动阅读 + 均匀配图 | 续篇入口、高亮段 `[[hl:…]]` |
| 财经 legacy（若再发） | 数字 + 板块名前置标题 | researcher-voice |

## 八、与稿末转化分工（勿混写）

| 位置 | 写什么 | 谁写 |
|------|--------|------|
| 正文倒数 1–2 段 | **站队问句** / 名字收束 | Agent 写稿 |
| 稿末最后业务句 | **星标引导**（无关键词领资料） | `wechat_mp_monetization` 注入 |
| 关注回复 / 简介 | 承诺「整理公开信息」 | follow-growth-copy 定稿 |

正文 **不要** 写「关注领资料」「星标本号」——会破坏完读气质；转化交给稿末一句。

## 九、推稿前自检（30 秒）

Agent 改稿或 repush 前逐项扫：

- [ ] 标题前 15 字能独立表意（sousou）  
- [ ] 首段 80 字内：谁 + 发生了什么（或续篇交代）  
- [ ] 全文 **无** `**`、无热榜播报腔、无分析报告腔 grep 命中  
- [ ] 段落多数 1–3 行；discussion 一句一段  
- [ ] 信息与论证逐层推进，没有为了固定间隔硬塞悬念
- [ ] 按 §6.5 检查转述价值、事实限定与重复表达，不凑数量
- [ ] 结尾：名字 + 事实 **或** 一句站队问句（非关注诱导）  
- [ ] 站队问句与稿末关注句 **不重复**  

```bash
# 语音 / 报告腔扫描（生成门禁同源）
cd stock-ai
uv run python -c "
from scripts.tools.wechat_mp_discussion_polish import scan_report_voice
import json, pathlib
p=pathlib.Path('data/wechat_mp_tv_body_cache/你的slug.json')
if p.exists():
    t=json.loads(p.read_text()).get('body_core','')
    hits=scan_report_voice(t)
    print('hits:', hits or 'OK')
"
```

## 十、生成 Prompt 可追加块（复制进 DeepSeek）

```text
引流写法（牛马也智能热点号）：
- 标题路牌完整；开篇 80 字内落地标题事件；禁止热榜播报与震惊体。
- 语气像群里转述热搜：短句、口语，禁止行业归纳与政策解读腔。
- 短段为主，按论证自然变化节奏，不按固定间隔埋钩子。
- 优先解释影响读者选择的事实，给出有依据、保留必要限定的可转述判断；不凑数量，不重复金句。
- 结尾用事实或具体问题收束，不制造阵营对立，正文不催促关注或转发。
- 禁止 Markdown **加粗**；禁止：风向、松绑、服化道、一拨另一拨、与其说不如说。
```

与 `_discussion_voice_prompt_block()` 并用；冲突时 **禁词表优先**。
