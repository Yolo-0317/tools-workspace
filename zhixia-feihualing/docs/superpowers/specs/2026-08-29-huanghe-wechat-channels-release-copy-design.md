# 《黄河》视频号发布文案设计

## 目标

为《黄河之水天上来》10 秒舞蹈诗境制作一套可直接用于视频号的发布文案。文案以栀夏腾跃和黄河水弧建立第一钩子，再自然落到李白《将进酒》的诗境与阿砚的俏皮惊叹，突出“用舞蹈演绎诗景”的系列特色。

## 标题

固定使用：`栀夏这一跃，接住了从天上来的黄河`

标题以栀夏为主体，将封面中的腾跃动作与“黄河之水天上来”建立直接关系；不在标题中堆入 AI、美女、古风或平台搜索词。

## 正文结构

1. 首段描写黄河从云间奔来、栀夏踩着浪声腾跃、长袖带起水弧，承接视频和封面中的真实画面。
2. 第二段自然使用“AI美女舞蹈”和“中国古典舞”各一次，说明舞蹈不是脱离诗景的展示，而是栀夏跳进李白笔下的黄河。
3. 单独引用“黄河之水天上来，奔流到海不复回。”，注明来自李白《将进酒》但不扩写成长篇诗词讲解。
4. 保留阿砚的对白“哇，黄河真从天上冲下来啦！”，强化原创双角色关系和俏皮感。
5. 结尾邀请观众留言下一首想看的诗境，延续系列互动。
6. 明示“原创虚构角色｜AI辅助制作”。

## 标签与置顶评论

- 使用六个标签：`#栀夏飞花令`、`#李白`、`#将进酒`、`#AI美女舞蹈`、`#中国古典舞`、`#古诗词`。
- 置顶评论询问观众：如果只能选一句诗让栀夏跳出来，最想看哪一句；引导直接留下诗句。

## 边界

- 不把栀夏称为真人美女、真实舞者或专业舞蹈演员。
- 不承诺舞蹈套路由真人编舞，也不使用最高级、擦边或夸张能力表述。
- 不写 Seedance、提示词、镜头编号或其他制作代码。
- 发布时选择视频号要求的 AI 内容声明。
