# 公众号健康题材独立写法：设计与实施计划

## 目标与边界

为「牛马也智能」增加独立的健康题材研究和写作入口，按年轻、中年、老年读者的真实问题研究生活方式与营养话题；同时可用现有 Select 接口只读考察营养类商品候选。选题和选品不强制配对。本次只新增写作 Skill 与入口导航，不新增草稿 `kind`，不改 `product_feature` 的零食、日用小百货过滤、商品卡或独立槽位，也不推送草稿。

## 两类交付物

1. **健康知识稿**：围绕一个具体问题，用国家卫健委、疾控、专业指南等原始资料解释生活方式、膳食或就医边界；不在同页放相关保健食品、药品、医疗器械、特殊医学用途配方食品的购物链接。无相应资质时不生产专业诊疗科普。
2. **商品研究表**：Select 仅用于候选发现；逐个核对普通食品、保健食品、药品、医疗器械等身份，以及注册/备案、标签、适宜与不适宜人群、广告审查材料。预计佣金和来源平台销量只用于内部研究。若将来制作保健食品广告，须另走广告审查与平台资格核验，不能把科普文章换个标题后贴卡，也不能擅自改写已审查广告内容。

发布页的「健康医疗分享」声明只作为待核查的平台操作项，不视为医疗资质或保健食品广告批准。商品与正文弱关联，不改变同页购物链接的监管要求。

## 本次实施

1. 新建 `.cursor/skills/wechat-mp-health-content/SKILL.md`，规定年龄选题、来源、成分与功效核验、两类交付物和停止条件。
2. 在公众号 `SKILL.md` 和 `INDEX.md` 中只增加该 Skill 的导航，不改小商品稿型描述和代码。
3. 验证新 Skill 格式、导航可定位，检查差异确保 `product_feature` 执行路径未变。

## 后续研究阶段

先验证账号资质和平台声明；再为三个年龄群各建选题候选及原始来源；随后用 Select 按品类采样并形成商品证据表；最后分别评估不带卡的健康知识稿与独立、已审查的商品广告稿。是否开发新草稿 `kind`，待这些证据齐全后单独决定。
