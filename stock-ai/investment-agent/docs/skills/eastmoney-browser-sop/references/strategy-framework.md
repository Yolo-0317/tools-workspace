# 操作策略分层框架

## 1. 投资风格分类

### 激进型投资者
- **特点**：追求高收益，容忍高风险，短线操作
- **时间周期**：1-5个交易日
- **仓位**：可承受较大波动

### 稳健型投资者
- **特点**：追求稳定收益，风险承受度中等，中线操作
- **时间周期**：1-3个月
- **仓位**：控制风险，分批建仓

### 保守型投资者
- **特点**：追求本金安全，风险承受度低，长线持有
- **时间周期**：3个月以上
- **仓位**：谨慎建仓，分散风险

## 2. 分层操作策略模板

### 场景1：底部启动信号（主力流入+大幅上涨+低估值）

#### 激进型
```
入场时机：
- 明日若高开不多（涨幅<2%）或盘中回踩分时均线时介入
- 或在5日均线附近分时支撑处介入

仓位建议：
- 初始仓位：5-7成
- 加仓条件：突破今日高点后追加2-3成

止损设置：
- 止损位：昨日低点下方
- 止盈位：短期压力位或涨停价

风险控制：
- 设置严格止损，控制单笔亏损<3%
```

#### 稳健型
```
入场时机：
- 等待突破今日高点（8.50元）确认
- 或缩量回踩确认支撑（如回踩8.00元或20日均线）时介入

仓位建议：
- 初始仓位：3-4成
- 加仓条件：确认支撑后再加仓2-3成

止损设置：
- 止损位：支撑位下方5%
- 止盈位：中期压力位或目标价

风险控制：
- 分批建仓，控制平均成本
- 设置合理止损，控制单笔亏损<5%
```

#### 保守型
```
入场时机：
- 等待充分调整后（回踩20日均线或更低）再介入
- 或等待基本面有明确利好确认

仓位建议：
- 初始仓位：1-2成
- 加仓条件：长期趋势确认后逐步加仓

止损设置：
- 止损位：支撑位下方10%
- 止盈位：长期目标价

风险控制：
- 长期持有，不追高
- 设置宽松止损，控制单笔亏损<10%
```

### 场景2：机构减仓信号（主力流出+高换手+下跌）

#### 激进型
```
操作建议：
- 回避，不参与
- 或等待底部确认后再考虑反弹操作

理由：
- 机构减仓表示看空信号
- 短期继续下跌风险较大
```

#### 稳健型
```
操作建议：
- 观望，不建议新建仓位
- 若已持仓，可考虑减仓或止损

理由：
- 需等待资金稳定后再介入
- 风险收益比不佳
```

#### 保守型
```
操作建议：
- 坚决回避
- 若已持仓，建议止损出局

理由：
- 机构减仓是明确的看空信号
- 需要等待底部充分确认
```

## 3. 仓位管理建议

### 初始仓位确定
```
综合评分 ⭐⭐⭐⭐⭐ → 激进型5-7成，稳健型3-4成，保守型1-2成
综合评分 ⭐⭐⭐⭐   → 激进型3-5成，稳健型2-3成，保守型0.5-1成
综合评分 ⭐⭐⭐     → 激进型1-3成，稳健型1-2成，保守型观望
综合评分 ⭐⭐      → 激进型观望，稳健型观望，保守型回避
综合评分 ⭐        → 全部回避
```

### 加仓条件
```
1. 技术面确认：突破关键压力位或确认支撑
2. 资金面确认：主力持续流入或融资余额增加
3. 基本面确认：业绩预告超预期或政策利好
3. 时间确认：持仓周期内表现符合预期
```

### 减仓条件
```
1. 技术面破位：跌破关键支撑位
2. 资金面反转：主力大幅流出或融资余额下降
3. 基本面恶化：业绩预告下调或政策利空
4. 止盈条件：达到目标价或预期收益率
```

## 4. 风险控制框架

### 止损设置
```
激进型：
- 单笔止损：<3%
- 日止损：<5%
- 周止损：<10%

稳健型：
- 单笔止损：<5%
- 日止损：<8%
- 周止损：<15%

保守型：
- 单笔止损：<10%
- 日止损：<15%
- 周止损：<20%
```

### 止盈设置
```
激进型：
- 短期目标：+5-10%
- 中期目标：+15-25%
- 长期目标：+30%以上

稳健型：
- 短期目标：+3-5%
- 中期目标：+10-15%
- 长期目标：+20%以上

保守型：
- 短期目标：+2-3%
- 中期目标：+5-10%
- 长期目标：+15%以上
```

## 6. 操作纪律

### 必须遵守
1. **止损纪律**：必须设置止损，不能无限亏损
2. **仓位纪律**：不能超过预设仓位上限
3. **时间纪律**：到达预设时间必须评估是否继续持仓
4. **收益纪律**：达到止盈条件必须执行止盈

### 禁止操作
1. **禁止追高**：不在涨幅过大时追高
2. **禁止加仓亏损**：不在亏损时盲目加仓
3. **禁止逆势操作**：不违背主要趋势操作
4. **禁止过度交易**：不频繁进出，增加成本和风险
