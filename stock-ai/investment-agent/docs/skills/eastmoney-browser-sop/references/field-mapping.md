# 字段映射规则

## 基本面字段映射

字段名 -> 值 固定映射规则（强制）：

1. 先建立标准字段字典（以上字段名为 key，初始值 `未获取`）
2. 优先解析行情主信息卡 HTML，按"字段名 -> 同行右侧值"映射
3. 同一字段多次出现时，优先主卡区域；其次副卡/工具条
4. 任何仅抓到裸数值、无法回指字段名的条目，一律丢弃（禁止无键入库）
5. 若值为 `--` 或空字符串，统一记为 `未获取`

## 资金面字段映射

字段名 -> 值 固定映射规则（强制）：

1. 先建立标准字段字典（以上字段名为 key，初始值 `未获取`）
2. 解析页面 HTML 表格/列表后，按"字段名 -> 同行右侧值"映射；禁止跨区块错配
3. `实时成交分布图` 采用二维映射：`类型` x (`流入`,`流出`) 映射到对应数值
4. 任何仅抓到裸数值、无法回指字段名的条目，一律丢弃（禁止无键入库）
5. 若值为 `--`、空字符串或占位符，统一记为 `未获取`
6. 输出时保留 `数据来源`（东方财富Choice）与 `更新时间`

判定口径建议：

- 主力/大单净流入偏强：判定"资金偏多"
- 主力/大单净流出明显：判定"资金偏空"
- 页面无明确净流入字段：标记"未获取"

## 财务面字段映射

字段名 -> 值 固定映射规则（强制）：

1. 先建立标准字段字典，初始值统一为 `未获取`
2. 仅在 `公司核心数据/公司数据全览` 两个区块内解析，按"字段名右侧就近值"映射
3. 同一字段出现多次时，优先级：`公司核心数据` > `公司数据全览` > 页面其他区域
4. 任何无法回指字段名的裸数值一律丢弃（禁止无键入库）
5. 值为 `--`、空字符串或 `加载中...` 统一写 `未获取`
6. 输出时保留 `抓取页面URL` 与 `抓取时间`

## 北向资金字段映射

字段名 -> 值 固定映射规则（强制）：

1. 先建立标准字段字典（以上字段名为 key，初始值 `未获取`）
2. 优先从 `hsgtV2` 页面 HTML 可见文本按"字段名后就近值"映射
3. 同名字段多次出现时，优先"主摘要卡片"；其次"详情区块"；再次"历史区块"
4. 禁止无键入库：任何无法回指字段名的裸数值一律丢弃
5. 值为 `--` 或空字符串，统一写 `未获取`
6. 输出时保留 `数据来源`（东方财富Choice）与 `数据日期`

## 研报面判定口径

- 最近研报以"买入/增持"为主且目标价上调：`研报偏多`
- 评级偏中性或分歧较大：`研报中性`
- 出现下调评级或负面措辞集中：`研报偏空`
- 页面无研报或不可见：`未获取`
