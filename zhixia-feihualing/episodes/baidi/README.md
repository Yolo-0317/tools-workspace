# 《白帝城》15秒诗句诗境

## 取句

李白《早发白帝城》：

> 两岸猿声啼不住，轻舟已过万重山。

字幕出处：`唐·李白《早发白帝城》`。

## 内容定位

本集是15秒诗句诗境。它通过轻舟顺流穿行、阿砚数山和两人回望完成一个小事件，不是整首诗的30秒完整诗境，也不是逐句换景的静态配画。

关闭字幕后应能读懂：轻舟行得极快，阿砚来不及数完两岸青山，回头时已经越过层层峡谷。

## 对白与目标时间轴

| 时间 | 角色与内容 | 画面任务 |
| --- | --- | --- |
| 0.0—1.5秒 | 阿砚：“栀夏，船在飞！” | 建立轻舟高速顺流和阿砚的兴奋 |
| 1.5—3.4秒 | 栀夏：“坐稳，山要追不上了。” | 栀夏稳定回应，近岸开始产生明显视差 |
| 3.4—5.6秒 | 阿砚：“一座、两座、三座——” | 阿砚留在前甲板，只转头数岸边山峰 |
| 5.6—7.0秒 | 栀夏：“别数了，回头。” | 栀夏看向阿砚，两人开始回望 |
| 7.0—9.6秒 | 阿砚：“它们什么时候，都跑到身后了？” | 人物回望，镜头同步揭示身后层层高峡 |
| 9.6—约14.7秒 | 阿砚朗诵取句 | 略高宽景跟随帆船，万重山成为主体 |
| 14.7—15.0秒 | 无人声 | 保留江水、破水和远处猿声收尾 |

0.0—9.6秒的五句对白连续衔接，只保留自然换气和角色反应需要的极短停顿，不设置独立的纯画面对话空窗。正式TTS生成后按真实时长微调，不得为了维持上述估算明显加速对白或朗诗。

## 固定角色与船上位置

- 栀夏始终位于后部船舱前方或后甲板固定位置，面向船头，不换位、不攀爬桅杆、不触水。
- 阿砚始终位于前甲板，可以压低身体、看向栀夏、转头数山和自然回望，不换位、不落水。
- 固定道具[`tang-three-mast-passenger-ship-v01`](../../assets/props/tang-three-mast-passenger-ship-v01/README.md)：同一条深棕色唐风中型木质客船，船长约22至26米、宽约5至6米，船头狭长微翘、船尾较宽。
- 中央只有一层通高长舱，长约7至9米、内部净高约2.2至2.5米、舱门高约1.8至2米，成年人能够直立进出；三根桅杆沿船体纵轴前中后排列。
- 主帆约7至9米高、4至5米宽，前帆和后帆面积约为主帆75%和65%；三面米白或浅麻色帆布不得遮挡人物、船舱和峡壁。
- 三面帆受到同一峡谷顺风，鼓起方向一致；帆面、船头破水、尾流和人物衣带共同指示前进方向。
- 只保留必要固定索具，无船桨、竹篙、发动机、船夫、水手、其他乘客和货物。“轻舟”通过顺流迅疾和船行轻快表达，不再限定为双人小舢板。

## 四张卡

1. 船型结构卡：锁定一层舱、三桅三帆、船头船尾、甲板和人物位置。
2. 开场卡：船尾左后或船身左后方三分之四视角，船头明确指向画面中央偏上的峡谷入口。
3. 中段卡：同一左侧轴线的船头左前或船身左前三分之四视角，锁定阿砚留在前甲板数山和栀夏稳定回应。
4. 结尾卡：船尾左后上方宽景，锁定人物自然回望和身后近峡壁、中景山体、远景峡口、雾中远山四层“万重山”。

两岸峡壁必须从水边以约70至85度陡直拔起，并延伸到画面顶部之外；左右峡壁合计占宽约60%至70%，天空约占10%至15%，前景无主体空水面不超过约20%至25%。船头始终指向狭窄、可通行的峡谷纵深，不能横在江面中央或朝向岸壁。
