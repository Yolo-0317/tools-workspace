# 栀夏舞蹈不得退化为持续奔跑设计

## 背景

《山行》15 秒诗境虽然完成了寒山、石径与霜林转红，但栀夏大部分时间沿石阶持续奔跑，舞蹈主要依靠张臂、裙摆和镜头追随形成运动感，缺少可辨认的中国古典舞动作单元。结果是“人物一直跑过诗景”，而不是“栀夏用舞蹈演绎诗景”。

## 方案比较与选择

- 完全禁止位移：能避免跑步化，但会让舞蹈失去空间发展，不适合所有诗境。
- 限制连接位移：允许一至两步短距离移步连接舞句，主体由明确舞蹈动作完成；既保留空间变化，又能防止持续奔跑。采用此方案。
- 继续允许长距离行进舞：自由度最高，但 Seedance 容易把“行进、疾行、推进”简化为普通奔跑，无法稳定满足舞蹈表现目标。

## 核心规则

1. 栀夏不得把持续奔跑、连续疾行、长距离赶路或普通走路作为舞蹈主体。
2. 位移只用于连接舞句；单次连接默认使用一至两步，并在连接前后形成清楚的舞蹈动作变化。
3. 每个主要舞句必须至少包含两类可观察的中国古典舞要素：重心转换、沉提、拧倾、圆场步、翻身、旋转、甩袖、云手、腾跃或其他具有明确身体发力链的动作。
4. 手臂展开、裙摆飘动、长袖余摆、特效跟随和摄影机运动只能反馈身体动作，不能替代舞蹈。
5. 摄影机围绕舞姿、重心变化和动作高潮运动，不以长时间追赶奔跑人物作为主路径。
6. 开场第一秒要呈现可见的快速起舞过程，不允许第一帧已经停在完成姿态后只继续平移。
7. 前景穿越不得遮挡栀夏面部或核心舞姿；阿砚开场若入镜，必须保持完整可辨的角色轮廓。

## 阿砚边界

阿砚不受栀夏的“禁止持续奔跑”限制。它可以在栀夏侧后方或路线内侧以真实四足奔跑、跨步、短距离避让和至多一次短跃保持动态参与，但不得进入栀夏舞蹈路线、抢占高潮或迫使摄影机离开栀夏的主要舞姿。

## 提示词约束

- 避免单独使用“沿山路疾行”“持续推进”“一路奔跑”等容易被解释为普通跑步的表述。
- 若诗境需要空间位移，写明“一至两步连接舞句”，并同时列出连接前后的身体动作、重心变化与方向变化。
- 明确“不是奔跑、不是赶路、不是张臂跑动”，同时用正向动作描述替代单纯否定。
- 高潮必须由舞蹈动作触发环境或特效变化，不能只由人物跑到新景点后让景色自行变化。

## 验收标准

- 任意连续两秒内都能识别至少一次明确的舞蹈动作变化，而不是只有跑步循环、衣袖飘动或镜头移动。
- 长距离移动镜头中，栀夏仍以舞步、翻身、旋转、腾跃或清楚的重心转换推进，不出现连续普通跑步。
- 栀夏是舞蹈主体，诗景是舞蹈结果；阿砚可以奔跑跟随，但不改变这一主次关系。
