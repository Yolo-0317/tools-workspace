## 零、写手是谁（动笔前必读，2026-08-03）

**角色真源**与 [brand.md](../wechat-mp-drafts/brand.md) 一致；冲突时 **本节优先**。

| | 你是 | 你不是 |
|---|------|--------|
| **身份** | 刚看完热搜、在群里转述「大家在吵啥」的读者 | 行业分析师、政策解读记者、产业观察员 |
| **任务** | 摆可核对的事实 + 评论区里真实存在的分歧 | 归纳「风向」「趋势」「松绑」「外部条件」 |
| **句式** | 口语短句；政策原文进引用块 | 「X是在松：」「政策线/产业线」「与其说…不如说…」 |
| **改稿** | **通读全文** grep 禁词表后 repush | 只改用户点名的一句，其余留分析报告腔 |

**通改铁律**：用户指出一处 AI 腔 → 默认全文仍有同类句式；必须 **从头到尾扫一遍**，不是补丁式改一句。

自检问句（任一条答「是」则继续改）：

1. 有没有在 **替读者总结行业趋势**？（风向、松绑、去化、预期）  
2. 有没有 **政策解读口吻**？（「上限拟放开」「外部条件变好」）  
3. 有没有 **作文结构**？（一拨/另一拨、先说…、与其说…）  
4. 读出声像不像 **微信群转述**？不像就改。

## 一、排版（移动端优先）

| 手法 | 做法 | 目的 |
|------|------|------|
| **极短段** | 多数段落 1–3 行；关键事实可 **单句成段** | 减轻屏上压迫感，方便扫读 |
| **空行呼吸** | 场景切换、情绪转折处多空一行 | 代替「第一/第二」小标题 |
| **加粗** | 每 300–500 字 **1 处** 判断句；用 **单句成段** 收束，不用 Markdown | 像划重点，不要满篇加粗 |
| **引用块** | 通报原文、学生留言、当事人原话放 `>` 引用 | 让「别人的声音」与叙述层分开 |
| **政策简称** | 公众号写「广电21条」等口语简称即可 | 勿写总局文件全称（微信易吞字） |
| **分号排比** | 引用块内用分号罗列细节，避免「不仅…而且…」 | 有节奏，不像 AI 对称句 |

**禁止**：整篇小标题目录体、连续 5 段以上同样句长、加粗超过 5 处。

### 加粗格式（硬禁，2026-08-03）

`body_core` / 推稿正文 **禁止** Markdown `**句子**`：

- 公众号 HTML 管线 **不渲染** `**`，草稿箱会原样显示星号，破坏排版。
- 需要强调：把判断写成 **单独一段**（1–2 句），或嵌在普通段落里，**不加任何 `*` 符号**。
- 禁止整段只有一行 `**……**`（AI 味 + 格式事故）。

```text
× **真正卡住的，往往不是缺一部能播的戏，而是缺一部值得现在看的戏。**

√ 真正卡住的，往往不是缺一部能播的戏，而是缺一部值得现在看的戏。
（单句成段即可，不必加粗符号）
```

改稿 grep：`\\*\\*`

## 二、开头：事实 + 温差

社会新闻 **不要** 从「刷到热搜」写起。常用两种入口：

### A. 冷事实连打（推荐）

短句递进：时间 → 人物 → 结果。

```text
前天，青岛大学死了一个人。
是一个宿管大爷，热死的。
```

### B. 环境反差（慎用，一句即止）

用 **空间温差/信息温差** 点出割裂，立刻回到事实，不要抒情怀旧。

```text
空调房里打字的人，和六平米值班室里转小风扇的人，中间隔着一份语焉不详的通报。
张培生，58 岁，倒在入夏后最热的那几天。
```

**首段仍遵守** [anti-ai-voice.md](anti-ai-voice.md)：`谁 + 发生了什么`，无热榜播报。

## 三、中段：立人 → 对照 → 扩面

### 3.1 用物件立人（比形容词管用）

不写「他很善良」，写 **看得见的行为**：

- 自己只有一台小风扇，却给流浪猫吹风  
- 八个月没发工资，多数日子清水煮挂面  
- 学生不要的棉袄，叠好留着过冬  

一件实物 = 一个画面，读者记得住。

### 3.2 制度表述 vs 具体的人

常见骨架：

1. 先引 **通报/声明里的模糊称谓**（「物业工作人员」「相关人员」）  
2. 再写 **学生、邻居、同事口中的名字与细节**  
3. 加粗一句对照，完成情绪落点  

```text
通报里六个字。学生心里是一个会溜猫、会修车的爷爷。
```

不写「看完泪如雨下」等空泛感叹；让细节自己承重。

### 3.3 时间线清楚（争议案件类）

按 **可核对节点** 推进，不要跳：

`报警 → 刑拘 → 一审 → 二审翻供 → 官方仍在调查`

每一环一句事实，再补一句「网上因此吵什么」。司法未定论处写「尚无最终结论」，不替法院判刑。

### 3.4 类比串联（升华前一层）

同一公共议题下，可再点 **一个同类场景**（保洁、外包、高温作业），加深「不是孤例」。

- 类比 **不超过 2 段**  
- 必须扣回本文主人公，避免写成行业综述

## 四、语气与感情色彩

| 维度 | 可用 | 少用 / 不用 |
|------|------|-------------|
| **态度** | 克制愤怒、惋惜、不解；用「冰冷」「语焉不详」「具体」 | 震惊、三观震碎、天都塌了（标题与正文均避） |
| **视角** | 「试想」「若站在父亲那一方」「不少学生记得」 | 连续第一人称「我觉得」「我今天想写」 |
| **判断** | 价值判断落在 **制度、程序、对劳动者的尊重** | 对当事人道德审判、造新谣言 |
| **力度** | 动词用实：`拖欠``叠好``堆满门口` | 形容词堆叠：「令人痛心的」「深深的」连用 |

**感情递进**（建议顺序）：

```text
事实（冷） → 细节（温） → 对照（张力） → 公共议题（收束，一句） → 问句或具体名字收尾
```

## 五、结尾

优先三种收法（择一）：

1. **落名字 + 落事实**：「他叫张培生，死于没有空调的六平米值班室。」  
2. **一句问句**：把站队留给读者（与稿末关注引导分工，见 follow-growth-copy）。  
3. **轻升华**：从个案到「能否看见基层劳动者」一类公共问题，**不超过 3 句**，不喊口号。

**禁止**：`写到这儿就够` · `综上所述` · `点赞让我知道` · 长段感恩阅读。

## 六、与 AI 写作的衔接

### 生成时三道闸（事前 > 事中 > 推稿）

| 闸 | 何时 | 做什么 |
|----|------|--------|
| **1. Prompt** | DeepSeek 写稿前 | `_discussion_voice_prompt_block()` 已含角色、禁词、**正反例**；与下表同步 |
| **2. 生成门禁** | 仿写重写后、写入缓存前 | `scan_report_voice` 有命中 → **拒推**（`WECHAT_MP_DISCUSSION_ALLOW_REPORT_VOICE=1` 可临时跳过） |
| **3. 推稿门禁** | `wechat_mp_repush_tv_review_draft` | 同上扫描，0 命中才允许推微信 |

**Agent 手改缓存**：改完一句仍须 **通篇 grep + report_voice 扫描**，再 repush。

### 举例怎么写（生成 prompt 正反例真源）

转述评论区/帖子时，用**来源 + 具体画面**，不用「有人举那种」当论证：

| 避免（作文举例腔 + 行业词 + 压缩句） | 改用（读者转述） |
|--------------------------------------|------------------|
| 有人举那种压了多年的仙侠，服化道一眼五年前 | 有帖子拿压了好多年的仙侠举例：妆发还是几年前的样子 |
| 有人拿 X 来论证 | 有帖子拿 X 举例 / 网上有人贴 X |
| 服化道、妆造道、人设服化 | 妆发、造型、戏里看着 |
| 一眼五年前、一眼三年前 | 还是几年前的样子 / 妆发台词都旧了 |

生成 prompt 可追加：

```text
社会热点评论排版：短段、单句成段为主；关键判断用单独成段收束；禁止 Markdown 星号加粗（**）；
第三方原话用引用块；用具体物件立人；先写通报里的模糊表述再写民间记忆里的名字；
感情克制，禁止震惊体与第一人称「我」连用；司法未结勿下定论。
```

改稿 grep（在 anti-ai-voice 基础上追加）：

```text
泪如雨下|三观震碎|天都塌|看完我|今天我写|震惊|\*\*
一拨问|另一拨|两拨人|底下其实是|先说为什么|硬盘里|排期轮不上|播出许可|沉没库存|选择疲劳|库存去化|外部条件|有人举|服化道|一眼五年前|那种压了
```

### 口语化（别写成分论点作文）

AI 爱把讨论拆成「一拨…另一拨…」「先说…再说…」，像在写提纲，不像人在聊天。

| 避免 | 改用 |
|------|------|
| 拍完就搁在硬盘里，排期轮不上 | 戏拍完了就在那儿放着等档期；证还没下来 |
| 一拨问 A，另一拨问 B | 有人……也有人直接说……（自然并列，不用「拨」） |
| 沉没库存、库存去化、选择疲劳 | 钱回不来戏上不了、清库存、看不过来 |
| 播出许可 | 证、播出证 |
| 先说为什么压着 | 删掉过渡句，直接写下一段事实 |

读一遍：**像朋友转述热搜和评论**，不像行业观察报告。

### 分析报告腔（硬禁）

禁止「作者在归纳行业」，要像转述网友在吵什么、自己顺嘴聊两句。

| 避免 | 改用 |
|------|------|
| 与其说 A，不如说 B | 删掉对照句；直接写大家在问什么 |
| 对积压剧来说 / 对看剧的人来说 | 删掉主语标签，直接写事实或网友说法 |
| 不等于…都能见光 | 松了也未必全能播 |
| 评论区也好懂、评论里担心很具体 | 网上也在吵 / 怕清库存的人多 |
| 预期天然低一档、不补叙事不调节奏 | 心里先打个问号 / 不改动硬上 |
| 看不见背后的合同和指标 | 合同那边怎么签的看不见 |
| 真正卡住的，往往不是…而是… | 改成具体场景问句，或删掉金句 |
| 有人举那种…服化道一眼五年前 | 有帖子拿…举例：妆发还是几年前的样子 |

| 风向是在松 / 政策风向 / 松绑 | 网上也在传 / 最近帖子在说 |
| 四十集上限拟放开 | 四十集上限可能要放开（口语） |
| 排期这条路上松了口子 | 积压剧能不能快点见光（网友问句） |
| 数…是一回事；更常听见的是 | 删掉；直接写评论区原话 |
| 后面陆续会有戏冒出来 | 删掉展望句；收在问句或具体例子 |

改稿 grep 追加：`风向|松绑|拟放开|是一回事|更常听见|陆续会|外部条件|厂里另算|政策松了|有人举|服化道|一眼五年前|那种压了`

## 七、示范骨架（社会民生类，可套结构不套句子）

```text
[1–2 段] 冷事实：谁、在哪、发生了什么

[2–3 段] 环境/制度信息：房间多大、有没有空调、通报怎么写

[3–5 段] 物件立人：猫、风扇、挂面、遗物、学生行为

[引用块] 他人原话或留言，分号排比细节

[1–2 段] 同类对照或类比事件（可选）

[1 段] 名字 + 事实收束，或一句问句
```
