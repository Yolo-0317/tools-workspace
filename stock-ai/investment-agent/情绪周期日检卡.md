# 情绪周期日检卡

> 独立 **游资轨** 每日巡检（龙头打板 / 题材情绪）
> 创建：2026-06-02 | 方法论：龙头战法 + 情绪周期（散户降维版）
>
> **权威数据**：MySQL `emotion_cycle_daily` + `emotion_cycle_dragon_watch`（本文件为字段说明与纪律）
>
> **与主账户关系**：本卡为 **方法论 + 字段说明**；仿真 **可执行摘要** 见 **`龙头执行卡.md`**（仅 emquant）。实盘仍以 `持仓执行卡.md` 为准。

## 数据落库

| 表 | 用途 |
|----|------|
| `emotion_cycle_daily` | 每日主记录（`trade_date` + `checklist_slot`） |
| `emotion_cycle_dragon_watch` | 龙头观察池（同日同 slot 覆盖） |

| 时段 slot | `pre_market`（9:26 盘前）| **`intraday`（盘中每 15min，OpenCLI 涨停池）** | `eod`（17:10 收盘复盘） |

**迁移**（首次或升级）：

```bash
cd tools-workspace/stock-mysql && bash scripts/init-db.sh
```

**自动化**（2026-06-02）：

| 调度 | 命令 |
|------|------|
| 工作日 17:00 | Tushare → MySQL `stock_daily` |
| 工作日 **17:10** | `./sync_emotion_cycle.sh eod`（须在 Tushare 之后） |
| 工作日 09:26 | `./sync_emotion_cycle.sh pre_market` |
| 工作日 **盘中每 15min** | `./sync_emotion_cycle.sh intraday`（launchd `com.user.stock-emotion-intraday`） |

计算来源：`stock_daily` 全市场（eod/pre_market）或 **东财涨停池 OpenCLI**（intraday）→ `emotion_cycle_*`。  
调度：eod/pre_market 在 `docker/scheduler/crontab`；**intraday** 在 launchd `com.user.stock-emotion-intraday`。

手动：

```bash
cd stock-ai && ./sync_emotion_cycle.sh eod
```

```bash
cd tools-workspace/stock-ai

# 输出 JSON 模板
uv run python -m scripts.tools.emotion_cycle_checklist template > /tmp/emotion_cycle.json

# 编辑后写入 MySQL
uv run python -m scripts.tools.emotion_cycle_checklist save -f /tmp/emotion_cycle.json

# 读取最新 / 指定日
uv run python -m scripts.tools.emotion_cycle_checklist show
uv run python -m scripts.tools.emotion_cycle_checklist show --date 2026-06-02 --slot eod

# 已有交易日列表
uv run python -m scripts.tools.emotion_cycle_checklist list
```

Agent 做题材/短线建议前：**`load_emotion_cycle_checklist()`** 或上述 `show` 命令。

## 使用说明

| 项目 | 说明 |
|------|------|
| **何时填** | 每个交易日 **9:25 前**（竞价后）+ **15:05 后**（收盘复盘）各 5 分钟 |
| **谁填** | 人工 + AI 辅助采集；Agent 做题材/短线建议前 **必须先读本卡当日记录** |
| **资金边界** | 游资轨总预算 ≤ 可用资金 **40%**；单票 ≤ 总资产 **8%**（1～2 手）；与执行卡 B/C 档对齐 |
| **硬冲突** | 执行卡禁止项（梅花补仓、>75% 新开仓、单日 >5% 追建主仓）**始终优先** |

## 一、盘前快扫（9:25 前，约 3 分钟）

复制字段到 JSON 模板保存，或直接 `save -f`。**可选**备份摘要到 `memory/YYYY-MM-DD.md`。

### 1.1 情绪温度计

| 指标 | 今日数值 | 参考阈值 | 信号 |
|------|----------|----------|------|
| 涨停家数 | | ≥40 偏多；≤20 偏冷 | |
| 跌停家数 | | ≥30 退潮；≥15 谨慎 | |
| 涨跌家数比 | | <1:2 偏空；>1:1 偏多 | |
| 连板最高板（空间龙） | __ 板 | ≤3 冰点；≥5 发酵 | |
| 昨日涨停今日平均溢价 | __% | <1% **不打板**；≥3% 生态尚可 | |
| 炸板率（炸板/曾触板） | __% | ≥40% **不接力** | |
| 成交额（全 A） | __ 亿 | 量缩+题材多 → 切换快，难做 | |
| 同时在炒题材数 | __ 个 | **>3 个 → 主线不清，降仓** | |

**数据来源（东财，OpenCLI 或浏览器）**：

- 涨跌停统计：`https://data.eastmoney.com/zjlx/list.html`（或战报指数脚本输出）
- 连板梯队：`https://data.eastmoney.com/stock/lhb.html` + 涨停复盘页
- 昨日涨停表现：同花顺/东财「昨日涨停表现」板块

### 1.2 阶段判定（六选一）

对照 `memory/trading-strategies.md` 第十章，勾选 **唯一** 主阶段：

- [ ] **冰点期** — 连板≤3、跌停多、炸板率高、无清晰主线
- [ ] **启动期** — 连板突破 3、涨停≥40、**新主线**出现
- [ ] **发酵期** — 梯队完整、连板≥5、中军放量、龙头辨识度集中
- [ ] **高潮期** — 批量一字/秒板、散户狂热、几乎无亏钱效应
- [ ] **分歧期** — 主线大分歧、炸板增多、高度下降
- [ ] **退潮期** — 龙头 A 杀、跌停≥30、全面亏钱

## 三、买卖纪律（盘中对照）

### 3.1 可以做的

- [ ] 阶段 = 启动期 / 发酵期，且昨日涨停溢价 ≥1%
- [ ] 炸板率 <40%
- [ ] 标的是主线龙头，非跟风
- [ ] 买点 = **回封** 或 **分歧转一致**，非盲目开盘接力
- [ ] 已写好 **止损价** 与 **次日竞价割** 预案

### 3.2 禁止做的

- [ ] 冰点期 / 退潮期新开（默认）
- [ ] 追 **三连板以上** 加速（小资金排不进 + 盈亏比差）
- [ ] 打 **缩量一字** 板
- [ ] 题材 >3 个时重仓
- [ ] 亏损 **补仓**（尤其梅花生物 — 执行卡红线）
- [ ] 用游资轨预算 **接主账户收息/深套老仓**

### 3.3 止损与出局

| 情况 | 动作 |
|------|------|
| 买入逻辑被证伪（破板、主线退潮、龙被卡位） | **次日 9:25 竞价割** |
| 日内浮亏达 -5% | 能卖则卖；T+1 买入的 **次日开盘优先割** |
| 持仓 5 日未达预期 | 时间止损，换股或空仓 |
| 阶段转入 **退潮期** | 游资轨 **无条件清仓** |

## 五、与自动化选股的关系

| 来源 | 用途 |
|------|------|
| `core_v2/stock_selection_combined.py` | **主轨** — 回踩/突破/埋伏，17:30 Top5 |
| `scripts/selection/stock_selection.py` | 量价突破辅助，**不等于** 龙头打板 |
| **本日检卡** | **游资轨** — 连板/题材/情绪，人工 + 东财二遍 |

**交叉规则**：综合选股 Top5 与龙头观察池 **重叠** → 可提高关注优先级；**仅龙头池有、综合无** → 视为高风险题材试探，最多 1 手。
