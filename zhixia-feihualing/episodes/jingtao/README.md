# 《乱石穿空》10 秒诗境

## 取句

- 苏轼《念奴娇·赤壁怀古》：乱石穿空，惊涛拍岸，卷起千堆雪。
- 形式：Seedance 2.0，10 秒，9:16 竖屏，电影级高写实 CG，一镜到底。

## 当前输入

- 图片1：栀夏 Seedance 上传版角色母版，只锁定身份、面部、发型发冠、服装结构与配色。
- 图片2：阿砚 Seedance 上传版角色母版，只锁定原创物种、约 40 厘米体型、结构、标记、外扩纸纤维和唯一墨尾。
- 不上传状态卡、场景图、动作分镜、舞蹈参考视频或运镜参考视频。

## 诗境与舞蹈

真实赤壁、奔涌大江、湿黑乱石和拍岸巨浪构成诗景主体。栀夏沿湿石斜向移动，以两次换重、沉身提转和一次完整旋转发展舞蹈；衣袖、裙摆和水雾沿同一弧线跟随。旋转离开后，她跨步倾身向大江展开，巨浪拍岸形成白色浪沫高潮。白色浪沫只表达水势，不出现真实降雪。

摄影机全程沿低位斜向后退主路径运动：栀夏旋转时短暂加速并有限同向弧移；巨浪拍岸时沿原路径抬升拉开，穿过一层短暂透明水雾，揭示高耸赤壁和奔涌江面。

阿砚位于侧后方较高的安全礁石，不参与舞蹈、不增加强制特写。每次出现均贴近母版，保持足底至耳尖约 40 厘米、笔锋双耳、四足、单尾、朱砂额印、暖金纹样和向外呲出的纸纤维毛束。

## 声音边界
