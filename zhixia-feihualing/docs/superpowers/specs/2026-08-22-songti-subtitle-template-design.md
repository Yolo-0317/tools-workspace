# 栀夏飞花令宋体诗签字幕模板设计

## 目标

为《栀夏飞花令》建立可重复使用的国风字幕模板，在720×1280竖屏视频上兼顾诗意、角色画面和手机端可读性。本设计只覆盖字幕视觉与时间，不包含背景音乐。

## 字幕样式

- 使用 macOS 系统宋体 `Songti.ttc`。
- 诗句采用水平居中排版，每句最多两行。
- 正文字号以44像素为基准；较长诗句在不换出安全区的前提下缩小至40像素。
- 正文为深墨灰，使用极细暖白描边和轻微水墨灰阴影。
- 每句中的主题字“花”使用朱砂红，其余文字保持深墨灰。
- 字幕下方使用淡象牙白半透明圆角纸签，提供稳定对比度并弱化画面底部多余书本。
- 纸签位于底部安全区，主体中心距离画面底边约130像素，不遮挡栀夏与阿砚的脸。

## 文案与时间

| 时间 | 文案 | 角色 |
| --- | --- | --- |
| 0.00—2.69秒 | 今日飞花令｜花 | 阿砚 |
| 2.90—5.97秒 | 夜来风雨声，花落知多少。 | 栀夏 |
| 6.00—9.86秒 | 人闲桂花落，夜静春山空。 | 阿砚 |
| 10.00—15.23秒 | 桃花潭水深千尺，不及汪伦送我情。 | 栀夏 |
| 17.75—20.01秒 | 第四句，你来接。 | 阿砚 |

每条字幕在语音开始时快速淡入，在语音结束前后自然淡出。字幕时间允许与相邻转场重叠，但不得让两条字幕同时完整显示。

## 实现方式

当前 FFmpeg 缺少 `drawtext`、`subtitles` 和 `ass`，但支持 `overlay`。因此先在本地使用系统字体将每条字幕渲染成720×1280透明PNG，再由 FFmpeg 按时间叠加到配音版视频。

输出必须保留原视频720×1280、24fps和AAC音轨。字幕渲染失败、字体缺失或文字超出安全区时停止导出，不回退到不明来源字体。

## 验证标准

- 五条字幕均在对应语音期间显示。
- 中文无乱码、无缺字，主题字“花”为朱砂红。
- 字幕不越出画面，不遮挡人物面部。
- 最长诗句在手机尺寸预览下清晰可读。
- 输出时长与配音版一致，视频和音频均可完整解码。
- 字体为本机系统字体，不引入未记录的第三方字体授权风险。
