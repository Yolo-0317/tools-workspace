# 公众号返佣畅销候选与文案试验设计

日期：2026-09-26。状态：根据用户“不要卖书，卖零食或者日用小百货”的最新要求，替代同日单品稿型设计中的默认选品范围。

## 目标

保留手动独立 `product_feature` 稿型和单商品卡草稿槽位。每次先在现有公众号返佣商品 Select 接口中，只在零食与日用小百货中找高销量候选，再选一件写有明确推荐倾向的文章，并在本地保存几种标题、开头或推荐角度供人工试验。默认不搜、不选书籍和小家电；不进入定时任务，也不自动发表。

## 数据能力与边界

Select 支持关键词分页搜索，返回 `sales_tips` 及 `basic_info.sale` 中的来源平台销量、返佣流量销量等字段。2026-09-26 对零食、休闲零食、早餐面包、家居日用、洗洁精、纸巾、垃圾袋、收纳用品等词各两页采样；已查样本的 `sales_on_flow` 均为 0。因此不能称“公众号流量主全站最畅销”或给出平台榜名次。候选报告应写“本次采样内来源平台销量提示”，列采样词、页码、时间、来源、价格、佣金和销量字段。跨来源数值不保证同口径；同值时用预计单笔佣金及与读者需求的贴合度辅助判断。

## 选品

默认词池只覆盖零食与日用小百货，可在以后按数据调整。每词读前两页、每页最多 30 件，去重并排除书籍、小家电及其他无关品类、商品身份不清、销量提示低于 1000、价格或佣金缺失、金额与佣金率矛盾的条目。输出采样内销量领先候选和各品类代表；避免只有高销量但无法核对商品详情、无法说明使用需求或佣金极低的条目直接进稿。入选理由须说清销量近似值、预计佣金、读者需求和能核实的产品事实。

## 文案试验

一件商品至少准备三种不同切入角度（如时间成本、具体使用情境、购买判断），从中选一版写完整推荐稿。正文先让读者认出需求，再用可核事实解释为什么推荐这一件，保留简洁的适用边界和替代办法；不能用硬广告词、虚构亲测或假稀缺性。结尾要有明确、有条件的推荐倾向。预计佣金只在内部选品记录出现。商品卡前单独显示“广告”标识，正文不朗读返佣机制。试验记录保留角度、标题、开头、入选原因，未来如有阅读、卡片点击、订单与确认佣金数据，再复盘，不将来源平台销量当本号转化率。

## 验证

扩展当前选品测试：默认词池不含书籍和小家电；跨品类去重；按销量提示领先排序；记录返佣流量销量是否可用和采样口径；书籍和小家电候选被排除。结构化稿保留现有事实、广告标识和商品卡门禁，并新增可审阅的文案角度记录。真实接口只读采样及 `--dry-run` 验证后，才可按用户明确要求写入公众号草稿。
