# 热点稿编辑指令泄漏门禁设计

## 问题

热点稿正文出现了“这是辽宁的地方政策，更不能写成全国统一取消历史、地理和生物计分”。事实限定本身正确，但“不能写成”是写作者或审稿者之间的编辑指令，不应出现在读者可见正文中。

现有流程只在自动生成链路检查部分报告腔表达。用户粘贴 DeepSeek 初稿、Agent 编辑后入库的链路，以及最终推送前，均缺少专门的编辑指令泄漏门禁。已有报告腔扫描又包含“不等于”等宽泛词，不能直接作为硬门禁，否则会误伤“不计入总分不等于取消课程”这类正常论述。

## 目标

- 拦截正文中面向写作者、编辑者或模型的过程性指令。
- 不拦截面向读者的正常事实限定、反驳和论证。
- 在热点稿入库和最终推送前各检查一次，避免后续改稿重新引入问题。
- 修正当前辽宁中考稿的问题句，并重新生成无泄漏的公众号草稿。

## 判定范围

新增独立的“编辑指令泄漏”扫描器，不复用宽泛的报告腔硬门禁。首批规则只覆盖高置信度表达：

- 带编辑动作的禁令或要求，如“不能写成”“不要写成”“应表述为”“建议改成”。
- 明确指向稿件构成的过程语言，如“正文应当”“标题需要”“稿件中不要”“文章里应补充”。
- 明确暴露工作流的语言，如“提示词要求”“审稿时需要”“配图建议”“来源列表如下”。

下列表达不得仅因出现“不能”“不等于”等词而被拒绝：

- “不计入总分不等于取消课程。”
- “不能据此推断全国统一调整。”
- “不能把管理成本转嫁给家长。”

扫描结果返回命中规则、短片段和修改提示，便于编辑直接定位，不输出整篇正文。

## 接入点

1. 在热点稿入库校验中扫描标题、摘要和正文；命中后拒绝入库。
2. 在最终推送读取已确认稿件后再次扫描，并在上传图片或调用微信接口前终止。
3. 现有自动生成流程可复用该扫描器，但不改变原有报告腔提示逻辑。

## 外部写作经验吸收

本次同时参考公开的公众号与新闻评论写作资料，但不整套搬入外部 Skill：

- 微信公众平台运营中心要求标题准确、清晰并体现正文主旨，禁止仿冒官方、无依据夸大严重程度或隐去关键信息：[《关于规范公众号标题夸大营销的公告》转述](https://www.thepaper.cn/newsDetail_forward_26514412)。
- `bigpeng-hot-gzh` 从公众号样本提炼出“具体对象、可感知结果、读者身份”，并强调标题中的数字、反转和附赠承诺必须由正文兑现：[项目说明](https://github.com/BigPengSays/bigpeng-hot-gzh)与[标题规则](https://github.com/BigPengSays/bigpeng-hot-gzh/blob/main/references/title-formulas.md)。其语料主要来自 AI 工具赛道，只吸收可迁移的标题兑现原则，不照搬情绪型公式。
- 复旦大学新闻评论写作课程把集中、连贯、效率，以及事实判断、价值判断、论点、论据、论证、结构和语言列为完整训练链条：[课程大纲](https://jwc.fudan.edu.cn/_upload/article/files/d4/56/707002a8413b8a3cc690244c1118/a7491833-eb4d-41df-bef8-ad5e663ea2e4.pdf)。
- 新闻类公众号内容编排研究强调接近普通人的生活场景、口语表达和移动端精简阅读：[《浅析新闻类微信公众号内容编排策略》](https://zjjcmspublic.oss-cn-hangzhou-zwynet-d01-a.internet.cloud.zj.gov.cn/jcms_files/jcms1/web3214/site/attach/0/7fc53868bde74271b6c2b462bc0fb176.pdf)。

这些资料形成两层门禁。

### 阻断门禁

只处理能够稳定自动判断的错误：

1. 编辑指令或工作流语言泄漏。
2. 标题含“震惊”“重磅”“炸裂”“看完即删”等已明确禁用的营销词。
3. 标题冒充通知或扩大政策范围，如无对应权威依据却使用“紧急通知”“全国统一”“全面取消”“所有学生”等绝对表述。该项必须结合稿件来源与正文判断，不做单词级误杀。
4. 标题中的具体数字、人物、地区、政策动作或括号承诺，在摘要和正文中找不到对应内容。
5. 标题核心事件没有在正文开头落地，正文前段仍停留在选题过程、热搜播报或空泛议论。
6. 正文出现重复段落、连续同义结论、未清理的小标题或清单格式。

### 编辑评分门禁

以下项目需要结合语义和稿件类型判断，不用单个正则一票否决；评分低于阈值时退回 Agent 编辑：

1. 全文是否围绕一个可争论、可检验的核心判断推进，而非只复述新闻。
2. 是否清楚区分已确认事实、当事人说法、推测和作者判断。
3. 每个主要判断是否有事实、规则、案例或逻辑支撑。
4. 是否在前段落到普通人的金钱、时间、机会、尊严或选择成本。
5. 是否回应最强反方理由并给出适用边界，而非单向输出情绪。
6. 结尾问题是否由正文自然推出，并且具体到读者能够作答。
7. 段落是否适合手机阅读；长段应拆分，但不把完整逻辑拆成口号式短句。

不采纳“标题必须带情绪词”“每 300 字必须设置悬念”“固定套用若干爆款结构”等经验。这些做法缺少稳定适用性，也容易与热点深评的事实边界和克制口吻冲突。

## 当前稿件修正

将问题句改为：

> 这是辽宁的地方政策，各地中考方案并不相同，辽宁的调整不代表全国统一安排。

该改写保留事实边界，同时去掉面向编辑者的过程语言。

## 测试与验证

- 先写失败测试，确认原问题句会被拒绝。
- 确认修正句以及三个正常论述反例均可通过。
- 验证用户粘贴稿入库时会拒绝泄漏文本。
- 验证最终推送会在任何图片上传或微信接口调用前拒绝泄漏文本。
- 用标题与正文配对样本验证：承诺已兑现、数字有依据的标题通过；标题夸大范围、承诺未兑现或核心事件未落地时拒绝。
- 用正常反问、政策范围限定和长短段混排样本验证，避免把克制评论误判成标题党或低质量文章。
- 运行热点写作、工作流和推送相关单元测试。
- 用原有三张抖音封面重新入库并推送修正版，核对公众号草稿标题与正文。

## 非目标

- 不把所有“提示性”或“判断性”措辞一律视为泄漏。
- 不使用“不等于”“不能”等单词级规则直接阻断发布。
- 不改变热点稿事实核验、图片数量、双确认和 IP 白名单处理流程。
