# 《白雪歌送武判官归京》Seedance 精简提示词重写设计

## 目标

在不改变已确认创意和音画节点的前提下，重写《白雪歌送武判官归京》10 秒诗境 Seedance 提示词，降低重复与权重冲突，让模型优先理解原创角色身份、开场人物钩子、连续镜头、角色尺度和自由舞蹈边界。

## 输入与生成方式

- 只上传两张角色母版：@图片1为栀夏，@图片2为阿砚。
- 不上传状态图、首帧图或其他场景参考图。
- 使用参考生成，不使用首帧图生视频。
- 雪林、首帧构图、角色运动和摄影机路径均由文字提示词生成。

## 提示词结构

1. 正文第一句使用固定原创虚拟角色声明，明确两个参考对象均为本项目原创虚拟角色，不对应现实人物、艺人、真实动物或既有影视动漫角色。
2. 第二句立即映射栀夏与阿砚两张母版，并限定母版只锁定角色身份、结构和造型，不复刻档案卡排版。
3. 用一个总控段锁定10秒、9:16、电影级高写实CG、一镜到底、雪林光线、唯一雪花和镜头变化次数。
4. 依照已定音频时长保留七个连续时间节点，但每段只保留当前画面必须执行的主体、动作、镜头和局部身份重锚。
5. 结尾分别写身份优先级、画面禁止项和声音限制，不在时间轴中反复复制全局限制。

## 必须保留的内容

- 0.5秒内由栀夏完成全片第一个可感知动作；首帧已经能辨认她的脸、发冠和服装。
- 阿砚足底至耳尖约40厘米、肩高约24至28厘米、躯干长度约40至45厘米且不含尾巴；保持双耳、四足、单尾、朱砂额印和纸墨材质。
- 阿砚与栀夏分别在既定时间完成一次无声口型，对白和诗句只在后期合成。
- 舞蹈约束完整且仅为“中国古典舞身韵、轻盈克制、连续自然、不遮脸”；不指定动作、连接、角度或收势。
- 全片只使用一片唯一引导雪花，只发生一次跨景别变化和一次运动方向变化。
- 雪林只形成梨花般的视觉联想，不出现实体梨花、花瓣、春叶或季节切换。
- 生成音轨不得出现对白、朗诵、旁白、耳语、吟唱或其他可辨识人声。

## 精简原则

- 删除同一限制在输入说明、总控段、时间轴和禁止项中的无必要重复。
- 身份特征只在开头完整定义，在换焦、舞蹈拉远和景观揭示等高风险节点做最短局部重锚。
- 不使用含糊的“真实体型”代替阿砚的明确尺寸，也不以透视关系改变其物理尺度。
- 不重新加入状态图依赖、具体舞步、三张状态卡、雪晶微距开场或阿砚先动开场。
- 精简不能改变既定时间点、角色先后关系、后期音频接口与生成前付费确认要求。

## 验收标准

- 正文第一行与固定原创虚拟角色声明逐字一致。
- 提示词只声明@图片1和@图片2，不引用第三张图或状态图。
- 栀夏先动、阿砚40厘米、自由舞蹈固定短语、唯一雪花、无声口型和无可辨识人声均可被自动检查定位。
- 现有白雪音频时间轴检查、写实视觉规范检查、自由舞蹈检查和栀夏优先开场检查全部通过。
- 文本不存在互相矛盾的首帧、角色尺度、舞蹈或声音要求。
