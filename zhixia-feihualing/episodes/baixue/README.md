# 《白雪歌送武判官归京》10 秒诗境

## 取句

- 诗句：忽如一夜春风来，千树万树梨花开。
- 作者：唐·岑参。
- 形式：Seedance 2.0，10 秒，9:16 竖屏，电影级高写实 CG，一镜到底。

## 当集画面主线

本集采用一个主要视觉事件和三个宽时间段：栀夏先动建立形象；她以弧线移动、两次换重和一次由低到高的身体层次发展中国古典舞身韵短句，动作带起的轻风使枝头粉雪自然落下；逆光把落雪与覆雪枝梢连成梨花般的视觉联想，栀夏三分之四正面完成收束，阿砚安静见证。

全片始终是冬季雪景。诗意来自真实落雪、逆光和景深，不出现独立图形雪花、真实梨花、花瓣、绿叶、季节转换或魔法爆发。

## 输入边界

- 正式生成只上传栀夏与阿砚两张角色母版，使用参考生成。
- 两张母版只锁定原创角色身份、结构、造型、材质与比例，不作为首帧或场景构图。
- 不上传状态图、首帧图、场景图或动作参考视频；场景与全部运动由纯文字建立。
- 已验收的开场状态卡只保留为人工构图参考，不参与 Seedance 生成。

## 角色与舞蹈

- 栀夏严格沿用当前 v04 高写实 CG 身份、固定脸、黑色高马尾、固定发冠和盛唐高腰服装，是第一视觉主体，并产生全片第一个清楚动作。
- 阿砚足底至耳尖约40厘米，保持双耳、四足、单尾、朱砂额印、暖琥珀眼、浅暖金纹样和纸墨纤维材质；与栀夏同框时耳尖低于她的膝盖。
- 舞蹈保持中国古典舞身韵、轻盈克制、连续自然、不遮脸，并写明弧线移动、两次换重、由微沉至提起、高低错落的双臂圆弧、衣料延迟反馈和稳定收势；具体连接只在这些可观察条件内自然完成。
- 阿砚只做抬头、转耳、注视等低复杂度反应，不参与舞蹈，不承担精确口型。

## 三段画面节奏

- 0—3 秒：开场立即看见栀夏正面偏侧中全景。她在 0.5 秒内抬眼、沿小弧线迈步，并把重心由后脚移向前脚；阿砚在她侧后方雪地保持约40厘米体型。
- 3—8 秒：栀夏继续侧向弧移，完成第二次换重并由微沉进入提起，转向覆雪松枝；高低错落的双臂圆弧与衣料余摆带起轻风，使粉雪自然落下。
- 8—10 秒：栀夏向较高层次舒展后稳定落回双脚支撑，以三分之四正面收势；逆光、落雪与覆雪枝梢形成梨花般的视觉联想，阿砚仍在同一空间关系中。

画面时间段只控制起承转合，不与后期四句 TTS 的毫秒长度硬绑定。

## 摄影机

摄影机沿侧向贴身跟随并逐渐拉开的一条主路径运动，近处覆雪松针提供前景视差。全片只有两次动作触发反应：栀夏微沉换重时镜头小幅降低；粉雪开始落下时，镜头沿原路径向侧后方有限弧移并拉开。结尾停在较宽的三分之四正面双角色构图；摄影机不绕到背后，不追逐雪粒，不无原因升空或突然反向。

## 声音分工

- 固定互动：阿砚“梨花？”；栀夏“是新雪。”；随后由栀夏朗诵两句诗。
- 四段文本、固定音色、实际时长与字幕时间以 [`voice-lines.json`](voice-lines.json) 和 [`subtitles-baixue.json`](subtitles-baixue.json) 为事实源。
- Seedance 只生成无人声背景音乐与自然环境声，不生成人物对白、朗诵、旁白、吟唱或其他可辨识人声。
- 视频模型不承担精确说话口型；对白、诗句和字幕全部后期合成。
