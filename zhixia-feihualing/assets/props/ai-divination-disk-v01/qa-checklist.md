# AI 卦盘母版验收清单

资产标识：`ai-divination-disk-v01`。

## 文件与画幅

- [ ] 文件名为 `master.png`，可以完整解码。
- [ ] 画幅为 16:9 横版，至少 1280×720 像素。
- [ ] 画面主体和文字安全区没有被边缘裁切。

## 身份一致性

- [ ] 左侧主视图和右侧六段流程属于同一面“星轨六爻盘”。
- [ ] 左侧主盘与右侧第二至第六格中的所有卦盘均为严格 90 度正俯视正交投影，横纵直径相等，所有星轨严格同心，没有椭圆或透视压缩。
- [ ] 六段流程保持完全相同的外框、星轨、配色、刻度、六个空爻槽和信息区域。
- [ ] 卦盘为不依附古籍、桌面或手掌的单层平面半透明悬浮光盘，不是 3D 分层结构、厚重实体圆盘、托盘或游戏法阵。
- [ ] 卦盘直径约 30 厘米、视觉上近乎无厚度，展开后能稳定悬浮在两位角色之间的桌面上空。
- [ ] 主色为浅青、月白、暖金与极少朱砂，没有蓝紫霓虹、强光柱或粒子漩涡。

## 六爻与信息区

- [ ] 主视图中心恰好六个空爻槽，没有第七槽，也没有预填六条阳爻。
- [ ] 组件特写恰好展示一枚阳爻和一枚阴爻；阳爻为完整横线，阴爻为中央中断的两段等长横线。
- [ ] 六段流程示例恰好六个爻位，生成方向自下而上；首集“山雷颐”自下而上为阳、阴、阴、阴、阴、阳。
- [ ] 卦名、上下卦和原文各有独立、清楚、无遮挡的可变区域。
- [ ] 精确中文和六爻可以在后期叠加，不依赖生成模型绘制可读文字。

## 直接淘汰

出现六段流程不是同一件道具、主视图不是恰好六个空槽、出现第七槽、默认六条阳爻、生成方向相反、阴阳爻无法区分、文字区被装饰遮挡、3D 分层结构、蓝紫游戏法阵、Logo 或水印时，母版不进入后续单集引用。
