# 《莲台天乐》舞蹈封面设计

## 目标

为《栀夏·敦煌十六舞》06《莲台天乐》制作一张 1080×1920 竖屏正式封面。封面直接取自已完成的无字幕高清朗诵版，不调用图片生成模型，不重绘人物、服装或石窟场景。

## 底图

- 视频：`exports/liantai-tianyue-15s-voiced-v01.mp4`。
- 固定取帧时间：14.000 秒。
- 画面内容：栀夏位于画面中右侧，完成结尾斜向仰身大开幅舞姿；左臂横向伸展，右臂斜向上举，脸部保持三分之四侧面可辨，蓝橙飘带在上身周围构成双重环线。
- 天窗月光从上方垂落，暖金油灯、赭褐石窟和浅刻莲纹保持清楚，人物与背景形成稳定冷暖对比。
- 直接从 1080×1920 无字幕高清朗诵版精确截帧，不改变人物比例、构图、光影或色彩，不修复飘带连接和背景壁画。
- 保留右下角原片已有“AI生成”标识。

## 文字层级与排版

- 左侧第一列小字竖排“栀夏”，作为系列角色识别。
- 左侧第二列主标题竖排“莲台天乐”，作为缩略图第一阅读信息。
- 左侧第三列小号题署竖排“唐·李白《庐山东林寺夜怀》”。
- 主标题使用项目既有行楷字体，角色名与题署使用楷体。
- 主标题使用暖象牙白，角色名与题署使用稍暗的柔和旧金色；统一添加克制深色柔影，确保文字在石壁和月光暗部上清楚可读。
- 主标题字距紧凑但不相连，字号、列距和起始高度延续《回雪胡旋》《霓裳飞天》《雪袖白纻》的敦煌舞封面体系。

## 安全区

- 三列文字集中在左侧石壁暗部，不遮挡栀夏眼睛、鼻口、头冠主体和躯干中心。
- 主标题允许覆盖少量横展左臂或外围飘带，以保证缩略图辨识度，但不得切断手掌轮廓。
- 题署不得进入人物脸部、承重腿、中心月光柱或右下角已有标识区域。
- 不增加横排副标题、英文、印章、边框、平台图标、完整诗句或营销文案。

## 制作方式

1. 使用 FFmpeg 从无字幕朗诵版 14.000 秒精确提取一张 1080×1920 原帧。
2. 使用本地 Swift/AppKit 确定性渲染器叠加三列准确中文。
3. 输出 PNG，并检查尺寸、色彩模式、文字、人物可读性和右下角标识。
4. 将封面路径、取帧时间和制作方式登记到单集 README 与素材清单。

## 输出

- 正式封面：`exports/liantai-tianyue-dance-cover-v01.png`。
- 构建入口：`scripts/build_liantai_tianyue_dance_cover.sh`。
- 渲染器：`scripts/render_liantai_tianyue_dance_cover.swift`。
- 验收门禁：`tests/test_liantai_tianyue_dance_cover.sh`。

## 验收标准

1. 输出恰为 1080×1920 PNG，可正常解码，色彩模式为 RGB 或 RGBA。
2. 底图来自无字幕高清朗诵版 14.000 秒，人物姿势、比例、光影和场景与源帧一致。
3. 三列文字依次为“栀夏”“莲台天乐”“唐·李白《庐山东林寺夜怀》”，无错字、乱码、截断或相互重叠。
4. 栀夏脸部、头冠、躯干、双臂大开幅和蓝橙飘带环线清楚；文字不遮挡五官和躯干中心。
5. 主标题在缩略图状态下清楚可读，允许覆盖少量左臂或外围飘带，但不切断手掌轮廓。
6. 右下角已有“AI生成”标识保留；不新增水印、边框、特效、装饰或平台元素。
7. 制作过程不调用图片生成模型，不重绘、补画、美化或修改栀夏与石窟场景。

## 不在本次范围

- 不修改朗诵字幕正式视频。
- 不制作横版封面、动态图封面或多套视觉方向。
- 不制作视频号发布文案。
