# Stock AI 家庭 MySQL 环境配置设计

## 目标

让本机运行的 `stock-ai` 脚本通过家庭局域网连接 MySQL，同时不把数据库密码提交到 Git。

## 方案

- 仅修改 Git 已忽略的 `stock-ai/.env`。
- 复用项目现有的 `MYSQL_URL`，将主机和端口设为 `192.168.1.13:3306`。
- 用户名设为 `stt_app`，数据库设为 `stock_data`。
- 密码位置保持为空，由用户在本机自行填写。
- 不新增并行的数据库配置键，不修改应用代码。

目标格式：

```dotenv
MYSQL_URL=mysql+pymysql://stt_app:<PASSWORD>@192.168.1.13:3306/stock_data
```

其中 `<PASSWORD>` 仅表示本机待填位置，不写入设计文档或版本控制中的真实配置。

## 验证

- 确认 `.env` 仍被 Git 忽略。
- 只检查连接串的协议、用户名、主机、端口和数据库名，不输出密码。
- 密码填入前不执行认证成功测试。

## 安全约束

- 不在终端输出、日志、设计文档或 Git 历史中记录密码。
- 密码若含 `@`、`:`、`/`、`#`、`%` 等保留字符，需要进行 URL 编码。
