# 案例使用与反馈记录

本页只登记实际用于稿件的案例及后续发现，作为参考库的使用记录。选例、迁移和审稿方法见[公共Skill索引](../../../.cursor/skills/wechat-mp-article/references/external-article-cases.md)，不在这里另设流程。

## 怎样记录

稿件完成后，为实际采用的案例追加一条记录；多张卡片共同支持一个组织动作时可合记。复核、撤回借鉴或后来收到反馈时更新原条目，保留发生日期。只看过、拆解过、实际使用过、收到反馈分别记录，不能由入库推定已使用，也不能由使用次数推定有效。

每条记录包含：

- **稿件与版本、案例编号**：链接实际稿件，标出采用的卡片。
- **借鉴动作与检查位置**：简记采用了什么，链接既有提纲和审稿的具体位置；支持材料、适配差异和处理经过继续留在原记录，不抄写第二份。
- **使用结果与问题**：依据交付版说明保留、调整或撤回了什么，以及发现的限制；不能仅写“有效”“已去AI味”。
- **真实反馈与来源日期**：如有用户具体反馈，保留原话并指向可追溯的对话、文件或数据，标明所对应版本；没有就写“未收到”。模型自评和模拟读者意见只链接审稿记录，不能填作用户反馈。

反馈只支持所涉及稿件和位置，不自动成为普遍写作规则；用户明确认可的改稿仍按基座维护正例，本页只引用相应位置。
