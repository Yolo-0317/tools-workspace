# 扫码价调查｜外部文章参考

来源：北京日报客户端，李松林，2021-10-22。[原文](https://xinwen.bjd.com.cn/content/s61721cb3e4b08aed9d9a8471.html)。2026-10-28读公开全文（不含图片细节与评论）。

调查先列同一产品扫码标价与促销成交的不同数字，再采访二维码服务商，说明页面资料由谁录入；最后进入定价评论。本文采用前两项材料的关系，不搬用法律判断，不把历史价格当现价，也不把某类二维码后台扩大成所有条码服务。

可借鉴：先把交易数量与单价讲清，再追问标价来源。扫码2688与33.2不是两款酒的品质比较。文章末尾的专家劝告不搬进本篇。

本地已比较A040一元图书卡，其出版参与关系不适配本篇具体查询机制；故补读此篇。非用户口吻正例，不升级成固定段落公式。
