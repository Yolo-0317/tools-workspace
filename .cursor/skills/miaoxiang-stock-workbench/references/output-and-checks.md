# 输出与验收

## 日度选股

- 结论：目标市场、筛选条件、研究假设、数据截止时间、返回数量与复核数量。
- 市场背景：妙想热点及证据状态，不生成 ALLOW/LIMITED/FREEZE 等本地引擎状态。
- 表格：名称/代码、V3硬条件、五项分数和总分、原排序键、关键指标及日期、主要风险、证据链接、分组。按V3规则区分未通过和未核验；用户自定义模式另列。
- 分组：条件已核验的研究候选、待核验观察、排除项。零候选可接受，不凑数。
- 缺项：未核验字段、时间冲突、接口失败、未覆盖的市场或历史期间。
- 附件：完整筛选表、原始报告、来源链接。不得将观察名单称为买入许可。

## 个股与板块分析

先给结论与限制，再列指标及日期、用户要求的专项、反证/风险、待核验问题和来源。保存原始数据和检索证据，工作台分析与上游事实分开。只基于真实来源数据（注明当前六技能名称、原始结果与实际数据日期），不输出“已通过本地风控”、LIVE、最大股数或未经计算的入场/止损计划。

## 验收场景

| 场景 | 预期 |
|---|---|
| 今天选股 | 妙想预筛及mx-data日线 → 验证输入适配与完整性后计算V3，未验证则标记未完成 → 资讯复核 |
| 查股价 | 仅查数，不读本地账户或运行全市场 |
| 买点、资金与公告 | 妙想查数与明确专项；按V3计算技术参考位，数据不足时标记未完成 |
| 综合分析一下 | 查数+资讯，按意图选择专项，不强制所有维度 |
| 最新财报 | 实体 → 已发布期间 → mx-data数据和mx-search公告 → 工作台解读 |
| 两板块谁强 | 同期可核验指标对比，报告分别保留 |
| 筛选不满足或零结果 | 原样说明，不调用旧 combined/V1.3 兜底 |
| 日期矛盾 | 待核验且排除当日催化 |
| 缺失关键排除条件 | 待核验观察，不声称满足 |
| 接口失败/空正文 | 明确未完成，不引用旧文件冒充成功 |
| 历史研究 | 明确接口历史覆盖限制，不用当前报告补历史 |
| 每日使用 | 按需调用，不默认创建调度 |

校验记录只证明已执行的检查，不将文档走查描述为真实选股测试。

新六技能验收还包括：查看自选只读；模拟持仓明确标注模拟；未授权不自动发布/互动或下单；旧十技能路径不存在且活跃路由无旧依赖。

短线综合报告按市场环境、板块相对位置、V3技术、资金/龙虎榜、催化/事件风险、观察条件排列；每栏注明日期和覆盖状态。适配器仅验证单日榜，不用单侧前五差额冒充全榜净额。
