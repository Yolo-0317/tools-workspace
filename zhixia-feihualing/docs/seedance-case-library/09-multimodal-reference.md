# 多模态参考

收录图片、视频、音频、分镜板及组合输入对角色、构图、动作、运镜、声音和风格的控制案例。

案例按统一 `CASE-xxx` 字段登记；动作或运镜迁移只建议使用自有或获授权素材。

## CASE-073 分镜、角色、场景与道具分工

- **来源：** [Seedance 2.0 正式发布](https://seed.bytedance.com/zh/blog/official-launch-of-seedance-2-0?view_from=content_recommend)
- **访问日期：** 2026-08-28
- **证据等级：** A
- **模型版本：** Seedance 2.0
- **输入方式：** 分镜图 + 角色图 + 场景图 + 道具图 + 文字（R2V）。
- **中文结构化改写：** 第一张图负责分镜、景别、运镜、画面与文案，第二张图锁定人物，第三张图锁定场景，第四张图锁定道具，最终生成十五秒治愈短片。
- **可复用写法：** 每个素材只分配一个清楚职责，提示词逐项映射，不让多张图争夺同一控制权。
- **失败风险：** 分镜图信息密度过高时可能只参考部分面板；文字还原仍是官方承认的弱项。
- **栀夏适用性：** 需要强镜头控制时直接适用，但比“两张角色母版 + 纯文字”增加制作成本。

## CASE-074 四类素材的明确映射

- **来源：** [GitHub：Seedance 2 Prompt Library](https://github.com/gracech0322-cmd/seedance-2-prompt-library)
- **访问日期：** 2026-08-28
- **证据等级：** C
- **模型版本：** 仓库面向 Seedance 2.0，示例未逐项提供结果证明。
- **输入方式：** 首帧图 + 运镜视频 + 动作视频 + 背景音乐。
- **中文结构化改写：** 指定图片只作为第一帧，第一段视频只提供摄影机运动，第二段视频只提供人物动作，音频只提供背景音乐。
- **可复用写法：** 使用“素材 A 作为 X、素材 B 仅参考 Y”的映射句，避免模型自行猜测素材用途。
- **失败风险：** 多素材仍可能相互污染；视频素材必须自有或获得授权。
- **栀夏适用性：** 非常适合未来分别锁定角色、古典舞和运镜路径的高控制流程。

## CASE-075 首帧与末帧之间连续过渡

- **来源：** [SeedanceTips 50+ Prompt Library](https://seedancetips.com/prompts/seedance-prompt-library/)
- **访问日期：** 2026-08-28
- **证据等级：** C
- **模型版本：** 页面声称 Seedance 2.0，未见逐例结果证明。
- **输入方式：** 首帧图 + 末帧图 + 文字，10 秒。
- **中文结构化改写：** 第一张图明确为起点，第二张图明确为终点；摄影机在十秒内持续缓慢前推，光线自然变化，把两个场景连接成连续运动。
- **可复用写法：** 除了给首末帧，还要说明中间唯一摄影机路径和允许变化的环境元素。
- **失败风险：** 两张图差异过大时会出现溶解、变形或跳切。
- **栀夏适用性：** 可用于明确起势与收势，但会重新引入状态卡制作成本。

## CASE-076 动作视频与角色替换模板

- **来源：** [SeedanceTips 50+ Prompt Library](https://seedancetips.com/prompts/seedance-prompt-library/)
- **访问日期：** 2026-08-28
- **证据等级：** C
- **模型版本：** 页面声称 Seedance 2.0，未见逐例结果证明。
- **输入方式：** 已获授权动作视频 + 角色图 + 文字，10 秒。
- **中文结构化改写：** 从动作视频保留舞蹈动作、摄影机角度、时间和能量，用角色图替换原舞者，背景改为有明确灯光的摄影棚。
- **可复用写法：** 清楚列出“保持动作和镜头，替换人物和环境”。
- **失败风险：** 模板页没有逐例结果；未经授权的视频不可使用。
- **栀夏适用性：** 可用于建设合法古典舞参考流程，不能据此宣称必然逐帧复刻。

## CASE-077 人物图与对白音频的橱窗表演

- **来源：** [GitHub：Seedance 2 Prompt Library](https://github.com/gracech0322-cmd/seedance-2-prompt-library)
- **访问日期：** 2026-08-28
- **证据等级：** C
- **模型版本：** 仓库面向 Seedance 2.0，示例未逐项提供结果证明。
- **输入方式：** 人物图 + 对白音频 + 文字。
- **中文结构化改写：** 人物图锁定窗边女孩身份，文字只描述她在晨光中举杯、喝下并微笑，对白音频负责具体说话内容和节奏。
- **可复用写法：** 外形、动作和声音分别由图、文字和音频承担。
- **失败风险：** 口型、杯子接触和面部同时发生时仍可能失稳。
- **栀夏适用性：** 可用于角色短对白实验；后续诗舞优先使用 Seedance 原生画外朗诵，因为不要求人物对口型。准确诗文、生僻字和末句位置仍是验收硬门槛，失败时只替换声音，不因音色轻微差异重做画面。

## CASE-078 两张场景图与音乐的行走镜头

- **来源：** [Magnific：How to write prompts for Seedance 2.0](https://www.magnific.com/blog/how-to-write-prompts-for-seedance-2-0/)
- **访问日期：** 2026-08-28
- **证据等级：** C
- **模型版本：** 页面面向 Seedance 2.0，示例缺少逐例结果证明。
- **输入方式：** 人物图 + 风景图 + 音频 + 文字。
- **中文结构化改写：** 第一张图锁定人物，第二张图锁定她行走的风景；摄影机用单一跟随路径，上传音乐控制整体节奏。
- **可复用写法：** 人物身份和环境身份分图提供，文字只负责两者的空间关系和镜头。
- **失败风险：** 人物图与风景图光线、透视不匹配时容易产生贴图感。
- **栀夏适用性：** 适合两张角色母版之外再增加一张场景卡的中等控制方案。

## CASE-079 外形图、动作视频与情绪音频分离

- **来源：** [Seedance 2.0 Complete Prompting Guide](https://docs.seedance.tv/en/seedance-2-complete-prompting-guide)
- **访问日期：** 2026-08-28
- **证据等级：** C
- **模型版本：** 第三方文档面向 Seedance 2.0。
- **输入方式：** 角色图 + 参考视频 + 音频 + 文字。
- **中文结构化改写：** 角色图只定义人物外形，参考视频只提供动作和摄影机节奏，音频只驱动情绪推进；文字描述目标场景并禁止把参考视频原人物带入。
- **可复用写法：** 先声明每种素材“只参考什么”，再说明最终画面要重新组合什么。
- **失败风险：** 第三方指南不是官方规范；多模态“仅参考”边界可能执行不完全。
- **栀夏适用性：** 适合未来高控制舞蹈诗境，需逐项小规模验证。

## CASE-080 参考视频中的对象定向替换

- **来源：** [GitHub：Seedance 2 Prompt Library](https://github.com/gracech0322-cmd/seedance-2-prompt-library)
- **访问日期：** 2026-08-28
- **证据等级：** C
- **模型版本：** 仓库面向 Seedance 2.0，示例未逐项提供结果证明。
- **输入方式：** 参考视频 + 替换对象图或文字描述。
- **中文结构化改写：** 保留原视频的场景、动作和摄影机，只替换指定主体，例如把原视频中的猫换成狗，其余时间与空间关系不变。
- **可复用写法：** 编辑任务要列出“唯一替换对象”和“必须保持不变的元素”。
- **失败风险：** 复杂遮挡或互动会把原主体特征残留到新主体；素材权利必须明确。
- **栀夏适用性：** 可用于替换临时角色测试片中的阿砚，但正式母版仍应从源头生成。
