# 带货稿模板精华 — 简选小电（默认 `home`）

**唯一定型模板**：**[template-jianxuan.md](template-jianxuan.md)（jianxuan-v1）** · 金样 `stock-ai/output/templates/jianxuan-guide-v1.md`  
旧副本 `jianxuan-guide.md` 已并入 v1，新稿只用 v1。勿套用财经五槽。

## 总原则

| 项 | 要求 |
|----|------|
| 分节 | 仅 `> 标题`，禁止「一、二、三」 |
| 披露 | 首段或摘要含推广/佣金说明 |
| 结尾 | 代码追加带货免责声明 + 可选互动问句 + **CPS 卡（免责前）** |
| emoji | 禁止 |

## 1. 买前对照体 `guide`（默认，推荐）

**适用**：全品类小电；**不写假「我」**；栏目前缀见 brand（如 `买前对照 · 厨房`）。

**标题示例**（处境 + 品类 + 结果）

```
合租单间，环境小电怎么配才不抢插排？
厨房小电器怎么二选一？窄台面先淘汰哪三类
租屋清洁小电：无打孔、低耗材怎么选
```

**骨架**（分节名优先与 brand 一致）

```
（编辑口吻：租屋/单间常见现象 + 本篇对照什么；披露放摘要句尾即可）

> 什么情况下才需要
（2～3 段：插座、台面、使用频率）

> 三类容易买错的
1. … 2. … 3. …

> 两类通常更值的
· … · …

> 买之前对照三件事
· 量 · 问 · 想
```

**home 插图**：三节 `窄台面为什么先谈收纳` / `两类通常更值的` / `买之前对照三件事` 与 `HOME_COMMERCE_FIGURE_SLOTS` 对齐；改分节名须同步 `wechat_mp_figures.py`。

## 2. 清单体 `guide`（多 SKU 场景）

**适用**：热门行业 + 多 SKU 场景对照（文末 CPS 选该类佣金最高款）。

**标题模板**（口语、具体数字，少用「必看」「一文读懂」）

```
52cm台面，我劝你别先买空气炸锅
租房厨房踩坑：炸锅吃灰，两样还在用
去年双十一买的炸锅，一个月后进了柜子
```

**骨架**

```
（首段：场景 + 推广披露一句）

> 为什么现在值得看
（行业热点 1～2 句，带数字或时间）

> 三类场景对照
1. 预算档 …
2. 均衡档 …
3. 进阶档 …

[[fig:…]]   ← 第一节之后可选

> 怎么选不踩坑
（参数表格式短段：尺寸/接口/噪音等）

> 小结
（适合谁 / 不适合谁，不喊「必买」）
```

## 2. 测评体 `review`

**适用**：单品深度体验，文末 CPS 挂同品类。

**标题模板**

```
用了{N}个月，这款{品类}到底值不值？
{品类}测评：三个优点和两个槽点
```

**骨架**

```
> 我实际在用什么
（型号、价格区间、使用场景）

> 三个优点两个槽点
（具体体验，禁「全网最好」）

> 适合谁不适合谁
```

---

## 3. 行业趋势体 `trend`

**适用**：AI 办公、新能源周边、露营等「热词」引流，文末挂关联消费品。

**标题模板**

```
{热词}火了，普通人先别急着买？
从{热词}到桌面装备，只需看懂这一条线
```

**骨架**

```
> 这周行业在聊什么
> 和普通人有什么关系
> 如果要入手从哪类开始
（引导到文末商品品类，不编造收益）
```

## 垂直与选品词（`--vertical`）

| vertical | 正文主题 | auto-pick 搜索词 |
|----------|----------|------------------|
| `tech` | 数码、AI 办公、键鼠屏 | 机械键盘 显示器 充电宝 |
| `home` | 简选小电全品类（厨房/清洁/环境/个护） | 默认 `小家电 空气炸锅 收纳`；按周见 [brand.md](brand.md) |
| `mother` | 母婴、绘本、安全 | 母婴 绘本 儿童 |
| `outdoor` | 露营、骑行、防晒 | 露营 防晒 户外 |
| `office` | 工学椅、台灯、桌面 | 工学椅 台灯 支架 |
| `beauty` | 护肤、个护（注意资质） | 护肤 洗面奶 防晒 |

覆盖全部垂直：`WECHAT_MP_FOOTER_PICK_KEYWORD="词1 词2"`。
