# 唐风三桅客船固定道具

## 身份

- 道具名：唐风三桅客船。
- 资产标识：`tang-three-mast-passenger-ship-v01`。
- 状态：母版待生成。
- 适用场景：江河远行、峡谷航行、夜泊、送别和沿江叙事。
- 类型：唐风中型木质客船，不是双人小舢板，不是军舰，不是双层或多层楼船。

## 固定尺寸与结构

- 船长约22至26米，船宽约5至6米，长宽比约4.3:1至4.8:1。
- 深棕色硬木船体，船头狭长微翘，船尾较宽。
- 前甲板、中央一层通高长舱、后甲板三段结构清楚。
- 中央船舱长约7至9米，内部净高约2.2至2.5米，舱门高约1.8至2米；成年人能够直立进入。
- 船舱具有可用舱门、窗格、立柱、舱顶、墙板厚度和内部暗部，不是甲板上的半人高木箱。
- 三根桅杆沿纵轴前、中、后排列，顺序、位置和间距固定。
- 主桅高出甲板约12至14米；主帆约7至9米高、4至5米宽。
- 前帆面积约为主帆75%，后帆面积约为主帆65%。
- 帆底与甲板、舱顶保持清楚空隙，不遮挡人物、船舱和船体。

## 人物尺度与区域

- 栀夏是舱门、舷墙与甲板的成年人尺度基准。
- 阿砚的固定活动区域是前甲板。
- 栀夏的固定活动区域是后甲板、船舱门前或船舱入口内部。
- 人物可以按剧情坐下、站立或进出舱门，但不得无动作原因换到船体另一端，不得攀爬桅杆。

## 不可变内容

- 船体长宽比、木色、船头船尾结构。
- 一层通高长舱的位置、长度、高度和门窗结构。
- 三根桅杆的位置、顺序和高度关系。
- 主帆、前帆、后帆约100:75:65的面积关系。
- 前甲板、中央船舱、后甲板的三段布局。

## 可变内容

- 时间、天气、雾气和主光源。
- 三帆全开、部分收帆或停泊状态；同一镜头内必须服从同一风向和动作过程。
- 少量甲板生活道具、舱内陈设和灯光。
- 摄影机位、景别、水域、环境和角色在允许区域内的动作。
