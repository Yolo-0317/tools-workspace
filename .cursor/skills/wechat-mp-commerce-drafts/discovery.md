# 简选小电 — 引流与搜一搜

账号定位见 [brand.md](brand.md)；成稿模板见 [template-jianxuan.md](template-jianxuan.md)。  
代码：`wechat_mp_seo.py` 中 `kind=commerce`；推稿默认 `WECHAT_MP_COMMERCE_SEO=1`。

## 搜一搜怎么工作（你要利用什么）

微信 **搜一搜** 会索引：公众号名称、简介、**文章标题、摘要、正文**（含文末 `#话题`）。不保证排名，但可系统性提高「被搜到」概率。

| 信号 | 简选小电做法 |
|------|----------------|
| 账号名 | **简选小电**（已含「小电」） |
| 简介 | 含「租屋 / 合租 / 小家电 / 买前对照」 |
| 标题前 15 字 | **租屋、合租、单间、厨房、吸尘器、加湿** 等具体场景词 |
| 摘要 | 1 句场景 + 核心词；句尾披露 |
| 正文 | 自然重复 2～3 次品类词；**首段后**自动插入 `#话题` 行（搜一搜可索引） |
| 原创 | 勾选后索引与推荐权重更好 |
| 分类 | 发布选 **生活 / 家居**，勿选财经 |

与财经号区别：不要写 A股、龙头、复盘；搜一搜流量来自 **居住 / 租房 / 小家电** 长尾。

## 关键词矩阵（按周栏目）

写作时标题或摘要至少命中 **场景词 1 + 品类词 1**。

| 栏目 | 场景词（标题优先） | 品类词 | 长尾（摘要/正文） |
|------|-------------------|--------|-------------------|
| 厨房 | 租屋厨房、合租单间、窄台面 | 小家电、空气炸锅、电水壶 | 插排不够、台面收纳 |
| 清洁 | 租房、无打孔 | 吸尘器、除螨、蒸汽拖把 | 低耗材、小户型 |
| 环境 | 回南天、暖气房、单间 | 加湿器、除湿机、暖风机 | 占地、噪音、电费 |
| 个护 | 合租、洗漱台 | 电吹风、电动牙刷 | 低频使用、收纳 |

**00 后 / 大城市** 不必写进标题；用 **合租、一线、单间、插排、外卖盒占台面** 等处境词更易共鸣、也易被搜。

## 推荐 #话题（发布后手动点，≤5 个）

脚本推稿终端会打印；默认池：

| slot | 顺序建议 |
|------|----------|
| `guide` | `#租房好物` `#小家电` `#买前对照` |
| `review` | `#小家电测评` `#租房` `#避坑` |
| `trend` | `#季节好物` `#小家电` `#租房` |

原则：**先场景大词（租房好物）→ 垂直（小家电）→ 栏目（买前对照）**；禁「必买、躺赚、根治」。可替换 1 个为当周品类，如 `#空气炸锅` `#除湿机`（≤8 字）。

## 发布节奏

**完整 SOP（分阶段频率、时段、引流、复盘、文献）** → **[operations-sop.md](operations-sop.md)**（真源，勿在此重复改表）。

| 阶段 | 公众号推送 | 时段 |
|------|------------|------|
| 冷启动第 1 周 | **3 篇** `guide`（厨房/清洁/环境） | 20:00–22:00 |
| 冷启动第 2～4 周 | **每周 3 篇**（2 guide + 1 review/trend） | 周二、周四、周六 |
| 稳定期（第 5 周+） | **每周 2～3 篇**（默认 3；完读&lt;35% 两周则降为 2） | 同上 |

朋友圈/群：**每周 2～3 次节选**，不等于公众号日更。  
单篇目标：**完读 > 收藏 > 分享**；文末问句要具体，忌「点赞在看」。

## 冷启动引流（0～500 粉）

1. **搜一搜**：标题/摘要坚持矩阵词；满 10 篇后更容易出现长尾结果。  
2. **朋友圈**：发草稿预览截图（简选顶栏 + 清单一节），配文一句处境不问买。  
3. **微信群**：租房、同城、同事群 **只发干货节选**（三类买错的），文末「完整对照在公众号」。  
4. **小红书**：若 **独立运营**（不导流公众号）→ 真源 [xiaohongshu-sop.md](xiaohongshu-sop.md)。若作微信外链：同一篇拆 3 图，口径一致，披露推广。  
5. **知乎节选**（可选）：拆 3 图引流公众号。  
6. **菜单栏**：公众号菜单「厨房 / 清洁 / 环境 / 个护」链到合集或关键词回复（需后台配置）。  
7. **不要**：买粉、标题党、跨类蹭 A 股热点（伤账号标签）。

## 预览期用财经 AppID 的注意

草稿在财经号箱里时，搜一搜仍按 **该号名称/简介** 索引；读者搜「简选小电」可能找不到。  
**独立号上线**后立刻改：名称、简介、头像、合集，并按 [operations-sop.md](operations-sop.md) **阶段 A 第 1 周**连发 3 篇同模板稿，帮搜一搜建立标签。

## 数据复盘（每月看一次）

| 指标 | 动作 |
|------|------|
| 搜一搜来源占比 | 后台「流量分析」；低则加场景词到标题前 15 字 |
| 完读率 | 低于 40% 则缩短开篇、加强清单 |
| 收藏率 | 高则多做「对照表」体 `guide` |
| CPS 点击 | 文末品类与正文一致才升 |

