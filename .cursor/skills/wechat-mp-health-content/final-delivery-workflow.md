# 健康文章：从请求到终稿

写或重写健康知识稿时执行本流程。内部研究、写稿和审稿由 Agent 完成；交付完整文章，不把等待用户逐句纠错当作正常流程。用户指定某个阶段或局部修改时，按其范围处理。

## 流程总览与完成标准

主流程：选题与取证 → 叙述设计（需要艺术图解时先拆场景）→ 完整正文与暂定标题 → 独立审稿 → 主笔统一修订与交叉复核 → 图解文案与排版核验 → 交付；用户要求推送时再进入草稿 API 流程。

完成标准是：事实和必要信息保留，正文读起来像自然的生活文章，标题给清楚场景并自然留下正文能接住的信息。没有禁词不等于自然，提醒读者“注意安全”也不等于有打开理由。规则为这两个阅读结果服务，不将检查表写进正文。

本文件规定的是每次写作请求内由 Agent 主动执行的审稿循环，不是已经部署的独立程序或定时任务。具体循环见第4节；用户无需逐轮批准正常改稿。已有正文只改标题时仅运行标题循环；只整理 Skill 时不擅自重写或同步已有草稿。

## 1. 事实卡与叙述设计

有题目直接研究；没有时沿用当前读者定位，选与最近稿件不重复、可靠资料能够说明的生活问题。仅缺少实质影响内容的信息时询问。近期选题按选题 Skill 参考丁香医生并独立查证；打不开的页面如实记录阅读范围，不将摘要说成全文。只有声称热门或用户要求热点时，才核近期关注信号。常青题不包装成热点。

先读作者卡。事实卡记录关键主张、原始来源与日期、适用人群、必要条件和不能推出的结论。优先中国现行权威资料，国外来源的补充理由另记。资料负责支撑事实，不直接决定文章句式；证据没有说明的原因不自行补写。事实卡中的误判风险和限制先按[审核语言与文章语言转换](../wechat-mp-article/references/editorial-language.md)组织成具体解释，不逐条写成对家长的纠正；必要就医、急救和禁忌指令保持明确。

动笔前用简短内部笔记确定四件事：

- **读者处境**：谁在什么生活场景遇到这件事；不以年龄推断个人疾病，也不编造当事人。
- **文章主线**：围绕哪件具体事情展开，哪些现象或变化自然衔接，读完能理解什么、调整什么。
- **作者位置**：读懂资料后把事情讲清楚，不扮演医生、患者或亲历者，不站在上方训诫。
- **口吻与节奏**：平实、具体、温和，解释充分；段落长短随意思变化，不刻意模拟聊天或追求金句。

重写既有文章时，先提取原稿的信息清单：事实、原因、建议、适用条件、不确定性和就医边界。可以合并、移动或重组段落，不能以去 AI 味为由删掉信息或压成摘要。重复的表达可合并，承载的意思必须保留。原稿先留快照。

## 2. 写完整的叙述初稿

### 先逐句写，再合成段落

先执行共用[具体内容起稿](../wechat-mp-article/references/editorial-language.md#起稿先写具体内容)：直接写现象、原因、条件和动作，不先写概括或总结占位句；正文完成后再补确有理解作用的概括、提炼小标题。内部稿用短而完整的句子，一句一段，便于单独检查。每句围绕一个主要意思写清人物、动作或关系；一句里解释层次太多时拆开，但不能拆掉原因、条件或指代。不设机械字数上限，也不能把完整意思截成口号、标签或半句话。

起稿和逐句审稿先执行共用[单句语法与自然表达检查](../wechat-mp-article/references/sentence-grammar.md)：暂时脱离段落，检查骨架、搭配、语序、修饰、指代、并列和否定范围；分清语病与表达不自然，再恢复上下文。此检查沿用既有三轮额度，不另开循环。

单句先读通，再连着前后句读。逐句核对日常词语的搭配，特别是句子的后半部分：动作与对象是否说得通、指代是否清楚、有没有用抽象词凑一句看似完整的话。不能只因整段大意成立就放过一句生硬表达。需要换成读者平时会说的具体动作，而不是只缩短或补语气词。

执行共用的[句子关系与建议落点检查](../wechat-mp-article/references/sentence-relations.md)。尤其不能从身体变化直接跳到调整锻炼；评估症状与介绍一般运动知识的依据分别讲清。关系问题被指出后回查全文同类位置，并在统一修订后核对，不能只改被点名的句子。

完成单句检查后，把确实连贯的两三句合成自然段；一句已经独立讲清或需要停顿时可单独成段。成段只是阅读排版，不再顺手添加过渡句、金句或修辞。合并后重新读每句及上下文，不能因前半段顺畅而忽略后面的句子。最终交付仍是信息完整的文章，不把内部的一句一段检查稿机械当作终稿。


提纲只安排内容，不充当正文。每段写清具体情形以及需要解释的关系，建议从已讲明的困难中自然出现。不要把一个提纲要点换成完整句子就算写完，也不强迫所有段落套“场景—机制—建议”的固定结构。

开头从具体情形进入，不堆生活细节制造气氛；前两段进入主线。已获支持的核心判断及时讲明，不把必要结论和条件藏到末尾。读者疑问留在内部研究，正文、大小标题和图中解释统一用叙述语气：不设问、反问、自问自答，不把记录项目串成间接问句。必要的名词标签和医学条件保留准确含义。

每写完一个完整意思，核对再继续：

- 主语、动作、对象和指代明确，比较有对象，条件与因果有证据；重要解释不能靠文末出处补齐。
- 语言是这件事本来的说法，不把研究工作台、说明书或分析提纲搬进文章。术语需要时保留，再解释清楚。
- 转折来自真实差异，不为句式漂亮强加对举、反转、比喻和段末金句。不能先选一个“像文章”的句式，再填意思。
- “就、还、也、才、了”等承接词随动作和态度使用，不配额添加“呢、吧、啊”。去掉语气词仍生硬的句子应重写。
- 建议有依据并回应前文，不假设读者懒、忘事或一定会犯错，不添无来源小窍门。可选做法用商量语气，必要的急症求助指令保持明确。

初稿应当已经能够自然阅读。中老年稿约1200～1800汉字是检查内容是否充分的参考，不是删减上限；用户要求保留内容时完整讲清，不为字数补重复或删边界。

正文成形后定标题，执行[标题 Skill 的当前偏好](../wechat-mp-title-writing/SKILL.md#当前标题偏好2026-10-09)：先给具体场景或对象，再自然留下正文能补齐的信息，不罗列全部要点，不强凑反差或只写泛提醒。已有明确场景时，“这几种情况”等指代可以留下具体内容，不能按禁词处理；没有对象和正文承接的泛话才是空悬念。不靠省略号或夸大后果制造点击。小标题自然承接本节，不写口号、对仗金句或内部工作标签。连着标题和首段读一遍，确认语气和内容接得上。

## 3. 独立审稿与三遍检查

完整稿默认执行[多角色审稿](multi-role-review.md)：事实审稿人、行文编辑、普通读者、标题与图文编辑独立检查，主笔统一修改，修改后交叉复核。有可用的子代理工具时，用独立子代理承担审稿；只改标题或局部时按修改范围启用相关角色，不扩写文章。无子代理能力时按角色分开检查，并如实记录为单模型分角色检查，不声称完成独立审稿。

下面三遍是检查维度，不是三个额外审稿轮次；分工、材料、意见格式与交叉复核见上述文件。主笔仍负责整篇阅读与最终取舍，不能把多角色意见数量当成质量证明。

### 第一遍：整篇

从头读到尾，检查主线、开头、段落衔接、重复和节奏。内容安排有问题先重组，不靠连接词补救。连续几段只列建议、资料或感受时，补回缺失的解释或事实。

### 第二遍：逐句

连读整段核作者位置：是否反复预设家长判断错了，连续告诫却没有讲清原因。依共用转换规则检查，不能只判每句事实正确。

先单独读每句，再按上下文检查；句子的前半部分和后半部分都要读，不能以段意大致成立代替单句核验：词语搭配自然；意思具体完整；没有问答推进、提纲串列、抽象概括替代解释、刻意反转和居高临下的提醒。标题、高亮、图中解释也读，不能只检查正文。

修改后连同前后句复读。改变一句不能使指代失效、条件移位或新添问答和提纲语气。同类问题多处出现时处理整类表达，不能只替换被用户指出的那一句。仍需大面积重写的稿件不得作为已完成终稿交付；达到循环上限时按第4节保留版本并说明残留问题。

### 第三遍：信息对照

逐项对照事实卡；改旧稿时同时对照原稿信息清单。事实、原因、建议、对象、日期、条件、不确定性和就医边界均有着落，没有润色造成的遗漏、范围收窄或确定性增强。遮住来源名称和链接后，正文仍讲清核心关系。新增事实必须重新取证，不能以自然口吻为理由扩展结论。

内部审稿记录写实际发现与修改，以及仍存在的资料限制。词表搜索只能辅助，不能证明语气自然；不以检测分数或笼统“全部通过”代替阅读。修改触及事实时重新核实，只重查受影响部分，完成后停止无依据的反复润色。

## 4. 自动检查与修订循环

每轮都遵循：**独立审稿 → 主笔合并意见并选择修改层级 → 统一修改 → 交叉复核与上下文复读 → 信息对照 → 决定继续或结束**。不能只写“检查过了”，也不能生成修改稿后不再读它。正文、标题、图中文字分别检查，最终再连起来读。

**轮数上限：同一篇稿件在一次写作请求内，正文、标题及图中文字的集中语言修订共享最多三轮。** 提前达到出口就结束，不要求跑满。各角色共用这三轮额度；每轮可以包含多份审稿意见和一次统一修订，不能每个角色各跑三轮。交叉复核只检查当前版本；发现新问题留给剩余轮次处理，不启动角色内部的嵌套修订。每轮可批量处理多个已发现的问题；完成修改与复读后再做新一轮诊断，计入下一轮。不能把重新起标题、重写段落、切换阶段或“本轮小修”作为重置计数的理由。用户后续提出新的修改要求时，可针对新要求开始新的有限循环。

初次取证、初稿写作和单纯技术性渲染修复不算语言修订轮数，但不能借此继续改文案。每轮检查实际改动及其上下文，只有主线、事实或引用受到影响时才返回对应阶段，不每轮从选题和取证重新跑起。

### 正文循环

1. 按第3节整篇、逐句、信息对照检查，先记录影响阅读或事实的具体位置及原因。无具体问题的句子保留，不为显得认真而改。
2. 按问题层级处理：主线不连贯就重组段落；同类生硬表达多处出现就重写相关段落；孤立搭配问题才局部换词。不能用补“也、就、了”解决结构问题。
3. 复读改过的整段及前后段，核对新句是否自然、衔接是否成立，原有信息是否仍在。新改法引入问题时恢复较好的表达，必要修订纳入剩余轮次，不能嵌套无限的“本轮再修”。不能修掉问答又添提纲，或修顺语气却删条件。
4. 继续下一轮时针对实际残留问题，不重新套禁词表扫描一遍就算审稿。连续两轮同类问题未改善，下一轮重新组织相关段落，不继续局部换词；重写仍计入三轮上限。

正文循环的出口：开头进入具体事情；解释和建议自然衔接；句子不需要读者猜主语或关系；没有问答推进、提纲拼接和刻意修辞造成的生硬感；原稿事实、建议及条件有着落。以整篇阅读判断，不追求“全口语”或保证所有人评价一致。

### 标题循环

执行[标题 Skill](../wechat-mp-title-writing/SKILL.md)的候选与修订循环。在内部明确：标题已交代什么，暂时没说尽什么，读者想继续了解什么，正文在哪里展开。候选若只剩提醒、提前揭完内容、故作反差或空泛指代，就重新起，不只换几个近义词。

出口是一个自然的标题：主题识别清楚，语法完整，信息留一部分，正文能兑现，不虚构经历或夸大风险。大标题留下内容不等于正文也要含糊；小标题仍负责自然承接本节。

### 图文与排版循环

正文和标题确定后定图解解释，再渲染并看实际画面。标题与图文编辑核对成图及手机预览，事实审稿人复核图中健康表述；渲染前后的语言修订仍计入同一三轮额度，应留出需要的轮次，不能到配图阶段另起循环。文字、图片或样式有具体问题就修改对应部分，再看受影响的页面或图片。修改图文不得增加健康主张；正文变化影响图解时，重新核对图解解释。

### 循环停止与记录

以下任一情况结束循环：达到出口；没有具体问题；已经完成第三轮。第三轮后仍有问题，保留事实完整且表达较好的版本，列明具体残留问题及位置，不伪称终稿通过，不启动第四轮。事实错误或信息缺失尚未解决的版本不能以语言上限为理由判定可推送。

未发现具体问题，且上述出口满足时停止；不能为了多跑一轮反复改动已经自然的句子。若新版本只增加花样、变得绕口或丢信息，恢复更清楚的版本。同一问题修不动时换修改层级，不无限补词。证据缺口需要回源，实际不可获取就保留已有支持的范围并说明限制，不以流畅文字掩盖。

在简要 review.md 中按[多角色审稿的记录格式](multi-role-review.md#记录与交付)记录执行方式、稿件版本、各角色实际发现、主笔采纳或不采纳的理由、交叉复核结果、轮次与停止原因；保留实际信息对照和版式核验结果。不用 AI 味分数、轮数或一句“全通过”证明文章好。交付前用读者视角连续读标题、首段及全文，判断它是否已经是一篇自然文章，而不是一份处理过禁词的稿件。

## 5. 图解、排版与保存

默认真实配图按中老年 Skill 和 layout.md 核画面、出处与许可；用户明确选择艺术图解时按指定艺术 Skill 执行，替代真实图片要求。不更换已确认的风格，不将艺术图伪装为病例或检测数据，也不在图中加账号品牌。

艺术图解可先按文章主线拆场景，解释文案须从成熟正文提炼。可以减字，但关键条件不能压掉，不改成问答、口号或含糊标签；功能标签与解释文字分开。图片不能为追求美感添加健康主张。

保存 article.md、内联样式 HTML、事实来源与简要审稿记录。首次原始正文另存 original_first_article.md，此后不覆盖；改稿前保存对应快照。

全文定稿后同步图片文案、封面标题、HTML 与当前审稿记录。按 layout.md 用分节、克制高亮及文末资料排版，实际检查约390px手机宽度、图片加载、文字溢出及图文对应。不能把本地浏览器检查说成微信端核验；不能视觉核验时记录实际限制。

## 6. 一次交付

默认展示选定标题和完整正文，保留高亮与图片位置，附正文链接及必要状态。内部设计、规则、候选标题和检查记录不代替全文，不要求用户批准初稿后才完成正常审稿。

写作不自动推草稿。用户明确要求推送或同步时按现有 API 步骤执行并回读；已有草稿更新原 media_id，不重复创建。已授权同步无需再次确认，草稿状态依据实际回读汇报；不自动公开发表。
