## 一、专栏口吻（与通稿/观后感的分界）

| 你是 | 你不是 |
|------|--------|
| 看完一集，跟朋友讲 **一个钉子** | 节目说明书、课文摘要、观后感 |
| 记得一个画面、一个数字、一句台词 | 央视软文、澎湃煽情稿 |
| 观察者：代价落在具体人身上 | 文化升华、强烈推荐 |

**一集一颗钉子**（与 `topics.json` 的 `nail` 一致）：全文只服务这一问，其他集内容点到即止。

## 二、结构骨架（5 段，无小标题）

```text
段1  场面+对白+现场一人反应（约120字；时间/节目名勿作首句）
段2  人物代价链：数字、地名、动作（150～200字）
段3  钉子：本篇唯一问题，用一场戏或一句引语（120～180字）
段4  古今对话 + 一句连到今天（100～180字）
段5  物件/问号收束；可选一句轻互动（80～120字）
```

| 场景 | 用词/句型 |
|------|-----------|

## 四、专栏专用 — 禁用

| 类型 | 禁词/禁句 |
|------|-----------|
| 煽情通稿 | 鼻头一酸、史诗感、神助攻、演活了、太精彩了 |
| 观后感 | 热泪盈眶、强烈推荐、问心无愧、薪火相传（连用） |
| 节目宣传 | 节目旨在、挑战性极大、声情并茂、期期动人 |
| 课文腔 | 政书之祖史书之源（开篇堆砌）、五经之一（除非一句带过） |
| 全句引用外国人 | 「除非你读《尚书》否则不理解今天的中国」整句照搬 |
| AI 元叙述 | 它先把代价摆出来、读者手里还握着选择、节目想让你感到 |
| 对称代价句 | 天冷…妻子不让；儿子为护书，死在… | 主语写清 + 口语串讲：伏生想烧，妻子不干；后来儿子护书，人没了 |
| 剧评/meta | 正片还没、列篇目、篇目表、戏里先出来的是、镜头先落到、片头还没把你拉进课文 |

## 五、专栏金样（5 段全文节奏，仿结构勿整篇照抄）

对应 §二 五段骨架，每段一块金样。

### 段1 · 开头（场面+对白，时间放第三句）

```text
倪大红演的伏生，抱着从土墙里掘出的残破竹简，嚎啕大哭。身边人劝他：「先生，书毁了可以再写。」
他嘶哑着回了一句：「我妻、我子、我全家，舍命护它啊！」
就这一句话，让台上的撒贝宁泪崩，也把不少观众当场破防。
2021年大年初一，《典籍里的中国》第一集《尚书》，就这么把一个两千多年前的老头和那部难读的《尚书》，砸进很多人心里。
```

**勿**开篇先写「2021年大年初一…开播」；**勿**用「很多人先愣住」等平淡导语替换戏里对白。

### 段2 · 代价链

```text
史料和节目都写到同一段：伏生少时学《书》，秦末带着家人和简牍逃亡。
天冷想烧简取暖，妻子不让；儿子为护书丢了命。
天下平定后他掘墙取出竹简，损毁过半，整理得二十八篇。
汉文帝想召伏生入朝，老人腿脚走不动，派晁错到章丘学《书》，听伏生口传。
```

### 段3 · 钉子（民本，一句引语）

```text
戏里也演了一句常被引用的：「民惟邦本，本固邦宁。」
大禹治水、武王牧野，古装大戏一场接一场。
意思很白：百姓是不是根，竹简上早就写了。
```

### 段4 · 今天画面（古今对话）

```text
撒贝宁和伏生在国图拍古今对话：玻璃柜里是《尚书》展陈，手机屏上也能翻到今文读本。
戏里老人愣了一会，说「书有了你们的传承，我放心了。」
```

### 段5 · 收束（物件）

```text
墙里掏出来的竹简，后来在柜子里，不是只在作文题里。
```
