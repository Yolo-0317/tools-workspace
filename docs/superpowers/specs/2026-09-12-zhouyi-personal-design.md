# 自用周易起卦与典籍解读系统设计

日期：2026-09-12。本文记录讨论确定的产品方向与技术选型，作为实现计划的输入。

## 目标与范围

在独立的 `zhouyi` 项目中，实现主题预选、可编辑问题模板、自由提问、程序模拟起卦、固定规则取辞、典籍对照、DeepSeek 白话解释和历史复盘。前端 Vue 3、Element Plus；后端 Python FastAPI；复用现有局域网 MySQL 实例，建议业务库名 `zhouyi`。电脑和手机均可使用。

第一版采用一种钱币起卦方法及一种有版本的卦爻辞取用体系。不加入六爻纳甲、梅花易数、生辰八字或自动每日起卦。

## 用户流程

1. 首页可直接自由输入，也可选工作、合作、感情、学习、生活主题，再修改模板。背景与关注时段可选。
2. 展示最终问题，用户点击开始起卦即锁定本次问题。多件不相关的事仅提示聚焦，不擅自改写问题。
3. 后端随机生成三枚钱币的六次结果并保存，前端自下而上逐爻呈现。
4. 展示本卦、动爻、之卦、取辞理由及解读。原文与注疏可展开。
5. 历史页查看原记录、解读版本并添加后续复盘；典籍页可按卦独立查阅。

## 起卦与规则边界

每枚钱币独立等概率取字或背，字计 2、背计 3；三枚之和为一爻。6 为老阴、7 为少阳、8 为少阴、9 为老阳；6 与 9 变化，7 与 8 保持。六爻数组统一自下而上，展示与编码转换显式处理方向。四类结果概率为 1/8、3/8、3/8、1/8，不采用四类等概率抽样。使用操作系统提供的安全随机源。

取辞以《易学启蒙》变占体系为依据，建立独立、版本化的规则资料。实现时先核验完整《考变占》与相关图表，再固化 0—6 动爻及乾坤全变的规则与例证；三爻变须核对原文的前十、后十主次，不将网络简表直接命名为完整朱子规则。规则资料及验证必须先于解读功能上线。

规则输出主读、辅读及背景材料的明确标识。AI 不决定动爻，不选择或更改取用规则，也不重新计算卦象。之卦不固定翻译为必然的未来结果。

参考：

- 《易学启蒙通释·考变占第四》：https://www.shidianguji.com/book/SK0061/chapter/1l9qr24ok8562

## 典籍与解释

以《周易》经传为基础，《周易本义》为主注本，《周易正义》为补充参照。入库时记录书名、版本、篇目、卦爻定位、来源链接、文本校验值与核验状态。经、传、注分开存储。仅使用已核验条目；未核验或缺失材料显示缺失状态，不由 AI 补造。全卦基本文本覆盖是完整发布的条件，补充注疏按实际覆盖展示。

先按卦与爻精确检索，不需要第一版建设向量数据库。送给模型的每段材料带稳定来源编号和主辅读标识。

输出包括整体判断、典籍依据、联系问题、行动与观察。保留经文中的吉凶悔吝及适用条件；注家分歧分开说明。现代应用明确标记为引申，无法对应问题时直说。原文由系统显示，模型只返回解释及引用编号；后端校验引用编号属于本次材料。解释中的引文需与材料核对，不接受模型生成的来源地址。解释不表达经过验证的预测能力，不生成无来源的日期、成功概率或确定事件。

## DeepSeek 接入

用户指定沿用现有 DS。已检查 `stock-ai/scripts/tools/deepseek_client.py`：其支持 `DEEPSEEK_API_KEY`、`DEEPSEEK_MODEL`、超时和重试配置，同时含 Cursor 与公众号业务路由。

新项目使用独立的轻量 DeepSeek 适配层，复用现有密钥、模型与接口配置约定，不直接引入股票项目及其业务依赖。明确使用 DeepSeek，无其他模型自动回退。模型以接入时的有效配置为准，不将客户端代码的默认值当作实际已配置值。

环境变量优先，其次读取显式指定的本机配置文件，仅提取需要的 DS 字段；初次接入可指定现有 `stock-ai/.env`。使用专门的典籍解释提示词，不沿用默认量化分析师提示词。密钥只在后端使用，不进入前端、数据库、文档、日志或 Git。只发送本次问题、背景与所选典籍材料，不附带其他项目数据。

## 存储、接口与失败恢复

MySQL 保存典籍版本和条目、问卦记录、原始六掷、规则版本与选文快照、解读尝试与版本、复盘记录。历史解释保留当时的材料快照及模型、提示词版本，后续修改材料不覆盖历史。每次请求使用幂等标识，双击、刷新和网络重试返回同一次起卦记录。

FastAPI 提供主题模板、创建问卦、问卦详情与列表、生成或重试解读、复盘和典籍检索接口。数据库事务提交起卦结果之后才调用模型。模型失败或进程中断保留卦象，并允许基于同一记录重试；解读失败不重掷。数据库不可用时不显示起卦成功。第一版按记录查询解读状态，无需额外消息队列。

已有设计记录的 MySQL 地址为 `192.168.1.13:3306`，这是接入线索，不代表已验证当前连接。实现接入时读取实际本机配置，核验连接与独立库权限；避免将周易业务表写入股票业务库。开发服务默认本机访问，局域网服务访问在运行配置中单独设置。

## 验收与实施顺序

1. 核验并固化完整取辞规则、典籍来源与卦象映射。
2. 实现起卦和规则核心，验证全部 4096 种六爻状态，特别检查上下爻方向、0—6 动爻、乾坤全变和三爻变主次。钱币八种组合穷举验证分布，不依赖随机频率测试。
3. 建立 MySQL 存储与 API，验证幂等创建、失败保留、解读版本和历史复盘。
4. 接入现有 DS，验证引用越界或缺失、超时、限流和同卦重试。真实调用在读取有效配置后进行。
5. 完成四个页面，执行前端构建及电脑、手机宽度下的完整流程检查。
