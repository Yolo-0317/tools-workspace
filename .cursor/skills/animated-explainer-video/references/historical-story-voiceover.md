# 历史故事口播专题

2026-10-13 用户确认，适用于清末民初人物、事件、品牌、档案与系列「那年今天」等**历史故事**口播；与机制科普、儿童拆解、默认一分钟栏目区分。

2026-10-14 用户确认讲述风格：明月体的幽默解构、网络拟讲史的叙事、单口相声的节奏，最后落成短视频史话。写稿和改稿先读 [明月体史话口播](mingyue-shihua-voice.md)。幽默只在叙述者的说法上，不借此编场面、心理或对白。

## 时长

- **历史故事不限制时长约束。** 不把 60 秒、3 分钟或「字数÷语速」当作写作硬上限。
- 以**把故事讲清楚**为优先：人物、行动、时间、证据和结果交代完整；配音后按真实音频排镜头，不为旧时长删段、加速或吃句尾。

## 文体：故事，不是史评

- **要有故事性**：沿行动—回应—局面变化推进，用具体人物、物件、地点和文件承载情节；读 [非虚构视频的编剧方法](screenwriting-for-nonfiction.md)。
- **不要写成历史事件评论**：避免通篇评价意义、定位时代、归纳教训、对比今昔或替观众下结论。学者综述、百科「影响」「意义」段落不能当口播主干。民国八卦可以有贴在文书上的短评，写法见 [明月体史话口播](mingyue-shihua-voice.md)；短评不是文末鉴定。
- 仍遵守 Skill 最高优先级禁令：禁止「提出问题—给出判断—总结道理」及隐性说教链。民国八卦主线用叙事，只在关键处加一两句损友吐槽，见 [明月体史话口播](mingyue-shihua-voice.md)。其他历史故事的结尾停在具体结果与可核材料，不升华。
- **禁止前后工整对仗的句子**（如「一边……一边……」「谁……谁……」成对排比、连续「不……不……」、刻意字数相当的短句并联）。转述照会、布告时并入叙述，少照搬公文排比。语句须自然流畅，符合中文记叙习惯；连读时按 [中文承接与段落推进](chinese-writing-coherence.md) 检查。

## 流程（与主 Skill 一致）

1. 单集目录建 `research.md`：主张、来源、日期、阅读范围、待核项。民国八卦先写 `fact-card.md`。
2. 用 [非虚构视频的编剧方法](screenwriting-for-nonfiction.md) 和 [视频文案与叙事](video-script-design.md) 定结构。史话口气再按 [明月体史话口播](mingyue-shihua-voice.md) 写，史话不代替编剧。
3. 写完整口播 `script.txt`（或项目约定文件名）。用户要求 DeepSeek 起稿时，先由技能整理 `prompt-brief.md`，再让 flash 生成 `deepseek-prompt.txt`，然后用这份提示词另调一次 flash 写正文。见 [明月体史话口播](mingyue-shihua-voice.md) 的「用 DeepSeek 写稿」。
4. 按 [中文句法与病句审校](chinese-sentence-review.md) 逐句检查，再按 [中文承接与段落推进](chinese-writing-coherence.md) 连读。事实卡上的核对不能省略这两步。
5. 严格任务可另存 `language-review.md`；交付给用户以正文为主。

## 系列「那年今天」

- 标题格式：**那年今天 xxxx年xx月xx日**（公历）；农历可副标。
- 选题：该公历月日有**当日记载**的行动或文件；前后数日的事不挪到「今天」充数。
- 画面优先报刊影印、档案照、地图与授权史料；不编台词与内心戏。
- **读音与字幕**：生僻人名在单集 `production-notes.md`（或项目约定文件）标注拼音，供配音与 TTS；**成片字幕只出汉字，不写拼音**。
