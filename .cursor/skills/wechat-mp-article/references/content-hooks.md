# 公众号钩子筛选与兑现

类型与编号真源是[内容钩子库](../../../../docs/内容钩子库.md)。本页只维护公众号适配，不复制240条模板。新选题、重新设计标题开头或规划封面时选读相关条目；局部修改只核改动和受影响承接。

## 先筛类型，再写本篇的话

先明确已核事件、读者及正文实际提供的信息，再定一个主要目标；需要时加一个次要目标。标题内部至少比较三个不同类型的候选，默认只交付选中的一个。O开头、P推进、V封面按本篇需要选，不要求凑齐每一类；无配图任务不生成封面。文末按[交付规则](delivery.md#文末自然结束)自然结束，不调用评论互动模板。

[基座](../../../../docs/writing/中文写作基座.md)优先于库中示例。编号表示借鉴的结构作用，改写后可标“适配”，不能把自写句说成平台验证过的爆款。

| 库中结构 | 公众号筛选方式 |
| --- | --- |
| 具体场景、细节、物件、真实动作、有限范围 | 先看证据与读者是否能识别对象，留下正文确有内容可展开的一项信息，不按模板制造惊讶。 |
| 定义、比较、数字、流程 | 只有正文确有必要解释、可比对象和完整条件才用。正文直接叙述，不把标题中的研究问题铺成问答链。 |
| 纠偏、反转、两难、身份揭秘 | 先核误解、预期或选择确实存在。缺依据就换类型，不补“很多人以为”、心理、群体反应或隐瞒已知关键事实。 |
| 提问、测验、先别急、看完你就懂等话术 | 默认不照搬。能保留信息作用就改为自然叙述；改后只剩训导、概括或空悬念时弃用。用户明确指定的问句按主流程例外处理，不扩散成正文问答腔。 |
| 评论、点赞、收藏、分享、关注 | 不默认调用。文末不加问号钩子或评论邀请；用户本次明确指定的互动只在授权范围内处理。 |

选定标题与开头连同正文一起核兑现，不为钩子另改通用表达标准；已确认标题保留。

## 同题观察的边界

新选题或整篇正式定稿时，沿库中同题观察要求，通过可用浏览器查小红书相关图文，记录真实链接、可见数据和实际读到的评论范围，区分观察与推测。不因高赞照搬句子，不把其他家庭经历当本篇当事人的反应。库中“页”在公众号对应具体段落或图片，不强迫文章改成图卡。

仅修改已有稿件的标题或开头时，沿用本篇已核材料与已有观察，不自动扩成新一轮平台采集。未做同题采样就如实记录，不能宣称标题源自高赞帖子；无法访问不冒充已读，也不以此补造效果。

## 记录与审核

在本篇outline.md或review.md简记：`目标｜主/副类型ID（适配）｜三个不同类型候选及取舍｜选定标题和开头｜正文兑现段落｜互动（适用时）｜同题观察状态`。已确认标题无授权不自动更换；没有合适的现成类型时保留清楚的自然表达，说明未采用模板，不硬贴编号。

标题图文角色按本页钩子卡核对象、信息缺口和兑现位置，其他事实与语言意见并入[统一审稿](review.md)，不新增评分或轮次。
