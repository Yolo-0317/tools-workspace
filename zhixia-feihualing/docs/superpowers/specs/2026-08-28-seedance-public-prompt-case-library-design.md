# Seedance 公开提示词案例库设计

## 目标

建立一套可持续扩充、可回源核查、可直接服务于《栀夏飞花令》的 Seedance 公开提示词案例库。案例库覆盖人物、风景、舞蹈、动作、运镜、物理特效、声音与多模态参考，不把未经成片验证的社区“万能公式”直接提升为项目规范。

首版收录不少于 60 个案例，目标约 80 个；优先保证来源和信息完整度，不以机械凑数替代筛选。后续允许按同一字段持续增补。

## 采用方案

采用“主索引 + 分类专题库 + 可复用句式库”的文档结构。

- 主索引说明证据等级、收录标准、分类导航和使用方法。
- 分类专题库保留案例的完整语境，避免单篇文档过长。
- 句式库只从高等级案例中提炼可直接改写的中文结构，不收录来源不明的口号式模板。

不采用单篇“提示词大全”：它不利于维护来源、适用条件和失败风险。暂不建立表格数据库：首版案例需要解释动作因果和镜头过程，Markdown 专题比扁平表格更易读；未来案例量明显增长后再考虑增加机器可读索引。

## 文件结构

在 `docs/seedance-case-library/` 下建立：

- `README.md`：总索引、等级标准、字段说明、分类导航和统计。
- `01-characters-and-portraits.md`：人物肖像、角色亮相、服装与表情。
- `02-multi-character-interaction.md`：双人及多人互动、空间关系与比例稳定。
- `03-dance-and-body-movement.md`：舞蹈、步法、重心、方向、层次与节拍。
- `04-action-and-performance.md`：奔跑、骑乘、武打、表演和主体—摄影机联动。
- `05-landscape-and-environment.md`：山水、森林、花海、雪雨、沙漠、海洋、城市与建筑。
- `06-camera-and-one-take.md`：推拉摇移、跟随、环绕、升降、穿越、视差与长镜头。
- `07-effects-and-physics.md`：风雪、水火、烟雾、花瓣、衣袖、发丝、破碎与材质反馈。
- `08-sound-dialogue-and-rhythm.md`：环境声、音乐、对白、动作音效和节拍同步。
- `09-multimodal-reference.md`：图片、视频、音频、分镜板与参考素材映射。
- `camera-phrases.md`：从 A/B 级案例提炼的运镜句式库。
- `character-dance-phrases.md`：从 A/B 级案例提炼的人物与舞蹈句式库。

同一案例可能涉及多个维度，但只在最主要的专题中完整收录；其他专题使用短链接引用，避免复制后产生版本分叉。

## 来源优先级

按以下顺序搜集：

1. Seedance、字节 Seed、火山引擎等官方发布与官方文档。
2. 公开展示输入、提示词和生成结果的社区案例。
3. 公开工作流、提示词仓库及作者复盘。
4. 只有提示词或术语表、缺少结果证明的公开资料。

所有涉及当前模型能力、输入数量、产品规则或平台限制的内容必须回到官方当前页面核对。社区资料只能证明特定作者在特定输入条件下获得过某种结果，不能表述为平台保证。

## 证据等级

### A 级：官方且有结果

- 官方发布、官方文档或官方账号案例。
- 可看到提示词、输入说明或足以判断方法的官方描述。
- 可看到对应成片、关键帧或官方结果说明。

### B 级：社区可复核案例

- 有公开来源与作者。
- 至少同时公开提示词或工作流，以及对应成片或关键帧。
- 能判断主要输入方式，例如纯文字、角色图、分镜板、动作视频或音频。

### C 级：词汇参考

- 只有提示词、镜头表、教程观点或营销示例，缺少可验证结果。
- 可以进入词汇池和研究备注，但不能单独成为栀夏全局规则的依据。

来源不明、转载链断裂、明显冒充官方、无法区分模型或版本的内容不收录。

## 单条案例字段

每条案例统一记录：

1. 案例编号和中文名称。
2. 来源、作者或机构、公开链接和访问日期。
3. 官方/社区标记及 A/B/C 证据等级。
4. 模型或版本；无法确认时明确写“未确认”。
5. 输入方式：纯文字、图片、视频、音频、分镜板或组合输入。
6. 主体与场景。
7. 动作过程及可观察的因果链。
8. 摄影机：起始景别、角度、路径、速度、焦点或景深变化。
9. 光线、色彩、材质和环境反馈。
10. 声音与节拍；来源未披露时不推测。
11. 中文结构化提示词改写。
12. 可复用写法。
13. 已知失败风险、输入依赖和能力边界。
14. 对栀夏诗境的适用性：直接适用、改写后适用或不建议。

案例缺失的字段统一标注“来源未披露”，不得根据成片外观反向臆造原提示词。

## 中文改写与引用规则

- 保留原始页面链接，不大段复制社区或官方原文。
- 将案例改写为中文结构化描述，重点保留主体动作、镜头反应、环境结果和输入条件。
- 必须引用的原文短语只保留必要长度，并注明来源；不把多篇原文拼接成伪原创长提示词。
- 明确区分“来源明确写出”“根据公开成片观察”和“项目适配建议”。推断内容必须标注为推断。
- 不把项目内部编号、资产路径或制作代码混入可直接提交给 Seedance 的句式。

## 分类覆盖目标

首版以约 80 个案例为目标，最低覆盖：

- 人物肖像与首次亮相：8 个。
- 双人/多人互动与尺度：6 个。
- 舞蹈与身体运动：10 个，其中至少 4 个包含脚步、重心或节拍信息。
- 动作与表演：8 个。
- 风景与环境：14 个，覆盖自然、天气、建筑和城市。
- 运镜与一镜到底：12 个，覆盖至少 8 类不同摄影机路径。
- 物理特效：8 个。
- 声音、对白与节拍：6 个。
- 多模态参考：8 个。

这些是覆盖下限，不要求各专题互斥；总案例按唯一编号去重统计。若可靠公开案例不足，不以 C 级材料补足 A/B 级数量，而是在统计中如实显示缺口。

## 句式库生成规则

`camera-phrases.md` 和 `character-dance-phrases.md` 只提炼 A/B 级案例，并为每条句式反向链接到案例编号。

每条句式包含：

- 最小可用中文表达。
- 必填槽位，如主体、方向、速度、前景、揭示目标或节拍节点。
- 适合的时长和输入方式。
- 不应同时叠加的目标。
- 对栀夏诗境的示例改写。

句式库不承诺生成结果，只描述“有公开案例支持的表达方式”。

## 与现有项目规范的关系

- 本阶段只建立研究案例库，不立即修改 `docs/realistic-visual-style.md`、`docs/production-workflow.md`、角色圣经或单集提示词。
- 旧版“自由舞蹈”“单一主运镜”等规则仍保留当前历史状态，但案例库会明确记录它们与公开证据之间的冲突。
- 案例库完成后另行形成规范变更提案，只允许 A/B 级案例和项目自身成片复盘共同支撑全局规则变更。
- 已发布视频不因案例库新增内容自动返工。

## 搜集与核验流程

1. 建立来源清单并优先打开官方原页。
2. 判断是否能确认模型、输入、提示词/工作流和结果。
3. 分配证据等级与唯一案例编号。
4. 写入最主要的专题文件，并从其他相关专题建立交叉链接。
5. 提炼中文结构化描述、复用点和限制，不补写来源缺失信息。
6. 仅从 A/B 级案例更新句式库。
7. 检查链接、编号、字段完整性、分类统计和重复案例。

## 验收标准

- 主索引和 11 个专题/句式文件齐全，导航链接有效。
- 唯一案例不少于 60 个，目标约 80 个；人物、风景、舞蹈、运镜及其余分类达到最低覆盖或明确记录可靠来源缺口。
- 每个案例均有公开链接、证据等级、输入方式、中文结构化改写、复用点、风险和栀夏适用性。
- 官方与社区案例清楚区分；C 级案例不进入默认句式库。
- 没有大段复制受版权保护的原始提示词或教程正文。
- 没有把观察、推断或营销主张写成 Seedance 官方能力保证。
- 运镜句式与人物舞蹈句式均能追溯到 A/B 级案例。
- 现有提示词规范和单集文件不在本阶段被悄然修改。
- 文档中不出现项目内部镜头代码作为模型提示词。

## 非目标

- 不调用 Seedance 或其他付费模型生成测试视频。
- 不下载、转载或纳入社区作者的视频文件。
- 不把案例库等同于平台官方手册。
- 不在首版建立自动爬虫或持续抓取服务。
- 不在案例库阶段直接重写“白雪”诗境或其他单集最终提示词。
