# 抖音账号规划

## 定位

一句话定位：原创国风诗词幻想动画IP，少女栀夏与墨灵阿砚用飞花令打开藏在诗句里的东方世界。

账号不是AI教程号、随机国风美图号或单纯古诗科普号。AI位于幕后，前台品牌资产是角色、世界观、飞花令机制和持续故事。

## 目标受众

首阶段核心受众：

- 16至35岁的国风、动画、古诗词与东方幻想内容爱好者
- 喜欢治愈、轻奇幻、角色陪伴和互动答题的年轻用户

首阶段不同时兼顾儿童启蒙和应试教育。教育合作可在IP受欢迎后扩展。

## 账号包装

- 名称：栀夏飞花令
- 头像：优先使用阿砚正面头像，保证小尺寸识别度
- 简介：栀夏与墨灵阿砚，在诗句里打开一个个东方幻境。原创国风动画｜AI辅助制作
- 封面：每条只突出一个关键字，如“花”“月”“风”，避免堆叠长标题

## 内容支柱

### 主线动画

- 时长：30至60秒
- 结构：异常钩子、阿砚出题、栀夏接诗、文字响应、诗境回报、下一题悬念
- 频率：每周1至2条

### 阿砚出题

- 时长：12至20秒
- 结构：阿砚给出上句或关键字，邀请观众在评论区接诗
- 频率：每周1至2条

### 诗境与角色片段

- 时长：8至15秒
- 内容：文字苏醒、春风水墨、阿砚读诗、栀夏进入诗境等强视觉片段
- 频率：每周1至2条

### 长期栏目结构

《栀夏与阿砚》的长期定位不是单纯诗词讲解号，而是“东方古典世界里的原创动画IP”。诗词是进入这个世界的第一扇门，后续可依次扩展为：

> 古诗 → 节气 → 节日 → 古人故事 → 民间传说 → 古代生活 → 栀夏自己的故事。

栏目采用统一叙事方法：每一集都让栀夏和阿砚遇到一个“人间的小问题”，通过一个可见动作推进，而不是对镜头讲解知识。

冷启动阶段建议内容比例：

- 60%古诗微剧情：走进一首诗，拍出诗中发生的事件。
- 20%时令节气：走进一个时节，表现一个物候、动作或感受。
- 20%传统节日与民俗：走进一种过法，表现人在节日里做什么。

内部选题判断标准：这首诗、这个节气或节日能否被“拍成一个事件”，而不仅是生成一幅漂亮画面。

### 时长升级路线

| 阶段 | 建议时长 | 内容任务 |
| --- | ---: | --- |
| 起号期 | 约15秒 | 一首诗、一个节气或节日中的一个瞬间 |
| 稳定期 | 20至30秒 | 一个完整的微故事 |
| IP期 | 30至45秒 | 古典题材与栀夏、阿砚自身故事 |
| 成熟期 | 45至90秒 | 连续剧情、人物关系和系列短剧 |

时长升级不是“讲更多知识”，而是“讲更完整的故事”。账号进入稳定期后仍保留15秒内容承担拉新，再用25至35秒故事承担留粉；不能因单次涨粉就全部切换为长视频。

长视频复盘不再只看完播率，重点增加平均观看时长、评论率、关注转化、回访和连续追更表现。

## 首发置顶三条

1. 世界观预告：书里的字为什么会醒。
2. 角色介绍：栀夏与阿砚是谁。
3. 互动代表作：阿砚第一次问“这一句，你会接吗？”。

## 首月目标

- 首发前储备至少5条成片。
- 首月发布12至16条。
- 用同一批角色和场景验证三种内容支柱，不急于扩展新角色。
- 每条只测试一个主要变量：开头、时长、题目或结尾形式。

## 观察指标

- 前2秒留存的相对变化
- 同类视频之间的完播表现
- 评论区真实接诗数量和有效互动比例
- 每千次播放带来的关注数
- 观众对栀夏、阿砚和诗境的偏好

不依据单条视频下结论；同一内容支柱至少发布3条再比较。

## 商业化顺序

1. 先验证角色认知和互动机制。
2. 再尝试头像、壁纸、表情包、诗词卡和书签。
3. 之后扩展音频故事、合集、文具周边和文化教育合作。

前30条不以带货为主要目标。

## 发布合规

- 作品文案可写“原创虚构动画”或“原创虚构故事”。
- 发布AI生成或合成画面时，使用抖音发布页的“内容由AI生成”声明。
