# Seedance 官方提示词交付门禁

状态：生效。官方依据核验日期：2026-09-03；项目案例补充日期：2026-09-24。适用于本项目 Seedance 2.0 系列新提示词及修订稿，包括诗舞、热舞、天宫日常与小黑单角色短片。

本门禁是助理交付前的语义审查流程，不是已接入 API 的自动检测器。通过只表示提示词与已知依据一致，不保证生成成功或消除画面漂移；不追溯返工已接受的视频。

## 1. 官方依据与适用边界

- [官方指南可读取正文](https://docs.byteplus.com/api/docs/ModelArk/2222480)：本次核验依据；该正文显示更新日期为 2026-06-08。
- [官方英文入口](https://docs.byteplus.com/en/docs/ModelArk/2222480)、[官方中文入口](https://www.volcengine.com/docs/82379/2222480)：用于后续回源。动态页面版本可能不同，不将仅抓到标题的页面视为已读正文。

官方依据摘要：主体与素材应明确绑定；避免冗余和语义冲突；不要直接提交完整剧本；按镜头顺序描述事件，精确分段时序并不稳定；单镜避免叠加互相竞争的运镜；多人参考优先清楚的独立单人图，拼接多视图存在身份风险。对应章节为主体定义、镜头编排、运镜、角色漂移及重复人物 FAQ。

以下分级、验收清单和本集实例是本项目的执行约定，不冒充官方平台审核规则。模型参数、输入上限、价格与功能可用性须另查当前型号的官方文档；不能由本指南推定 Mini 与其他型号的成功率相同。

## 2. 何时执行

用户要求“给提示词”“完整提示词”“整理一下”“改一下提示词”“检查规范”，或即将实际提交生成时，均执行本门禁。只在对话中贴正文也适用，不以是否保存文件为条件。

1. 先读取本页，确认本次栏目、用户最新决定和已有素材；不要重新套用不相干栏目的模板。涉及对白时，先确认是出镜角色亲口说、画外音、旁白还是传音；涉及无字幕时，确认目标是生成画面无字，还是后期不加字幕。
2. 将人读的设计稿与模型正文分开：设计稿可保留动机、笑点解释、精确剪辑轴和验收指标；正文只保留需要生成的内容。
3. 按下表逐项审查，修改后重新检查。用户只要求审查时，先报告问题，不擅自更换剧情或素材。
4. 正文交付与实际提交分两阶段检查素材标签：交付时可使用已明确告知如何替换的占位标签；实际提交前必须核对已绑定的真实素材。

## 3. 检查表

| 检查项 | 审查要求 | 处理方式 |
| --- | --- | --- |
| 主体与素材 | 每个角色有唯一名称；参考分别用于脸、服装、动作或声音；数字素材 ID 不代替正文引用 | 指代错误或职责冲突必须修正；实际提交缺素材必须拦下 |
| 稿件分层 | 去掉笑点解释、观众心理、内部文件路径、版本号、门禁说明等非生成内容 | 修改后再交付；不靠固定字数判定 |
| 时长与动作 | 保留目标总时长；正文默认按镜头及“开场立即、随后、结尾停留”组织；检查动作和对白是否挤占反应时间 | 不把硬秒点当成可靠控制；用户要求保留时间窗时标注目标性质及验收方式 |
| 空间与道具 | 剧情相关物件在使用前已有位置，或有明确入场来源；风向、交接和持有关系连续 | 无来源的物件或互相矛盾的空间描述必须修正；非剧情陈设可精简 |
| 身份与变化 | 分开写固定项和剧情允许改变的状态；例如脸与服装固定，头发由整齐变乱并持续到结尾 | 同时要求同一特征不变与改变必须修正；正常的状态变化不能误判为换角色 |
| 摄影与构图 | 镜头服务主要动作，避免同一时刻互斥的景别或复杂运镜要求；时间段不等于镜头数 | 有冲突则修正；不要机械规定所有视频只能两个镜头或必须一镜到底 |
| 手部与微动作 | 保留解释因果所需的拿取、施法、护头等动作；检查多次移动小道具是否必要 | 过密则合并或提示风险，不凭未经实测的动作数阈值放行 |
| 语音分配 | 每句台词有明确说话者；区分出镜对白、传音、旁白及无对白角色；正文台词集中写一次 | 说话者冲突或声音模式自相矛盾必须修正；保留自然语速与停顿 |
| 出镜对白与口型 | 若角色在画面中亲口说话，明确声音来自该角色、口部在镜头中可辨，开合与对白同步；动物保持物种口鼻结构，不以“自然口鼻动作”替代说话动作 | 若口型是核心要求，缺少可见口部或把对白写成画外音须修正；原生口型精度仍属成片风险 |
| 画面文字与字幕 | 用户要求无字幕或无字画面时，在正文集中写一次“不出现对白转写、字幕及其他屏幕文字”，并区分画面烙字和可关闭的字幕轨 | 缺少无字要求须补；提示词不能保证无烙字，成片须检查视频帧与字幕轨；已烙字不能靠关闭字幕轨移除 |
| 重复与排除项 | 同一要求合并；保留已发生或直接破坏本集核心效果的限制 | 删无关清单，不把“出现负面词就会生成该物”当定律；也不能一律删除必要限制 |
| 参考图风险 | 检查拼接卡中的脸是否太小、多人多视图是否易混淆 | 风险提醒，不自动判定角色卡不可用；需要换参考或制图时遵循用户决定 |

## 4. 放行规则

- **拦截：** 主体错绑、核心要求冲突、关键道具无来源、对白归属冲突；出镜说话是核心效果却被写成画外配音或让口部不可见；用户明确要求无字却未写进正文；把未实测效果或精确秒点写成保证。修正前不能标为可直接提交。
- **提醒：** 已确认的拼接角色卡、复杂盘发变化、10 秒内较多动作、单集指定时间窗、动物原生口型同步和模型画面烙字等不确定项。说明风险、保留理由和检查办法后，可标为“带风险可试生成”；不要强迫用户为所有提醒重复确认。
- **通过：** 无未解决拦截项；如有提醒，必须已记录处理。通过不代表画面、配音或字幕已实测。
- **证据不足：** 用户要求核验新能力，但无法取得相关官方正文时，明确待核验；可以提供标注限制的草稿，不能宣称已按最新官方指南验证。

不得为了通过门禁删掉用户确认的笑点、修改角色母版、改变时长或增加付费素材生成。出现这类取舍先报告，交由用户决定。已有创作要求可保留为目标，但不能凌驾于模型实际能力边界。

## 5. 交付记录

每次交付在可复制正文外留一句简短结论。涉及重要风险时追加必要说明，不把检查清单塞回模型正文。

最小记录包含：本页核验日期、本次检查日期、栏目及目标时长、检查结论、未消除风险与处理。已有单集文档时记入单集文档；纯对话交付时直接在正文外记录，不为此强制创建文件。

示例：按 2026-09-03 核验的官方指南检查；本次检查 2026-09-03；天宫日常 10 秒；带风险可试生成：保留已确认角色卡，盘发吹乱及跨镜持续状态尚未实测。

实际生成前另核对模型、时长等设置与素材绑定；付费授权仍按原生产流程执行，门禁通过不等于获得调用授权。

## 6. 《已经在路上了》审查样例

这是本次旧稿的待修项，不是已完成修订或实测通过的记录：

- `0—3秒、3—6.5秒、6.5—10秒` 留在设计节奏表；正式正文改为两个镜头及相对节奏。10 秒总目标、立即催促和乱发结尾保留。
- “嘴已经在路上”是脚本标题；模型正文直接描述坐着回答“在路上了”，不用隐喻解释。
- 纱帘是必要风效参照，保留开场位置与受风变化；不能因为精简让它在中途凭空出现。首饰匣等无关陈设可删除。
- 合并反复移近移远玉佩等微动作，保留拿起玉佩、低声求助、施风、护头及结尾反应的因果。
- 统一一次身份约束和一次状态约束：主发髻与冠饰保留，周围长发吹乱，风停与切镜后仍乱。
- 催促声来自玉佩，栀夏说其余三句，阿砚无对白；声音段不再重复完整台词。
- 现有拼接角色卡与乱发效果作为待实测提醒，不承诺一次成功，也不擅自重做角色卡。

## 7. 小黑《情绪稳定》已生成成片的项目案例

2026-09-24 核看 10.08 秒原片 `6f17bb69-959b-4ed0-841c-a9855757af67.mp4`：小黑对白时口鼻基本静止，声音呈画外配音感；白色字幕随台词出现在视频帧中，文件只有视频和音频流，没有独立字幕轨。倒粮和开吃动作已出现。用户明确不再重新生产这条视频。

本例说明“自然口鼻动作”和“不生成字幕”这类单句要求未达到预期，不说明模型每次都会失败，也不是官方新增规则。以后遇到**动物出镜亲口说话**，在模型正文中明确它是现场说话者、口鼻足够大且清楚可见、犬类上下颌随对白开合，并留出对白与动作时间；不要同时把同一句写成旁白或画外音。遇到**明确要求无字幕**，集中写明画面无对白转写、字幕及其他文字；交付记录提醒可能出现烙字，并在成片中查看视频帧和字幕轨。两项都只提高提示词的语义清晰度，不保证生成结果。

用户反馈已生成作品的问题时，先区分记录经验、后期处理和重新生成三种意图；用户明确选择不重新生成时，仅更新后续门禁与相关文档，不把新提示词或再生成列为当前交付。

## 8. 更新与旧规则协调

新增型号、官方页面更新、用户要求查最新规范，或现有规则与官方说明疑似冲突时回源复核，并更新核验日期和具体变更。不要仅因官网标题可访问就标为复核成功，不使用社区文章替代官方依据。

本页统一本项目最终提交文本的组织方法。旧文档中的毫秒轴、固定段数和密度指标可作为栏目设计与成片验收目标，不默认完整复制到模型正文；已确认历史作品不返工。栏目规则只在对应栏目内适用，例如文化诗舞持续舞动与后期朗诵要求，不能用于否定天宫喜剧的停顿、乱发状态或原生对白。
