# 语序与修饰范围

## 中性叙述与话题前置

没有特殊对比或承接时，常见的叙述顺序是先提出人物或事物，再交代相关动作、对象和结果。状语通常放在它修饰的谓词前，定语通常放在名词性中心语前，补语通常在中心语后。这是常用组织方式，不是所有句子都必须套用的模板。

例如，介绍一个人的学习经历时，“小林跟着老师学写字”顺着人物展开，关系容易理解。如果上文正在区分两门课分别向谁学，“写字，他跟张老师学；唱歌，他跟李老师学”则以前置话题组织对比，也成立。

调整语序前先看上文正在谈谁、当前句要补什么信息。不能把后一种表达一概判错，也不能把前一种普通叙述无端改成倒装来追求节奏。用户的实际改句见[语境诊断案例](语境诊断案例.md)。

## 修饰语离谁近，不一定就修饰谁

先找到中心语，再判断每一层修饰关系。“老师新买的书”说的是老师新买了一本或一些书，不等于“新老师买的书”。只调整一个修饰语的位置，就可能换了事实。

“学校新来的三位语文老师”以“三位语文老师”为被说明的对象，“学校新来的”限制这组老师。若要明确是某所学校的教师，可写“这所学校的三位新任语文老师”。两者是否可换，还要核原文究竟交代任职、到来还是所属关系，不能只看顺口。

多层定语、状语有常见次序，但没有适用于所有材料的唯一排列口诀。“新买的两本书”与“两本新买的书”都可能自然，选择取决于语境和信息重心。修饰层级过多时可拆出一句交代，不能只靠不断加“的”解决。

## 时间、处所与动作顺序

“他昨天在书房看书”通常先给时间、处所，再说动作。“昨天，他在书房看书”把时间作为全句背景，也可成立。若上文已确定“昨天”，重复它未必必要。

连续动作要核实际先后：“他拿出信，拆开信封，读了起来”通常按发生次序叙述。倒叙或插叙可以打乱叙述次序，但须让读者辨明时间关系。材料没交代先后时，不为使句子顺畅擅自添“随后、刚一……就……”。

## 的、地、得

| 常见用途 | 自编例子 | 不能机械化的地方 |
| --- | --- | --- |
| “的”连接定语与名词性中心，或构成的字短语 | 认真**的**学生；新来**的** | 不等于每个名词前必须加“的”。“三本书”不需要。 |
| “地”可标示状语与中心语的关系 | 认真**地**读 | “认真读”也可成立；不把所有动词前成分都补“地”。 |
| “得”引出补充说明的结构 | 读**得**认真 | “得”还有其他读音和用法；不是凡动词后都用它。“读完”无须加。 |

“他高兴地说”说明说话时的状态或方式；“他说得很高兴”把说明放在“说得”之后，具体理解仍需语境。定、状、补的改换可能调整关系，不能只按标记替换。

## 范围、否定和数量

“他只借了两本书”与“只有他借了两本书”限定的对象不同；不能把“只”移到哪里都当作同义。“大家不都同意”通常表示并非人人同意，不等于“大家都不同意”。如果口语形式可能使读者误解，按实际意思明确写“并非所有人都同意”。

“他没说一定来”否定的是说过某项承诺，不能改成“他说一定不来”。“还没写完”不等于“没有写”，未完成不代表没开始。

“三位学生的家长”不保证只有三名家长，“三名家长”也不交代他们与几位学生对应。材料只交代学生人数时，不通过移位把它变成家长人数。“六至十年级学生的家长”中的年级修饰学生，不能改得像在修饰家长。

这些表达首先涉及意义和范围，不能仅凭语法通顺判改写成功。基础来源与编辑归纳的界限见[来源与核对](来源与核对.md)。
