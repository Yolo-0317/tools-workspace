搜一搜把用户当「着急找路的人」——**标题是路牌，正文是答案**。牛马也智能写稿须同时过 eval 门禁与本节规则。

## 一、标题：清晰、简洁、直接（教程 01）

### 必做

| 规则 | 牛马执行 |
|------|----------|
| 表意完整 | 读者不看正文也能懂「什么事 + 和 A 股什么关系」；**禁止半句话截断**（如「从中东返…」→ 改「返港」） |
| 主旨前置 | 核心词落在 **前 15 字**（列表/搜一搜截断位） |
| 长度 | ≤ **32 字**；宁可压缩冗语（`从中东返回法国`→`返港`），勿硬切字 |
| 与正文一致 | 标题事件 = 开篇 + 第一节主题；**禁止**标题写 A、开篇大段写 B |
| 疑问/信息句 | 行情稿含 `？` 或 `！`；信息完整优先于悬念 |

### 禁止（平台明确打压或伤体验）

- 表意不明、隐瞒关键信息、夸大（震惊/100倍/稳赚）
- 标题与正文无关，或 **与开头大段无关**
- 标题过短无信息（如「7月12日复盘」）
- 标题过长在搜一搜被截断后 **语义残缺**
- 堆砌关键词、无意义符号（「A股A股复盘龙头龙头」）
- 假冒入口（「登录」「全集」「免费看」类）
- **股名重复 / 元叙述当事件**（见下节「标题硬禁 · 2026-07-28」）
- **通稿冒号后硬切人名**（「…针对内塔和A股」）

### 标题硬禁 · news / hotspot（2026-07-28 实盘）

推稿或改稿时 **口头读一遍标题**；命中任一条 → 重生成或手改，禁止上架。

| 硬禁 | 说明 | 正例 |
|------|------|------|
| 同一股名出现 ≥2 次 | `中际旭创…背景下，中际旭创与…` | `收盘值得看中际旭创？10条快讯拆开` |
| `背景下` + 双股名 | 把「XX人气榜首」当宏观事件再套模板 | 热股前置问句；事件钩子须真宏观 |
| `人气榜/榜首/人气标的` 进事件钩子 | 榜位元叙述不是可搜事件 | `_short_event_hook` 已拒；Agent 勿手写回去 |
| `甲与甲` / `人气标的与人气标的` | 仅一只热股时硬凑双股 | 单股模板：`今天人气在{lead}` |
| 冒号后砍半截人名 | `以色列国防部长：…内塔和A股` | 地缘压缩：`热点深评｜中东局势再升温，A股该关注啥？` |
| 钩子与「A股…」后缀粘连 | `升温A股该关注啥`（缺顿号） | `升温，A股该关注啥？` 或 `升温对A股…` |

**代码真源**（改模板勿回退）：

- news：`wechat_mp_news_titles.py`（拒榜位元叙述、禁 `背景下`、单股不凑对）
- hotspot：`wechat_mp_hotspot_article._topic_section_title` / `_title_hook` / `build_hotspot_title`（地缘映射、冒号取前半、A股后缀加顿号）

### 分稿型标题自检

| kind | 前 15 字优先 | 完整度示例 |
|------|--------------|------------|
| **news** | 热股名 + 问句/快讯 | `收盘值得看中际旭创？10条快讯拆开` |
| **dragons** | 龙头/情绪 + A股 | `情绪退潮：XX连板还能追吗？` |
| **hotspot** | 具体事实路牌 | `热点深评｜市值前十红了9家，建行、工行创新高？` |
| **market** | 时段 + 指数/结构 | `7月10日收盘：沪指3996点…` |

## 二、正文：鲜明、详实、可用（教程 01）

### 必做

| 规则 | 牛马执行 |
|------|----------|
| **单主题** | 一篇只深写 **1 条线**；hotspot 禁止 10 条快讯清单（news 已承担） |
| 论据具体 | 涨跌幅、家数、板位、板块名、可核对事实；复杂题写 **机制** 不写形容词堆叠 |
| 可读可操作 | 段 ≤3 行；每 2～3 段有 `>` 分节；「向后看」给 **可验证指标** |
| 原创增益 | 盘面 + 舆情 + AI 判断三线对照；勿纯搬运通稿 |
| 开篇即答案路径 | 首段 50～90 字：今日深写谁、怎么读（彩色开篇 / 路径句） |

### 禁止

- 拼盘式罗列（多条快讯、多个无关热点）
- 开头大段小编体/广告/免责后再进正题（免责在品牌头下 1 段即可）
- 元叙述：「根据你提供的」「在候选五条中」「相较某某标题没选」（编审过程 **读者不可见**）
- **结构导语**：「本篇不复盘快讯清单」「递进阅读」「阅读路径」「下文先交代选题逻辑」「单一变量」等预告文章结构的句子
- **采集缺口元叙述**：「数据未获取」「样本个股…未获取」「交易时段…未获取」——缺数改写板块/指数现象
- 搬运微信已泛滥的同一表述而不加盘面映射

### hotspot 纯段落长文（2026-07-30，取代旧四段标签）

- **禁止** `> ` 小标题与「为啥盯这条 / 明天盯什么」等节名
- 首句直接事实+数字；禁「公开报道里有一条值得先记住」等元叙述
- 标题用具体事实，禁「和A股啥关系」式逻辑重复
- 完整写稿 SOP → **[hotspot-deep-review.md](hotspot-deep-review.md)**

## 三、排版：突出重点和层次（教程 01）

| 必做 | 避免 |
|------|------|
| `>` 居中分节标题（代码已注入样式） | 全文无分段、无小标题 |
| 涨跌幅等着色数字 | 过度加粗（满屏重点 = 无重点） |
| 字段标签逐字：`发生了什么：` 等 | `>小标题` 与 `发生了什么：` 粘同一行 |
| 文末 1 块免责 | 正文插 `· · ·` 假广告位 |

## 四、账号侧（教程 03 · 改稿时顺带核对）

写稿 skill 主责是 **单篇**；以下在推稿/包装时一并看：

| 项 | 牛马 |
|----|------|
| 昵称 | **牛马也智能**（有品牌），勿改纯通用词「A股复盘」 |
| 描述 | 写清「A股收盘复盘 / 产业链 / 龙头观察」；勿关键词堆砌 |
| 菜单 | 功能名具体；勿第四个「A股/龙头」同类 SEO 菜单 |
| 原创 | 发布勾 **原创 · 财经/科技** |

## 五、Agent 改稿顺序（搜一搜优先）

```text
1. 标题：表意完整？前 15 字有信息？与开篇一致？
   · 硬禁扫：股名是否重复？有无「背景下」？有无半截人名/「升温A股」粘连？
2. 单主题：hotspot/news 是否分工清楚？
3. 开篇 2 段：结论/路径可见？
4. 分节与数字：≥2 个 `>` 块；有阿拉伯数字？
5. 去编审话术 + 去 AI 连接词 → anti-ai-voice.md
6. 跑 eval + push_quality_gate
```

### 快速命令

```bash
cd stock-ai
uv run python -m scripts.tools.wechat_mp_eval --kind hotspot --traffic
uv run python -m scripts.tools.wechat_mp_push_quality_gate --batch evening
```

## 反例 → 改法（牛马近期踩坑）

| 反例 | 问题 | 改法 |
|------|------|------|
| `A股快讯｜中际旭创人气榜首背景下，中际旭创与太极实业快讯` | 榜位当事件 + 股名重复 + SEO 前缀叠床架屋 | 重跑 `_news_title`；禁 `背景下`；单/双股分模板 |
| `热点深评｜以色列国防部长：伊朗…内塔和A股有关系吗？` | 冒号通稿硬切 + 人名半截 | `_GEO_SECTION_MAP` → `中东局势再升温`；后缀前加顿号 |
| `…航母从中东返…对A股有什么影响？` | 标题截断半句话 | 压缩为 `返港` 或删修饰语 |
| 「在候选五条中，相较戴高乐…故选海峡」 | 泄露编审过程 | 只写事件对 A 股链路的映射 |
| `能源…样本个股涨跌与换手数据未获取` | 向读者交代采集缺口 | 改板块现象：「链条内个股分化，对照油价/指数验证」 |
| `>为什么选这一题霍尔木兹…` | 节标题与正文粘连 | `reflow_hotspot_body` + `ensure_blockquote_sections` 拆行 |
| news 10 条 + hotspot 再列 10 条 | 拼盘、主题不鲜明 | hotspot 单主题四段 |
