# AI 卦盘母版验收清单

资产标识：`ai-divination-disk-v01`。

## 文件与画幅

- [ ] 文件名为 `master.png`，可以完整解码。
- [ ] 画幅为 9:16，至少 720×1280 像素。
- [ ] 画面主体和文字安全区没有被边缘裁切。

## 身份一致性

- [ ] “未起卦”“六爻生成中”“卦象揭示”三个状态可以明确辨认。
- [ ] 三个状态保持完全相同的外框轮廓、材质、配色、刻度和信息区域。
- [ ] 卦盘为不依附古籍、桌面或手掌的单层轻薄半透明悬浮界面，不是厚重实体圆盘、托盘或游戏法阵。
- [ ] 卦盘直径约 30 厘米、视觉厚度不足 1 厘米，展开后能稳定悬浮在两位角色之间的桌面上空。
- [ ] 主色为浅青、月白、暖金与极少朱砂，没有蓝紫霓虹、强光柱或粒子漩涡。

## 六爻与信息区

- [ ] 恰好六个爻位，生成方向自下而上。
- [ ] 阳爻为完整横线，阴爻为中央中断的两段横线。
- [ ] 卦名、上下卦和原文各有独立、清楚、无遮挡的可变区域。
- [ ] 精确中文和六爻可以在后期叠加，不依赖生成模型绘制可读文字。

## 直接淘汰

出现三个状态不是同一件道具、爻位不是六个、生成方向相反、阴阳爻无法区分、文字区被角色或装饰遮挡、蓝紫游戏法阵、机械改造栀夏或阿砚、Logo 或水印时，母版不进入后续单集引用。
