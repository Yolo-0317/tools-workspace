# 《霓裳飞天》朗诵字幕成片设计

## 目标

将用户确认保留的 15.069 秒《霓裳飞天》舞蹈原片制作成四句诗朗诵与逐句竖排字幕正式版，同时保留一份无字幕朗诵试听版。高清输出为 1080×1920、24fps，原片背景音乐与环境声全程保持原始时间结构和相对音量。

## 输入

- 用户原片：`/Users/huan.yu/Downloads/d2a00f67-6708-4440-b225-ccfc270a01c6.mp4`
- 项目归档：`episodes/nichang-feitian-15s/assets/video/content-seedance-v01.mp4`
- 诗文：唐·李白《古风·其十九》四句取句。
- 音色：栀夏固定清透明亮女声，与已完成敦煌系列保持一致。

## 声音设计

- 四句分别生成独立配音，使用栀夏固定音色 `ICL_uranus_zh_female_tianmeihuopo_tob`。
- 语气轻盈、清透、空灵而自然，不使用朗诵比赛腔、主持腔、戏曲腔或吟唱。
- 第一、二句轻巧清晰；第三句略带飘带延展感；第四句更加开阔，在 14.550 秒前自然收束。
- 每句依据实际有效语音区间裁切，必要时轻微减速以贴合目标字幕窗。
- 原片音乐与环境声从头至尾保持原音量，不设置侧链压缩，不设置分段音量包络。
- 人声独立进行高通、轻度均衡、动态压缩与响度整理，再与原片音轨直接叠加。
- 最终总线只做统一峰值限制，避免混音削波，不改变背景音乐内部强弱关系。

## 字幕设计

- 四句逐句显示为左侧竖排诗句，使用暖象牙白主字、克制旧金描边与柔和暗色阴影。
- 字幕位于左侧安全区，避开画面中央栀夏、头冠、双臂、飘带主线和下方莲花。
- 第一句题署采用较小字号，与诗句保持清楚层级。
- 每张字幕卡使用透明背景 PNG，按对应时间窗淡入淡出，淡入与淡出各 0.120 秒。
- 保留原片右下角已有标识，不增加额外标题、印章或发布文案。

## 高清处理

- 原始 496×864 画面按高度放大至 1920，再居中裁切为 1080×1920。
- 使用高质量 Lanczos 缩放、轻度时域降噪和克制锐化，保持人物五官、服装纹理与飘带边缘自然。
- 输出 H.264、24fps、CRF 17、AAC 192kbps、48kHz 双声道，并启用 faststart。
- 无字幕试听版与正式字幕版均保持原片 15.069 秒时长。

## 验收标准

1. 四句诗文字、顺序和题署正确。
2. 朗诵有效内容落在四个目标时间窗内，句间留白自然。
3. 栀夏四句音色、距离感和语气一致，第四句在画面结束前完整收住。
4. 原片音乐全程保持原音量，没有人声出现时的背景音乐抽吸或下降。
5. 字幕位于左侧安全区，不遮挡栀夏面部和核心舞姿。
6. 1080×1920 正式版无黑边、无异常拉伸、无爆音、无削波。
7. 无字幕朗诵试听版和正式字幕版均可正常播放，时长与音视频参数正确。
