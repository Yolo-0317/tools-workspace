# 居民存款减少 6300 亿元热点深评设计

## 目标

写一篇可推入「牛马也智能」草稿箱的热点深评，回答“7 月居民存款减少约 6300 亿元，钱去了哪里”。文章不把存款下降直接等同于消费复苏，也不把资金流向简化成单一股市叙事。

## 标题与核心判断

- 标题：`居民存款少了6300亿，钱去哪了？`
- 摘要方向：存款减少更像家庭资产在活期、定期、理财、权益资产、还贷和日常支出之间重新搬家，不能仅凭一个月的数据判断消费信心全面回升。
- 原创核心判断：真正发生变化的不是居民突然不再储蓄，而是低利率环境下，家庭开始重新计算“流动性、安全感和收益”之间的价格；资金搬家可以很快，信心修复却必须由收入与预期持续验证。

## 事实与来源

- 以中国人民银行公开金融统计数据为数字真源，核对 7 月住户存款、企业存款和非银金融机构存款的月度变化。
- 至少使用三个不同来源域，优先中国人民银行、澎湃新闻、中国新闻周刊、央视新闻或权威财经媒体。
- 区分可确认事实、机构解释和本文推论；不把资金流向股市、理财或消费写成已被单一数据证明的结论。

## 结构与排版

- 约 2200 至 2600 字，纯段落，无编号小标题。
- 开头 50 字内交代“7 月居民存款减少约 6300 亿元”。
- 先拆数字口径，再讨论可能去向，随后分析低利率下家庭风险偏好的变化，最后落到收入预期才是消费信心的长期锚。
- 使用混合短段：关键事实和判断一句一段，解释段保持一至两句，避免机械金句。

## 配图

- 封面 1 张、正文 3 张，均与居民储蓄、银行网点、金融数据发布或相关报道直接有关。
- 微博媒体原帖和百度新闻只作发现入口，图片必须回到可核验的原报道页。
- 优先澎湃新闻、央视新闻、中国新闻周刊等公开报道页；记录来源页、图片地址、媒体名与核验状态。
- 只有公开报道图不足四张时才生成缺口图，不替换已经找到的真实报道图。

## 推送与变现门禁

- 使用 Codex hotspot JSON 入口，先 dry-run 通过原创度、字数、来源、配图与合规门禁。
- 自动收益模型选择一部短剧，在正文约三分之二处插入且仅插入一张 `short-play` 卡片。
- 草稿写入后回读核对剧目 ID 与归因票据；任一环节失败即停止，不回退普通返佣商品。

## 验收

- 标题不超过 20 字且与首段同题。
- 正文去空白不少于 1920 字，至少三个来源域，原创判断不少于 20 字。
- 封面与三张正文图均可追溯，原则上不使用生成图。
- 草稿箱中正文、图片、短剧卡片完整，回读校验通过。
