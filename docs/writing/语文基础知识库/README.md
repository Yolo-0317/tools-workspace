## 使用命令

在工作区根目录执行，只有Python标准库依赖：

```bash
# 精确查一个词，保留其多个义项
python3 docs/writing/语文基础知识库/scripts/kb.py query 还是

# 按句召回已建的候选词，不自动判义或改稿
python3 docs/writing/语文基础知识库/scripts/kb.py query '又读了一遍，还是没懂。' --mode sentence --context '同一段的真实前文'

# 按关系或近义组查
python3 docs/writing/语文基础知识库/scripts/kb.py query 否定组 --mode tag

# 校验并更新阅读页和索引
python3 docs/writing/语文基础知识库/scripts/kb.py build

# 仅校验，不生成文件
python3 docs/writing/语文基础知识库/scripts/kb.py check

# 运行检索和校验测试
python3 -m unittest discover -s docs/writing/语文基础知识库/tests -v
```

精确查词不会把“还”扩成“还是”。按句查使用当前已建词中的最长匹配，不是真正的分词器；已登记的待核多字词会作为边界跳过，避免退回已核短字而绕过待核限制；未建复合词仍可能误命中短字，必须连上下文判断。程序保留多个义项和传入上下文，不声称已理解当前句义。查不到返回空结果，不补造词义；默认不返回待核、争议或停用词，排查时可用`--include-pending`查看待核/争议，停用词仍排除。

## 内容维护

`data/batch-*.json`是词条内容的数据源，[来源登记](sources/registry.json)另管证据。修改数据后执行build，不能直接手改views或indexes。自动校验只检查结构、引用和状态，不判断语言学真伪。新增批次可按`batch-*.json`命名，生成命令会合并检索；阅读页已按同名批次分开生成，目录集中列出入口。

常用义项先核资料，再编写带上下文的例句及比较，回读以确认没有增加时间、因果、程度、能力或态度。程序测试和语言校核分别登记。词性随义项填写；有不同体系的分类时保留说明，不冒充原词典标签。

本库例句为自编教学材料，不是文章事实或用户正例。用户确认原句仍在[中文口吻正例](/Users/huan.yu/.codex/references/chinese-writing-examples.md)中维护。来源音读不自动视为大陆普通话审音规范；本批不提供发音裁决。

优先精确查词。按句召回只筛词形：例如“重复登记”仍可能召回“重”的重量义，这属于已记录的误命中，不能把返回义项直接套进整句。当前没有可靠分词、词性消歧或自动判义能力。

未来按完整词表补齐词目、义项和用法，分别统计覆盖率。原五词已迁移；[旧快照](evaluation/原五词迁移前.md)仅供核对，不再维护第二套解释。
