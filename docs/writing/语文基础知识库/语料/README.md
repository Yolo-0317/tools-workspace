## 怎样用于改句

先确定当前句子想说的人、事情和关系，再查相关词及搭配。查看短摘录时必须连同`context_summary`、`editorial_analysis`和`transfer_boundary`阅读。短摘录不是可直接粘贴的完整句，摘要也不能冒充原文。需要核完整表达时回到来源正文。

`quote`保留原文连续短语；`context_summary`是编辑自写的局部语境摘要，`pattern`与分析是编辑归纳。第二批来源表中的`context_window_summary`补充前后段落怎样展开；`register`区分人物报道、生活报道、评论和随笔。`lookup_terms`是人工按实际关系标注的关联检索词，不是自动分词结果，也不将一个短语拆成多条新用例。`excerpt_checked`只表示短摘录已对照本轮打开的正文，不表示文章事实已独立验证、用法经过词频调查，或用户认可了该表达。

评论中的“应当、理性看待”等表述，可用于辨认搭配与语义，不能因已入库就自动搬进聊天体文章。随笔中的第一人称和主观感受属于原作者，不成为本号作者的经历。用例的文体标签供取舍，不是给整篇文章作好坏评定。

例如，CE0021所选“忍不住着急”，前文交代家长看到孩子写作业时边玩边做，表达的是事情触发人的情绪。可以参考这种具体关系，不能由一例推出“一种着急”在所有语境中都错，也不能把受访者的经历搬给文章里的另一位家长。

## 后续补充的边界

按实际表达疑点补用例，不平均给每个词凑数量。同一词可保留不同关系：本批“再检查一遍”中的“再”承接做完作业后的下一动作，不必然表示之前已经检查过一次；“反复刷才抢到”中的“才”则明确承接多次尝试。

新增材料仍保留链接、阅读范围、原话归属和必要语境。转载的相同原句不能作为另一条独立用法证据。不保存版权文章全文或长篇连续摘录。外部用例、教学自编例句、用户确认的改句继续分开，不互相升级身份。

写作与回读标准仍以[中文写作基座](../../中文写作基座.md)为准，本目录不另设轮次、词汇配额或固定句式。
