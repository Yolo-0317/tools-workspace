# 《一舞一愿·前程》01：重新出发

本集面向“换工作、毕业、重新开始，也可自我收藏”的分享场景，以“迎风破浪后远方航路打开”为唯一视觉事件。

`voice-v01` 使用赠送对象、现代祝福和原诗三段，共 32 个汉字；裁去无效静音后在 7.441 秒结束，后半段只剩舞蹈，不能用于十五秒成片。旧音频、哈希和时间轴仅作失败试验留档，不覆盖、不删除。

`voice-v02` 改为“赠送对象—处境共鸣—现代祝愿—古诗原句”四段，共 58 个汉字。实测时长进入自动门禁，但句间气口只有 180、240、350 毫秒，整体听感过密，人工验收失败。旧时间轴和音频继续作为“时长合格不等于听感自然”的实验记录。

`voice-v03` 保持相同四段结构，压缩为 52 个汉字，把段前气口调整为 650、750、850 毫秒。固定使用后期豆包 TTS 的栀夏当前音色和 `speech_rate=0`，不得加速、变调、拖腔或截断；首个可辨识语音最晚在 0.200 秒出现，最后一字目标落在 14.000—14.800 秒。精确 15 秒试听只能在自然尾音后补静音，不能用来伪装朗诵覆盖达标。

画面仍固定使用日常栀夏 v04 两张角色输入。Seedance 原片只生成音乐、环境声和动作声，不生成可辨识人声；只有 `voice-v03` 同时通过真实时长和人工试听后，才重新设计舞蹈与视频。
