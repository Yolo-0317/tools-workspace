# 《栀夏赛博起卦》第一集：最后一块桂花糕

## 单集定位

- 栏目：栀夏赛博起卦。
- 卦象：第二十七卦颐卦，常用卦名“山雷颐”。
- 卦辞：颐，贞吉。观颐，自求口实。
- 核心笑点：阿砚假装只想吃最后一块糕，镜头最后揭示同一只九宫格食盒中已有八个空格。
- 时长与画幅：约 15 秒，9:16 竖屏。
- 制作版本：第一集简版，使用三枚铜钱“掌心起卦”；星轨六爻盘不参与本集。

## 固定时间轴

| 时间 | 角色/画面 | 内容 |
| --- | --- | --- |
| 0.0—2.2 秒 | 阿砚/食盒 | 镜头紧贴九宫格食盒一角，只露出最后一个格子中的桂花糕；阿砚：“最后一块，能吃吗？” |
| 2.2—3.7 秒 | 栀夏 | 双手合拢，掌中轻摇三枚铜钱：“起卦。” |
| 3.7—4.9 秒 | 栀夏/字幕 | 打开双手，三枚铜钱落在左掌；二维字幕显示卦象，栀夏读：“山雷颐。” |
| 4.9—8.5 秒 | 栀夏 | 看着掌中铜钱：“颐，贞吉。观颐，自求口实。” |
| 8.5—10.1 秒 | 阿砚 | “卦说能吃？” |
| 10.1—12.1 秒 | 栀夏/证据 | “先数数空格。”镜头开始从食盒局部拉远。 |
| 12.1—14.6 秒 | 阿砚/证据 | 镜头完整揭示同一只九宫格食盒：八个空格和一个糕点格；阿砚收爪垂耳，小声辩解：“前八块……是试吃。” |
| 14.6—15.0 秒 | 落版 | 保留阿砚心虚反应；显示“栀夏赛博起卦”。 |

免责声明从 12.1 秒持续到结尾：`传统文化趣味演绎，请勿作为现实决策依据`。

## 四张场景卡目标

1. 双人中近景：只露出九宫格食盒装有最后一块糕的局部，另外八个空格保持在画外。
2. 起卦近景：栀夏双手刚刚打开，左掌恰好三枚铜钱。
3. 断卦中近景：栀夏看着掌中铜钱严肃解释，阿砚耳朵竖起、眼睛发亮；同一只食盒只露出局部。
4. 证据揭示：完整展示同一只九宫格食盒，恰好八个空格和一个糕点格，阿砚收爪垂耳。
