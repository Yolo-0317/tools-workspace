# 北上广深择校政策与家庭决策

用户要求北上广深择校稿、学区政策解读、幼升小、小升初或高中选校 → 使用本专题。它属于教育政策热点，不是学校排名、招生中介或房产投资稿。

## 适用范围

只处理北京、上海、广州、深圳的幼升小、小升初和高中选校。大学志愿继续归入高考政策与志愿填报；留学择校、国际学校商业推荐、学校排行榜和学区房投资建议不适用。

每次选题和成稿前先确定：

- 城市；
- 区县或市级范围；
- 幼升小、小升初或高中学段；
- 入学年度；
- 已发布、即将实施、征求意见、媒体报道或个人建议等政策状态；
- 户籍、学籍、住房、居住证等会改变结论的适用条件。

缺少会改变结论的关键条件时，继续回源或明确尚不能判断，不替教育部门确认资格。

## 选题优先级

优先关注当年招生政策变化、单校或多校划片、电脑派位、积分入学、公民同招、民办摇号及落选后的安排、指标到校、名额分配、高中招生范围、随迁子女、跨区入学、转学、学位预警、人户一致、多孩子女同校、民办收费、住宿与通勤变化。

专家择校建议只有在原话、身份、时间和语境可核验且已形成公开讨论时才纳入；必须与正式政策分开。

每个候选至少说明政策主体、发布时间、原始文件、城市与区县、学段与年度、受影响家庭、家庭成本、当前热度、争议点和事实风险。按热度、家庭相关性、政策确定性、可核验性和决策价值综合排序，不因标题更焦虑而提高优先级。

## 来源层级

1. 当年教育行政部门、考试院、区政府和官方招生平台的正式文件。
2. 与正式文件配套的官方政策问答、流程图和报考指南。
3. 学校经主管部门备案或公开发布的当年招生简章，只用于说明学校自述、计划、收费和课程安排。
4. 新华社、人民日报、光明日报、中国教育报等可靠媒体的采访和深度报道。
5. 家长经验、论坛、中介、房产平台和培训机构只作待核线索，不能单独支撑政策结论或学校评价。

涉及当前入学资格、材料、日期、招生范围、积分、批次、学费、住宿和计划时，必须回到当年官方原文。搜索摘要、往年文章、媒体转述和学校口头答复不能代替原文。

## 好文章的可迁移写法

官方问答型文章先回答家庭会失去或保留什么选择，再解释政策术语；家庭决策型文章比较招生范围、费用、住宿、通勤和适配条件，不只比较名气；新闻深评型文章按“政策变化—家庭具体不确定性—官方规则—实际选择成本—制度问题”推进。

可学习以下公开材料的组织方法，但其中事实只能按相应年度和地区使用：

## 四城专项边界

### 北京

区分市级原则与各区实施细则。重点核对登记入学、单校或多校划片、房产取得时间、学位占用、跨区和回户籍入学。某一区的“六年一学位”、购房日期和派位规则不得写成全北京统一规定。

### 上海

重点核对公民同招、民办摇号、一贯制直升、未被民办录取后的公办安排及各区排序规则。市级问答和区级细则不得混为一层；必须完整交代报名民办后的选择后果，不能只制造“失去公办学位”的恐慌。

### 广州

广州义务教育以区为主实施。重点核对各区“人户一致”、实际居住、学位占用、统筹安排和相对就近等口径。某区规定的距离、年限和排序不得外推全市。高中选校另行核对招生范围、批次、户籍或学籍条件、外区计划、随迁子女计划、学费和住宿。

### 深圳

深圳各区积分入学细则不同。户籍、住房、租赁、居住时间、社保、大学区和共享学区的计分方式不得写成全市统一积分表。每年重新核对区级细则、学位预警和材料截止日期；历史积分线只能标明为往年结果，不能当作当年录取线。

## 学校比较边界

只比较能够回源的招生范围、招生计划、办学性质、经批准的学费和住宿费用、住宿与通勤条件、课程与选科安排、指标到校或特殊类型招生资格，以及明确标注年份的历史录取数据。

不制作“最好学校”“名校梯队”或升学率排行榜，不以单一录取分数推导学校教学质量。学校官网、开放日和招生简章只能证明学校如何自述；涉及办学成果和教学效果时，应补独立可靠来源，补不到就标明“校方介绍”，不能改写成客观结论。

## 硬门禁

- 区级规则不得写成全市规则，北上广深规则不得互相套用。
- 往年分数、计划、积分和划片办法必须标注年份，不得冒充当年规则。
- 不得宣称学区房、落户、租房、缴纳社保或购买课程能够保证学位。
- 不得传播“内部名额”“关系入学”“花钱保录取”等服务信息；作为诈骗或违规招生报道时，必须有警方、教育部门或可靠媒体来源，并明确其不合法或不可信。
- 不得根据学校名气、录取分数或未经核验的升学率制作排行榜、梯队表或确定性推荐。
- 不得替具体家庭确认入学资格或给出确定录取概率；提醒以当年主管部门审核和正式录取结果为准。
- 不得把征求意见稿、专家建议、媒体预测或学校口头答复写成已经实施的政策。
- 不得收集、展示或推断未成年人姓名、住址、学籍、成绩和家庭财产等可识别信息。
- 不得贬低普通学校、职业教育、民办学校、特定城区或其中的学生和家庭。
- 不得将学校、房产中介、培训机构或择校咨询机构的宣传材料作为独立评价，不得植入未披露的商业推荐。
- 标题不得使用“选错毁一生”“学区房白买了”“不买就没学上”等无法由正文和政策直接证明的恐吓表达。

## 正文结构

沿用用户主动热点的900—1100字纯段落、DeepSeek手工交接、Agent核实编辑、抖音真实配图和双确认流程。文章按以下信息顺序推进，但不要在成稿中保留编号或小标题：

1. 用可核验的政策变化或家庭选择后果开场。
2. 在前五分之一交代城市、区县或市级范围、学段、年度和适用家庭。
3. 解释规则如何运转，尤其是选择某种报名方式后会失去、保留或新增什么机会。
4. 比较住房、租赁、通勤、住宿、学费、材料和时间成本，但不作房产投资建议。
5. 明确尚未公布或无法确定的部分，不替主管部门作判断。
6. 落到制度透明、教育公平和孩子适配性，而不是号召追逐名校。
7. 结尾只问一个具体、可回答的问题。

## 发布前检查

- [ ] 官方原文与文章使用的是同一入学年度。
- [ ] 市级原则、区级细则、学校简章和媒体报道已分层表述。
- [ ] 标题中的城市、区县、学段和后果均由正文兑现。
- [ ] 历史分数、计划、积分线和录取结果均标注年份。
- [ ] 没有学校排名、确定录取概率、学位承诺和投资建议。
- [ ] 学校自述没有被写成独立评价结论。
- [ ] 家长作出某项选择后保留和失去的路径已经说明。
- [ ] 没有暴露未成年人或家庭的可识别信息。
- [ ] 已按热点流程完成三来源、抖音优先真实图片和两次确认。
