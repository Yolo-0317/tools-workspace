## ⚠️ A 股 vs 美股关键差异

| 差异点 | 美股 | A 股（散户版） |
|--------|------|---------------|
| 交易制度 | T+0（当日可买卖） | **T+1（次日才能卖）** |
| 交易方向 | 做多 + 做空 | **仅做多** |
| 涨跌停 | 无限制 | **±10%（ST股±5%）** |
| 散户占比 | ~10% | **~60%**（情绪化、波动大） |
| 策略频率 | 日内/高频 | **中短线为主** |
| 涨跌幅限制 | 无 | **主板±10%、科创/创业±20%、ST±5%** |
| 最小交易单位 | 1 股 | **100 股（1 手）整数倍** |

> ⚠️ **核心结论**：A股止损纪律比美股更重要；追涨停、炒题材是散户绞肉机；**T+1 意味着当日买入无法当日纠错，入场前必须想好止损。**

### 制度红线（操作前必知）

```
❌ T+1：当日买入次日才能卖 → 禁止「赌当日反转」式重仓
❌ 涨跌停：一字板/秒板往往买不到、卖不出 → 不追无法成交的板
❌ 100 股整数倍 → 小资金账户注意最小建仓单位
⚠️ 除权除息日：价格跳空 ≠ 真实亏损，按「除权后成本」判断
```

## 一、仓位管理

### 1.1 Kelly 公式（仓位计算）

```
f* = (b·p - q) / b

f* = 仓位比例
b  = 盈亏比（盈利金额 / 亏损金额）
p  = 胜率
q  = 1 - p
```

**实操：半 Kelly 更安全（单笔风险 ≤ 2%）**

> 例：账户 50 万，单笔最大亏损 = 1 万元（2%）
> 止损幅度 = -5%，则单笔仓位 = 1万 / 5% = 20 万 ≈ 40% 仓位
> **但建议 ≤ 30% 单股上限，1-2% 单笔风险**

### 1.2 金字塔仓位

| 市场 | 仓位 | 说明 |
|------|------|------|
| 牛市 | 70-80% | 顺势重仓 |
| 震荡市 | 40-50% | 高抛低吸 |
| 熊市 | 0-20% | 轻仓或空仓 |

**分批建仓三步法**：
1. **1/3 试探仓**：趋势确认前先进 1/3
2. **+1/3 确认仓**：趋势确认（放量突破）后加 1/3
3. **+1/3 突破仓**：突破关键位后加最后 1/3

### 1.3 单股仓位上限

```
单股仓位 ≤ 30%（分散风险）
单笔交易风险 ≤ 2%（截断亏损）
总仓位：牛市 80%、震荡 50%、熊市 20%
```

## 二、止损体系（A 股核心！）

### 2.1 三线止损法

| 止损线 | 触发条件 | 动作 |
|--------|---------|------|
| **硬止损** | 亏损 -5% | 无条件立即清仓 |
| **软止损** | 亏损 -3% | 减半仓，剩余设保本 |
| **移动止损** | 浮盈后从最高点回撤 -5% | 锁定利润 |

### 2.2 时间止损

```
买入后 5 个交易日未盈利 → 考虑减仓或换股
（A股短线逻辑：横盘越久，向下概率越大）
```

### 2.3 动态风控规则

| 事件 | 风控动作 |
|------|---------|
| 单日浮亏 > 5% | **立即清仓** |
| 周亏损 > 8% | **停止交易 1 周** |
| 单笔亏损 > 预设 2% | **立即平仓** |
| 月度亏损 > 15% | **休息 2 周，复盘策略** |

## 三、趋势判断体系

### 3.1 A 股均线系统（调整版海龟）

```
短期线：MA5 / MA10（判断短期方向）
中期线：MA20 / MA30（判断中期趋势）
长期线：MA60 / MA120（判断牛熊方向）
```

**趋势信号**：
| 信号 | 买入条件 | 卖出条件 |
|------|---------|---------|
| 多头排列 | MA5 > MA10 > MA20，且价格 > 全部均线 | 反之 |
| 金叉 | MA5 上穿 MA10 | MA5 下穿 MA10 = 死叉 |
| 突破 | 价格突破 MA20 + 放量（>均量 50%）| 价格跌破 MA20 |

### 3.2 量价配合（A股 最有效信号）

```
✅ 最佳买入信号：
放量突破 + 涨幅 > 2% + K线实体阳线 = 方向确立

✅ 二次买入点：
放量突破后 → 缩量回踩均线支撑 → 再次放量阳线

⚠️ 危险信号：
价格创新高但成交量萎缩 = 量价背离 = 离场信号
```

## 四、板块轮动策略（A 股特色）

### 4.1 政策驱动 > 题材炒作

```
第一梯队（政策催化）：电力改革、新能源、半导体等国家重点方向
第二梯队（业绩驱动）：业绩超预期、涨价预期
第三梯队（题材炒作）：纯概念、无业绩支撑（散户绞肉机，慎入）
```

### 4.2 板块轮动规律

```
启动顺序：券商 → 权重蓝筹 → 消费 → 科技 → 周期
见顶顺序：垃圾股 → 题材股 → 成长股 → 蓝筹股 → 权重股
```

## 五、A股特色三步法

```
第 1 步：选板块（政策 > 业绩 > 题材）
   → 跟政策方向，不追纯概念

第 2 步：选个股（趋势 + 量价 + 估值）
   → 均线多头 + 放量突破 + PB/股息率合理

第 3 步：严止损（-5% 以内 + 分批入场）
   → 不幻想"跌了会反弹"，及时认错
```

## 六、大师体系适配

### 6.1 李佛摩尔法则（适配A股）

```
✅ 关键点交易：在新高/新低突破时入场
✅ 金字塔加仓：盈利时加码，不在亏损时补仓
❌ 绝不向下摊薄：深套不补仓（梅花生物教训）
✅ 3日规则：连续3天创新高/低确认趋势
```

### 6.2 海龟交易法则（调整版）

```
原版：20日突破入场，10日反向出场
A股调整：10日/20日均线（波动大用更长周期）
单位头寸 = 账户风险 / (2N)  [N=波动率]
每头寸风险 ≤ 4%
```

### 6.3 达利欧风控体系（适配A股）

```
桥水全天候策略 → A股版：分散持仓（股票+债券+黄金+现金）
风险平价 → 单股仓位 ≤ 30%，总仓位动态调整
极端风险 → 单日亏 > 5% 清仓
```

## 七、操作纪律清单

### 买入前必查（5项）

- [ ] 趋势是否向上？（均线多头）
- [ ] 量价是否配合？（放量突破）
- [ ] 止损位在哪？（≤ 5%）
- [ ] 盈亏比是否 > 2:1？
- [ ] 仓位是否超 30%？

### 持有期检查（每日）

- [ ] 趋势是否破坏？（均线死叉）
- [ ] 是否到达止损位？
- [ ] 是否有更好的机会换股？

### 卖出信号

| 信号 | 操作 |
|------|------|
| 均线死叉 | 减仓 50% |
| 跌破止损线 -5% | **清仓** |
| 浮盈从高点回撤 5% | 移动止损，锁定利润 |
| 价格到达目标位 | 分批止盈（1/2 → 1/2） |

## 八、心理铁律

```
1. 不看盘外消息，只看价格行为
2. 每笔交易必须有：方向 + 入场位 + 出场位（止损/止盈）
3. 亏损单：快跑！盈利单：耐心持有！
4. 不与市场对抗：趋势是你的朋友
5. 连续亏损 3 笔 → 停止交易，复盘策略
6. 不抄底！不补仓深套股！
```

## 十、情绪周期与动态仓位（A 股特色）

> 来源：题材投机风控、情绪择时研究；**适用于波段/短线，收息长线股可弱化**

| 阶段 | 典型特征 | 仓位上限 | 操作原则 |
|------|---------|---------|---------|
| **冰点期** | 连板≤3、跌停多、炸板率≥40%、无主线 | **0~2 成** | 空仓或极轻仓试错，**不接力高位板、不抄底老题材** |
| **启动期** | 连板突破3、涨停≥40家、出现新主线 | **3~5 成** | 分仓试错主线龙头，预留加仓空间 |
| **发酵期** | 梯队完整、连板≥5、中军放量 | **5~7 成** | 聚焦主线去弱留强，放弃杂毛 |
| **高潮期** | 批量一字、散户狂热、几乎无亏钱效应 | **7~8 成** | 持股龙头、**分批止盈**，不新开杂毛仓 |
| **分歧期** | 主线大分歧、炸板增多、高度下降 | **3~5 成** | 立刻降仓，只留核心龙头 |
| **退潮期** | 龙头 A 杀、跌停≥30家、全面亏钱 | **0 成** | **无条件空仓**，等下一周期 |

**情绪辅助指标**（每日扫一眼即可）：
- 涨跌家数比 < 1:2 → 偏空，新开仓减半
- 昨日涨停今日平均溢价 < 1% → 打板生态差，不做短线接力
- 指数涨但涨跌家数比差（「指数繁荣、个股普跌」）→ 总仓位 ≤ 4 成

## 十一、技术指标组合（多指标共振）

> 单一指标易假信号；**大周期定方向，小周期找买点**

### 11.1 趋势市 vs 震荡市

| 市场状态 | 优先指标 | 少用 |
|---------|---------|------|
| 单边趋势 | MA、MACD、BOLL 中轨 | RSI 超买超卖（易钝化） |
| 震荡市 | RSI、KDJ、BOLL 上下轨 | 均线金叉死叉（易反复打脸） |

### 11.2 常用共振买入（满足 ≥3 项再考虑）

```
✅ MA：EMA20 > EMA60，或 MA5 > MA10 > MA20 多头
✅ MACD：DIF 上穿 DEA 且柱体翻红；或底背离（比金叉更可靠）
✅ RSI(14)：40~72 健康区；超卖区(<30)反弹需配合 MACD
✅ BOLL：价格站稳中轨上方，突破上轨不追（等回踩）
✅ 量能：突破时成交量 > 5 日均量 50%
```

### 11.3 MACD 进阶（A 股实操）

```
弱信号：仅金叉/死叉（滞后，震荡市常骗线）
强信号：顶背离（价新高 MACD 不新高）→ 减仓
强信号：底背离 + RSI 超卖 → 试探仓
```

### 11.4 多周期框架

```
周线/月线：定牛熊与大方向（MA60/MA120）
日线：定趋势与买卖点
60 分钟：仅用于已有底仓时的做 T 参考，不作新开仓主依据
```

## 十二、A 股资金面辅助（验证用，非单独决策）

> 北向/两融/龙虎榜/ETF 是**辅助确认**，不能替代量价与止损

| 资金类型 | 怎么看 | 怎么用 |
|---------|--------|--------|
| **北向资金** | 连续净买入/卖出某板块 | 中长线偏好的参考，短线易反复 |
| **两融余额** | 行业融资增减 | 过热板块警惕反向；与趋势同向时可加强信心 |
| **龙虎榜** | 机构/知名游资席位 | 看主力是接力还是出货，**不盲目跟榜** |
| **ETF 申赎** | 宽基/行业 ETF 大额净申购赎回 | 机构方向参考（如红利 ETF 申购 = 防御） |

**原则**：资金面与技术面同向 → 可略加仓；背离 → 降仓或观望。

## 十三、做 T 与底仓管理（T+1 约束）

> 来源：金渐成等长线+波段实践；**适用于已有盈利底仓，不用于深套摊薄**

### 13.1 底仓 + 做 T 结构

```
建议：7 成底仓（长线逻辑） + 3 成灵活仓（做 T）
底仓不动的前提：主线逻辑未破坏 + 未触硬止损
```

### 13.2 正 T / 反 T

| 类型 | 操作 | 适用场景 |
|------|------|---------|
| **正 T** | 先买后卖（低买高卖同一日） | 有底仓 + 分时低点加仓，高点卖出等量 |
| **反 T** | 先卖后买 | 预判当日冲高回落，先卖灵活仓低位接回 |

### 13.3 做 T 铁律

```
1. 必须留够底仓，避免卖飞
2. 做 T 失败触及止损 → 停止当日 T，不扩大亏损
3. 深套股（如梅花生物）禁止用做 T 名义补仓
4. T+1：当日买入的部分次日才能卖 → 正 T 的「买」若当日无法卖，等于加仓
5. 单日做 T 净目标：降低成本 0.5~1% 即可，不贪心
```

## 十四、MA50 保本区与渐进式加码

> 来源：熊熊操盘手风控框架；与金字塔建仓互补

```
试单（小仓）→ 走势确认 → 逐步加码
浮盈后：MA50 上穿成本价 = 进入「保本区/自由单」
  → 可将止损上移至 MA50 或成本价，锁定不亏
过热信号：RSI>80 连续 3 日 + 偏离 MA20 > 15% → 分批止盈，不追加
```

**风险回报比**：入场前目标盈亏比应 ≥ **2:1**（理想 3:1）；不足则放弃。

## 十五、极简龙头 / 主线战法（中线适配版）

> 来源：龙头战法简化；**不追连板、不赌情绪**

```
1. 找主线：政策 + 业绩 + 资金三者至少其二共振
2. 选龙头：主线内趋势最流畅、辨识度最高（不一定是连板最多的）
3. 等入场：回踩 MA10/MA20 企稳、突破确认后右侧分步建仓
4. 持股：趋势不破 / 主线不散 / 资金不走 → 持有
5. 卖出：主线退潮、破 MA20、龙头爆量滞涨 → 减仓
```

**禁止**：逆势做龙头、追伪龙头、高潮期新开杂毛仓。

## 十六、收息股与除权除息

> 适用于中国广核、中国核电等股息策略

```
除权除息日：股价下调 ≠ 亏损，红利到账计入总回报
股权登记日前：若计划收息，登记日收盘前须持有
除权后：用「除权参考价」重新评估止损，勿因跳空误触发恐慌
操作优先级：临近分红 → 持有收息 > 短线波动；分红到账后可再评估换仓
```

## 十七、交易频率与成本控制

```
散户年均换手率 > 300% 时，交易成本显著侵蚀复利
建议：非短线选手月均交易 ≤ 3 次；核心仓持有 ≥ 若干月
每笔交易前问：这次换仓，期望值是否 > 手续费 + 印花税 + 滑点？
连续 3 笔亏损 → 强制停手 1~2 周复盘（与心理铁律第 5 条一致）
```

**止损带宽参考**（按风格）：
- 趋势/龙头持股：-8% ~ -10%（波动大略放宽，但必须机械执行）
- 套利/首板/短线：-5%（不及预期立刻走）
- 收息长线：以基本面止损为主（破关键支撑或逻辑破坏），非日常 -5%

## 十八、市场环境过滤器（开仓前置条件）

**新开仓前，至少满足以下条件中的多数**：

- [ ] 大盘 MA20 方向向上，或处于明确反弹段
- [ ] 涨跌家数比 > 1:1（冰点期例外：只允许空仓）
- [ ] 目标股所在板块非退潮期
- [ ] 可用资金 ≥ 总资产 20%（留安全垫）
- [ ] 总仓位 + 拟开仓 ≤ 计划上限（震荡市 ≤ 5 成）

**指数繁荣但个股普跌**（抽水行情）→ 总仓位 ≤ 4 成，只做最强主线龙头。
