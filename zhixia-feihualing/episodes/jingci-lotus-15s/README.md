# 《晓出净慈寺送林子方》15 秒全诗舞蹈诗境

## 诗文

杨万里《晓出净慈寺送林子方》：

> 毕竟西湖六月中，风光不与四时同。
>
> 接天莲叶无穷碧，映日荷花别样红。

## 成片形式

- Seedance 2.0，15 秒，9:16 竖屏，电影级高写实东方幻想 CG，一镜到底。
- 输入只使用栀夏和阿砚两张原创虚拟角色母版；不上传首帧图、场景图、动作分镜或舞蹈参考视频。
- 角色母版只锁定身份、外观、服装、材质、比例与结构，不决定视频第一帧。

## 舞蹈与诗景

栀夏第一帧处于尚未完成但可发力的低位蓄势，1 秒内以换重、沉身、拧倾和低位袖弧进入第一个主体舞句。全片以“低位扫展”为主高潮动作家族，包含沉提、拧倾、低位扫袖、回身展臂和纵向提起；舞句之间只用一至两步短距离连接，不使用完整旋转，不以持续奔跑或普通行走代替舞蹈。

袖风先触发近处真实水纹，水纹向中景传播并推动荷叶依次舒展；栀夏向朝阳纵向提起时，红荷沿水纹方向由近及远连续开放。舞蹈、湖水、荷叶、红荷与晨光共同呈现西湖六月诗景，特效始终有明确动作来源。

摄影机从水面附近的三分之四正面中景开始，沿同一方向缓慢后退并逐渐抬升。低位扫袖时镜头轻微降低，红荷盛开时沿原路径抬升拉开；摄影机围绕舞姿和重心变化运动，不追逐位移，也不让前景遮住栀夏面部。

阿砚保持约 40 厘米体型、四足、唯一墨尾、笔锋双耳、朱砂额印、暖金纹样和向外放射的宣纸纤维。它沿白石平台内侧短跑跟随并完成一次短距离避让，持续参与空间变化，但不进入舞蹈路线或抢占高潮。

## 后期朗诵与字幕

四句全诗由栀夏使用固定清透明亮声线朗诵，句间保留自然留白，并让朗诵分布在完整 15 秒内。Seedance 阶段不生成人声、诗句、字幕和精确口型；配音与字幕在视频生成并确认后统一加入。
