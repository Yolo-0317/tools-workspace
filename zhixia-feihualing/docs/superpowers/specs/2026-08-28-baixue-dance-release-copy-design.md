# 《白雪歌》栀夏舞蹈版发布文案设计

## 目标

为《白雪歌送武判官归京》10 秒成片重写抖音发布表达。本次发布不再以“雪景诗词展示”为唯一卖点，而是突出角色能力升级：栀夏第一次在成片中完成具有脚步、换重和身体层次的中国古典舞身韵短句。

发布文案同时承接“AI美女舞蹈”等搜索关键词，但关键词服务于拉新，不替代“栀夏”原创角色身份，也不把账号改写成 AI 工具教学号、随机 AI 美女号或擦边舞蹈号。

## 表达策略

采用“角色成长为主、搜索关键词为辅”的路线：

1. 标题直接建立新鲜变化，核心信息是“栀夏会跳舞了”或“栀夏这次真的跳起来了”。
2. 正文第一句继续强化角色升级，明确这次不再只是站姿、挥袖或诗境展示，而是有脚步、换重和收势的古典舞表演。
3. 正文第二层自然带入“AI美女舞蹈”和“中国古典舞”关键词，不把关键词机械并列成搜索词堆砌。
4. 结尾回到诗境，把舞蹈与“忽如一夜春风来，千树万树梨花开”连接起来，保留《栀夏飞花令》的诗词 IP 气质。
5. 话题标签控制数量，覆盖角色、舞蹈、技术形态和内容类型，不添加与本集无关的泛娱乐热词。

## 语气边界

- 可以写“栀夏终于会跳舞了”“这次真的跳起来了”，制造角色成长和更新感。
- 可以自然写“AI美女舞蹈”“AI古风美女”“中国古典舞”，用于搜索识别。
- 不写“全网最美”“绝美尤物”“看腿”“纯欲天花板”等擦边或低质审美词。
- 不写“真人美女”“真人实拍”，角色必须保持原创虚构 AI 角色身份。
- 不把技术过程写成主体，不展开 Seedance 参数、提示词教学或模型评测。
- 不夸大专业性，不宣称专业舞者、国家级古典舞或复刻现成剧目。

## 文案结构

最终交付包含四项：

1. 一条主标题，首屏突出“栀夏会跳舞了”。
2. 一段两至四句的发布正文，先角色升级，再自然嵌入关键词，最后落回诗句。
3. 一组精简话题标签，建议包含 `#栀夏飞花令`、`#AI美女舞蹈`、`#中国古典舞`、`#国风`、`#古诗词`，并根据平台字数限制删减。
4. 一条置顶评论，用角色口吻询问观众下一次想看栀夏跳哪首诗，承担互动而不是让正文堆叠提问。

## 成功标准

- 用户第一眼知道本条的新变化是“栀夏会跳舞了”。
- “AI美女舞蹈”自然出现在正文和话题标签中，但标题仍以栀夏为主体。
- 文案仍能识别为原创国风诗词角色内容，而不是泛 AI 美女舞蹈合集。
- 诗句、角色名、作品内容准确，不虚构专业舞蹈资历，不使用擦边词。
