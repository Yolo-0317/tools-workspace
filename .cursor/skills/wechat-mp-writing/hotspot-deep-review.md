# 热点深评（hotspot）写稿真源

> **2026-08-05 定稿**：社会/文娱/职场/公共事件 **热点深评**；纯段落长文 + 同题报道取材。用户主动热点文章声音另见 [essay-commentary-craft.md](essay-commentary-craft.md)。
> 代码：`wechat_mp_hot_trends.py` · `wechat_mp_discussion_research.py` · `wechat_mp_hotspot_article.py` · `wechat_mp_discussion_figures.py` · `wechat_mp_hotspot_polish.py`

用户说 **热点深评、hotspot 太水、像 AI、标题很怪、凑字数、配图不够、参考报道仿写** → **先读本文件**，再动 prompt / 模板。

## 稿型定位

| 项 | 要求 |
|----|------|
| 定时 | **09 / 11 / 15 / 18** 各 1 篇（`hotspot_early` / `morning` / `afternoon` / `evening`） |
| 选题 | 微博 + 百度热搜（`WECHAT_MP_HOTSPOT_SOURCE=trends`） |
| 形态 | **纯段落**，禁止 `> ` / `##` / 「一、二、三」小标题 |
| 长度 | 用户主动稿目标 **900—1100 字**，去空白后门禁 ≥850；信息复杂时允许超过 1100 字，但应优先精简，不为凑字重复观点 |
| 口吻 | 用户主动热点用 **[essay-commentary-craft.md](essay-commentary-craft.md)**：有依据的作者判断与散文式推进；`discussion` 和旧自动社会稿可用 [social-commentary-voice.md](social-commentary-voice.md) 的转述口吻 |
| 用户主动成稿 | Agent 给完整提示词，用户自行向 DeepSeek 取标题和初稿并贴回，Agent 核实编辑；两次确认 |
| 配图 | 至少 1 张可追溯真实图；合格图总数为 1—3 张时全部进入正文，其中 1 张兼作封面；超过 3 张时正文最多 3 张；禁止生成图 |

**默认主轴是社会热点**，不是 A 股收盘复盘。仅当热搜条目本身带盘面/个股关键词时，代码才走财经 `fetch_hotspot_research` 分支。

### 用户近期选题偏好：四城教育政策与升学规则

用户于 2026-09-13 确认：人工教育热点候选启用四城地域硬门禁，候选新闻必须以北京、上海、广州或深圳为新闻发生地。北京、上海包含各自所辖区；广州、深圳仅指对应城市及其所辖区，不扩展为广东全省。四城之外的新闻即使热度高、费用冲突强，也不得进入候选组。

全国政策只有在四城之一形成可核验的本地实施通知、执行案例、收费标准、办理流程或家庭账单变化，并以该本地事实为文章主体时，才可进入候选。只有全国性文件、专家观点或行业趋势，尚无四城本地事实承接的内容，以及无法从可靠来源确认发生地的内容，均不得进入候选。不得把“可能影响四城家庭”当作四城新闻，也不得用四城家长视角包装外地事件。

- 地域过滤必须发生在候选展示之前。通过地域门禁后，再依次优先家庭费用与退费、入学择校与升学、托管接送与时间成本、校园服务，以及其他具有明确家庭利益影响的教育新闻。
- 主题继续聚焦教育政策、招生考试和升学规则，优先四城市级、区级教育、发展改革、市场监管、考试招生等主管部门发布的正式文件，重点关注中考分流、普高学位、指标到校、随迁子女入学、选科要求、志愿投档、教育收费和学生管理。
- 普通校园纠纷、师生私德、泛教育鸡汤和仅靠专家个人观点支撑的内容暂不纳入；事件背后存在明确制度或政策问题时除外。
- 每个候选说明新闻发生城市、政策发布主体、发布时间、原始文件、适用地区、影响人群、当前热度、家庭成本、争议点和事实风险。
- 候选按热度、家庭相关性、政策确定性和评论空间综合排序，不因标题更焦虑而提高优先级。
- 对比例、人数、实施年份及“全面取消”“统一实施”“强制要求”等强结论回到官方原文核验；明确区分已发布、即将实施、征求意见和个人建议。
- 沿用现有 DeepSeek 手工交接、事实核验、抖音真实配图和双确认流程。

#### 教育费用政策优先（2026-09-11 用户反馈）

用户反馈江苏幼儿园退费稿阅读和转发较好，明确要求提高教育费用政策解读的选题权重。这是用户提供的运营观察，尚非后台同口径数据核验，不据此承诺费用题必然高流量或高收益。

- 在近期教育候选中优先检索、优先排序能解释家庭实际支出的政策：保教费和学费、请假退费、收费减免和补助、托管与延时费、餐费、校服教辅、研学及培训预付费。费用只是例示，不重复推荐已写或已推荐且没有事实增量的题。
- 同等时效、可信度和素材完整度下，能回答“谁适用、交多少、退多少、比过去变了什么、如何办理”的费用政策，排在泛教育进展和仅有制度口号的题目前面；家长时间与接送等利益题仍保留，不改成只写收费。
- 候选须指出一个有原文依据的家庭账单变化或具体收费规则。正式写作核验适用地区、园校性质、生效时间、费用类别、计算档位与例外；测算标明假设，不把地方标准全国化，不把减免包装为全部免费，也不预设收费违法。
- 这是人工选题排序偏好，不擅自改自动评分程序、定时或发布权限。后续有可比数据时，按相同观察窗口比较阅读、分享率及来源渠道，持续校准，避免单篇过拟合。

### 用户选题偏好：专家建议与普通人现实的落差

用户于 2026-09-03 确认：每组选题主动留意与普通人相关的专家建议，尤其涉及就业、退休、生育、消费、住房、养老和教育。与家庭伦理、政策民生和公共事件一起按实时热度、事实完整度及评论空间筛选；不限定该类数量，不为吐槽硬凑选题。

- 入选前核对专家身份、原始发布时间、完整原话与语境，识别旧闻翻炒、剪辑标题和断章取义；找不到可靠原话的不作为已核实建议推荐。
- 区分个人建议、机构研究结论与正式政策；不能把“专家建议”写成“国家要求”，也不能把建议尚未实施写成已改变普通人权利。
- 允许吐槽和反问，评论落在建议的适用人群、前提条件、可行性、配套措施，以及普通人承担的金钱、时间、尊严和选择成本。
- 承认建议中合理的部分，再解释它忽略了什么；不预设所有专家建议都错，不用人身攻击或“砖家”等标签代替论证。
- 候选简要说明“谁在何时建议什么、当前热度与来源、影响哪些人、现实落差在哪里、是否适合立即成稿”。沿用现有 DeepSeek 手工交接、事实核验、真实配图和双确认流程。

## 流水线（Agent 勿跳步）

```text
双榜热搜选题（自动避当日已用标题）
  → fetch_discussion_research（360/搜狗/百度新闻 + 报道页正文补摘要）
  → 用户主动稿：第一次确认后由用户自行向 DeepSeek 取标题和初稿并贴回
  → Agent 核事实、编辑并记录 edit notes
  → 可选：对照参考二次仿写（WECHAT_MP_HOTSPOT_IMITATE_REWRITE，默认关）
  → scan_report_voice 门禁 → 不足则重写（最多 2 轮）
  → 清洗元叙述 + 拆短段（reflow_hotspot_layout）
  → 抖音优先：只读搜索结果卡片与封面，禁止打开/播放视频
```

## 联网取材（社会热点核心）

成稿前 **必须** 有同题公开报道（`fetch_discussion_research`），写入 prompt：

1. **【联网事实】** — 可核对的时间、人物、机构、数字、通报表述  
2. **【参考文章·仿写】** — 2～3 篇同题稿摘要 + 开头示范（学第一句怎么直接写人+事）

仿写节奏（学澎湃/新浪/网易同题稿，不照搬）：

- **首段**：谁 + 在哪 + 发生了什么（与标题同题，50 字内落地）  
- **中段**：可核对细节、通报 vs 民间说法、多方观点  
- **末段**：一句后续观察或可讨论问句；**禁止**股市盘面、指数、个股  

二次仿写（`WECHAT_MP_HOTSPOT_IMITATE_REWRITE=1`，默认关）：删导读腔、补遗漏可核对事实。质量不稳时可手动开。

## 用户主动成稿入口（强制）

Agent 先研究并展示完整提示词，用户第一次确认后自行把提示词交给 DeepSeek，再将完整标题和初稿贴回当前任务；Agent 收到后核实编辑并记录改动。Agent 禁止直接调用、打开、绑定、操作或检查 DeepSeek，也不得用其他模型代写初稿。未收到用户贴回稿件时暂停。提示词的事实包只写正向、可核验的公开事实，不得混入“不能写成”“不要理解为”“不能把个案当成”等编辑指令。

收到用户贴回的初稿后，Agent 必须完整读取 [editorial-evidence-gate.md](editorial-evidence-gate.md)。先在内部区分可核事实、当事方说法、解释性判断、作者观点和暂不可核实信息，再修改公开正文；内部标签、来源清单和审校过程不得进入正文。风格参考只决定表达方式，不能充当事实来源。

编辑稿 JSON 必填 `title`、`digest`、`body`、`topic`、`original_thesis` 和 `research_urls`；`slot_key` 可选。`research_urls` 至少覆盖 3 个不同来源域，`original_thesis` 须用不少于 20 字写出可被反驳和检验的原创核心判断。用户主动稿正文目标 900—1100 字，去空白后少于 850 字直接拒绝；超过 1100 字不硬拒，但 Agent 应优先精简。来源多样性、原创观点、段落、套话、真实配图或合规门禁仍不通过时，由 Agent 修改源 JSON 后重试。

## 配图（抖音优先、只用真实图）

| 项 | 说明 |
|----|------|
| 开关 | `WECHAT_MP_HOTSPOT_SOCIAL_FIGURES=1`（trends 默认开） |
| 正文图 | 最多 3 张；合格图总数为 1—3 张时全部注入正文，其中 1 张兼作封面；超过 3 张时正文只取 3 张 |
| 封面 | 至少 1 张可追溯真实图，裁成 2.35:1；零图拒推 |
| 第一来源 | 已登录抖音的搜索结果卡片与封面；禁止点击、打开或播放视频 |
| 后续来源 | 政府官网、官方媒体、法条页面等可追溯证据图 |
| 留痕 | `douyin-search.json` 记录主题、检索词、完成时间、候选或无候选原因；`figure_sources.json` 记录来源与核验状态 |
| 封面复用 | 总图数不超过 3 张时自动复用；超过 3 张且需要封面占用正文名额时，在 `cover_source.json` 显式设置 `"reuse_in_body": true` |
| 数量原则 | 有几张用几张，正文允许少图；除显式复用封面外，不得使用搬运图、重复帧、无关画面或生成图 |
| 门禁 | 所选抖音候选须匹配 `douyin_cover` 来源；没有可追溯封面即拒推 |

合格真实图总数不超过 3 张时，封面图同时进入正文，不再要求额外声明。图片超过 3 张时，Agent 再根据内容决定封面是否占用正文的 3 个名额；不得突破正文图片上限。

配图不足不是生成图片的理由。抖音无合格候选时必须写明原因，再补权威网页证据图；合格图不足 3 张时全部使用。若连封面所需的一张可追溯真实图都没有，则停止并报告，不创建 `codex-image-request.json`，不调用 ChatGPT、ImageGen、DeepSeek 或其他图片生成能力，也不退回默认品牌封面。

## 禁止元叙述（AI 味重灾区）

**不要** 在正文里出现「我在引用资料」的导读句。以下 **一律禁止**（`strip_hotspot_meta_commentary` / eval 会扣）：

| 禁句示例 |
|----------|
| 刷到这条热搜 / 第一反应是 / 往下翻才知道 |
| 公开报道里有一条值得先记住 |
| 热搜在聊「…」 / 双榜讨论偏… |
| 值得注意的是 / 不难发现 / 需要指出的是 |
| 叙事溢价 / 情绪溢价 / 硬验证 / 露馅 |

**正确开头示例**（社会热点）：

```text
8 月 3 日，青岛大学一名宿管大爷在值班室热射病去世。
学校通报里写「已启动调查」，没写空调有没有、值班室多大。
```

## 标题路牌

- 格式：`{可搜实体 + 反常结果}？`（疑问句优先）  
- **前 15 字**含案由/地名/片名/数字，表意完整  
- **硬禁**：震惊体、`和A股啥关系`、平台名连读（`百度把…送上热搜`）、编审过程（`候选五条`）  
- **好例子**：`儿子病逝留 87 个游戏号，遗产该归谁？`  
- **坏例子**：`返…` `暂…` 半句话截断

详见 [sousou-content-rules.md](sousou-content-rules.md) · [traffic-copy-craft.md](traffic-copy-craft.md)

## 排版（移动端）

- 采用**混合短段**：事实落点、场景切换、转折和关键判断优先 **一句一段**；解释、证据与必要限定可 **两句一段**，单段原则上 ≤130 字。
- “一句一行”在成稿中指一句与下一句之间留空行，形成独立段落；不是只插软换行，也不是把一个完整逻辑拆成语义残片。
- 推荐节奏：`短事实 → 稍长解释 → 单句判断`。连续 5 段以上句长相近会像提词器；连续使用十几字的空泛金句会像鸡汤号，均须合并或补充事实。
- 一句一段只解决手机端阅读压力，不等于降低信息密度。法条适用、事实边界和因果解释不能为了排版被拆散。
- 段间空一行；禁止编号清单（`delist_hotspot_body`）  
- 社会稿 **禁止** 指数涨跌复读（财经分支才做 `dedupe_hotspot_index_mentions`）

### 一句一段参考（2026-08-12）

近期公众号排版资料普遍强调短段、留白和“一句话或一个完整观点即可分段”，核心原因是手机端以扫读为主，读者会先判断眼前这一屏是否读得完。这个方向与 [social-commentary-voice.md](social-commentary-voice.md) 的“多数段落 1～3 行、关键事实可单句成段”一致。

外部参考只用于观察排版趋势，不作为平台官方推荐机制结论：[TypeZen 2026 微信公众号排版法则](https://typezen.online/blog/wechat-typography-rules-2026) · [人间社区：一篇好内容，从排版开始](https://people.fukan.my/2026/02/%E4%BB%8E%E6%8E%92%E7%89%88%E5%BC%80%E5%A7%8B/)。

热点深评不机械执行“每个句号都换段”：

```text
× 系统出错了。

× 门店道歉了。

× 消费者不接受。

√ 门店承认结算结果有误，并称可能是系统识别问题。

但系统只能解释错误发生在哪一环，不能替经营者承担责任。
```

当前 `reflow_hotspot_layout` 仍按 ≤130 字重排并可能合并过短段落；本节先作为 DeepSeek 初稿后的 Agent 编辑参考。若要让自动稿稳定执行“一句一段”，应另开代码改造与 A/B 数据验证，不在文档修订中静默改变生产行为。

## 改稿检查清单

### 转述价值检查（2026-09-07，人工编辑项）

收稿后先按 [editorial-evidence-gate.md](editorial-evidence-gate.md) 核事实与适用范围，再按 [essay-commentary-craft.md](essay-commentary-craft.md) 查标题承诺和段落推进，最后参照 [traffic-copy-craft.md §6.5](traffic-copy-craft.md#65-转述价值给读者有用的信息与可复述的判断) 观察信息是否值得读者转述。影响家庭选择的事实细节应尽早出现；不硬塞两个钩子，不固定间隔，不强造反常识或阵营对立。风险假设不得暗示已发生问题，已有政策配套不得为增强冲突而删去。原有好句优先保留或前移，新增句须带来信息或论证增量。

编辑记录注明保留、前移或改写了什么，以及必要的事实限定。传播效果只作后续同口径观察，不承诺提升；缺少“钩子”本身不构成自动门禁失败。图片继续抖音封面优先、真实可追溯，不为制造可截图金句自动生图。

### 事实与编辑判断检查（人工项）

按 [editorial-evidence-gate.md](editorial-evidence-gate.md) 核对主张类型、原始来源、来源独立性、时间与适用范围。再看各段是否增加事实、解释、边界或判断；同义复述应删除或合并，必要限定不能因朗读不顺而丢失。全文保留一个由证据支撑的核心判断，并回应最强合理异议，不机械凑三来源、两派观点或固定数量金句。

**文章级否决先于句子润色**：动笔或改稿前在内部写清“替谁说话、读者最想问什么、全文只回答哪一个问题”。收稿后逐段说明它如何推进这个问题；若段落分别跑向消费建议、行业判断和购物清单，彼此没有因果推进，就退回重新立论或删段。不要用过了 75 分、AI 味低或改顺几句话代替这一关；机器只会检查有限的结构信号，不会替编辑判断文章是否真正成篇。

官方原文可以直接证明文件中的政策条文；争议相关机构的通报只能证明它公开作出了相应表述，不能自动当成中立调查结论。自动门禁不判断来源是否真正独立，这一项必须由 Agent 人工完成。

### 公开文案门禁（2026-09-05）

外部写作资料只吸收能改善当前热点深评的稳定原则，不照搬“必须带情绪词”“每 300 字设悬念”等爆款公式：

- 微信公众平台要求标题准确、清晰并体现正文主旨，禁止仿冒官方、无依据夸大严重程度或隐去关键信息：[标题夸大营销规范转述](https://www.thepaper.cn/newsDetail_forward_26514412)。
- 公众号标题样本总结中可迁移的原则是“标题里的具体对象、数字、反转和附赠承诺必须由正文兑现”；其 AI 工具赛道情绪公式不直接套用：[bigpeng-hot-gzh](https://github.com/BigPengSays/bigpeng-hot-gzh)。
- 新闻评论应保持集中、连贯，清楚处理事实判断、价值判断、论点、论据和论证：[复旦大学新闻评论写作课程大纲](https://jwc.fudan.edu.cn/_upload/article/files/d4/56/707002a8413b8a3cc690244c1118/a7491833-eb4d-41df-bef8-ad5e663ea2e4.pdf)。
- 新闻类公众号应贴近普通人的生活场景、采用口语表达并适应移动端精简阅读：[新闻类微信公众号内容编排研究](https://zjjcmspublic.oss-cn-hangzhou-zwynet-d01-a.internet.cloud.zj.gov.cn/jcms_files/jcms1/web3214/site/attach/0/7fc53868bde74271b6c2b462bc0fb176.pdf)。

`wechat_mp_hotspot_quality_gate.py` 分两层执行：

1. **阻断门禁**：编辑指令或工作流语言泄漏；固定夸大营销词；无权威来源支撑的绝对政策范围；标题数字未在摘要或正文兑现；完全重复段落；残留 Markdown 标题或清单。stage 与 push 各检查一次，且 push 必须在构建文章、上传图片和调用微信接口前检查。
2. **编辑评分门禁**：原创核心判断、三来源域、首段事件实体、前 1/3 普通人影响、反方或边界、具体结尾问句、移动端段落共 7 项，至少 5 项通过。单项只作弱信号，不因一个连接词、一个长段或一个词汇独立拒稿。该分数只表示结构完整度，不代表去 AI 感、事实准确性和图片门禁全部通过。

高置信度过程语言如“不能写成”“正文应补充”“标题需要修改”“提示词要求”“配图建议”直接拒绝；“不能简单理解成……更不能把个案当成……”这类连续解释文章应如何被理解的自我审稿腔同样拒绝。“不计入总分不等于取消课程”“不能据此推断全国统一调整”“不能把成本转嫁给家长”属于读者可见的正常论述，不得按单词误伤。

- [ ] 首段 **50 字内**落地标题事件（人+事）  
- [ ] 至少 **4 个可核对事实**（来自报道，非编造）  
- [ ] 无导读腔 / 热榜播报 / 财经盘面套话  
- [ ] 标题路牌完整、与开篇同题  
- [ ] 情绪主语+具体代价+两侧张力已在正文前 1/3 内体现；文末有清晰读者选择
- [ ] 已先检索抖音，且只读取搜索结果卡片/封面，没有打开或播放视频
- [ ] 至少 1 张可追溯真实图；总数 1—3 张时全部进入正文并由其中 1 张兼作封面；超过 3 张时正文不超过 3 张
- [ ] 没有创建图片生成请求，也没有自动生成图片

## 故障排查

| 现象 | 原因 | 处理 |
|------|------|------|
| 旧自动链路构建失败「未达 2000 字」 | 取材薄 / LLM 短稿 | `TREND_ENRICH=0` 重跑；换素材更足的题；查 `web_research_blob` 长度；该门禁不适用于用户主动稿 |
| 构建失败「缺少可追溯封面」 | 抖音和权威网页均无合格真实图 | 记录抖音无候选原因，换同题检索词或补权威来源；仍无封面则停止 |
| 单篇 3～5 min | 多轮 LLM + 配图抓取 | 默认已关仿写、2 轮上限；`DISCUSSION_FIGURES_FORCE=0` |
| 总分 <75 且正文几百字 | 旧短模板 fallback | 社会稿应已禁止；查 `generate_hotspot_body` 日志 |
| 文末「复盘的朋友」 | 财经增长句误注入 | `hotspot` 已在 `_NO_RECOMMEND_HOOK_KINDS` |
