# 关注引流话术 · 热点评论号（2026-08-03）

> **定位**：牛马也智能已转型为 **热点评论**（社会 / 文娱 / 职场 / 公共事件），不再以 A 股复盘为主轴。  
> **真源**：关注回复 / 简介 → [account-packaging.md](../wechat-mp-drafts/account-packaging.md)；稿末引导 → `wechat_mp_monetization.py` · `WECHAT_MP_FOLLOW_HOOK_*`

---

## 一、引流放在哪（优先级）

| 层级 | 触达谁 | 作用 | 频率 |
|------|--------|------|------|
| **功能介绍** | 搜一搜 / 名片 | 说明「写什么」，不是硬拉关注 | 改一次，长期有效 |
| **被关注自动回复** | 新关注 | 交代更新节奏 + 星标理由 | 每人 1 次 |
| **菜单「更新节奏」** | 已关注、忘节奏 | 自助说明，减少取关 | 常设 |
| **稿末 1 句关注引导** | **推荐流陌生读者** | 转化最高；读完再要关注 | hotspot / tv_review **每篇 1 句** |
| **文末「推荐 ♡」** | 老读者 | 助推荐池；热点号可弱化 | 见 §四 |
| **回复「写作」领笔记** | 新关注 / 老粉自取 | 发放夸克写作指南（真价值，非诱导空壳） | 常设 |

**数据依据（2026-07-31）**：热点稿推荐占比 **54%**，陌生读者占比高 → **稿末星标句**比简介更重要。

---

## 二、读者可见 vs 内部策略（必守）

**关注回复、简介、稿末引导、菜单** = 给读者看，只写 **你能得到什么**。

| 读者可见（可写） | 内部策略（勿外露） |
|------------------|-------------------|
| 整理公开信息、多方观点 | 有争议、有讨论度优先 |
| 社会 / 文娱 / 职场 / 公共事件 | 双榜、热/沸、推荐池、四关选题 |
| 方便阅读与讨论 | 站队、发酵、完读转化、陌生读者 |

写作笔记（夸克）可讲 **怎么写好一篇 + API 对接**，仍避免写选题、流量、运营策略。

## 三、定稿话术（直接粘贴）

### 3.1 功能介绍（≤120 字）

```text
热点观察：社会、文娱、职场与公共事件，有话题就写。整理公开信息与多方观点，供阅读与讨论。
```

### 3.2 被关注自动回复

```text
欢迎关注牛马也智能。

这里写社会、文娱、职场与公共热点：整理公开信息，把各方说法摆清楚，方便阅读和讨论。

建议星标本号，更新不易漏看。
回复「写作」领取 AI 写作技巧与公众号 API 对接笔记。
回复「节奏」或「免责」看说明。
```

### 3.3 关键词「写作」（夸克资料）

文档真源：`stock-ai/docs/share/牛马也智能-AI写作与公众号API笔记.md`  
上传说明：`stock-ai/docs/share/README.md`

**内容范围**：AI 写作技巧、避坑、微信草稿箱 API 示例。**不含选题策略。**

**回复正文**（`{{QUARK_WRITING_GUIDE_URL}}` 换成夸克分享链）：

```text
【AI 写作与公众号 API 笔记】

含：AI 写作技巧、社会热点排版语气、避坑清单、草稿箱 API 对接示例。

夸克打开（建议收藏）：
{{QUARK_WRITING_GUIDE_URL}}

仅供学习交流，转载请注明出处「牛马也智能」。不含选题与运营策略。
```

**合规要点**：

- 资料须 **真实可读**（本指南约 2500 字，非空壳引流）  
- 关注回复里 **顺带提一句**「回复写作领取」，不要写成「必须关注才能看」  
- 稿末 **不写**「关注领资料」；与星标句分工（见 §3.3）  
- 禁止：领股票资料、领 AI 工具、与热点评论无关的福利

### 3.4 关键词「节奏」

```text
【更新节奏】

· 工作日：更新热点话题评论
· 范围：社会、文娱、职场与公共事件

内容来自公开报道，呈现多方观点，供阅读与讨论。
```

### 3.5 稿末关注引导（代码默认，可 env 覆盖）

**hotspot / tv_review 共用定稿**：

```text
我们会继续整理社会与文娱热点；星标本号，下一篇不易漏看。
```

环境变量覆盖：`WECHAT_MP_FOLLOW_HOOK_TEXT=你的定稿`

**分工**：第一句星标（主转化）；第二句顺带「写作」关键词入口（与关注回复、夸克笔记一致），勿写成「必须关注才能领」的硬福利。

**禁用旧版**（财经口吻，勿再用）：

- × 交易日收盘后还会写当日主线
- × 推给同样在复盘的朋友

## 四、话术原则（研究归纳）

### 4.1 有效句式结构

| 结构 | 示例 | 为何有效 |
|------|------|----------|
| **承诺内容** | 「整理公开信息，方便阅读和讨论」 | 读者知道关注能得到什么 |
| **损失厌恶** | 「不易漏看」「下一篇」 | 比「请关注」软，但不空 |
| **星标** | 「星标本号」 | 订阅号通知弱，星标 + 推荐流双通道 |
| **短** | 1 句，≤35 字 | 不破坏完读；推荐流读者耐心有限 |

### 4.2 避免

| 避免 | 原因 |
|------|------|
| 稿末「关注领资料」硬诱导 | **禁止**（微信审核）；稿末仅保留星标句 |
| 空壳资料 / 无关福利 | 平台诱导关注；须为真内容（见 §2.3） |
| 每段重复「欢迎关注」 | 像营销号，伤完读 |
| 「打工人 / 大模型 / AI 写作」 | 与热点评论定位无关 |
| 财经免责腔（荐股、复盘） | 新读者会误以为仍是股票号 |
| **内部策略外露** | 争议优先、讨论度、双榜、推荐池等只写进 Agent/SOP |
| emoji、震惊体 | 全站规范禁止 |

### 4.3 与留言问句分工

- **留言问句**（稿末倒数第二段）：引互动 → 「你站哪边？」「哪部最不出戏？」  
- **关注句**（最后业务句，免责声明前）：引关注 → 上表定稿  
- **不要**把关注句写成问句堆砌

## 五、推荐 ♡ 引导（可选弱化）

热点 / 话题讨论稿（`tv_review`）**默认不注入**财经号「复盘的朋友」推荐句。

| 稿型 | 推荐 ♡ | 关注引导 |
|------|--------|----------|
| `hotspot` | **关闭**（与 tv_review 一致，禁「复盘的朋友」） | 开启 |
| `tv_review` / discussion | **关闭** | 开启 |
| 旧 `sector` / `news` 等 | 若再发，改口径或关闭 | 按稿型 |

关闭推荐句：`tv_review` 已在 `recommend_hook_applies_to_kind` 排除。

## 六、A/B 可测变体（稿末 1 句）

同一时期只测 **一个变量**；连续 5 篇用 A，再 5 篇用 B，对比 **关注来源 · 稿末关注转化**（后台内容分析 → 阅读后关注）。

| ID | 文案 | 侧重 |
|----|------|------|
| **A（默认）** | 我们会继续整理社会与文娱热点；星标本号，下一篇不易漏看。 | 星标引导 |
| **B** | 若你关心这类话题，星标本号，后续更新不易漏看。 | 读者身份（更短） |
| **C** | 同类公共话题我们还会写；星标本号，方便追后续。 | 连载感（勿写「发酵」「讨论度」） |

**不建议 C 长期使用**：超 35 字，移动端像广告。

## 七、怎么衡量有没有用

| 指标 | 哪里看 | 说明 |
|------|--------|------|
| 阅读后关注 | 单篇内容分析 | 稿末引导主 KPI |
| 新增关注时段 | 用户分析 | 发文后 2–6h 是否抬升 |
| 推荐占比 | 内容分析柱图（单日 picker） | 引流句主要服务推荐陌生读者 |
| 完读率 | 单篇详情 | 关注句加了若完读掉 >3pt，改短或去掉 |

**无效信号**：关注涨了但完读、推荐双跌 → 引流太硬或文不对题。
