# 资产目录

- `characters/`：栀夏、阿砚最终角色定稿图和角色卡
- `scenes/`：固定场景、道具和环境参考图
- `props/`：跨单集复用的固定道具母版、提示词和验收规则
- `generated-images/`：按集数和镜头保存生成关键帧
- `generated-video/`：视频生成平台导出的原始镜头
- `audio/`：对白、旁白、环境声和音效
- `music/`：有明确来源与授权记录的音乐
- `inventory.csv`：全部资产的路径、版本、状态和来源台账

推荐命名：`ep01-04c-v01.png`、`ep01-04c-v02-rejected.png`、`ep01-04c-final.png`。

未登记来源和授权状态的音乐、字体与第三方素材不得进入最终成片。
