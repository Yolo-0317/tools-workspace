# 带货公众号写作法则 — 简选小电

面向 **租屋年轻人 · 全品类小电器 · 买前对照清单**。品牌与栏目见 [brand.md](brand.md)。与 [wechat-mp-drafts](../wechat-mp-drafts/writing-guide.md) 财经稿 **不要混用** prompt。

## 2025 分发与变现（摘要）

- **返佣 CPS**：文末 `mp-common-cpsad`；读者下单你拿佣金 → 文内须 **披露推广关系**（见下节）。
- **流量主**：完读率低则广告曝光少；种草文用 **场景开头 + 清单锚点 + 文末问句** 拉完读（`wechat_mp_monetization` commerce 池）。
- **搜一搜**：标题/摘要含垂直词（如「机械键盘」「厨房小家电」），勿堆砌。

## 广告法与平台红线（硬）

| 要求 | 写法 |
|------|------|
| 推广披露 | **摘要末尾**轻带「文内有合作推广」或自写「合作推广/佣金」；**正文不插**「本文含推广链接」模板句；文末统一免责 |
| 不虚假宣传 | 禁「全网最低」「100%有效」「根治」；用「我个人用了 X 个月」体验口径 |
| 不替代专业意见 | 美妆/母婴/医疗补充「因人而异，遵医嘱」 |
| 不荐股 | 禁股票代码、买卖、仓位（财经内容换 `wechat-mp-drafts`） |
| 敏感网络 | 禁 Clash、机场、substore（同 `wechat_mp_public`） |

文末统一免责（代码追加）：

> 本文为个人体验与信息整理，部分链接含推广合作（佣金）。请按需购买，理性消费。

## 标题

- ≤32 字；前 15 字给 **场景 + 结果**（如「宿舍桌面三件套？」）
- 可用 `？` `！`；禁「震惊」「必买」「错过亏亿」
- 与摘要分工：标题吸睛，摘要写清 **谁该看**；披露放摘要**句尾**括号或半句，勿占摘要开头

## 开头（前 3 句）

- ✅ 「租房党桌面只有 80cm，键鼠屏只能竖着叠——下面是我用过的三档方案。」
- ❌ 「在当今消费升级时代，好物越来越多……」

## 正文结构（三三原则）

- 每段 ≤3 行（手机屏）
- 每 2–3 段一个 `> 分节标题`（居中、17px）
- **清单体**：`> 为什么现在值得看` → `> 三类场景对照` → `> 怎么选不踩坑` → `> 小结`
- **测评体**：`> 我实际在用什么` → `> 三个优点两个槽点` → `> 适合谁不适合谁`
- **行业趋势体**：`> 这周行业在聊什么` → `> 和普通人有什么关系` → `> 如果要入手从哪类开始`

正文可 **自然提 1～2 次** 与文末 CPS 商品同品类名词（提高转化），但不要编造未测参数。

## 摘要 digest

- ≤128 字
- **必须**含推广披露词 + 垂直关键词
- 示例：`合租单间环境小电怎么配？对照插排和占地。（文内有合作推广。）`

## 正文插图（home）

- **贴近生活**：水槽/台面要有日常杂物（碗碟、沥水架、清洁瓶），禁空无一物的样板间
- 图库：`assets/wechat_mp/inline-commerce/home/`（与财经 `inline/` 分离）
- 换图后跑 `download_wechat_mp_commerce_figures --vertical home --force` 并肉眼验图；推稿会按 **文件 md5** 重新 uploadimg（勿只换文件不推稿）

## 去 AI 味（参考 [DealMoon 选购帖](https://www.dealmoon.com/post/2609984)、租房收纳爆款）

| AI 腔 | 真人写法 |
|-------|----------|
| 三类场景对照 / 怎么选不踩坑 | 具体事故：房东追问、吃灰一个月 |
| 综上所述、一文读懂、赋能 | 我、去年双十一、劝退、交学费 |
| 全是优点 | **必须**写 1 处踩坑或退货 |
| 模糊「三件套」 | 52cm 台面、600W、15cm 散热缝 |

结构：痛点开头 → 翻车 → 还在用的 2～3 件 → 买前检查 → 推广披露。分节用 `> 我去年踩过的坑` 这类口语。

带货稿默认 **不** `humanize`；靠作者写人话，不靠机器洗。

## 流量主优化（带货垂直）

- 开篇 2 句给 **结论**（适合谁 / 不适合谁）
- 中段用 **数字清单**（三件套、三档预算）做视觉锚点
- 文末问句促留言（代码 `commerce` 互动池），禁「点赞在看」套路
