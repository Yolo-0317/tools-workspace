# 妙想股票工作台

## 当前范围

2026-09-20 最新用户要求：股票研究数据仅通过 mx-data、mx-search、mx-xuangu、mx-zixuan、mx-moni、mx-poster 六个妙想 Skill 获取，覆盖并撤销此前 Tushare/stock_daily 读取与同步例外。不直接调用东财旧接口、网页抓取、浏览器行情采集、其他行情源或通用网页搜索补数。V3公式保留；仅在当前六技能来源的日线完整性、复权、单位及适配经过验证后计算，缺项标记未完成，不回退旧来源。

先读 [唯一数据来源与缺项处理](references/skill-only-data.md)。V3公式与门槛继续按 [规则](references/v3-rules.md)保留；不调用旧选股后端。

股票结果统一称为“研究候选 / 观察名单”，不声称通过本地风控、LIVE 验证或获得交易资格。不生成未经验证的胜率、最大股数、自动止损计划或订单。不因本次来源调整修改已有调度。

## 按需加载

1. 在工作区先用项目注册表定位 `stock-ai`，遵守根 AGENTS 的妙想唯一股票路由。
2. 默认选股或个股技术分析先读 [V3规则](references/v3-rules.md)，再按 [工作流](references/workflows.md) 选择选股、个股分析或板块研究；只加载当前需要的子 Skill。
3. 按 [命令](references/commands.md) 使用持久环境变量 `MX_APIKEY`，产物写入被 Git 忽略的独立运行目录。
4. 按 [交付与验收](references/output-and-checks.md) 核实实体、期间、事实来源与业务错误。纯股价/单条新闻请求直接用基础子技能，不跑完整工作台。

短线诊股额外读取 [短线信息覆盖与核验](references/short-term-diagnosis.md)：按市场、板块地位、V3、资金龙虎榜、事件风险组织分析，保留缺项，不更改V3分数。

## 调用效率

涉及外部调用先读 [调用预算与缓存流程](references/call-efficiency.md)：仅复用可追溯至当前六技能的有效缓存，再按需查询；不复用旧行情源缓存或旧分数冒充本次结果。默认每轮最多8次外部Skill调用、并发1；业务额度错误立即停止。批量查数节省效果尚待真实验证。

## 妙想依赖

路径为 `/Users/huan.yu/.codex/skills/<名称>/SKILL.md`，调用前检查存在性。

2026-09-20 起只依赖以上六个官方技能。旧十个技能已移出全局技能目录，不调用归档副本。资金、财报、机构、热点和行业分析由 mx-data + mx-search 提供事实，工作台综合分析；不再声称调用上游专项报告。宏观查询是否受支持以实际返回为准。

## 调用边界

- 子技能意图边界、实体数量和市场范围仍有效；泛化“分析一下”不能强行触发所有专项。
- 原始报告单独保留。工作台另列证据核对，不能改写上游结论冒充原文，也不能把报告共识当成独立事实或量化胜率。
- 不调用 stock-strategy-selector、stock-opencli、旧东财八维/十一维 SOP、QClaw 个股诊断及其脚本回退。
- 用户要求查看自选时仅调用 mx-zixuan 查询；自选不等于持仓。明确要求模拟持仓时调用 mx-moni 只读接口；实盘持仓仅使用用户提供或本会话已提供的快照并注明时点；六技能尚无已验证实盘持仓能力，不再浏览券商页面或读本地账户库刷新。模拟持仓不能代替实盘。
- 自选增删、模拟买卖/撤单、社区发布/点赞/评论与策略配置分别需要用户明确授权；研究或安装授权不包含这些动作。mx-moni 不启用自动发帖，mx-poster 不因研究结果自动发布。
- “每日”不代表定时运行；不创建调度、推送、监控规则或交易订单。
- 接口失败就报告缺项，不借旧链路补造研究结果。

来源和版本见 [来源清单](references/upstream-manifest.json)，实测范围见 [验证记录](references/verification.md)。
