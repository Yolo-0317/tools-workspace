# 《九歌·云中君》缓慢朗诵字幕成片设计

## 目标

将用户确认直接使用的 15.093 秒《九歌·云中君》Seedance 原片制作成一份无字幕朗诵试听版和一份正式字幕版。画面、舞蹈、镜头、原片音乐与环境声内容不重生成；后期只增加栀夏固定女声的两句缓慢画外朗诵、逐句竖排字幕、必要的轻度音乐避让和保真高清输出。

## 输入与输出

- 原片：`episodes/jiuge-yunzhongjun-15s/assets/video/content-raw-v01.mp4`。
- 原片规格：496×864、24 fps、H.264；AAC 44.1 kHz 双声道；15.093 秒。
- 无字幕试听版：`exports/jiuge-yunzhongjun-15s-voiced-v02.mp4`。
- 正式字幕版：`exports/jiuge-yunzhongjun-15s-subtitled-v02.mp4`。
- 两份输出均为 1080×1920、24 fps、H.264、48 kHz 双声道 AAC，时长保持约 15.093 秒。
- 保留原片右下角“AI生成”标识，不遮挡、不裁掉。

## 朗诵内容

全片只由栀夏画外朗诵《楚辞·九歌·云中君》两句，不念题目、作者、篇名或其他旁白，不要求画中人物对口型：

1. 灵皇皇兮既降。
2. 猋远举兮云中。

成片语义仍是两句，但声音制作拆成四个自然短段：“灵皇皇兮｜既降”“猋远举兮｜云中”。四段均以正常声速单独生成，通过短段之间的自然气口形成舒缓感；字幕仍按完整两句显示。第一句对应云神降临和云门显现，第二句对应横向旋转、远游与目送。

## 声音表演与缓慢语速门禁

- 使用栀夏既有固定女声：年轻、清透、克制、低甜度、有书卷气和高天空间感，不换成成熟御姐、幼童、主持人、仙侠旁白或神谕声线。
- 自然说诗，不使用朗诵比赛腔、戏曲腔、吟唱、耳语、拖字或刻意神秘化表演。
- “缓慢”必须来自正常人声的自然吐字、语义短段之间的气口和句尾留韵，不以持续放慢音素制造拖腔。
- 四段全部固定使用 `speech_rate=0`，构建阶段禁止使用 `atempo`、变调、时间拉伸或其他语速处理；不得再使用 `speech_rate=-50`、0.5 倍速或低于正常速度的合成参数。
- 第一行字幕与声音组使用 1.000—6.000 秒区域：“灵皇皇兮”约 1.000 秒进入，“既降”在前段自然结束后保留约 0.700—1.000 秒气口再进入。
- 第二行字幕与声音组使用 7.700—13.300 秒区域：“猋远举兮”约 7.700 秒进入，“云中”在前段自然结束后保留约 0.700—1.000 秒气口再进入。
- 两组之间和第二组结束后继续保留云风、音乐和舞蹈余韵。短句不再以“有效人声占满 82%—90%”为目标；该比例不能凌驾于人声自然度，也不能作为拉长音素的理由。
- 生成后优先试听声线是否仍像自然人声，其次才检查整体节奏。发现非人声感、拖腔、音素扭曲或明显变速痕迹即淘汰，不能进入混音。
- “猋”按“biāo”读，必须复核读音；不得误读为“犬”“飙”的其他声调或省略该字。

## 字幕设计

- 字幕使用两张透明竖排诗句卡，随对应朗诵逐句出现。
- 第一行“灵皇皇兮既降”位于画面右侧，并附较小题署“屈原《九歌·云中君》节选”。
- 第二行“猋远举兮云中”位于画面左侧，不重复题署。
- 字体沿用九歌正式字幕体系：暖象牙白主字、低反射暗金细描边、玄黑柔影；风格克制，不使用发光字、霓虹、卷轴边框或装饰性法阵。
- 字幕位置必须避开栀夏脸部、双手、主要袖缘轨迹和身体中轴；同时避开右下角原片“AI生成”标识。
- 第一张字幕在约 1.000 秒淡入，随“既降”结束后淡出；第二张在约 7.700 秒淡入，随“云中”结束后淡出。具体消失时间依据四段正常人声的实际边界确定。

## 混音设计

- 原片音乐、风声、衣料声和落脚声保持原有时间结构，不替换音乐、不重新配器。
- 栀夏人声居中，保留适度远近感，不做贴脸广播式响度；两句音色、距离和空间感保持一致。
- 人声期间对原片音乐做约 3 dB 的平滑轻度避让，使用缓慢起落，避免明显泵动；非人声区间恢复原片音量。
- 第一行开始前保留约 1 秒原片开场，句间与片尾保留完整环境声和音乐呼吸。
- 最终总线无削波、爆音或明显底噪突变，真峰值不高于 −1.0 dBTP；不得为了追求固定响度破坏原片动态。

## 实现边界

- 建立 v02 独立配音清单，四段音频分别生成并保留；字幕清单继续只包含两句完整诗句。
- 使用现有豆包 TTS 生成流程及栀夏固定音色，四段全部以正常声速生成。废弃 v01 的 0.5 倍速音频和成片，不覆盖，保留为失败样本。
- 先输出无字幕试听版，检查声线、读音、单句内部速度、句尾留韵和音乐关系；通过同一套已验收音轨再输出正式字幕版。
- 画面只做适配 1080×1920 的保真放大，不重绘、不插帧、不改变人物比例，不裁掉右下角原有标识。

## 验收标准

1. 两句文本准确，只有栀夏画外朗诵，无新增对白、题目朗读、作者朗读、吟唱或画中口型要求。
2. “猋”正确读作“biāo”；两句保持同一声线、同一距离和同一高天空间感。
3. 四个短段全部是正常声速原生人声，构建脚本不包含 `atempo` 或其他语速处理；听感自然、舒缓，不赶、不拖、不机械，不出现非人声感。
4. 第一组从约 1.000 秒进入，第二组从约 7.700 秒进入；每组内部有约 0.700—1.000 秒自然气口，组间和片尾均保留可感知的音乐余韵。
5. 两张竖排字幕分别位于右侧和左侧，不遮脸、双手、主要袖缘轨迹、身体中轴或“AI生成”标识。
6. 原片音乐只在人声期间平滑轻压约 3 dB，无明显泵动；最终无削波、爆音和突然音量跳变。
7. v02 无字幕试听版和正式字幕版均可播放，规格为 1080×1920、24 fps、H.264、48 kHz 双声道 AAC，时长与原片一致；v01 明确标记为淘汰版本，不再用于发布。

## 版本决策

本次采用用户确认的修订 A 方案：正常声速分段录制，以自然气口形成慢诵。此前 v01 使用原生 `speech_rate=-50`，并叠加 `atempo=0.84/0.95`，用户确认已失去自然人声感，判定不可用；0.5 倍速、强制拉长与“为了占满时间窗而牺牲自然度”的做法永久退出后续基线。当前原片画面保持不变，已记录的云门、圆台、动作和景别偏差不在本次后期中修复，只用于后续生成优化。
