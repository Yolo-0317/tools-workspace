## 固定结构

- 全卡与视频中始终只有同一把修长梨形四弦曲项琵琶。
- 琴体严格四根连续琴弦、四枚弦轴；正面、侧面、背面和局部结构保持一致。
- 主体为深胡桃木、暖象牙琴面与克制旧金包边，以孔雀蓝、朱砂红和绿松石矿物彩绘表现莲花、忍冬卷草和火焰宝珠纹样。
- 视频中的琵琶横置于栀夏后颈下方与双肩后方，琴弦面朝向身体后外侧；一手握琴颈，另一手接触琴弦与捍拨区域。
- 琵琶不使用现代背带、支架或扣具，不悬浮、不发光、不增生、不换色、不穿过头颈肩臂、飘带或躯干。

## 视频输入规则

3. 不复刻两张参考卡的版式、文字、分栏、三视图、拆解区、色板或灰色技术人台。
4. 不同时上传旧敦煌角色卡、其他人物图、动作照片或另一张琵琶图。
