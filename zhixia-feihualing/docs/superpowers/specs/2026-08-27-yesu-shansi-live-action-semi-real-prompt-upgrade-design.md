# 《夜宿山寺》真人电影化半写实提示词升级设计

## 目标

在继续使用栀夏、阿砚半写实角色卡的前提下，降低 Seedance 2.0 成片中的二维动画、游戏 CG 和塑料建模感，把最终画面稳定到“真人电影化半写实东方奇幻”。人物材质与摄影语言真实可信，飞升、穿云、登塔、触星和摄影机轨迹可以超越物理规律。

本次只升级生成提示词与付费生成前检查规则，不要求重新制作全写实角色照片，也不要求先做额外付费视频测试。

## 已确认路线

采用“角色卡锁身份，文字锁渲染，超现实只豁免运动”的组合约束：

- 栀夏、阿砚角色卡只固定五官关系、脸型、发型、发冠、服装结构与配色、物种轮廓、耳形、朱砂印、浅暖金纹样和唯一墨尾。
- 成片主动转换为真人电影化半写实：真人演员比例和面部骨骼、可见但克制的皮肤微纹理、湿润眼球反光、独立发丝、真实丝织衣料、真实毛发、接触阴影、自然镜头透视与电影动态范围。
- 栀夏与阿砚可以随镜头悬浮、踏云、滑行和升空；只有重力、位移与空间路径可以超现实，人物材质、身体结构、服装、物种和数量不能动画化或漂移。
- 视觉奇观由高速视差、遮挡穿越、方向反转、空间揭示、真实云雾和星光完成，不依赖动漫速度线、卡通光效或无来源粒子爆发。

## 语义冲突处理

生成《夜宿山寺》新版视频时，适用以下优先级：

1. 本设计与 `docs/realistic-visual-style.md` 中的真人电影材质规则。
2. 当前上传的栀夏、阿砚角色身份卡所表达的身份与造型。
3. 当前上传场景卡中的构图、环境和角色位置。
4. 旧文档中的“二维动画”“不是现实真人演员”“电影级半写实角色”等风格描述不进入新版视频提示词。

`docs/visual-bible.md` 的二维动画方向属于早期栏目基线，不作为本次 15 秒梦境长镜头的渲染依据。旧场景卡仍可用于身份、场景和构图参考，但不继承其插画或动画材质。

## 提示词结构

新版 Seedance 提示词按固定顺序书写：

1. **参考资产映射**：逐张说明栀夏角色卡、阿砚角色卡、场景卡分别负责什么，禁止模型混用身份。
2. **最高优先级风格锁**：用可观察的真人皮肤、眼睛、发丝、衣料、毛发、光影和镜头特征定义风格，不只写“半写实”。
3. **一镜到底总轨迹**：只保留一个“摄影机在双角色前方倒退领飞并反向上升”的核心运镜机关。
4. **四段时间轴**：每段只写一个摄影机动作、每个角色一个主动作、一个环境变化；减少模型同时执行的命令数量。
5. **声音规则**：Seedance 只生成东方奇幻背景音乐和环境声，不生成可辨识人声；栀夏、阿砚对白及两句诗朗诵由后期固定音色加入。
6. **关键禁止项**：只保留动画化、身份漂移、身体畸变、随机切镜和错误文字五类高风险禁止项。
7. **结束状态**：最后一个诗字读完时画面仍保持轻微上升或环绕，不额外添加片尾、解释镜头或强制闭合结局。

## 风格锁定文本要求

提示词必须明确包含下列正向语义：

- 高预算真人东方奇幻电影镜头，而非动画或游戏过场。
- 真人比例、真实面部骨骼与鼻唇结构、自然皮肤微纹理、克制次表面散射。
- 真实眼球湿润高光、逐根发丝、具有重量和褶皱响应的丝织衣料。
- 阿砚具有真实幻想生物毛发、爪部接触、环境反光和唯一墨尾，不是普通猫或卡通宠物。
- 真实摄影机曝光、景深、运动模糊、体积雾、空气透视、克制锐度与轻微电影颗粒。
- 从第一帧到最后一帧材质等级、角色身份、面部结构和服装设计保持一致。

提示词只保留下列核心负向语义：

- 禁止二维动画、二次元、国漫立绘、卡通描边和夸张萌系五官。
- 禁止游戏 CG、塑料 3D、蜡像皮肤、瓷白发光脸和过度磨皮。
- 禁止栀夏换脸换装、阿砚普通猫化、多尾、多耳或身体结构漂移。
- 禁止随机切镜、瞬移、无意义旋转和把高速运动做成动画速度线。
- 禁止模型生成对白、朗诵、字幕、诗句、标题、Logo 或水印。

## 角色与运镜兼顾

- 0—3 秒先以强视差中近景锁住栀夏与阿砚，摄影机已经运动，但两者五官和关键身份特征清楚可辨。
- 3—9.5 秒摄影机在双角色前方倒退领飞，两者从低处远方持续飞向高塔；人物与镜头保持稳定相对距离，不能迅速缩成远处小点。
- 9.5—12 秒摄影机停止坠落并反向上升，沿塔身高速抬升，完成全片唯一一次方向反转和空间揭示。
- 12—15 秒两人抵达塔顶并接近星辰，镜头减速但不停；保留清楚的双角色中景或中近景，为两句诗朗诵和后期诗词字幕留出稳定画面。
- 高速段由前景塔檐、云层和衣带形成真实视差；角色脸部连续无遮挡超过 0.5 秒的情况不得出现。

## 声音与对白防错

- 不在 Seedance 画面时间轴中重复写任何对白或诗句原文。
- Seedance 音轨只描述背景音乐、风声、铜铃、踏云与触星声，不出现说话、吟诵、耳语或可辨识人声。
- 栀夏与阿砚对白分别使用固定后期音色，台词只在单一音频清单中出现一次，按编号和时间顺序混音。
- 两句诗由栀夏固定音色朗诵，最终字幕由本地后期准确烧录，不让视频模型生成中文。
- 若时间冲突，先删除可选对白，不压缩诗句、不重复台词，也不改变播放顺序。

## 付费生成前检查

提交前必须同时满足：

1. 提示词开头已逐张映射角色卡，且声明角色卡只锁身份、不继承动画材质。
2. “真人电影化半写实”由具体材质和摄影特征定义，不只出现抽象风格词。
3. 全片只有一个核心运镜机关和一次方向反转。
4. 四段时间轴中，每个主体每段最多一个主动作。
5. 提示词中不存在对白或诗句原文，音轨明确禁止可辨识人声。
6. 栀夏、阿砚至少有一次稳定双角色中近景，且高潮后没有缩成不可辨认的小点。
7. 禁止项已压缩到五类核心风险，没有大量互相竞争的否定命令。

## 验收标准

- 首帧、运动高潮和末帧均保持真人电影化半写实材质，不出现从写实滑向动画或游戏 CG 的过程。
- 栀夏的面部、发型、服装与阿砚的物种、耳形、朱砂印、纹样和唯一墨尾全程稳定。
- 飞升和镜头运动可以不符合重力，但皮肤、发丝、布料、毛发、接触阴影和运动模糊符合真实摄影观感。
- 画面无可辨识人声、无错误中文、无模型生成字幕；后期对白、朗诵和字幕可独立替换，不需要重新生成视频。
