# 公众号公共 Skill 接入参考案例

2026-10-26。用户在多轮讨论与案例积累后要求“优化基座，把这些放到公众号写作的公共 skill”，本次实施已有授权。

## 选择与范围

采用“基座维护通用边界，公共 Skill 路由，参考库维护卡片”的方式。把62篇拆解复制进主 Skill 会增加默认加载量并产生两份真源；只放一个总目录链接则不容易按写作任务找到案例。新增一页任务索引，将原库接入结构、起稿和既有审稿流程。

基座只补外部案例的适用边界与公众号入口，不把无第一人称偏好扩到全部中文写作。公众号公共 Skill 保存当前报道与评论的非亲历叙述偏好，遇用户明确要求的其他文体仍按请求执行。

## 文件职责

- `docs/writing/中文写作基座.md`：说明组织参照不能替代当前材料，指向公众号公共 Skill。
- `.cursor/skills/wechat-mp-article/SKILL.md`：维护公众号叙述偏好及案例调用时机。
- `references/external-article-cases.md`：按论证任务选择卡片，提供少量阅读和实际迁移办法，链接现有库；不复制正文或全部拆解。
- `references/drafting-loop.md`、`references/review.md`：沿用现有工作文件和审稿记录检查参考动作，不新增轮次或独立检查表。
- `references/method-sources.md`、参考库`README.md`：记录已接入及各自的维护边界。

文章卡片、正文入口、日期与已记录的不足保持在原库。外部文章仍不是用户口吻正例，亦不是本次写稿的事实依据。教育与上海只帮助选择组织参照，不成为所有题材的默认范围。

## 验收

核相对链接与锚点；运行Skill校验；用纯评论、报道、教育评论、局部改句四种任务检查路由。确认全局技能链接仍指向仓库公共Skill，原62条目录与卡片未变，不新增发布权限、审稿轮次或全量阅读要求。不提交Git、不改其他已有工作区变更。
