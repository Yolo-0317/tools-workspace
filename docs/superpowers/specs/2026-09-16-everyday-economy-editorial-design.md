# 普通人的经济生活：热点研究与公众号写作设计

日期：2026-09-16
状态：设计提案；未创建 Skill、运行选题研究或改变发布流程。

## 定位与范围

从当前可核实的事件出发，解释普通人的收入、支出、时间和选择怎样受到影响。目标读者不需要金融知识，也不需要持有股票。文章应当通俗、有事实增量，值得转给具体的人，能引出真实经历。

涵盖工作收入、消费物价、住房房贷、储蓄、养老、养娃、汽车、黄金汇率、平台经营与公共政策。行业与公司是解释生活现象的证据来源之一。当前请求扩展财经主题范围；已有教育稿专属地域要求不自动扩展到所有财经话题，实际进入教育稿流程时仍核对其规则。

沿用现有账号角色卡中的普通人视角、事实纪律与克制表达。入口文档和角色卡存在品牌名称差异，本设计使用栏目工作名，不改账号名称和包装。

## 方案选择

- 纯妙想市场热点驱动：金融数据衔接快，但候选容易集中于 A 股。
- 广义热点加妙想研究（采用）：从政策、公共数据、消费新闻及市场事件发现问题，再按需查数，覆盖普通人的经济生活。
- 常青家庭理财知识：可持续、便于搜索，但时效联系较弱，只作为某次热点研究的解释材料，不冒充当前热点。

## 每次执行流程

### 1. 发现事件

执行时记录北京时间与检索截止时间。优先过去 72 小时事件；不足时扩大到 7 天。更早事件仅在出现新数据、新执行节点或新进展时纳入，标明原始事件时间。没有合格事件时交付缺项与待观察题，不硬写热点。

来源分三路：政府部门和统计机构的政策及数据；正规媒体的消费、就业、住房和民生报道；妙想的金融市场热点与定向资讯检索。

妙想热点发现仅承担其 A 股市场能力范围，不冒称全社会热榜。搜索命中不等于热度已证实：记录讨论信号、新闻来源和时间，无可靠热度数据时称“近期议题”。同源转载合并，不能用转载数量虚增热度。

### 2. 把事件转成生活问题

每个候选必须回答：发生了什么新变化；具体影响谁；改变哪笔钱或哪项选择；为什么现在写；读者可能转给谁；评论能讨论什么真实经历。

示意转换（不是已核验新闻）：存款利率调整→同样本金利息变化与现金安排；车企降价→购车价与总持有成本；金价变化→金饰买入和回购差异；费用减免→哪些家庭符合条件、实际减少哪项支出。

### 3. 选题排序

先过硬条件：事件与日期可核验、有明确受影响人群、能取得支持核心论点的证据、存在新的解释价值。标题前提未证实、只有情绪、旧闻翻炒的题目淘汰。

通过后按生活相关性、时效、可解释性、转发对象是否明确、真实讨论空间排序，用高/中/低及理由说明，不输出伪精确爆款概率。热度相近时优先账单清楚、条件明确的题目。

默认交付最多三个候选、推荐一个。用户要求直接写时自主选最合适候选进入研究；只要求选题时停在候选交付。选题排序不构成额外确认关卡。

### 4. 按问题调用妙想

| 研究问题 | 能力 | 边界 |
| --- | --- | --- |
| 物价、就业、利率、汇率、商品价格 | mx-macro-data | 先验证实际返回的指标、期间和口径 |
| 公司收入、利润、成本及金融数据 | mx-finance-data | 不由企业样本推断全部商家或家庭 |
| 明确事件、公司或政策线索 | mx-finance-search | 检索结果继续追溯原始出处 |
| 行业变化 | 妙想工作台中的行业分析路由 | 符合行业研究意图才调用 |
| 财报解释 | stock-earnings-review | 确认已披露报告期，按专项规则调用 |

每篇按需用少数相关能力，不为使用工具而调用所有专项。宏观和单项查询直接进入基础技能；股票和板块研究遵循妙想工作台路由，不调用已停用旧股票链路。

具体银行条款、地方补贴、租金、保险、工费、回购报价等回到官方文件或可追溯的原始报价补证。妙想缺少指标时明确缺项，可用权威公开资料补充，不把补充数据署名为妙想结果。

### 5. 建立证据与算账底稿

记录每项关键主张的来源链接、发布日、事件日、数据期、地区、人群、单位和核验结果；区分事实、机构观点、作者推断与示例假设。原始妙想报告独立保留。

关键数字回原文；多份报告引用同一公告只算同一证据。不同数据相冲突时先查口径与修订，未解决不能任选其一支撑标题。政策区分建议、正式发布、生效和地方实施。

算账列出输入、单位、公式、时间范围和遗漏成本，核算总数。假设例子显著标为示例，不编造受访者或个人账单。不把全国均值写成读者个人情况，不把相关性写成单一原因。

核心证据不足则缩小论点、换题或交付研究缺口，不输出貌似完成的文章。

### 6. 写作设计

一篇回答一个主问题。建议 1200—1800 字，具体进入已有稿型时遵守其长度和交接要求。正文选择两三组必要数据，复杂口径和详细来源留在编辑底稿。

阅读顺序：可核验的新事件及生活后果；一笔账或一个对比；背后的原因与利益关系；对不同人群成立的条件和例外；一个读者能回答的具体问题。可以随题变化，不固化成每篇完全相同的小标题。

标题采用具体变化、生活后果或已经证实的矛盾。提供三个不同角度的备选，不夸大受影响人数、不承诺收益、不用未经验证的涨跌当事实。专业词首次出现用白话解释。

讨论围绕实际经验和选择，例如“决定提前还贷时，你最看重哪一项？”不编造对立、不强行站队、不用利益诱导转发。文章应有可以复述的判断，并交代判断适用条件。

### 7. 接入现有公众号流程

拟新增研究与编辑编排 Skill，工作名“普通人的经济生活”，职责为热点筛选、妙想调用、证据包、算账、写作要求与核验。实际创建时按 skill-creator 流程实施，本设计不创建入口。

现有主动热点深评要求由 Agent 展示完整提示词，用户确认后自行交给 DeepSeek，贴回全文，再由 Agent 核验编辑并在确认后推草稿；本方案沿用该交接，不通过新增名称绕开。此类稿件交付完整提示词和研究包，而非声称已完成初稿。其他稿型按其既有写稿规则执行。

图片、排版、草稿写入和发布沿用命中的既有稿型规则。图片不凭空展示假报价、假政策或假现场。本设计不创建定时任务，不自动发表，不改变草稿槽位。

### 8. 交付与复盘

一次选题研究交付：候选与推荐理由；选中题目的事实和数据底稿；算账及局限；标题备选和写作提示词。收到适用流程所需初稿后，再交付核验编辑稿、来源和具体讨论问题。

先人工试做六篇：家庭账单、消费现象、热点解释各两篇。发布后用统一的 24 小时与 7 天窗口观察完读、分享、收藏和有效评论；只有后台实际提供的指标才报告，不推算缺失指标。

分享指标注明是人数还是次数，比例注明分母。有效评论看是否提供经历、提出实质问题或讨论选择，不仅看数量。记录流量渠道、发布时间、曝光基数，避免把推荐曝光差异全归因于选题。

六篇只用于探索，不据少量样本宣称爆款规律。用户过去反馈的教育退费稿传播较好属于选题线索，不是本次已核验的统计证据。

## 设计验收

- 不炒股的读者也能理解文章与自己的关系。
- “当前”有执行时的事件和日期证据；示意题不冒充今日热点。
- 妙想和补充来源职责明确，未知能力不冒称已验证。
- 核心结论可追溯，算账可复核，假设和人群边界明确。
- 转发对象与真实讨论问题明确，传播潜力不被承诺为结果。
- 接入原有写稿交接，不擅自发布或新增自动化。
