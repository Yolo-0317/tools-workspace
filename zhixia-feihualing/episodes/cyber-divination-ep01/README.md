# 《栀夏赛博起卦》第一集：最后一块桂花糕

## 单集定位

- 栏目：栀夏赛博起卦。
- 卦象：第二十七卦颐卦，常用卦名“山雷颐”。
- 卦辞：颐，贞吉。观颐，自求口实。
- 核心笑点：阿砚假装只想吃最后一块糕，镜头最后揭示石栏下已有八只空盘。
- 时长与画幅：约 15 秒，9:16 竖屏。
- 制作版本：第一集简版，使用三枚铜钱“掌心起卦”；星轨六爻盘不参与本集。
