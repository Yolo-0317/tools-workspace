# 综合选股 D+A 优化设计

## 目标

修复 `stock_selection_combined.py` 成交额单位与流动性评分（D），并提升 Top5 可执行性（A）。

## 阶段 D — 数据与评分

| 项 | 现状 | 改后 |
|----|------|------|
| DB `amount` | Tushare 千元 | 过滤 `>= 50000`（5000 万） |
| CSV `成交额(万)` | 误存千元 | `amount / 10` 万元 |
| 流动性分 | `amount/200000` 按千元 | `min(10, amount_wan/20000)`，20 亿封顶 |

## 阶段 A — 信号与 Top5

1. **早埋伏**：要求当日收阳（`close > open` 且 `pct_chg >= 0`）。
2. **非持仓下跌日**：`pct_chg < 0` 且动作非买入类 → 降为 `谨慎回避`，不进入候选池。
3. **Top5**：`pick_selection_top` 默认仅选 `强势关注/观察买入/小仓埋伏/持有`；无结果时回退并打日志。

## 验收

- 单元测试：`amount_qian_to_wan`、流动性分边界。
- 回跑：`uv run python core_v2/stock_selection_combined.py`（需 MYSQL_URL），CSV 中 `成交额(万)` 在 5000～数十万合理区间。
- Top5 不含「早埋伏 + 大跌日 + 继续观察」组合（除非回退）。

## 阶段 E — 震荡市与信号质量（2026-06-02 续）

1. **大盘 regime**：按 `up_ratio` 分 weak/neutral/strong，动态抬高买入类总分门槛。
2. **突破质量**：上影线过长（收盘靠低）不记「大底突破」。
3. **禁追高动作**：非持仓单日涨幅 >5% 强制 `继续观察`（不入 Top5，可留 CSV 备查）。
4. **早埋伏**：允许 -1.5%～0% 小幅回踩，扣分但不硬拒。
5. **漏斗统计**：打印信号命中数、最终入池数。

## 范围外

- 五因子 v3 策略重构、OpenCLI 基本面自动过滤、全仓库 `MIN_AMOUNT` 清扫。
