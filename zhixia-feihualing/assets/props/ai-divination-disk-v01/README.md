# AI 卦盘固定道具

## 身份

- 道具名：AI 卦盘。
- 资产标识：`ai-divination-disk-v01`。
- 当前状态：等待用户提供并确认母版图。
- 适用场景：《栀夏赛博起卦》系列的起卦、六爻生成和卦象揭示镜头。
- 唯一母版：`master.png`。母版通过验收后，后续场景不得重新设计卦盘外观。

## 固定内容

- 外框轮廓、整体比例和悬浮层级。
- 卦盘名称固定为“星轨六爻盘”。
- 浅青、月白、暖金与极少朱砂构成的低饱和配色。
- 同一平面的半透明星轨、八方刻度、星点连线和信息区域布局；不做 3D 分层结构。
- “星点聚拢”“星轨显现”“能量汇聚”“六爻生成”“卦象稳定”“余光收束”六个流程状态属于同一件道具。
- 卦盘不依附古籍、桌面或其他实体道具；召唤后悬浮在栀夏与阿砚之间的桌面上空。
- 单层平面光盘直径约 30 厘米，视觉上近乎无厚度，距桌面约 15—20 厘米。
- 中心恰好六个等宽、等距的低亮度空爻槽，不得出现第七槽，不得预填六条阳爻。
- 阳爻和阴爻使用独立后期组件填充：阳爻为完整横线，阴爻为中央断开的两段等长横线。
- 六个爻位自下而上逐条激活，阴爻和阳爻必须清楚可辨。

## 单集可变内容

- 卦名与上下卦名称。
- 六爻的阴阳组合。
- 经核对的卦辞或爻辞原文。
- 与当集节奏匹配的状态切换时点。

可变内容只在既定信息区域和六个空爻槽内替换，不改变道具外框、星轨、配色、刻度与界面层级。精确中文和六爻必须由后期透明卡叠加，避免视频模型生成错字、七个爻位或错误卦象。

召唤动作统一引用 `zhixia-summon-divination-disc-action-v01`，模板视频统一引用 `zhixia-summon-divination-disc-template-v01`。单集不得另行设计召唤手势。

## 使用门槛

用户将确认的原图放入本目录并命名为 `master.png`。只有用户明确确认道具卡、验收清单全部通过，且 `assets/inventory.csv` 将其登记为 `approved` 后，场景卡和正片视频才能引用该母版。
