## 一、基础信息

| 项 | 建议 | 操作路径 |
|----|------|----------|
| **名称** | **牛马也智能**（≤16 字，已用则不动） | 设置与开发 → 公众号设置 → 账号详情 |
| **头像** | `stock-ai/assets/wechat_mp/banner.png` 居中裁切；或换更中性的品牌图（非行情屏） | 同上 → 头像；240×240 以上 |
| **微信号** | 已绑定则不动 | 同上 |
| **二维码** | 下载后可用于朋友圈/私聊拉新 | 设置与开发 → 公众号设置 → 下载二维码 |

### 功能介绍（≤120 字，搜一搜用）

**定稿（直接粘贴）**：

```text
热点观察：社会、文娱、职场与公共事件，有话题就写。整理公开信息与多方观点，供阅读与讨论。
```

（共 64 字；勿写「荐股」「必涨」「内幕」「关注领资料」。）

### 认证 / 类目

- 热点 / 社会 / 文娱稿：原创分类选 **社会、娱乐或资讯**（按稿型最接近项），**勿默认勾财经**。
- 若偶发财经深评单篇，该篇可单独选财经；账号简介不再写 A 股复盘。

## 二、自定义菜单（建议 3 个一级）

路径：**内容与互动 → 自定义菜单** → 保存并发布（手机预览确认）。

| 菜单名 | 类型 | 配置 |
|--------|------|------|
| **更新节奏** | 发送消息 | 触发关键词回复 `节奏`（见第三节 B） |
| **近期文章** | 跳转网页 | 公众号主页链接（`__biz=` 从后台复制） |
| **免责说明** | 发送消息 | 触发关键词回复 `免责`（见第三节 B） |

## 三、自动回复

路径：**内容与互动 → 自动回复**

### A. 被关注自动回复（必做）

**定稿**：

```text
欢迎关注牛马也智能。

这里写社会、文娱、职场与公共热点：整理公开信息，把各方说法摆清楚，方便阅读和讨论。

建议星标本号，更新不易漏看。
回复「写作」领取 AI 写作技巧与公众号 API 对接笔记。
回复「节奏」或「免责」看说明。
```

### B. 关键词自动回复

| 关键词 | 规则 | 回复正文 |
|--------|------|----------|
| `写作` | 半匹配 | 见下「关键词：写作」 |
| `节奏` | 半匹配 / 全匹配均可 | 见下「关键词：节奏」 |
| `免责` | 半匹配 | 见下「关键词：免责」 |

**关键词：写作**

> 夸克链接真源：`stock-ai/docs/share/README.md`（上传后把 `{{QUARK_WRITING_GUIDE_URL}}` 换成真实地址）

```text
【AI 写作与公众号 API 笔记】

含：AI 写作技巧、社会热点排版语气、避坑清单、草稿箱 API 对接示例。

夸克打开（建议收藏）：
{{QUARK_WRITING_GUIDE_URL}}

仅供学习交流，转载请注明出处「牛马也智能」。不含选题与运营策略。
```

**占位示例**（上传夸克后替换整行链接）：

```text
https://pan.quark.cn/s/xxxxxxxx
```

**关键词：节奏**

```text
【更新节奏】

· 工作日：更新热点话题评论
· 范围：社会、文娱、职场与公共事件

内容来自公开报道，呈现多方观点，供阅读与讨论。
```

**关键词：免责**

```text
【免责声明】

本公众号整理公开报道与网络讨论，仅供阅读与交流，不构成任何专业建议或事实背书。

文中观点不代表本号立场；转载请注明「牛马也智能」。
```

### C. 收到消息自动回复（可选）

```text
你好，私信暂不逐一回复。可回复「写作」「节奏」或「免责」，或星标后阅读更新。
```

## 四、配置后自检（5 分钟）

- [ ] 小号取消关注再关注 → **关注回复** 无 A 股 / 复盘字样  
- [ ] 发私信 `写作`、`节奏`、`免责` → 回复正确（写作含夸克链）  
- [ ] 点菜单三项 → 无 404  
- [ ] 搜一搜试「牛马也智能」「热点观察」（索引有延迟）  
- [ ] 新发 1 篇热点稿 → 稿末有星标引导（见 follow-growth-copy.md）
