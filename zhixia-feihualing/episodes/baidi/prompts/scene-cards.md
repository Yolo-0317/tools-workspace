# 《白帝城》四张独立写实场景卡提示词

使用时同时上传栀夏与阿砚固定角色卡。四张图分四次生成；第一张通过后，把固定道具`tang-three-mast-passenger-ship-v01`的船型结构卡与两张角色卡一起用于第二至第四张，确保船体、通高长舱、桅杆、帆形和人物位置一致。

## 提示词一：船型结构卡

```text
请使用我上传的栀夏与阿砚固定角色卡，生成《早发白帝城》15秒动画的船型结构参考卡。只输出一张独立的9:16竖屏高清图片，不要输出四宫格、拼图、分镜表、编号、标题、诗句、字幕、印章、边框、水印或任何文字。

本片取诗为“两岸猿声啼不住，轻舟已过万重山”。诗句只用于理解意境，不在图片中生成文字。

角色必须严格沿用上传参考图。栀夏保持固定脸型、五官、乌黑高马尾、浅青白交领汉服和淡粉腰带，人体比例自然，衣料有真实重量、厚度和褶皱。阿砚保持固定宣纸白墨灵结构、黑色墨纹尾巴、少量金色细节和膝高体型，具有稳定体积、重量、环境反光和甲板接触阴影。画面只出现一个栀夏和一个阿砚。

完整设计固定道具`tang-three-mast-passenger-ship-v01`。船长约22至26米、宽约5至6米，深棕色硬木船体，船头狭长微翘、船尾较宽；它不是双人小舢板，也不是军事巨舰。中央只有一层通高长舱，长约7至9米、内部净高约2.2至2.5米、舱门高约1.8至2米，具有真实甲板、舷墙、可打开舱门、窗格、立柱、墙板厚度、门内暗部、木板拼接、潮湿反光和吃水线。三根桅杆沿船体纵轴以前、中、后的顺序排列，间距清楚。

主桅高出甲板约12至14米，主帆约7至9米高、4至5米宽；前帆面积约为主帆75%，后帆约为主帆65%，三帆约为100:75:65。相较上一张返图，三面帆视觉面积缩小至约60%至70%，帆底与甲板、舱顶之间保留明显空隙，不能遮挡人物、船舱、船体和峡谷。

栀夏直立站在打开的舱门旁，以成年人尺度证明舱门高约1.8至2米且能够直立进入；她的头顶明显低于门框上沿，门内可见真实纵深暗部。阿砚固定在前甲板。两者不遮挡船型关键结构。

采用船尾左后方或船身左后方的低机位三分之四视角，摄影机只高于甲板约2至4米，不做高空俯拍。完整展示船头、船尾、一层通高长舱、三根桅杆、三面缩小布帆、前后甲板、舷墙和水线。船体占画面下半部主要面积，完整读出22至26米长度和5至6米宽度；船头朝画面中央偏上，船身形成明显纵深，不能横贯画面。背景只保留低细节清晨江水与少量远岸薄雾，不生成抢主体的高山。

统一风格为偏写实东方动画电影加克制的诗意自然景观。人物保持动画身份，但衣料、木材、水体、接触阴影、环境反光和空间透视真实可信。清晨柔和侧逆光来自船头前方，所有物体共享同一光源方向。自然电影色彩，低至中等饱和度，不是真人照片，不是3D渲染，不是扁平赛璐璐插画，不使用全屏宣纸纹理、仙侠辉光、霓虹光或魔法粒子。

禁止巨帆小船、半人高木箱船舱、栀夏无法直立进门、假门、门内没有空间、帆面遮住船舱和人物。禁止多条船、多个角色、双层或多层船舱、桅杆少于或多于三根、帆面少于或多于三面、桅杆穿透船舱、船体弯曲、船首尾镜像。禁止船夫、水手、乘客、货物、船桨、竹篙、发动机、复杂绳网、旗阵、灯笼和现代物品。
```

## 提示词二：开场卡

```text
请使用我上传的栀夏角色卡、阿砚角色卡和已经确认的船型结构卡，生成《早发白帝城》15秒动画的开场场景卡。只输出一张独立的9:16竖屏高清图片，不要输出四宫格、拼图、分镜表、编号、标题、诗句、字幕、印章、边框、水印或任何文字。

本片取诗为“两岸猿声啼不住，轻舟已过万重山”。诗句只用于理解意境，不在图片中生成文字。

严格复用固定道具`tang-three-mast-passenger-ship-v01`：22至26米长、5至6米宽的深棕木船，中央7至9米长、2.2至2.5米净高的一层通高长舱，1.8至2米舱门，三根桅杆前中后固定排列。主帆7至9米高、4至5米宽，前帆与后帆面积约为主帆75%和65%；三帆相较旧返图缩小至60%至70%，帆底留空，结构和比例不得改变。

栀夏严格沿用角色卡，固定在后部船舱前方或后甲板，重心稳定，镇定而带一点笑意地看向前甲板。阿砚严格沿用角色卡，固定在前甲板，压低身体兴奋地看向峡谷前方。画面只出现一个栀夏、一个阿砚和一条船。

镜头位于船尾左后方或船身左后侧，以中远景三分之四角度跟随。船尾靠近画面下方偏右，船头明确指向画面中央偏上的可通行峡谷入口。船身由近向远形成强烈但自然的纵深对角线，绝不能正侧视、与画面底边平行或横在峡谷中间。

三面帆受到同一峡谷顺风并朝同一方向鼓起，三面帆的受风方向必须一致。船头切开水面，形成低矮连续的真实破水；船尾只有短而破碎、逐渐消失的自然尾流。栀夏的马尾、腰带、衣袖与阿砚的耳尖、墨纹尾巴受到同一迎面风影响。

环境为险峻清晨三峡。左右最近峡壁直接从水边以约70至85度拔起并延伸到画面顶部之外，不展示完整山顶；峡壁合计占画面宽度约60%至70%，中间只保留狭长可通行水道。天空约占10%至15%，前景无主体空水面不超过约20%至25%，远处只留一道较窄亮色峡口。山体形成出框近壁、中景高峰、远景峡口和雾中远山四层。禁止低缓青山、完整露顶近山、宽阔湖面、黄山孤峰、悬浮山和巨大瀑布。

统一风格为偏写实东方动画电影加克制的诗意自然景观。清晨柔和侧逆光来自峡谷前方，人物、三桅帆船、水面和山石共享同一光源。真实衣料、木材、水体反射、接触阴影和空气透视，自然电影色彩，低至中等饱和度。画面上方左侧保留少量低细节区域供后期对白字幕使用，图片本身不生成文字。

禁止桅杆增减、帆面消失、三帆风向相反、船舱变成双层、角色换位、人物攀爬桅杆、船体镜像、船头朝向岸壁、船身横贯江面、船体腾空、摩托艇尾浪、速度线、全景拖影、可见猿猴、飞鸟群、其他人物和现代物品。
```

## 提示词三：中段卡

```text

左右最近峡壁从水边以约70至85度陡直拔起并延伸到画面顶部之外，合计占画面宽度约60%至70%。中间航道狭长，远处只留一道窄亮峡口；天空约占10%至15%，前景无主体空水面不超过约20%至25%。山体形成出框近壁、中景高峰、远景峡口和雾中远山四层。禁止低缓青山、完整露顶近山、宽阔湖面、黄山孤峰和仙侠悬浮山。

统一风格为偏写实东方动画电影加克制的诗意自然景观。人物、帆船、水面和山石共享清晨柔和侧逆光，衣料、木材、帆布、索具、水体与接触阴影真实可信，自然电影色彩，低至中等饱和度。图片本身不生成说话口型或文字。

禁止桅杆增减、帆面消失、三帆风向相反、船舱变双层、人物换位、阿砚跳跃或悬空、栀夏站立、船体镜像、船身横贯江面、船头朝岸、摄影越轴、多船、多角色、船夫、水手、可见猿猴、摩托艇尾浪、速度线和现代物品。
```

## 逐张验收顺序

1. 先检查角色身份、数量和人物位置。
2. 再检查是否始终为同一条一层舱、三桅三帆的中型木船。
3. 检查船头是否指向可通行峡谷纵深，船身是否保持三分之四透视而非横船。
4. 检查三面帆是否受到同一风向，破水、尾流和衣带方向是否一致。
5. 检查最近峡壁高度、四层山体、天空与空水面占比。
6. 最后检查写实材质、统一光源、接触阴影与角色面部一致性。
