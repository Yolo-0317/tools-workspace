## 来源与语义检查

逐项对照新增词目的所列意义与已读来源。官方原始资料中的171个匹配词目已读完整释义，另打开要是、有点的《重编国语辞典修订本》页面。给的原条目虽已读，但对本批接收者结构的直接支撑不足，仍保留待核。其余7个待核组合也不把其组成字词的已核状态直接继承过来。

修订记录包括：

| 条目 | 查出的问题 | 本次处理 |
| --- | --- | --- |
| 通过 | 所选来源核到经过空间、议案通过，不能直接证明通过电话的渠道义 | 当前只启用表决通过的意义，渠道义另核 |
| 只有 | 不能由仅有释义直接推出整套条件逻辑说明 | 先保留仅有义，条件结构明确留待另核 |
| 家长 | 原定义额外扩展到所有家庭照护负责人 | 收窄为当前教育语境中的父母称呼，不据词义判断制度资格 |
| 很 | 把程度义与特定句法中的弱化用途合并，来源支撑不充分 | 当前先核程度义，其他句法功能另核 |
| 虽然 | 原说明过度规定前项必须已发生 | 改为让步关系，事实是否已发生需看完整语境 |
| 确认 | 把肯定答复一律写成核对后确定，添加了过程 | 分清肯定答复、认定和独立核实，不从确认反推查证 |
| 不仅 | 要求后项同向，会误排不仅没有……反而……等表达 | 保留补充或递进关系，不要求内容一律同向 |
| 相当、不如 | 同一已核卡混入本批未直接核到的其他用法 | 收窄当前所列意义，其他用法单独标明 |
| 一直、随后、继续 | 例句或说明容易混淆持续、紧接和中断 | 改为明确时段的持续例句；保留随后的紧接意味；不由继续反推中断 |
| 当时、对于、仅仅 | 存在重复时间成分、对象省略或表达绕的自编例句 | 调整例句，回读主体、动作对象和指代 |
| 过 | 经历义核对与轻声音读规范混在一起 | 只核经历助词用法，审音另查，不套用来源地区读音规范 |

所有例句均为自编教学材料，不能当成政策、活动或真实人物的新闻事实。比较和风险是编辑归纳，不是辞书原话，也不是遇到相关词就必须改写的禁用表。

## 程序验证

执行：

```bash
python3 docs/writing/语文基础知识库/scripts/kb.py build
python3 -m unittest discover -s docs/writing/语文基础知识库/tests -v
```

结果：19项测试通过。其中扩充检索测试逐一检查200个词目的精确查询状态，并检查[30条句子召回及语义边界样例](cases-200.json)。语义边界由主笔回读，程序只核候选召回，不能将测试通过称为自动理解语义。

新增检索修复：默认隐藏待核多字词时，过去会回退到已核短字。例如听到会召回听，并不可能召回并、不。现先保留已登记词形边界，匹配到待核组合后跳过；显式开启待核选项才返回该组合。已观察到修复前测试失败，修复后通过。未知多字词仍可能发生短字误命中，这不是完整中文分词器。

另核官方ZIP的SHA-256、压缩完整性及使用说明PDF格式；7批阅读页均与对应JSON一致，重复构建结果一致。原始来源包与释义读取记录保存在工作区output目录，未将原辞典全文写进本库。

## 保留的边界

本轮没有取得并冻结大陆基础常用词全量目录，没有补齐每词全部义项，也没有引入真实语料统计。第一批的历史验收及cases-001.json保留为20词版本记录；本次新增了200词阶段样例，不把旧检索结果冒充新版本结果。

库的作用是提供可查依据及比较边界。查词以后仍须结合真实上下文判断主体、时点、范围、程度和话语关系；本库不能替代文章事实核查或逐段回读。
