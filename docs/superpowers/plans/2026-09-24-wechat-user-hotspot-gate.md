# 用户主动热点稿质检分流实施计划

**目标：** 用户主动稿使用专用只读预检，自动稿原评分不变；月饼稿按单一主线重写。

**架构：** 在现有 `wechat_mp_eval` CLI 增加单独入口，复用 `wechat_mp_codex_hotspot` 与 `wechat_mp_hotspot_quality_gate` 的检查，不另造一套评分。Skill 明确人工否决与推稿权限的边界。

**技术栈：** Python、pytest、Markdown。

## 全局约束

- 用户主动稿目标 900—1100 字，少于 850 字拒绝；自动长稿现有要求不变。
- 纯段落；至少三个来源域；机器通过不等于编辑通过。
- 不推送、不发表；不覆盖工作区已有更改。
