# 去 AI 味（anti-ai-voice）

引流节奏、开篇钩子、站队问句 → [traffic-copy-craft.md](traffic-copy-craft.md)。社会稿形态 → [social-commentary-voice.md](social-commentary-voice.md)。

浓缩自 `wechat-mp-drafts/writing-guide.md` · `researcher-voice.md` · `wechat_mp_eval` 罚分项。

## 口吻定位

**研究员笔记**：有数字、有出处、有判断边界；不是券商研报腔，也不是聊天灌水。

- 用：**收盘、涨跌幅、板块、情绪、龙头、连板、成交额**
- 少用：**显著、持续、深度、全面、助力、赋能**

## 机械连接词（eval 扣分）

删除或改写：

- 综上所述、值得注意的是、与此同时、不仅如此
- 一方面…另一方面、总而言之、不可否认
- 在此背景下、随着…的不断发展

## 禁词与模板句（eval + 合规）

| 类型 | 示例 |
|------|------|
| AI 套话 | 感谢您的阅读、希望对您有帮助、点赞让我知道 |
| 财经合规 | 怎么玩、还在榜、领衔、100倍、稳赚 |
| 标题党 | 震惊、重磅、突发（`BANNED_TITLE_WORDS`） |

## 对称句式

避免成对排比：「不仅 X，而且 Y」「既 A，又 B」连用。改为一短句 + 数据。

## 具体感 checklist

- [ ] 正文含 **阿拉伯数字**（涨跌幅、家数、板数）
- [ ] 至少 1 处 **可验证名词**（东财、Tushare、板块名、股名）
- [ ] 段落 ≤3 行（移动端）；过长段拆开
- [ ] 2+ 分块标题（`>` 引用或 `一、`）
- [ ] **标题表意完整**（搜一搜路牌：读者不看正文也懂主题；禁止「返…」「暂…」半句）→ [sousou-content-rules.md](sousou-content-rules.md)

## news / hotspot 分工

- **news**：10 条清单；AI 点评各条不同角度
- **hotspot**：**单主题纯段落长文**（≥2000 字）；联网参考仿写；禁小标题、禁快讯列表、禁编审过程。完整 SOP → **[hotspot-deep-review.md](hotspot-deep-review.md)**
- **sector 导语**（手动稿）：第一句给「今日最强行业 + 一句逻辑」，勿空开场

### hotspot 元叙述硬禁（2026-07-30）

正文禁止导读式套话：`公开报道里有一条值得先记住`、`盘面一句`、`热搜在聊`、`双榜讨论`、`值得注意的是`、`来源公开信息`。首句直接写事实+数字。

### 11:00 话题讨论稿（2026-08-02）

`content_mode=discussion` 另见 `tv-morning-discussion-sop.md` §六。除上表外硬禁：

- 导读：`刷到这条热搜`、`第一反应`、`往下翻才知道`
- 结构：`一块…另一块`、`不是A而是B`、`惹眼…其实是`、`吵得最凶`
- 假口语：`挺寒的`、`基本盘`、`落锤`、`从别的口子`
- **热榜播报腔**：`百度把…送上热搜`、`微博词条#…#也在转`、`热度破亿`、`吵上热搜` — 写观众在吵什么，勿连读平台+词条
- **压缩怪句/弹幕缩写**（叙述层）：`进度飞`、`眼里没光`、`班味儿`、`贴角色`、`演技能补`、`添了乱`、`更碎`、`熟脸上阵`、`魔改，`、`劝退，`；禁止逗号串短短语（见 discussion SOP §六表）
- **分论点腔**：`一拨问`、`另一拨`、`两拨人`、`底下其实是`、`先说为什么`、`有人举`、`那种压了` — 像作文提纲，改成人话并列（见 social-commentary-voice §口语化）
- **分析报告腔**：`与其说`、`不如说`、`对…来说`、`不等于`、`预期天然`、`不补叙事`、`调节奏`、`看不见背后…指标`、`真正卡住的往往不是`、`服化道`、`一眼五年前` — 见 social-commentary-voice §分析报告腔

首段对齐蜘蛛侠金样：直接写**谁+发生了什么**，不要先写「你怎么刷到」。

社会民生热点另见 [social-commentary-voice.md](social-commentary-voice.md)：短段、物件立人、通报与民间记忆对照、引用块、克制感情色彩；**禁止正文 Markdown `**加粗**`**（公众号不渲染，会露星号）。

## 影视稿 tv_review（大白话）

剧评写给普通观众，不是写给影评系交作业。

| 避免 | 改用 |
|------|------|
| 戏眼、戏眼不在 | 重点不是、片子讲的其实是 |
| 意象、留得最久的意象 | 画面、留到最后的 |
| 场面堆叠 | 大战场面一通堆 |
| 正向反馈 | 好处、一声谢谢、一点回报 |
| 遮羞布 | 窗户纸、最后一点遮挡 |
| 拍实、拍得很直 | 演出来了、立住了 |
| 耳目一新 | 算久违、算新鲜 |
| 排片热度对得上 | 票房和口碑配得上 |
| 预告片素材 | 给预告片凑画面 |
| 痛感弱一层 | 没那么扎心 |
| 不帮忙煽情 | 不故意催泪 |
| 话却接不到以前那种熟 | 半句话/缺宾语；改成完整口语，如「再没有以前那种能乱开玩笑的熟络」 |
| 欲言又止（连用） | 话到嘴边又咽回去 |

改稿后全文搜上表左列，命中须改；并自查「那种+单字形容词」等半截话。
