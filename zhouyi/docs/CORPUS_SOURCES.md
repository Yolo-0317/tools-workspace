# 古籍来源与变占证据

采集日期：2026-09-12。原始文字来自公开古籍网页，程序从留存的网页文本抽取，未用模型生成或补写经文。`data/sources.json` 保存每份输入快照的 SHA-256；每段资料另存正文 SHA-256。

## 已入库范围

- 《周易》维基文库分卦页面：64 卦卦辞、384 爻辞、乾用九及坤用六、64 彖传、64 大象、384 小象。来源按页面固定链接保存修订号。例如[乾](https://zh.wikisource.org/wiki/周易/乾)。卦爻原文保留该页面标点与用字。
- [《周易本义》四库全书本](https://zh.wikisource.org/wiki/周易本義_(四庫全書本)/全覽)：64 卦经传及本义合录。作为每卦的注释材料，未做逐爻注释切片，不声称是仅含朱熹注语的纯注释。上下经以外各传的单独卷次不在本次入库范围。
- [《周易正义》四库全书本](https://zh.wikisource.org/wiki/周易正義_(四庫全書本)/全覽)：目前仅收录卷一乾卦开篇节录，包含卦辞及部分爻辞注疏。其余 63 卦没有《正义》补注，不能宣称《正义》全量覆盖。

所有材料校验状态均为 `source-extracted/structure-checked`，意为“来源抽取并通过结构检查”，不是人工逐字校勘。注释有未加现代标点和缺字图片的情况，缺字保留 `Image:` 标记。网页转录可能存在异文或误字，复核时应回看影印本。古代经传为公版；维基文库整理文本按页面所列 CC BY-SA 4.0 署名及相同方式共享条款使用。

导入器将《本义》的上下卦文字与固定八卦位串对应，而不单凭 Unicode 卦符。源页面蹇卦位置显示了困卦卦符，但文字为“艮下坎上”，据此正确归入第 39 卦；原始快照完整保留，不偷偷改写源文。

## 三爻变的前后十项

依据[《易学启蒙通释·考变占第四》](https://www.shidianguji.com/book/SK0061/chapter/1l9qr24ok8562)。网页原文快照见 `bianshi-source.txt`。项目设计阶段已核对原图 49—52，程序将图序明确固化为自下而上的爻位组合：

```
前十：123 124 125 126 134 135 136 145 146 156
后十：234 235 236 245 246 256 345 346 356 456
```

这里的“前后”是图序，不是变卦文王卦序，也不是变爻数量阈值。乾卦 156 变恒（第 32 卦），仍以本卦为主；234 变益（第 42 卦），以之卦为主。姤卦 156 变大壮（第 34 卦），仍为前十；234 变观（第 20 卦），为后十。两组交叉实例在测试中独立列出。
