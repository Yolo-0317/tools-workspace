## 每集最少记录项

1. 主题字和三句诗。
2. 15秒主内容结构。
3. 栀夏、阿砚的出现规则。
4. 人物与诗境的构图关系。
5. 片头和片尾话术。
6. 配音角色。
7. 当前状态和成片路径。
