# 当前系列配置

这是当前用户系列默认配置，不是所有视频的硬规则。最新单集指令可覆盖，其余沿用，不重新询问。

| 项目 | 当前设置 |
|---|---|
| 题材与受众 | 近期母婴、儿童教育场景拆解，默认面向家长；具体年龄按选题核对。 |
| 比例 | 2:3 竖版，成片基线 1080×1620、30fps。 |
| 时长 | 一分钟左右优先，约 60–70 秒为规划目标；完整自然对白需要更长时调整，不当硬上限。 |
| 主持人 | 栀夏、阿砚、小黑的既有 Q 版形象，三人可轮流介绍。 |
| 叙述 | 介绍方式，不默认问答，不编人物冲突凑篇幅。 |
| 人物动画 | 身体、姿态固定，仅当前说话者有嘴型；旁听、停顿、无声时闭嘴。不额外加点头、呼吸位移、眨眼和手势。 |
| 场景 | 丰富的具体道具、空间层次和有意义变化；避免大段静图及简陋文字卡。 |
| 动画方向 | 学习参考片的分层图形与资料拼贴；需要变化的对象用 HTML／JS、SVG／Canvas 或独立素材控制。每句同时安排主体和过程，不以换整张图代替机制演示；原布局与人物身体固定要求继续有效。 |
| 配图密度 | 当前系列至少每个完整句子有一张对应主体图；长句含多个解释点时可再拆。不能用同一图片裁切、描框或加字代替新画面。上方整段正文可保持不变，中部逐句换图。 |
| 文案 | 开头直接、快速引入悬念；自然完整中文，不刻意省字，不加生硬零食袋等结尾桥段。 |
| 互动引导 | 沿用“欢迎点赞关注收藏。”，开篇一段有效内容之后单独一小幕；单集已定位置不擅自挪动，不扩写长引导。 |
| 声音 | 现有豆包 TTS 声线；未要求配音时不抢先生成，已要求则继续合成。 |
| 顺序 | 先视觉后声音时留足时长，后续按真实对白修订；遵循当前授权阶段。 |

2:3 不保证所有平台界面都不遮挡。重要物件、人脸和字幕留边距，按实际发布界面检查，不杜撰通用安全区百分比。

## 本地定位

在 tools-workspace 先按 AGENTS.md 读取项目注册与入口。下面相对工作区根目录，使用前核对存在性和最新状态：

- 项目：`zhixia-feihualing/README.md`。诗词系列旧比例和电影写实风格不覆盖当前栏目。
- 素材：`zhixia-feihualing/assets/inventory.csv`，结合最近已确认单集定位三个 Q 版原图，不从成年设定重新生成不一致头像。
- 声线：`zhixia-feihualing/episodes/sanju-ban-buyaoye-10s/tts-voices.json`，键为 `zhixia`、`ayan`、`xiaohei`。引用路径，不复制凭证。
- TTS 客户端：`zhixia-feihualing/scripts/zhixia_tts_client.py`。旧五句诗词 CLI 的格式限制不等于三角色解释视频格式。
- 已跑通的时序样例：`artifacts/traditional-folk/ep01-wangchuan/video-v02/README.md`，该目录的 `engine/audio-sync.cjs`、`audio/alignment.json` 和 `qa/verification.json`。

这是现有工具入口与样例，不是新集可直接运行的流水线。王船 `synthesize.py` 含固定单集路径，复用前检查路径、缓存、语速与请求范围，不能直接执行重生成旧集。

研究用 `/private/tmp` 克隆不能作必备依赖。需要 art-motion 引擎时定位实际安装或在项目保存明确来源版本。资源缺失就说明，不能假装已加载素材。新集建独立目录，生成媒体登记现有台账，不复制旧集正文和完成状态。
