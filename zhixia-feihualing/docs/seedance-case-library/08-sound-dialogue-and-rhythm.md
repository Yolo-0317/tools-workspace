# 声音、对白与节拍

收录环境声、动作音效、音乐、对白、画外音、口型和音画同步案例。

案例按统一 `CASE-xxx` 字段登记；必须区分模型生成声音、上传参考和后期声音。

## CASE-067 第一视角材质 ASMR

- **来源：** [Seedance 2.0 正式发布](https://seed.bytedance.com/zh/blog/official-launch-of-seedance-2-0?view_from=content_recommend)
- **访问日期：** 2026-08-28
- **证据等级：** A
- **模型版本：** Seedance 2.0
- **输入方式：** 纯文字（T2V），模型联合生成声音。
- **中文结构化改写：** 暖黄柔光下，一双手依次轻刮磨砂玻璃、揉搓毛绒、敲击亚克力、捏气泡纸并划过木梳；近景动作缓慢，每种接触只对应自身材质声，无背景音乐。
- **可复用写法：** 让每个动作、材质和声音一一配对，并减少音乐干扰。
- **失败风险：** 多段物品切换可能产生手和道具跳变；官方也承认偶发音频失真。
- **栀夏适用性：** 可用于衣料、雪落、纸张和脚步的克制环境声设计。

## CASE-068 音频驱动的新闻播报

- **来源：** [SeedanceTips 50+ Prompt Library](https://seedancetips.com/prompts/seedance-prompt-library/)
- **访问日期：** 2026-08-28
- **证据等级：** C
- **模型版本：** 页面声称 Seedance 2.0，未见逐例结果证明。
- **输入方式：** 人物参考图 + 上传音频，10 秒。
- **中文结构化改写：** 主播正对镜头清晰讲话，以稳定手势配合上传语音；棚内柔蓝光和固定景别减少视觉变化，口型跟随音频。
- **可复用写法：** 口型任务应减少身体动作和镜头运动，并明确音频是上传参考。
- **失败风险：** 多人口型与长句仍不稳定；不应让画中人物承担诗词口型。
- **栀夏适用性：** 后续诗舞由 Seedance 生成无人声音乐、环境声和动作声；准确诗文与当代映射使用当前栀夏固定音色后期生成，画中人物不做朗诵口型。

## CASE-069 播客主持人的自然手势

- **来源：** [SeedanceTips 50+ Prompt Library](https://seedancetips.com/prompts/seedance-prompt-library/)
- **访问日期：** 2026-08-28
- **证据等级：** C
- **模型版本：** 页面声称 Seedance 2.0，未见逐例结果证明。
- **输入方式：** 人物参考图 + 上传对白，12 秒。
- **中文结构化改写：** 主持人坐在麦克风后自然说话，偶尔用手势强调；暖光和吸音板保持稳定背景，上传对白决定说话时长。
- **可复用写法：** 用“偶尔手势”限制动作频率，让口型和面部成为主任务。
- **失败风险：** 手靠近脸和麦克风时易遮挡或融合。
- **栀夏适用性：** 适合角色口播番外，不适合舞蹈诗境。

## CASE-070 多语言角色问候

- **来源：** [SeedanceTips 50+ Prompt Library](https://seedancetips.com/prompts/seedance-prompt-library/)
- **访问日期：** 2026-08-28
- **证据等级：** C
- **模型版本：** 页面声称 Seedance 2.0，未见逐例结果证明。
- **输入方式：** 角色参考图 + 对应语言音频，8 秒。
- **中文结构化改写：** 动画角色在明亮棚景以中近景完成一段问候，面部表情随上传语言变化，摄影机保持稳定。
- **可复用写法：** 语言、口型和表情集中在固定中近景，避免额外转身或景别切换。
- **失败风险：** 方言、快速音节和牙齿细节可能失真。
- **栀夏适用性：** 可用于角色问候测试，正式对白仍建议后期合成。

## CASE-071 音乐重拍驱动演唱会灯光

- **来源：** [SeedanceTips 50+ Prompt Library](https://seedancetips.com/prompts/seedance-prompt-library/)
- **访问日期：** 2026-08-28
- **证据等级：** C
- **模型版本：** 页面声称 Seedance 2.0，未见逐例结果证明。
- **输入方式：** 上传音乐 + 文字，12 秒。
- **中文结构化改写：** 乐队在大舞台演出，每个音乐重拍触发灯光闪变；摄影机从人群扫向舞台，烟雾、聚光和剪影共同响应节奏。
- **可复用写法：** 明确节拍触发对象，例如灯光、动作停点或转场，不只写“卡点”。
- **失败风险：** 人群、乐队、多灯光和手持镜头目标过多。
- **栀夏适用性：** 可将重拍换成古琴、鼓点或诗句落字时的环境变化。

## CASE-072 雨窗书写的低保真节奏

- **来源：** [SeedanceTips 50+ Prompt Library](https://seedancetips.com/prompts/seedance-prompt-library/)
- **访问日期：** 2026-08-28
- **证据等级：** C
- **模型版本：** 页面声称 Seedance 2.0，未见逐例结果证明。
- **输入方式：** 上传音乐 + 文字，15 秒。
- **中文结构化改写：** 动画女孩在雨窗旁写字，偶尔抬头；雨滴、笔尖和咖啡蒸汽保持缓慢循环，上传音乐只控制整体松弛节奏，不要求逐拍动作。
- **可复用写法：** 柔和音乐适合控制动作密度和停顿，不必强制每拍发生事件。
- **失败风险：** 循环动作可能机械重复，纸上文字不可依赖。
- **栀夏适用性：** 适合安静诗境的声音气质，但栀夏开场仍需一个清楚动作钩子。
