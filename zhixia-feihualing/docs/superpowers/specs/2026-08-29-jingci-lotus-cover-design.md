# 《晓出净慈寺送林子方》舞蹈版封面设计

## 目标

从用户已确认并完成朗诵字幕的 15 秒诗境原片中截取栀夏、朝阳与红荷共同达到高潮的画面，制作一张 1080×1920 竖屏发布封面。封面第一信息为“荷花一舞”，同时保留“栀夏”的系列角色识别，并让西湖晨雾、映日红荷和阿砚清楚可辨。

## 方案选择

- 11.400 秒帧的人物比例更大，但荷花数量不足，诗景高潮尚未完整形成。
- 13.800 秒帧中栀夏仰身展臂，太阳、红荷和阿砚均完整可见，人物与诗景最平衡，确定为正式底图。
- 14.400 秒帧的荷花最盛，但人物进一步缩小，更接近风景海报，不作为本集首选。

## 画面与排版

- 使用 `episodes/jingci-lotus-15s/assets/video/content-seedance-v01.mp4` 13.800 秒的无字幕原片帧，不从已经烧录诗句的正式成片截图。
- 直接按原始 9:16 构图使用 Lanczos 放大至 1080×1920，不裁切栀夏、阿砚、朝阳、前景荷花或右下角“AI生成”标识。
- 右上晨雾天空留白区采用三列竖排：系列名“栀夏”、主标题“荷花一舞”和题署“杨万里《晓出净慈寺送林子方》”。
- 主标题使用项目既有行楷粗体与暖象牙白；系列名和题署使用楷体与较低亮度象牙色；统一添加轻微深色柔影，不使用色块底板、描边框或贴纸。
- 文字不得遮挡太阳、栀夏面部和双臂、阿砚、前景红荷或水面主要倒影；题署保持手机缩略图可辨，但视觉权重低于“荷花一舞”。

## 图像边界

- 只允许原片截帧、Lanczos 放大和本地精确文字排版，不调用图像模型，不重绘、补画、换脸或改变角色和诗景。
- 不加入完整诗句、对白字幕、搜索标签、“AI美女舞蹈”等发布关键词或额外水印。
- 封面独立输出，不拼入视频，不反向修改已完成的朗诵字幕成片。

## 输出与验收

- 输出文件：`exports/jingci-lotus-dance-cover-v01.png`。
- 输出为 1080×1920 PNG、无透明空图且可完整解码。
- 手机缩略图中先读到“荷花一舞”，再识别“栀夏”和作品题署。
- 栀夏完整仰身展臂舞姿、阿砚、朝阳、红荷与西湖晨雾同时可辨；文字不遮挡角色或核心诗景。
- 在本集 README 与 `assets/inventory.csv` 中登记取帧时间、输出规格、来源和无重绘边界。
