# 世界观母版

## 核心设定

诗句中的文字并非普通符号。某些字保存着诗人在写下它们时留下的情绪、季节与景象。墨灵阿砚能够辨认并唤醒这些文字，但无法独自完成飞花令。

栀夏接出符合规则的诗句后，被选中的字才会完整离开书页，展开对应诗境。

## 飞花令机制

1. 阿砚阅读诗句并选出一个关键字。
2. 阿砚向栀夏提出接诗邀请。
3. 关键字出现克制的物理异常，如墨迹离开纸面。
4. 栀夏接出包含同一关键字的诗句。
5. 文字完整苏醒，诗境打开。
6. 栀夏与阿砚在诗境中面对一个情绪或选择，而不是完成知识测验。

## 叙事原则

- 诗词是进入故事的钥匙，不是课堂讲解材料。
- 每集只围绕一个关键字或一组高度相关的诗意。
- 超自然变化从微小异常开始，逐层升级。
- 栀夏和阿砚的关系成长与诗境同等重要。
- 观众能够在评论区参与接诗，但正片本身仍需有完整情绪回报。

## 诗境边界

- 诗境不等同于仙侠副本，不使用等级、法阵或战力体系。
- 诗境来自文字、墨迹、光影、风、水、季节和空间变化。
- 不随意改写古诗原意；需要改编时，以“受诗意启发的原创幻想”表述。

## EP01的世界观任务

EP01只需让观众理解三件事：

1. 阿砚会读诗。
2. 阿砚会邀请栀夏接诗。
3. 诗句里的字会回应并被唤醒。

EP01不承担解释阿砚完整来历、世界历史或所有规则的任务。
