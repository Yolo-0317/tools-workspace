# 工作流与证据规则

## 一、每日选股

1. 确认上海时区下当前时段与目标交易日。盘中使用上一完整交易日日线；盘后确认当日已完整入库；非交易日使用最近完整交易日。查询时间不等于数据时间。
2. 运行本地 V1.3 正式手动入口，保留返回的规则版本、SHADOW/LIVE、数据缺失、拒绝统计与全部分层。不要运行旧 combined 来兜底正式资格。依赖失败时先说明具体缺项；不自行降低完整性要求。
3. 热点发现取一次市场背景。同一轮复用同一返回，不对每只股票重复查询。若接口不支持指定日期，不把当前热点用于历史选股回放。
4. 从本地结果选择最多三只重点标的做外部复核：优先正式候选，其次准备中观察；没有正式候选时如实输出零只。用金融数据查当前价、成交和资金指标，用资讯搜索查近期公告与风险。核实标题、发布时间、原始来源和关联公司。
5. 有明确板块研究需求或需要解释重点方向时，对一至两个板块独立调用行业分析。板块强弱排序来自本地轮动检测器，不能根据两段妙想报告主观重排。
6. 妙想智能选股仅用于用户给出的筛选条件或明确的补充名单需求。输出单独标为“妙想观察名单 / 未获本地资格”；不能当作本地全市场扫描的输入替代品。已在本地结果中的股票可按代码关联，未出现的股票不能推定通过或精确推断未入选原因。
7. 用户明确要求资金、消息、财报或机构维度时，按专项路由补充。默认不对每个标的跑全部报告。输出数据截止日、候选分层、条件计划和未完成项。

本地数据缺失时可以继续公开数据研究，但整份报告应标记“研究观察，未完成本地资格验证”，没有正式候选、最大股数或可执行买入结论。妙想缺失而本地成功时，只能说本地筛选完成、外部复核未完成。

## 二、个股分析

1. 确认证券名称、代码和市场。综合诊断使用单只沪深京 A 股；本地选股宇宙以当前引擎为准，不能把妙想覆盖的港美股自动纳入。用户给多只时明确逐只分析，默认先处理其指定优先项；不把多只拼进单股专项接口。
2. 综合分析先运行 `diagnose_stock.py`，由程序判断交易时段。只问当前股价或单条公告时直接查数/资讯，不访问账户或运行完整诊断。
3. 对时效敏感的行情核验价格时间。妙想数据可交叉核对，不能以昨收覆盖盘中现价；来源冲突时显示各自时间与口径，必要时走已有 OpenCLI 原始行情采集。
4. 对用户明确的维度选择子 Skill：

| 问题 | 路由 |
|---|---|
| 均线、突破、回踩、买点、支撑压力 | 本地诊断 + 金融数据；不臆造技术面接口 |
| 主力、承接、资金净流入、筹码 | 资金面专项；规范 Query 为“公司中文名的资金面” |
| 公告、减持、监管、事件影响 | 资讯搜索核实原文 + 消息面专项；Query 为“公司中文名公告、新闻及其潜在影响” |
| 财务数值、估值数值 | 金融数据 |
| 业绩质量、财报解读 | 业绩点评；只选接口返回的已发布期间 |
| 券商、机构评级、盈利预测、目标价 | 机构观点；Query 为“分析公司中文名的机构观点” |
| 为什么涨跌 | 查行情与同期原始资讯，区分事实与可能解释；未安装涨跌归因 Skill 时不声称已调用 |

5. 宽泛“分析一下”默认本地诊断、行情、资讯即可；不伪造用户意图以强行触发所有专项。用户已明确要求多维综合分析时逐维执行，各子任务保留原始问题及关注维度。
6. 涉及持仓时使用本地最新的授权账户事实。不得把持仓股数、资金、成本、账户标识或私人策略正文发给妙想；外部请求仅含必要的公开证券名称和研究问题。账户数据缺失就不计算个性化仓位。

## 三、板块研究

本地轮动检测器确定强度、启动/回踩状态及观察名单；热点发现解释市场背景；行业分析解释用户指定板块的产业链、驱动和风险。按需要取板块成分或条件筛选。形成的名单仍是研究观察，不自动变成正式候选、监控规则或订单。

## 四、证据与异常

- 每项证据记录：证券/事件、来源、数据期间或发布时间、采集时间（带时区）、文件/原文链接、状态（已核验、待核验、过期、缺失、来源冲突）。不要用采集时间冒充原始发布时间。
- 核对正文的事件日期与表格发布时间、目标分析日。明确的历史回顾可以作背景；正文把过去事件写成当前事件、年份相互矛盾时，标记“时间冲突 / 待核验”，排除出当日催化和排序依据，回到原始公告或资讯核实。不能仅因接口成功或发布时间看似今天而放行。
- 对本地 `news_impact` 沿用其时间窗：海外公司/市场 24 小时，政策/产业 3 天，A 股公告/业绩/监管 7 天。更早信息可以保留为背景，不暗中刷新成新事件。财报历史数据注明对应报告期。
- 同一公告或同源转载合并为一个事件；热点、资讯、消息专项反复提到同一事件不能重复加分。妙想报告无原始出处时保留“外部解读待核验”。
- 当前报告不用于历史回测，不生成伪造的 PIT 历史证据。源报告未支持特定日期时明确限制。
- 鉴权失效停止该依赖，提示更新私有配置；不打印 Key、不循环授权。超时最多原参数重试一次，业务拒绝不重复调用。退出码为零仍需检查正文非空、业务错误、实体和日期是否符合请求。
- 上游“买入评级”不是本地 BUY_ALLOWED；SHADOW、账户限制和重大风险优先。上游目标价不替换本地结构失效价或冻结目标。
