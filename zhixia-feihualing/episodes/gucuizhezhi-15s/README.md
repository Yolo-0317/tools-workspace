# 《鼓催柘枝》15 秒试播集

## 单集定位

- 系列：《栀夏·敦煌十六舞》
- 编号：试播 01
- 舞蹈：柘枝舞意象原创编舞
- 形式：15 秒、9:16 竖屏、电影级高写实 CG、一镜到底
- 当前状态：首轮视频已保留并完成四句诗朗诵、竖排字幕与 1080×1920 保真高清后期；v02 修正提示词继续保留给未来重生成

本集用于先验证栀夏敦煌角色母板 v02 的人物与服化道稳定性，以及“纵向、横向、纵深”三次同等强度舞蹈爆发在 15 秒内的可读性。舞蹈只借鉴柘枝舞刚健与婀娜并存、鼓点鲜明的审美意象，不复刻任何现成剧目或舞者编舞。

## 关联诗句

唐·白居易《柘枝妓》前四句：

> 平铺一合锦筵开，
>
> 连击三声画鼓催。
>
> 红蜡烛移桃叶起，
>
> 紫罗衫动柘枝来。

诗句已在本地后期中使用栀夏固定声线完成四句画外朗诵与逐句竖排字幕，不提交给 Seedance，不要求画中栀夏说话或对口型。“紫罗衫”只是原诗内容，不改变敦煌固定的孔雀蓝、琥珀橙、象牙白与旧金服装配色。

## 生成输入

只上传一张图片：栀夏敦煌十六舞角色母板 v02 的 Seedance 上传版，并指定为 `@图片1`。不上传其他角色、道具、动作图、场景卡或参考视频。

角色卡仅用于锁定栀夏的脸、年龄感、身体比例、双环望仙式高髻、莲焰旧金冠、妆容、固定舞服、六组配饰和双层飘带连接点。不要复刻角色卡排版、三视图、表情格、文字、服装拆解区或可选法器。

## 舞蹈与画面

场景为傍晚敦煌丝路乐舞庭院。三次强动作分别使用纵向弹起、横向改面翻身和纵深沉提展开；中间由短距离交叉舞步、换重与躯干拧倾连接。全片只使用真实金色细沙作为核心视觉元素，三次依次形成窄柱扬沙、贴地横向薄沙带和由近向远的纵深沙痕。

摄影机只走一条低位斜向后退主路径，三次分别作降低微推、有限弧移加速、后撤抬升拉开。13—15 秒继续保持高能量弧形舞步，在运动余势中结束。

## 声音与后期

Seedance 原片只提供无人声敦煌风格配乐、画鼓重音，以及脚步、衣料、细沙和庭院环境声。本地后期只加入栀夏四句画外朗诵，不加入阿砚对白、额外旁白或吟唱；人声期间原声平滑压低，句间恢复鼓点与环境声。

## 首轮成片复盘

首轮视频的人物服装、敦煌庭院和连续舞蹈基本成立，但不能作为正式第一集，主要有六项问题：

1. 第一帧偏直立，没有直接落在设定的低位交叉弓步。
2. 第一、第二次高潮较强，第三次高潮缺少明确的纵深沉身再提展。
3. 第二高潮之后又出现接近完整的旋转，削弱三段动作差异。
4. 第一段纵向扬沙成功，但第二段接近环形沙尘，第三段没有形成贴地纵深沙痕。
5. 双手多次出现手抓飘带的错觉，上臂连接点不够稳定。
6. 约 12.5 秒后镜头拉得过远，人物缩得过小，第三高潮和结尾冲击力下降。
