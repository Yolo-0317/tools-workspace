## 一、起号三档定义（与 growth-playbook 对齐）

| 档位 | 含义 | 周期 | 牛马也智能（2026-06） |
|------|------|------|------------------------|
| **A · 跑通** | 稳定更新 + 阅读底盘 + 流量主入账 | **2–4 周** | **已到**：evening 三篇、日读 75–85、¥1.2–1.5/日 |
| **B · 站稳** | 周均 90+、搜一搜稳、推荐缓升 | **1–2 月** | **进行中**；推荐仍 3%–7% |
| **C · 做大** | 日读 200+、粉丝线性涨、推荐成第二引擎 | **3–6 月+** | 未开始；不作日常 KPI |

**判断「是否起号」**（吸收自 [人人都是产品经理·首次曝光](https://www.woshipm.com/share/5908037.html)）：

- **内容层**：单篇能偶发推荐读，但断更或混领域后会掉回低位
- **账号层（入池）**：持续发 **同垂直** 内容时，推荐占比 **稳定为正** 且缓升——才算账号标签化完成

牛马当前：**内容标签部分成立（搜一搜强）**；**账号入池未完成（推荐偏弱 + 6 月限推滞后）**。

## 二、平台机制（教程提炼 · 财经号校准）

### 2.1 三股流量（[卢松松](https://lusongsong.com/reed/18837.html) · [woshipm 5932632](https://www.woshipm.com/operate/5932632.html)）

| 来源 | 机制 | 牛马策略 |
|------|------|----------|
| **群发/推送** | 粉丝订阅消息 | 占比 ~4%；**忽略**，优化搜一搜与头条完读 |
| **推荐** | 看一看、文末相关、订阅号流排序、小绿书 | 新号弱；**合规第一**，见 §七 |
| **搜一搜** | 关键词匹配 + 社交链加权 | **主引擎**；标题热股名、原创·财经 |

### 2.2 推荐：内容标签 vs 账号标签（[woshipm 5908037](https://www.woshipm.com/share/5908037.html)）

```
稳定原创垂直更新 → 单篇内容标签 → 偶发推荐读
        ↓ 累积
合集标签 + 常读用户 + 互动数据 → 账号标签（入池）→ 持续推荐读
```

| 因素 | 教程要点 | 牛马落地 |
|------|----------|----------|
| 内容垂直 | 前 **5–10 篇** 同领域，忌混发 | 固定 `news+dragons+sector`，禁周中插情感/带货 |
| 更新频率 | 稳定 > _burst_；日更或周 2–3 | 交易日 **1 批 3 篇**；周六 skip；周日单 news |
| 原创 | 勾选原创，权重明显高于非原创 | 后台人工勾选；推稿前 `audit_recommendation_safety` |
| 合集 | ≤5 个，与文高度匹配 | 建议固定：**A股复盘 / 行业产业链 / 情绪龙头**（勿每月换） |
| 冷启动互动 | 朋友圈、群、在看、评论 | 财经清单号分享欲弱 → **控群转发每周 2 次**（growth_focus 配置），不刷量 |
| 常读用户 | 100 常读 > 1000 僵尸粉 | 不追买粉；追 **头条完读** 与 **搜一搜复访** |

### 2.3 推荐入口（[极致了·流量池指南](https://www.jzl.com/news/gzh-13)）

| 入口 | 牛马是否可依赖 |
|------|----------------|
| 看一看 | 中长期；限推期增量受压 |
| 文章底部相关推荐 | sector/dragons 垂直链内有效 |
| 订阅号消息流排序 | 常读用户↑ 后才有意义 |
| 小绿书 | **不做**（非主轴） |

### 2.4 搜一搜五维（[爱盈利手册](https://www.aiyingli.com/294001.html) · [woshipm 6183938](https://www.woshipm.com/share/6183938.html)）

| 维度 | 教程 | 牛马动作 |
|------|------|----------|
| 内容相关性 | 标题/首段/小标题含目标词 | 标题前 15 字 **热股名/板块名**；`wechat_mp_seo` |
| 账号权威性 | 认证、领域一致 | 个人号无企认 → 靠 **垂直 + 原创** 补 |
| 互动数据 | 留言、收藏、转发 | 文末 **1 个可回答问题**（monetization 问句）；禁「推荐 ♡」堆砌 |
| 社交关系链 | 曾读过你文的人搜索时优先 | 搜一搜复访靠 **股名命中** |
| 时效性 | 当日热点词 | news 绑当日人气榜；数据日写「M月D日收盘」 |

**工具**：`fetch_wechat_mp_sousou_opencli` · `sousou-analytics-sop.md` · `wechat_mp_seo_topics.md`

### 2.5 算法考核指标（教程共识 · 映射 eval）

| 指标 | 权重 | 工程/运营对应 |
|------|------|----------------|
| 点击率 | 高 | 标题 + 封面；`sanitize_public_title` |
| 完读率 | 高 | `wechat_mp_readability` · 段长 · 头条开篇 2 句结论 |
| 互动率 | 中高 | 留言问句；**不看在**（2024 后权重下降，但仍可作社交链） |
| 关注转化 | 中 | 简介/菜单；非财经 ≤1/周 |
| 打开速度 | 中 | 图不过大；banner 缓存 |

## 三、牛马也智能起号时间线（实测校准）

> 通用教程写「7 天推荐转正、30 天推荐 30%–60%」——**不适用于财经个人号 + 三篇同批 + 6 月限推**。以下以页面 picker=单日为准。

| 阶段 | 通用教程 | 牛马实测 / 预期 |
|------|----------|-----------------|
| 第 1 周 | 前 5 篇定标签 | 6/2–6/8 起量；6/8 evening 三篇首日 |
| 第 2 周 | 推荐 0→5%–15% | 6/9–6/10 稳态 75–85；推荐 **2%–12%** 波动 |
| 第 3 周 | 推荐扩大 | 6/5–6/12 **限推窗口**；推荐未归零但增量受压 |
| 第 4 周 | 稳定推荐 | 6/15 合规新标题后推荐仍 **3.9%** → **恢复滞后 1–2 周** |
| 第 2 月 | 搜一搜成主粮 | 交易日常搜一搜 **30%–63%**（已验证） |
| 第 3–6 月 | 推荐成第二引擎 | **目标**：推荐缓升至 8%–15%；非保证 |

**渠道结论**（与 growth-playbook §零-b 一致）：起号成功 **不以推荐为主**；**搜一搜 + 头条完读** 才是牛马的「起号完成」标志。

## 四、发表前必勾 SOP（人工 · 每批）

吸收 [jzl 流量池指南](https://www.jzl.com/news/gzh-13) §操作 1，合并 [draft-ops.md](draft-ops.md) §六：

| 步骤 | 操作 | 漏勾后果 |
|------|------|----------|
| 1 | **原创** 声明 | 推荐权重明显下降 |
| 2 | **允许推荐** 开关打开 | 直接不进推荐池 |
| 3 | **合集** ≤5，与文匹配（固定三合集，勿篇篇换） | 账号标签散乱 |
| 4 | `#` 话题与 `wechat_mp_seo_topics.md` 一致 | 搜一搜占位弱 |
| 5 | 标题过 `sanitize_public_title` / 后台无「不适合推荐」 | 财经限推 |
| 6 | 文首 **仅 1 段**【说明】 | 重复叠段伤完读 |
| 7 | **一次群发** 3 篇（+ 可选 market） | 个人号二次通知违规节奏 |
| 8 | 封面槽 1 牛马 → 2 多屏 → 3 财经 | 品牌识别 |

**头条选择**：同批内 **news** 放槽 1（搜一搜 + 完读最强），与教程「首屏抓人」一致。

## 五、冷启动互动（财经号适配）

教程常写「求在看、求转发」——牛马为 **清单型财经**，分享欲弱，按下列优先级：

| 优先级 | 动作 | 频率 | 禁忌 |
|--------|------|------|------|
| P0 | 发表后 **控群** 转头条（附 1 句结论，非硬甩链接） | 每周 2 次（`wechat_mp_growth_focus.json`） | 用 321 读当 KPI |
| P1 | 朋友圈转 **news 标题**（含热股名） | 发表当晚可选 | 不要三篇连发刷屏 |
| P2 | 文末 **1 个验证问句** 引留言 | 每篇 | 禁「建议买入/建仓」 |
| P3 | 股吧软 CTA（搜同名） | 交易日 15:15 飞书 | 正文不写微信/公众号 |
| 不做 | 互推买粉、搜一搜点击任务、矩阵霸屏 | — | 见 §九 拒绝 |

**新号 3–5 天拉起权重**（教程）→ 牛马靠 **evening 稳定批 + 搜一搜股名**，不靠互助群刷互动。

## 六、搜一搜起号专项（主粮）

### 6.1 关键词从哪来

| 来源 | 命令/文档 |
|------|-----------|
| 当日人气榜 | `load_wechat_top5_hot_picks` / news 标题 |
| 搜一搜下拉/联想 | OpenCLI plugin 10071 · `sousou-analytics-sop.md` |
| 行业榜 | `sector-discovery` → sector 标题 |
| 微信指数 | 后台 · 人工 occasional 查 |

### 6.2 布局规则

- **标题**：前 15 字含 **1–2 个** 可搜实体（股名/板块/事件）
- **摘要**：20–40 字复述标题钩子，禁空洞「每日复盘」
- **正文**：首段 80 字内再出现目标词 1 次；小节名用「产业链怎么拆」等 **可搜结构词**
- **密度**：教程写 1%–3%；牛马 **禁止堆砌**，以 `eval --traffic` 为准

### 6.3 复盘

```bash
cd stock-ai
uv run python -m scripts.tools.fetch_wechat_mp_analytics_opencli \
  --daily-series --series-begin YYYY-MM-DD --series-end YYYY-MM-DD \
  -o output/wechat_mp_recommend_daily_page.json
uv run python -m scripts.tools.fetch_wechat_mp_sousou_opencli
```

周表：`output/wechat_mp_weekly/` · 只调一类见 growth-playbook §五。

## 七、推荐恢复 SOP（限推 / 推荐长期偏低）

适用：后台「财产安全 / 不适合推荐」或 picker=单日推荐 **<5%** 持续 2 周+。

### 7.1 先做（教程 + 6/12 实盘）

1. **后台改已发违规标题**（不只改新稿）——`怎么玩` `还在榜` `领衔` `热股N条` 等
2. 新稿推前 `audit_recommendation_safety`（`wechat_mp_draft_batch` 已门禁）
3. 连续 **2–4 周** 合规更新，观察推荐% 是否从 ~4% 缓升

### 7.2 禁止（[jzl 紧急处理](https://www.jzl.com/news/gzh-13) §四）

- 批量删文（单日删多篇 → 异常判定）
- 焦虑日更加低质篇（推荐衰减；operations-sop 已写 2–3 篇/日上限）
- 无证据盲目申诉

### 7.3 可选暂停

限推严重时可 `echo YYYY-MM-DD > data/wechat_mp_skip_scheduled.date` 停 **1–2 天** 写稿，但 **勿停超过 3 天**（算法看稳定度）。
