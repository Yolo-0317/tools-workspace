# 智能体需求文档

> 示例：交易日收盘三栏目内容智能体  
> 格式参照：`智能体需求文档【需求样例】.docx`  
> 平台能力：同创智能体平台（Agent Studio）· WorkFlow · Skill 广场 · MCP 广场 · 自然语言取数 · 合规风控

---

## 智能体基本信息

| 项 | 内容 |
|----|------|
| **智能体名称** | 财经日更收盘复盘（行业研究 + 龙头情绪 + 热点快讯） |
| **需求提出部门 / 负责人** | 内容运营 / [填写] |
| **使用对象** | 财经自媒体运营人员、券商投顾 content 编辑、投教运营人员 |
| **同创平台组件** | 主 Agent（Function Call）+ WorkFlow 编排 + Skill 广场 ×4 + MCP 广场 ×5 + NL 取数 + 合规风控节点 |

---

## 核心需求描述（一句话）

在每个 A 股交易日收盘后，基于同花顺行情与资讯数据，自动生成 **3 篇** 结构固定、数据可追溯、合规可发布的财经长文（行业研究稿、龙头复盘稿、热点快讯合辑），供运营人员审核后分发至微信公众号等内容渠道。

---

## 使用场景说明

### 3.1 场景描述

财经内容团队每个交易日需在较短时间内完成「收盘复盘」类日更：一篇讲 **当日领涨行业与产业链逻辑**，一篇讲 **涨停龙头与情绪周期**，一篇汇总 **市场热点快讯并附短评**。纯人工产能低、结构易漂移；纯大模型易产生数据幻觉、AI 味重、触碰自媒体推荐红线。

希望在同创工坊上以 **WorkFlow 零代码编排**：自动取数 → 并行写三稿 → 交叉去重 → 合规质检 → 输出终稿，非研发人员也可调整 prompt 与阈值。

### 3.2 场景中的使用对象

- 财经自媒体运营（C 端公众号、MCN）  
- 券商投顾 content 团队（企微/APP 内容库）  
- 投教运营编辑  

### 3.3 场景发生的频率

- **A 股交易日**：盘后执行 **1 次**（建议 18:30 定时触发）  
- **休市日**（可选扩展）：仅生成热点快讯合辑，或跳过

## 输入内容说明

### 输入内容来源

| 输入内容 | 内容来源 | 同创能力映射 |
|----------|----------|--------------|
| 行业板块涨跌榜、领涨股、板块量价摘要 | 问财行情库 / iFinD | MCP 广场 `sector_board_rank` + **自然语言取数** |
| 涨停家数、连板高度、EOD 龙头名单 | 问财行情库 / iFinD | MCP 广场 `limit_up_dragon_eod` + 金融插件 |
| 72h 热点快讯 Top10（按互动排序） | 同花顺资讯接口 | MCP 广场 `hot_news_topn` |
| A 股人气榜 Top10（过滤 ST，供交叉校验） | 问财行情库 | MCP 广场 `stock_popularity_rank` + NL 取数 |
| 账号品牌规范、合规词表、成稿样例（脱敏） | 需求方提供 | **金融知识库 RAG**（可选） |
| 机构自有数据（若有） | 本地库 / 第三方 | **数据盒子** 对接 |

### 输入内容说明

- 所有输入须带 **交易日 T** 与 **指标溯源**（来源、更新时间），供正文引用与质检校验。  
- 行业主线由 **当日数据投票** 决定，不写死单一板块（如科技）。  
- 快讯输入包括：标题、摘要素材、发布时间、来源链接（若有）。  
- 龙头输入包括：代码、名称、连板数/涨停类型、所属题材。

## 输出内容 & 形式

### 输出形式

单次 WorkFlow 执行输出 **1 个 JSON 包**，内含 3 篇稿件：

```json
{
  "trade_date": "2026-06-20",
  "batch_id": "evening-20260620",
  "articles": [
    {
      "kind": "sector",
      "title": "A股电力｜XX股份领涨：产业链怎么拆？",
      "digest": "……（≤128 字）",
      "content": "……（Markdown 正文）",
      "hashtags": ["#A股", "#电力"],
      "meta": {
        "primary_sector": "电力",
        "lead_stock": "000001.XX",
        "data_sources": ["iFinD", "问财"]
      },
      "quality": {
        "score": 82,
        "ai_flavor": 15,
        "compliance_pass": true
      }
    },
    {
      "kind": "dragons",
      "title": "……",
      "digest": "……",
      "content": "……",
      "hashtags": ["#A股", "#龙头"],
      "meta": {
        "deep_write_codes": ["000001", "000002"],
        "eod_board_match": true
      },
      "quality": { "score": 80, "ai_flavor": 12, "compliance_pass": true }
    },
    {
      "kind": "news",
      "title": "……",
      "digest": "……",
      "content": "……",
      "hashtags": ["#A股", "#快讯"],
      "meta": { "news_count": 10 },
      "quality": { "score": 78, "ai_flavor": 18, "compliance_pass": true }
    }
  ],
  "gate_report": {
    "passed": true,
    "title_dedup_ok": true,
    "cross_dedup_ok": true,
    "failed_reasons": []
  }
}
```

> Nice to Have：`content_html`（微信公众号友好 HTML），由平台模板节点生成。

### 输出要求

#### 一、行业研究稿（`sector`）

- 标题形态：`A股{主线}｜{领涨股}领涨：……`（**≤32 字**）；禁以「资金流」作主标题词。  
- 开篇 **80 字内** 给出当日结论（研究员口吻：数字→机制→映射→验证）。  
- 正文含：行业涨跌背景、产业链拆解、代表股观察（**≤4 只**，每主题 ≤2）。  
- 代表股 **不得与** 快讯稿热股代码重复。  

#### 二、龙头/情绪复盘稿（`dragons`）

- 标题含情绪词 + 龙头 + 板数；与行业稿、快讯稿 **标题互不雷同**。  
- 正文 **≤2 只** 深写；连板数/高度须与 EOD 榜 **一致**，禁止幻觉个股。  
- 含情绪周期判断（涨停家数、高度、退潮信号等，基于 MCP 数据）。  
- 文末含合规免责表述（「复盘笔记」口径，非「投资日记」）。  

#### 三、热点快讯合辑（`news`）

- **10 条** 快讯；每条：摘要 **230–250 字** + AI 短评 **120–220 字**。  
- 短评须点名板块/龙头/可验证动作，禁空泛套话。  
- 任意 **3 条以上** 摘要或短评不得雷同。  
- 标题：**热股名前置** 或「事件 + 股名」；含 `？` 或 `！` 之一。  

#### 四、三稿共性

- 调性：打工人视角 A 股复盘；**不喊单**；禁止 emoji。  
- 单段约 **≤120 字**；节间用短过渡句，禁「往下看」「→」等导流腔。  
- 宏观政策 + 主观判断，非纯新闻复述。  
- 全文经 **合规风控节点**（平台 1B 模型 + 自媒体财产风险规则）扫描后输出。

## 智能体能力边界

**平台内应实现（同创组件）：**

| 能力 | 实现方式 |
|------|----------|
| 数据获取与融合 | MCP 广场 + 自然语言取数 + 数据盒子 |
| 三稿并行生成 | WorkFlow 并行分支 ×3 + 子 Agent |
| 写作方法论 | Skill 广场：`fin-researcher-voice`、`fin-evening-trilogy` |
| 去 AI 味改稿 | Skill 广场：`fin-anti-ai-flavor` + ReAct 改稿节点（最多 2 轮） |
| 交叉去重 | 主 Agent Function Call：标题相似度 + 热股代码去重 |
| 合规审计 | 平台合规风控 + Skill：`fin-mp-compliance` |
| 定时触发 | WorkFlow Cron（交易日 18:30） |

**允许：**

- 在数据整理基础上进行归纳总结与逻辑分析  
- 基于行情数据给出 **观察方向与验证动作**（非买卖指令）  
- 对快讯给出 AI 短评与机制解读  

**不允许智能体自行完成（Out of Scope）：**

- 微信公众号草稿箱 upsert / 发表（由使用方接 Webhook 或人工粘贴）  
- 流量主、搜一搜看板、CPS 插入等运营层动作  
- 替代 iFinD 深度研报产品

## 使用限制与规则

1. **不对具体个股给出买卖建议**，不预测收益或具体点位。  
2. 当某行业/龙头 **数据缺失或榜位无法确认** 时，仅输出可获得数据范围内的背景与关注点，不编造代码或板数。  
3. 标题/摘要/正文须通过 **财产风险审计**（禁「怎么玩」「还在榜」「领衔」「热股」「A股必读」等，详见附录）。  
4. 质检门禁未通过（总分 < 75 或 AI 味 > 20 或合规失败）时，**不输出终稿**，仅输出 `gate_report`。  
5. 数据段以 MCP/NL 取数结果为准；ReAct 改稿 **仅允许修改** 标题、开篇、连接词、禁词，**不得篡改** 数字与个股代码。

## 成功标准与验收方式

### 成功标准

1. 能清楚说明 **当日行业主线为何成立**（有涨幅/领涨股/机制链条）。  
2. 龙头稿深写标的与 **EOD 榜一致**，情绪判断有数据支撑。  
3. 快讯 10 条结构完整，短评有实质、无批量套话。  
4. 三稿标题互不雷同；行业代表股与快讯热股无代码重复。  
5. 内容 **不涉及具体投资建议**；合规节点 0 失败。  
6. 非研发人员可在同创平台 **30 分钟内** 跑通一次完整交易日流程（含查看质检报告）。  

### 范例事件

**事件**：2026-06-XX 交易日收盘，东财行业涨幅榜前列为「电力设备」「有色金属」，涨停高度板为某 5 连板龙头，当日财经门户热议「XX 政策」及 3 只人气股。

**预期效果**：同创 WorkFlow 在 **18:30 触发** 后 **≤30 分钟** 内：

- 生成行业稿（主线=电力设备，领涨股与榜一致）；  
- 生成龙头稿（深写 5 连板标的，板数与榜一致）；  
- 生成快讯稿（10 条含该政策条目，短评不雷同）；  
- `gate_report.passed = true`，三稿可直接进入运营审核队列。  

### 验收方式

1. **查看生成内容示例**：提供 1 个完整交易日的 JSON 输出包 + 3 篇 Markdown 正文。  
2. **内容运营人员试用反馈**：人工改稿时间从基线（如 2 小时）降至目标（如 20 分钟）以内。  
3. **数据一致性抽检**：龙头稿 `deep_write_codes` 与 MCP EOD 榜比对，通过率 100%。  
4. **合规抽检**：随机 10 个交易日批次，财产风险审计 0 失败。  
5. **平台交付物核对**：WorkFlow 样板间可克隆、Skill ×4 可引用、MCP 清单文档齐全。  

### 竞品 / 示例展现形式

- 同花顺问财对话机器人（C 端 Agent 问答，非固定三栏目长文）  
- 同创已有案例：直播底稿、脱水研报、投顾收盘点评（ToB 内容，结构较自由）  
- 本需求差异：**固定三栏目 + 交叉去重 + 自媒体合规门禁 + 日更批量 JSON 输出**
