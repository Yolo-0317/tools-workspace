# 妙想股票工作台设计

## 目标与已确认方案

用户认可前一轮“本地 V1.3 选股与新版诊断 + 妙想补充证据”的建议，并要求创建统一 Skill。采用编排型 Skill：复用现有命令，不新建选股算法，不替换数据库或修改策略参数。相比完全用妙想选股，该方案保留本地可复现门禁；相比只安装零散技能，该方案补上统一路由、证据检查和交付格式。

## 范围

- 新建 `miaoxiang-stock-workbench`，源文件放 `.cursor/skills/`，通过用户技能目录链接供 Codex 发现。
- 三种模式：每日选股、单股分析、板块研究；纯价格或新闻查询直接路由已有妙想基础 Skill。
- 补齐热点、行业板块、资金、消息、业绩、机构观点六个官方依赖；保留原有四项。
- 上游来自 2026-09-15 官网登录下载的本地合集。安装副本清除内嵌 Key，读取现有 `.env` 的 `EM_API_KEY`；不复制密钥到仓库。
- 每日选股指按需处理当日请求，不创建定时任务。现有命令可保存其正常计划和采集记录，Skill 不额外写持仓、监控或订单。

## 权威与降级

本地候选资格、计划、规则版本、运行模式与账户限制优先。妙想报告提供研究上下文，不能直接写成已验证结构化风险数据，不能改动正式候选排名或股数。新发现重大风险尚未复核时，明确暂停执行建议并保留本地原始结果。

日线完整日、盘中采集时间、财报期间、新闻发布时间分别标注。当前妙想报告不能用于过去日期的回测。缺少本地数据时输出“研究观察 / 无本地资格验证”，不凑满候选；缺少外部分析时保留本地结果并列出未完成项。

## 交付与验证

入口 Skill 保持简短；工作流、命令、输出契约和验收案例按需加载。检查 YAML、依赖存在性、CLI 帮助、内嵌密钥清除、相对链接和典型任务路由。不为安装验证运行全市场选股或写账户数据；可用一次公开热点查询验证新增依赖的真实调用链。
