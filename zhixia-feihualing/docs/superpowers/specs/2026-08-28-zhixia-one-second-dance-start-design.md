# 栀夏诗境一秒强起势设计

## 目标

让所有尚未生成的新诗境在第一秒内明确进入舞蹈主体，解决开场虽已看见栀夏、但只做呼吸、抬手、衣料摆动或等待镜头推进，导致舞蹈启动偏慢的问题。

## 固定时间门槛

- 第一帧：栀夏已经处于具有方向、重心和后续发力趋势的蓄势舞姿，脸部可辨；不从自然站立、静止凝视或整理衣袖开始。
- 0.3 秒内：开始第一次明确踏步或换重，同时启动一条大幅上肢或躯干运动轨迹。
- 0.8 秒内：形成第一个抓眼、完整、脸部可见的全身舞姿，观众能够明确判断主体已经在跳舞。
- 1.0 秒内：离开初始落点，进入主体移动路线，或已经进入完整旋转的准备动作。

呼吸、眨眼、转眼、轻微抬臂、衣料自行摆动和摄影机运动都不能单独计作舞蹈启动。

## 与现有规则的关系

- 本规则替换旧的“0.5 秒内产生第一个清楚动作”最低标准；旧标准只保证人物先动，不能保证舞蹈已经起势。
- 诗景仍是叙事基础，高冲击力中国古典舞身韵仍负责增强诗境，不把开场改成脱离诗意的舞台表演。
- 第一秒的踏步、换重、上肢轨迹和离开落点必须顺接本集已经选择的移动路线、完整旋转、衣料反馈、动作特效与摄影机主路径，不额外增加第二套开场动作。
- 阿砚不抢占开场动作，不增加特写；仍按角色母版保持约 40 厘米尺度与外扩纸纤维形象。

## 提示词写法

最终 Seedance 正文用平台可观察的自然语言表达四个节点，可以写入第一个宽时间段，但不得写内部动作或镜头代码。推荐结构：

> 第一帧栀夏已在可发力的蓄势舞姿中，脸部清楚可见；0.3 秒内踏步换重并启动大幅上身轨迹，0.8 秒内形成第一个完整抓眼舞姿，1 秒内离开初始落点进入主体移动或旋转准备。

具体姿态、路线和环境反馈必须根据诗句重新设计，不能逐集复制示例措辞。

## 验收

逐帧检查 0、0.3、0.8 和 1.0 秒附近：

1. 第一帧是否已经蓄势而非自然站立。
2. 0.3 秒是否出现脚下踏步或重心变化，以及同步的大幅身体轨迹。
3. 0.8 秒是否形成脸部可见的完整舞姿。
4. 1.0 秒是否离开初始落点，进入主体路线或旋转准备。
5. 是否误把微表情、衣料摆动或摄影机运动当成舞蹈起势。

任一项不满足，即判定“舞蹈启动偏慢”，下一轮优先强化第一秒动作链，不通过增加无关特效或加快摄影机来掩盖。
