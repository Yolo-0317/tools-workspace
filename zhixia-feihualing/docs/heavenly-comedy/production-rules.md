# 天宫日常：道具与审片规则

更新：2026-09-04。适用于栀夏、阿砚的天宫生活喜剧；不改动已确认角色卡的服装、鞋履，也不追溯返工已接受的视频。

## 提示词交付门禁

每次给出或修订提示词，先执行[官方提示词交付门禁](../seedance-official-prompt-gate.md)。保留剧情相关道具的开场位置、动作因果和结尾状态，精简剧本解释与重复限制；不要把精确秒表当成模型执行保证。审查记录放在可复制正文外，不擅自修改用户已确认的角色卡、剧情或时长。

## 道具保持仙侠世界观

- 现代生活烦恼和口语可以制造反差，但不能因此默认出现现代实物。未经用户明确批准，手持衣物和生活道具仍须属于古风仙侠环境。
- 衣物不能只写“衣服”“湿外衫”或“黑色衣物”：须明确古风形制、材质和可见结构。例如“独立手持的墨灰色古风交领宽袖外衫，丝绸质地、布带系结；展开后可见交领与宽袖”。
- 排除现代衬衫、T恤、卫衣、夹克、西装、牛仔服，以及拉链、现代衬衫翻领、罗纹袖口、品牌印花等现代成衣特征。不要将墨色本身视为错误，重点检查剪裁与结构。
- 手持衣物与角色身上的仙衣必须分开描述，避免脱换衣、衣物融合或凭空变形。
- 不要求固定场景图；仙房可直接用文字描述，场内道具仍按以上规则检查。

## 生成前与审片检查

- 生成前：逐件确认剧情道具的形制，不把“古风”仅写在背景或角色段落里。
- 审片：检查道具初次出现、展开与使用三个节点，尤其查看领口、袖口、扣合方式和材质。
- 对出现的现代物品区分“用户明确设计的反差”与“模型无意生成的穿帮”，不自行将后者合理化。
- 单条被用户接受不代表相同问题成为后续标准；记录偏差，之后提示词与审片继续规避。

## 天宫采访：栀夏的待机姿态与视线

- 姿态始终服从当集剧情。栀夏需要持物、施法、展示物件、回应环境或完成其他明确动作时，双手按该动作自然表演，不强制交叠。
- 只有在栀夏站立倾听、双手空置且暂时没有剧情动作的待机片段，才默认双手在腹前自然交叠，手腕、手指放松，保持端庄优雅；动作结束后可自然回到这一姿态，不要求全片保持。
- 视线必须随采访关系和笑点推进：阿砚提问时，栀夏自然转眼或小幅转头看向阿砚；思考或说出包袱时，可短暂移向斜前方；异常效果发生后，根据剧情选择看向效果来源或用余光看向阿砚。
- 不写“全程目视前方”“始终看向镜头外”等持续锁死视线的要求。需要栀夏装作若无其事时，只限制她不做夸张反应，不等于全片固定头眼方向。
- 审片时分别检查待机姿态是否自然、剧情动作是否优先、每轮问答的视线承接和结尾反应。无动作时双手持续下垂或视线全程固定可作为单条成片的小偏差接受，但不得继承为后续默认。
