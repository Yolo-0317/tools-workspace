# Seedance 证据分级提示词规范重写设计

## 目标

依据已完成的 80 条 Seedance 公开案例库，重写《栀夏飞花令》的全局视频提示词规则，修正两个已经由成片和公开案例共同暴露的问题：把“具体动作完全自由发挥”误当成复杂舞蹈保障，以及把“一条连续摄影机路径”误写成全程单调匀速运动。

新版继续保持低成本诗境流程，但明确不同输入方式的能力边界。规则只描述模型可观察的动作、镜头和物理结果，不恢复项目内部编号、逐毫秒时间轴或冗长负面清单。

## 依据

真源为 `docs/seedance-case-library/README.md` 及其专题文档。规则优先采用 A/B 级案例支持的结论：

- 官方查尔斯顿和双人花滑案例证明，高复杂运动提示会写出步法、重心、方向、身体协作、衣料反馈和摄影机响应，而不只写舞种与气质。
- Scenic 舞蹈案例证明，固定全身构图、动作分镜和音频参考可以分别提高脚步可读性、动作顺序和节拍控制；纯文字自由舞蹈容易退化为原地摆臂。
- 官方骑乘、武侠和社区一镜打斗案例证明，复杂镜头更有效的表达是“主体动作发生—摄影机作出反应”，而非互不相关的运镜术语堆叠。
- 官方发布同时明确，多主体一致性、文字还原和复杂编辑仍存在改进空间，单次公开成功不能写成稳定保证。

C 级词汇案例只用于补充普通摄影语言，不单独支撑全局能力结论。

## 采用方案

采用“证据分级输入 + 有限自由舞蹈 + 主路径与动作反应 + 可裁剪语义顺序”。

不采用以下方案：

- 小幅修补旧规则：旧“六段固定正文”“四项舞蹈约束后完全自由”和“只能有一个运动目的”等绝对表述会继续产生冲突。
- 全导演式精密提示词：为每条诗境写完整编舞、逐拍时间轴和多组焦段，会重新增加模型竞争目标，也不适合只上传两张角色母版的低成本流程。

## 输入控制三级

### 基础级：两张角色母版 + 纯文字

- 默认用于十秒单一视觉事件和一段中等复杂度短舞句。
- 两张角色母版只锁定栀夏、阿砚的原创身份、结构、造型、材质和比例，不作为首帧或场景构图。
- 文字可以定义开场构图、人物动作、摄影机路径、环境结果和结束状态。
- 不承诺严格复现复杂脚步、连续跳转、多人接触、逐拍卡点或多阶段特效。

### 控制级：增加一张分镜或场景参考

- 动作分镜用于明确姿态顺序、脚步、重心、转身和收势。
- 场景图用于固定复杂空间、主光源、前景遮挡和最终揭示目标。
- 每个额外素材只能分配一个主要职责；提示词必须写清“哪个素材只控制什么”。
- 状态卡仍为可选素材，不因存在而默认成为视频第一帧。

### 迁移级：增加自有或获授权参考视频

- 用于复杂连续编舞、严格节拍、特定动作或特定运镜路径。
- 必须声明保留项和替换项，例如保留动作、镜头和节拍，只替换角色与环境。
- 不使用来源不明、未获授权的网络舞蹈或影视片段。
- 参考视频提高控制力，但不表述为逐帧复刻保证。

## 舞蹈规则：从完全自由改为有限自由

新版不恢复 Dxx 动作编号、具体舞名、固定身韵术语、精确角度或逐拍自创编舞。现有古典舞动作库继续作为历史参考，不重新成为默认动作清单。

基础级提示词仍保留“中国古典舞身韵、轻盈克制、连续自然、不遮脸”的气质边界，但这四项不再是完整舞蹈指令。每段舞句还必须包含以下可观察条件：

1. 移动或脚步：人物不能全程原地站立；说明横向、斜向、前后或小范围绕行中的一种。
2. 重心变化：至少一次清楚的下沉、提起、左右转移或由一脚换到另一脚。
3. 方向或空间层次：至少一次转向、侧身、进退或高低变化。
4. 上肢与衣料反馈：说明手臂路径或袖、裙、外衫如何受动作带动并自然回落。
5. 起止状态：说明从何种站姿/动作开始，并以何种面向和身体状态结束。

提示词不得要求 Seedance 执行固定动作名称，也不得写“具体动作、连接与收势完全自由发挥”。可使用的默认表达是：

> 栀夏完成一段具有清楚移步、重心变化和方向层次的中国古典舞短舞句；动作轻盈克制、连续自然，面部始终可见，衣袖和外衫随转身产生真实惯性并在收势后自然回落。具体连接由模型在这些可观察条件内自然完成。

如果需要指定姿态顺序、连续旋转、跳跃或严格卡点，必须升级到控制级或迁移级，而不是继续加长基础级文字。

## 摄影规则：一条主路径加动作触发反应

每条一镜到底提示词仍只有一条主路径，但“主路径”表示全片的空间方向与摄影目的，不表示摄影机只能保持一种匀速动作。

完整镜头契约包含：

1. 起始景别与机位。
2. 主路径的方向、相对主体的位置和主要速度。
3. 至少一个前景、地面或背景参照，用于产生可见视差。
4. 最多两次由主体动作或环境事件触发的摄影机反应。
5. 结尾景别、人物状态和需要揭示的环境目标。

允许的摄影机反应包括小幅推近、后拉、降低、升高、有限弧移、速度短暂加快或放慢。每次反应必须紧接一个可见触发动作，例如人物转向、沉身、触枝、落雪或抬眼；反应完成后继续服从原主路径。

不允许把推、拉、摇、移、升降、环绕、甩镜和移焦无因堆叠，也不允许绕到栀夏背面、脱离人物追逐粒子或突然更换主体。复杂多镜头叙事使用独立分镜格式，不伪装成一镜到底。

## 栀夏开场与双角色稳定

- 首帧已经可以辨认栀夏，0.5 秒内第一个清楚动作来自栀夏。
- 开场动作优先是抬眼、转身、迈步、抬袖、触物或其他能立即展示面部与服装轮廓的动作，不用纯风景、纯特效或阿砚单独画面开场。
- 阿砚足底至耳尖约 40 厘米，通过栀夏脚踝、地面痕迹、近旁植物或道具形成尺度参照，不使用错误的微型宠物尺度。
- 阿砚保持双耳、四足、单尾、朱砂额印、琥珀眼、纸墨身体与暖金纹样，只承担抬头、转耳、注视和短距离跟随等低复杂度反应。
- 栀夏与阿砚的身份、结构、数量和比例优先于舞蹈、运镜、景观和特效。

## 提示词语义顺序

不再要求最终正文机械分成六个固定段落。每条提示词按以下语义顺序自然书写，删除当集不需要的内容：

1. 原创虚拟角色声明、参考图映射和每张素材的唯一职责。
2. 时长、画幅、场景、时间、主光源和总体视觉质感。
3. 栀夏开场动作、主体事件和环境因果结果；复杂事件可用三个宽时间段表达。
4. 当前输入等级与对应舞蹈/动作条件。
5. 摄影机契约：起点、主路径、速度、视差、动作反应和结尾揭示。
6. 必要角色稳定、真实物理、声音边界和少量已发生过的高风险禁止项。

三个宽时间段仍是十秒复杂事件的推荐工具，不再是所有提示词必须满足的格式。单一连续动作可以使用自然顺序描述；只有事件顺序确实重要时才写宽时间段，不恢复逐毫秒 TTS 轴。

## 声音与文字边界

- Seedance 负责无人声背景音乐、环境声和动作声。
- 对白、诗句、字幕、屏幕文字和精确口型继续由后期完成。
- 需要音乐卡点的复杂舞蹈应上传自有或获授权音频，并明确少数关键节拍；基础诗境不写逐拍时间表。
- 原创虚拟角色声明继续固定在正文开头，不对应现实人物、艺人、真实动物或既有影视动漫角色。

## 验收标准

- 全局规范明确基础级、控制级和迁移级三种输入方式及其能力边界。
- “中国古典舞身韵、轻盈克制、连续自然、不遮脸”保留为气质边界，不再被描述为完整舞蹈约束。
- 基础级舞句必须写出移动/脚步、重心、方向/层次、上肢/衣料反馈和起止状态。
- 全局默认不再出现“具体动作、连接与收势由 Seedance 自由发挥”或同义的完全放任表述。
- 一镜到底规则包含起点、主路径、速度、视差、最多两次动作触发反应和结尾揭示。
- 全局默认不再把“一条连续摄影机路径”解释为禁止一切推近、后拉、升降或有限弧移。
- 栀夏首帧可辨认并在 0.5 秒内先动；阿砚保持约 40 厘米和原创结构。
- 原创虚拟角色声明、参考素材职责、声音后期边界和内部代码禁令继续保留。
- 三个宽时间段从强制格式降为复杂十秒事件的推荐工具；逐毫秒 TTS 轴继续禁用。
- 《白雪》提示词未在本阶段改写，已发布内容未返工。
- 相关静态检查全部通过，且没有把用户已有的无关工作区修改纳入提交。

## 非目标

- 不在本阶段生成图片、视频或音频。
- 不为每首诗重新建设固定动作库。
- 不把 C 级社区词汇表提升为平台能力保证。
- 不在本阶段决定《白雪》的新舞句或新摄影机路径。
