## 默认规则

| 部分 | 原规则 |
|---|---|
| 范围 | 沪深 A 股，包含创业板/科创板；不擅自缩为主板 |
| 时间 | 截止指定交易日，向前450个自然日的数据；至少130根日线 |
| 价格 | 不复权收盘价 3–200 元，含边界 |

| 默认突破硬条件 | 当日上穿MA60，或收盘突破此前20日最高价；同时当日量/含当日5日均量 >=1.5，当日涨幅 >=3% |
| 筑底硬条件 | 默认关闭；原公式仍保留计算标签，不擅自开启 |
| 五因子满分 | 趋势25、形态25、动量20、量能15、支撑压力15；每项先执行加减分再截断在0与满分之间 |

## 指标口径不能替换

- “量比”是当日成交量 / 含当日的5日均量，不是行情页面分时量比。
- MA20斜率比较5根之前，MA60斜率比较10根之前。
- 20日振幅 = (含当日20日最高价 - 最低价) / 最低价；突破比较的是不含当日的前20日高点。
- 缩量比 = 最近20日均量 / 紧邻此前60日均量。
- MACD 为EMA12减EMA26，信号为其EMA9，柱值为两者之差（不乘2）。EMA `adjust=False`。
- RSI14 使用涨跌额分别做 `ewm(alpha=1/14, adjust=False)`；KDJ为9日区间、K/D的alpha均为1/3。不能直接套平台同名指标。
- OBV按收盘涨跌方向累计成交量。支撑/压力使用20/60日高低点、均线和整数价，保留原算法；它们是技术参考，不是自动订单价。
- 所有具体加减分、边界、截断和标签以冻结计算器为准，禁止模型凭文字估分。

## 数据获取与分阶段选股

1. 先检查当前六技能来源的有效缓存，再用mx-xuangu预筛。原条件不改，不把平台量比替代原公式。
2. mx-data按明确实体、日期、不复权口径获取日线，先小范围验证字段、单位与截断；不使用Tushare、数据库或网页回填。
3. 交易日历、停牌、上市日期等完整性证据同样仅来自六技能。450自然日窗口和至少130根要求不变，不能把部分历史冒充完整输入。
4. 当前mx-data输入适配未完成：交付预筛研究候选与缺项，V3标未完成，不运行旧来源评分冒充当前结果。后续适配必须核对rawTable、fieldSet、单位、复权、实体和日期并验证后才能启用，不能把新数据标为mx-finance-data或tushare-daily。
5. 数据具备且适配通过后，可在本地执行冻结公式；计算不是新增数据源。消息、资金、财务不加进原五因子分数。
