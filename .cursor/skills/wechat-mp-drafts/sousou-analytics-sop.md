# 牛马也智能 · 搜一搜数据怎么用（运营 SOP）

> **前提**：后台只能看 **汇总**，不能看「谁搜完哪篇才关注」。  
> 入口：`mp.weixin.qq.com` → **广告与服务** → **搜一搜** → **数据看板**；或小程序 **搜一搜数据助手**。  
> 代码对齐：`wechat_mp_seo.py`、`wechat_mp_traffic_checklist.py`、`stock-ai/docs/wechat_mp_seo_topics.md`。  
> 看板页 `pluginloginpage?pluginuin=10071` 内嵌 **「快速入门：在微信，如何优化你的搜索效果」** → 与 [微信开放社区 · 搜一搜优化教程](https://developers.weixin.qq.com/community/develop/doc/00080c559584e8578b312b8256bc09) 同源。

**账号定位（2026-08）**：热点评论（社会 / 文娱 / 职场 / 公共事件）。搜一搜优化以 **可搜实体词**（案由、片名、人名事件、金额）为主轴；财经 evening 三篇词表仅 **偶发手动财经稿** 参考。

## 〇、官方「优化搜索效果」→ 牛马执行清单

微信搜一搜团队强调：**账号侧**（昵称/描述/菜单/认证/可搜）+ **内容侧**（稳定更新、标题摘要正文自然含词、体验好）。**堆砌同义词、菜单 SEO、通用词昵称**会被打压。

### 账号侧（改一次，季度复核）

| 官方建议 | 牛马也智能 | 动作 |
|----------|------------|------|
| 昵称有品牌、勿占通用词 | **牛马也智能** ✓ | 勿改名为「热点八卦」等纯流量词 |
| 描述写清服务与领域 | [account-packaging.md](account-packaging.md) 介绍定稿 | **热点观察、多方观点**；勿荐股、勿「A 股复盘」 |
| 菜单名具体可理解 | 更新节奏 / 近期文章 / 免责说明 | 勿加「龙头」「复盘」类财经菜单 |
| 鼓励认证 | 按主体能力 | 有企业/商标则做 |
| 允许昵称被搜 | 隐私设置 | **开启**「允许通过名称搜索到本账号」 |
| 稳定更新 | **11:00 话题讨论 + 交易日 15:00 热点深评** | 停更 &gt;3 天先看板会跌 |

### 内容侧（每篇自动 + 发布时人工）

| 官方建议 | 仓库已实现 | 你还须做 |
|----------|------------|----------|
| 标题清晰完整、不截断半句 | `build_hotspot_title` 动态预算 + 短语压缩 | 人工扫残缺半句；见 **wechat-mp-writing/sousou-content-rules.md** |
| 正文单主题、勿拼盘 | hotspot / discussion 单主题纯段落 | 禁止快讯清单体塞进深评 |
| 标题/摘要含 **可搜实体**，勿堆砌 | `enrich_title_for_search`、`enrich_digest` | 前 15 字含 **案由/片名/事件名**；勿一句塞 3 个热词 |
| 正文自然出现垂直词 | `wechat_mp_monetization` + `traffic` 清单 | `wechat_mp_eval --kind hotspot --traffic` 推稿前跑 |
| **停留、收藏** 利于排序 | 短段、引用块、对照（见 social-commentary-voice） | 原创分类选 **社会/娱乐/资讯**；点 **#** 话题 |
| 持续原创 | LLM + 人工改稿 + 合规 | 禁止纯 AI 不审即发 |

### 主稿型标题（对齐看板 + `title_sousou_hook_score`）

| kind | 前 15 字优先 | 搜一搜句式 |
|------|--------------|------------|
| `tv_review` / discussion | **事件实体**（谁/啥事/片名） | 完整表意；路人秒懂发生啥 |
| `hotspot` | 同上 + **数字/案由** | 单主题；禁 `#A股` 打头当主粮 |
| `news`（手动） | 要闻、政策、社会 | 72h 要闻；非主轴 |
| `sector` / `dragons` / `top5`（**偶发财经**） | A股、行业、龙头 | 仅手动财经稿时用；见 §三 附录 |

**勿用**：私聊拉高阅读的 outlier 当模板；看板里 **荐股/代码** 不进标题。

### 每周闭环（看板 → 只改一类）

1. `pluginuin=10071` 看板抄四行指标 + 热门搜索词 Top5 + 热门文章 Top3。  
2. 点 Top 文看 **文章搜索词** → 下周同稿型 **换实体词、不换句式**。  
3. **只调一类**：`discussion` 标题实体 / `hotspot` 开篇 / 简介（三选一）。  
4. 推稿前：`wechat_mp_eval --kind hotspot --traffic`；讨论稿走 tv-morning §九。

## 一、两套数据，不要混口径

| 来源 | 路径 | 回答什么 | 和搜一搜看板关系 |
|------|------|----------|------------------|
| **搜一搜数据看板** | 广告与服务 → 搜一搜 | 用户在 **微信搜索** 里找到你后的阅读/关注/搜索词 | **本 SOP 主数据源** |
| **内容分析 · 流量来源** | 统计 → 内容分析 → 群发篇/日报 | 某篇阅读里 **搜一搜占比 %**（和 **推荐**、朋友圈等并列） | 验算哪篇吃搜一搜 vs **推荐流** |
| **用户分析 · 增长来源** | 统计 → 用户分析 → 增长来源 | 「搜索公众号名称/微信号」等 **关注渠道** | **≠** 文章搜一搜 |

| 指标 | 含义 | 热点号怎么用 |
|------|------|----------------|
| **搜索后阅读** | 搜索结果页 **点击** 次数 | 标题实体词是否可搜、可点 |
| **搜索后关注** | 搜索路径 **新关注** | 简介 + 首篇体验 |
| **热门文章** | 按 **搜索曝光** 排序 | 哪类热点稿占搜索（常与推荐高稿不同） |
| **文章搜索词** | 用户 **用什么词** 找到该文 | 下篇标题用 **真实词**，勿臆造 |
| **热门搜索词** | 账号相关高频词 | 月度校准；**实体词 &gt; 大盘泛词** |

## 二、用法 ① — 每周看一次看板（约 15 分钟）

### 何时

- **每周一**看 **近 7 天**；大改标题策略后再看 **近 14 天**。  
- 新发后 **至少等 3～7 天** 再评价搜索表现（索引有延迟）。

### 记什么

落盘：`stock-ai/output/wechat_mp_weekly/YYYY-MM-DD.md`

| 字段 | 判断 |
|------|------|
| 搜索后阅读 | 升 → 标题实体词有效；降 → 停更、节假日、标题残缺 |
| 搜索后关注 | 升 → 搜来的流量愿关注 |
| **关注/阅读比** | &lt;0.3% 持续 → 改 **简介/菜单/首篇** |
| 内容分析 **推荐 %** | 热点号主引擎；与搜一搜分开看（见 [content-analytics-sop.md](content-analytics-sop.md)） |

### 决策树（看完板后只做一件事）

```
搜索后阅读 ↓ 且 搜索后关注 ↓
  → 停更？标题前 15 字是否含可搜实体（案由/片名/事件）？简介是否仍像股票号？
搜索后阅读 ↑ 但 搜索后关注 ─
  → 优化简介、关注回复、稿末星标句；少改稿型
搜索后阅读 ↑ 且 搜索后关注 ↑
  → 保持 11:00+15:00 节奏；从「热门文章」复制成功 **实体词结构**
仅「用户分析-搜索公众号名称」高、看板低
  → 加强「牛马也智能」品牌 + 简介含「热点观察」
推荐占比高、搜一搜低
  → 正常（热点验证路径）；优化完读与稿末星标，勿强行改回财经 SEO
```

  --expect-url-substr 'pluginuin=10071' \

## 三、用法 ② — 热门搜索词 → 改标题/摘要

### 流程

1. 看板 → **热门搜索词** → 筛 **文章板块**。  
2. 分三类：

| 类型 | 例 | 动作 |
|------|-----|------|
| **品牌** | 牛马也智能 | 简介、菜单一致 |
| **事件实体** | 片名、案由、地名+事件、金额 | **优先写进 discussion / hotspot 标题前 15 字** |
| **泛词** | 热点、社会、文娱 | 摘要可带；标题勿只靠泛词 |

3. **相关搜索词** 选 **1 个** 并入下周标题，勿堆砌。  
4. 推稿前：

```bash
cd stock-ai
uv run python -m scripts.tools.wechat_mp_eval --kind hotspot --traffic
```

### 主稿型 ↔ SEO（改词真源 `wechat_mp_seo.py`）

| kind | 标题前 15 字优先 | 摘要 / # 方向 |
|------|------------------|---------------|
| `tv_review` / discussion | **事件实体**、完整表意 | 社会/文娱资讯类话题；勿财经默认 |
| `hotspot` | 实体 + 数字/案由 | `#热点` + 当日实体；**勿 `#A股` 打头当主策略** |
| `news`（手动） | 要闻、政策 | `#财经快讯` 等（仅财经快讯稿） |

### 附录：偶发手动财经稿（非主轴）

| kind | 标题优先 | 备注 |
|------|----------|------|
| `sector` | A股、行业、产业链 | 仅手动 |
| `top5` | A股、选股、收盘信号 | 仅手动 |
| `dragons` | A股、龙头、情绪 | 仅手动 |
| `market` | A股、收盘复盘 | 仅手动 |

**禁止**：荐股、牛股、代码进标题（`HASHTAG_BANNED`）。

### 从「文章搜索词」反哺

1. 热门文章 Top1～3 → **文章搜索词**。  
2. 记下用户 **实际搜索词**（往往比标题更土、更具体）。  
3. 下周 **复用句式 + 换实体词**，勿整句抄袭。

## 四、用法 ③ — 热门文章 → 调整稿型比重

### 怎么认 kind（对照草稿标题）

| 标题特征 | kind | 定时 |
|----------|------|------|
| 社会/文娱话题、纯段落讨论 | `tv_review` / discussion | **11:00** |
| 单主题热点长文 | `hotspot` | **交易日 15:00** |
| 行业/产业链/板块 | `sector` | 仅手动 |
| 选股/5只 | `top5` | 仅手动 |
| 龙头/情绪 | `dragons` | 仅手动 |
| 快讯/10条 | `news` | 仅手动 |

对照 `data/wechat_mp_draft_slots.json` 近期标题。

### 月度复盘表（搜一搜热门文章 Top5）

| 排名 | 标题 | 推断 kind | 文章搜索词 Top1 | 下月动作 |
|------|------|-----------|-----------------|----------|
| 1 | | | | |

### 决策（只调一类）

| 现象 | 动作 |
|------|------|
| **discussion** 占 Top3，词偏事件实体 | 11:00 选题加强路人可懂实体；标题勿只有人名 |
| **hotspot** 搜索高、关注低 | 改简介/星标句；正文加短段与引用块提完读 |
| **hotspot** 推荐高、搜一搜低 | 正常；保持推荐流口吻，勿强行加 `#A股` |
| 财经 kind 进 Top（手动稿） | 单篇可保留财经 SEO；**账号简介仍用热点定位** |
| 各稿搜索都低 | 查标题是否残缺；是否停更；合规限流 |

### 和「推荐流」分工

- **搜一搜**：关键词匹配、收藏、停留（标题实体、摘要一致）。  
- **推荐**：完读、星标引导、留言（`wechat_mp_monetization`）。  
- **推送阅读一般、搜索高** → 多改标题实体词；**推荐高、搜索低** → 多改开篇与完读，勿回退财经模板。

## 五、发布闭环（搜一搜 × 仓库）

每个 **发布日**（人工点发送后）：

1. 脚本已：`enrich_title_for_search` + `enrich_digest` + 正文 `#` 行（`WECHAT_MP_HASHTAG_INLINE=1`）。  
2. 后台：**原创** + 分类（社会/娱乐/资讯）+ 话题。  
3. 发表标题记入周表，便于对「文章搜索词」。

每个 **推稿日**（11:00 / 15:00 批次后）：

```bash
uv run python -m scripts.tools.wechat_mp_draft_batch --batch tv_trial --dry-run
uv run python -m scripts.tools.wechat_mp_draft_batch --batch hotspot_afternoon --dry-run
# 讨论稿：手改缓存 repush 后再 eval / §九 清单
```

## 六、勿做清单

- 用看板词 **堆砌** 标题。  
- 把「搜索公众号名称」当成「搜一搜读完文章关注」。  
- 无数据时大改 prompt（先查停更与合规）。  
- 为搜一搜把账号 **改回 A 股复盘** 简介或菜单。  
- 期待 API 拉搜一搜看板（无官方接口；内容分析见 content-analytics-sop）。
