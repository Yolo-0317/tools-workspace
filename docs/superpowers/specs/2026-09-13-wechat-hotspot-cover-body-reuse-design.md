# 公众号热点封面与正文图片复用规则设计

## 目标

用户主动热点稿在只有少量合格真实图片时，不再把封面图片从正文素材中排除。让已核验图片得到完整利用，同时保持正文最多三张图片的现有上限。

## 最终规则

- 合格真实图片共一至三张时，全部放入正文。
- 从这些图片中选择一张兼作封面；兼作封面的图片仍保留在正文。
- 合格真实图片超过三张时，按与文章主题的相关性、信息价值和画面质量精选三张放入正文，并从这三张中选择一张兼作封面。
- 正文图片上限保持三张，不因封面复用增加到四张。
- 所有图片继续遵守现有来源核验、抖音搜索留痕、图注和版权边界；不得为了凑数使用无关图片或生成图片。

## 数据与渲染约定

- 选中的封面来源必须写入 `cover_source.json`。
- 封面同时进入正文时，必须显式设置 `"reuse_in_body": true`。
- 正文图片选择阶段不得因为某张图片已被选作封面而将其剔除。
- 预演和推送前检查应同时报告封面数量与正文图片数量；当合格图片为一至三张时，正文图片数量应与合格图片数量一致。

## 异常处理

- 没有合格真实图片时，继续按现有门禁停止推送。
- 图片来源无法核验、与正文无关或不适合公开展示时，不计入合格图片数量，并记录排除原因。
- 微信草稿重建后，应回读正文 HTML，确认实际图片标签数量，而不能只依据本地预演结果判断。

## 验证标准

1. 一张合格图片：封面一张，正文一张，且为同一来源图片。
2. 两张合格图片：正文两张，其中一张兼作封面。
3. 三张合格图片：正文三张，其中一张兼作封面。
4. 四张及以上合格图片：正文仍为三张，其中一张兼作封面。
5. 现有来源核验、正文三图上限和零图拒推门禁保持有效。
