# 简选小电 · 发布运营 SOP（v1）

> **真源**：本文件为发布节奏与冷启动的**唯一运营 SOP**。  
> 成稿版式见 [template-jianxuan.md](template-jianxuan.md)；搜一搜词表见 [discovery.md](discovery.md)。  
> 机器可读节奏：`stock-ai/data/wechat_mp_commerce_template.json` → `publishing_rhythm`

**适用**：已上线的 **独立公众号「简选小电」**（非财经五槽预览）。

## 一、原则（有行业共识的部分）

| 原则 | 说明 | 参考（运营复盘，非微信官方） |
|------|------|------------------------------|
| 质量 > 篇数 | 垂直干货号常见 **每周 2～3 篇**，而非日更长文 | [掘金 2025 起步指南](https://juejin.cn/post/7545378879961006089)、[路由通垂直号频率表](https://nctoro.com/a280839) |
| 算法看互动质量 | 推荐/搜一搜更看 **完读率、收藏、分享**，不是推送次数 | [稿轻松 流量池文](https://a.jzl.com/exp/142)、完读率运营文（行业普遍说法） |
| 稳定 > 爆发 | 冷启动要 **同垂直、可识别、节奏稳定**；忽快忽慢伤标签 | [子午笔记 0→两位数](https://www.webziv.com/archives/96791.html)、[人人都是产品经理 起号](https://www.woshipm.com/share/5908037.html) |
| 慎日更长文 | 同质日更易疲劳取关；长文完读易掉 | [数英 取关调查](https://www.digitaling.com/articles/38653.html)、[路由通 频率与取关表](https://nctoro.com/a265325) |
| 新号要样本 | 前 **~10 篇** 同栏目、同模板，利于搜一搜与账号标签（经验值，非官方） | [91运营 搜一搜起号](https://www.91yunying.com/139211.html)、本 skill `discovery.md` |

**不采纳**：为冲量日更 1500 字以上同质 `guide`；跨类蹭财经热点。

## 二、分阶段节奏（折中 SOP）

### 阶段 A：冷启动（独立号上线后第 1～4 周）

**目标**：让系统识别「租屋 · 小家电 · 买前对照」；积累搜一搜样本；不牺牲完读。

| 周次 | 公众号正式推送 | 建议时段 | slot |
|------|----------------|----------|------|
| **第 1 周** | **3 篇** `guide`（可连发 3 天，或隔日） | 20:00–22:00 | 厨房 / 清洁 / 环境各 1 篇，同 `jianxuan-v1` 模板 |
| **第 2～4 周** | **每周 3 篇** | 周二、周四、周六 20:00–22:00 | 2×`guide` + 1×`review` 或 `trend`（按栏目表轮换） |

**外链引流（不算公众号日更）**：

| 渠道 | 频率 | 内容 |
|------|------|------|
| 朋友圈 | 每篇推文后 **1 次**（或每周 2～3 次） | 预览截图 + 一节「三类买错的」清单，不问买 |
| 租房/同城群 | 每周 **2～3 次** | 干货节选 +「完整对照在公众号」 |
| 小红书/知乎（可选） | 每周 **1～2 条** | 同一篇拆 3 图；口径与公众号一致，披露推广 |

**第 1 周连发 3 篇**：对齐独立号上线清单（名称/简介/头像/合集）+ 搜一搜标签建立，见 [discovery.md](discovery.md)「独立号上线」。

### 阶段 B：稳定期（第 5 周起，或完读率连续 2 周 ≥40%）

| 项 | 标准 |
|----|------|
| 频率 | **每周 2～3 篇**（默认 **3**：2×`guide` + 1×`review`/`trend`） |
| 时段 | 固定 **周二、周四、周六 20:00–22:00**（晚间打开率为运营统计常见高峰，见 [路由通](https://nctoro.com/a265325)） |
| 降频条件 | 完读率 **连续 2 周 &lt;35%** → 降为 **每周 2 篇** `guide`，先改结构/篇幅，不加篇 |
| 升频条件 | 完读 **≥45%** 且搜一搜来源升 → 可维持每周 3 篇，**不要**提到日更 |

### 阶段 C：严禁

- 日更多篇长文 `guide`（除非单篇改为 800～1200 字轻量稿，且仍须垂直）
- 停更 &gt;2 周（取关与标签衰减，见 [数英](https://www.digitaling.com/articles/38653.html) 断更讨论）
- 同一周换栏目、换标题风格、换模板节名（冷启动「单变量」原则）

## 三、每周执行清单（发布日）

**发文前**

- [ ] 复制 [jianxuan-guide-v1.md](../../stock-ai/output/templates/jianxuan-guide-v1.md)，栏目与当周 CPS 词一致
- [ ] 标题前 15 字含场景词；摘要句尾 `（文内有合作推广）`
- [ ] `--dry-run` 通过

**发布时**

- [ ] 原创；分类 **生活 / 家居**
- [ ] 终端「推荐 #话题」点选（≤5）
- [ ] 预览：简选顶栏、正文 #话题条、暖色免责、非财经图

**发文后 24h 内**

- [ ] 朋友圈 1 条节选
- [ ] 回复每条留言
- [ ] 后台记录：阅读来源、完读率、收藏率

## 四、数据复盘（每周一次，每月汇总）

| 指标 | 健康参考（行业区间，以你后台为准） | 动作 |
|------|-----------------------------------|------|
| 完读率 | 40%～60% 常见为「正常」；&lt;35% 预警 | 缩短开篇、清单前置、控制 1200～2000 字 |
| 搜一搜来源占比 | 新号逐月上升即正常 | 标题/摘要加场景词 |
| 取关率 | 推送日略升正常；持续升高 | 减频、减硬广感、检查 CPS 与正文是否一致 |
| 收藏率 | 高于分享则加大「对照表」体 | 延续 `guide` 模板 |
| CPS 点击 | 与正文品类一致才优化选品 | 调 `WECHAT_MP_FOOTER_PICK_KEYWORD` |

**决策树（简版）**

```
完读 ≥45% 且搜一搜升 → 保持每周 3 篇
完读 35～45%           → 保持每周 2～3 篇，优化标题/开篇
完读 <35% 连续 2 周    → 降为每周 2 篇 guide，不改垂直
停更 >14 天            → 先发 1 篇 guide 复更，再恢复阶段 B
```
