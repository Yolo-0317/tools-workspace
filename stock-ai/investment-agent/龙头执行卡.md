# 龙头执行卡

> 最后更新：2026-06-02  
> **适用范围**：东财掘金 **仿真户**（`emquant-sim` / `dragon_main.py`）  
> **不适用于**：券商实盘 jywg、微信持仓监控、`alert_rules` 主轨同步

**交易单位**：A 股最小 **100 股（1 手）**；游资轨单龙默认 **1 手试探**，观察池 **最多 3 只**。

---

## 与持仓执行卡的关系（双轨）

| 执行卡 | 账户 | stock-ai 用途 | 下游 |
|--------|------|---------------|------|
| **`持仓执行卡.md`** | 实盘 / 主账户 | 监控、微信、看板持仓、Agent 主决策 | MySQL `alert_rules`、`export_emquant_rules`（主轨 `main_combined` 可选） |
| **`龙头执行卡.md`（本文件）** | **仅仿真户** | 情绪识别、龙头池、游资买卖纪律 | MySQL `emotion_cycle_*` → `export_emotion_dragons` → Win11 `dragons.json` |

**冲突时**：实盘与主账户纪律 **一律以 `持仓执行卡.md` 为准**；本卡 **不得** 用来指导实盘加仓、接深套老仓或突破主轨仓位上限。

**方法论详述**：`情绪周期日检卡.md`（字段说明与复盘清单）；本卡 = **可执行的仿真操作摘要**。

## P0～P3 仿真纪律（掘金 `dragon_head_gm` 已实现部分）

### P0 — 阶段 gate（最高）

| 阶段 | 仿真动作 |
|------|----------|
| **退潮 / 冰点** | **禁止买入**；有仓 **无条件清仓** |
| **分歧** | **禁止新开**；有仓仅观察，手动逻辑「只留核心龙」未自动减仓 |
| **启动 / 发酵 / 高潮** | 允许按 P1 条件 **试探买入**（须 `allow_new_open=1`） |

附加 gate（代码强制）：昨日涨停溢价 **≥1%**；炸板率 **<40%**；单日涨幅 **≤5%** 才买。

### P1 — 买入（v2 增强试探）

- 标的须在 **当日龙头观察池** 内，`checklist_pass ≥ 5`，**≥2 板**
- **龙位**：启动 #1；发酵 #1+#2；高潮三只
- **仓位**：#1 40% / #2 25% / #3 15% × 当日 `position_cap_pct`（整手）
- **结构买点**（须满足其一）：**re-seal** 准回封 / **pullback** 分时回踩 / **weak2strong** 弱转强
- **禁买**：09:30–09:45；≥3 板且已涨 ≥7%；一字板；仿真以 60s bar 近似，**非真实排板**

### P2 — 卖出（v2）

| 触发 | 仿真动作 |
|------|----------|
| 阶段 → 退潮 / 冰点 | **sell_all** |
| **破板**（曾触板，现涨幅 <5%） | **sell_all** |
| 浮盈 **≥7%** | **sell_half**（减半） |
| 浮盈 **≥10%** | **sell_all** |
| 当日相对昨收 **≤-5%** | **sell_all** |
| 持仓 **≥5 个交易日** | **sell_all**（时间止损） |
| 破板 / 卡位 / 次日竞价割 | 日检卡人工；仿真 **未实现** |

### P3 — 禁止

- 用游资轨预算 **接主账户深套仓**（梅花等 — 见持仓执行卡红线）
- 退潮期 **连板接力**
- 单日追涨 **>5%**
- 题材混战（`theme_count>3` 时 `exclude_list` 含「多题材混战」）
