# 《典籍里的中国·徐霞客游记》文章设计

## 目标

为公众号“栀夏未完成”的「典籍里的中国·一集一点」栏目准备第八篇。文章不写旅行鸡汤，也不鼓励无视身体风险的冒险主义，而是回答：徐霞客为什么愿意用三十多年亲身核实书本与前人留下的答案。

## 标题与核心判断

- 标题：《腿已经走不动了，徐霞客为何还不回家？》
- 核心判断：徐霞客被记住，不只是因为走得远，而是因为当书本答案与现场观察不一致时，他愿意为核实事实承担时间、健康与安全的代价。
- 讨论张力：有目标、持续获得新信息的行动可以称为坚持；无视反馈、只重复同一动作则更接近执念。文章承认徐霞客选择的代价，但不把它写成所有人都应复制的人生答案。

## 正文结构

1. 用节目中徐霞客脚已受伤仍登山的场景开篇，百字内提出“为何还不回家”。
2. 交代他长期行走与记录，但把读者判断从“旅行”升级为“实地考察”。
3. 以游记中的日期、路线、天气和自然观察说明，他在做现场记录，不是只写风景感受。
4. 以长江源流考察和《溯江纪源》支撑“不肯照抄书里的答案”，谨慎表述历史认识与现代地理结论的差异。
5. 写徐母与“游必有方”，说明母亲的支持包含规划路程、计算时间和按期返回，不渲染成抛下家庭。
6. 写晚年身体受损与归乡，完成第二次判断升级：坚持并非没有代价，价值来自目标与成果，而非受苦本身。
7. 落到普通人的共同处境：权威说法、既有经验与亲眼所见不一致时，是否愿意继续核实。
8. 回到开篇并留下站队问题：回报不确定、代价明确时，是继续验证还是及时停下。

## 篇幅与排版

- 1800—2200 字，信息完整后不为凑字重复观点。
- 手机端短段落，一句一段与中短段交替，不设小标题、不使用列表式正文。
- 后期由 Agent 加 2—3 处高亮，配图优先使用央视节目公开页面或权威媒体节目报道图。
- 结尾保留星标提醒、栏目篇次与下一篇《道德经》预告；栏目顺序以 `stock-ai/data/wechat_mp_dianji_zhongguo_topics.json` 为准。

## 事实边界

- 节目开场、母子具体对白、穿越时空互动均标明为节目艺术呈现，不当作史实。
- “丈夫当朝碧海而暮苍梧”注明出自陈函辉《徐霞客墓志铭》，不写成《徐霞客游记》原句。
- “吾荷一锸来，何处不可埋吾骨耶”核对文献语境后再用，不为增强气势随意放置。
- “游必有方”完整呈现《论语》语境与徐母的解释，不写成无条件支持远游。
- 长江源流、喀斯特地貌、旅行年限、晚年身体状况均须从节目资料、可靠文献或权威报道复核。
- 不使用“国际公认领先西方一两百年”等缺少直接权威出处的夸张结论。
