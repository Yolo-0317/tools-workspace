# stock-ai 公开短线挑战者检查点记忆设计

## 目标

在 `stock-ai` 的专项工程记忆中追加一条可长期复用的阶段检查点，使后续任务在上下文压缩或新开任务后，能够快速恢复公开短线挑战者的真实进展、结论和下一步。

## 写入位置

追加到 `.cursor/rules/memory-python.mdc` 的“记忆条目”区域，标题日期为 `2026-08-20`。不创建第二套平行 Memory，也不改项目路由。

## 记录内容

检查点只记录稳定工程事实：

- 已实现的公开短线挑战者研究能力与三阶段边界；
- 630 个交易日真实研究窗口及 378/126/126 切分；
- 三条轨道的验证期核心指标和全部未达标结论；
- `point_in_time_complete=true`、`test_outcomes_read=false`、`trade_permission=NO-TRADE`；
- 已发现的验证比较器错误标签、正收益窗口口径问题和 V3 对照缺失；
- 外网 MySQL 应使用项目环境配置，不再强制改写为内网地址；
- 下一步先修复验证比较器、接入 V3 对照并重跑 `research`，在符合门槛前不执行 `freeze/test`。

## 隐私与安全边界

不记录数据库账号密码、完整连接串、持仓、个人交易决策、股票代码或其他个人投顾记忆。外网数据库只描述“使用项目环境配置”，不固化敏感地址。

## 验证

写入后检查：

1. 新条目仅出现一次，标题和日期正确；
2. 关键状态与真实 JSON 产物一致；
3. 不包含密码、持仓或个人交易信息；
4. Git 暂存范围仅包含本设计文档和后续明确的 Memory 修改。
