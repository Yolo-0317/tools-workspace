# 公众号艺术配图

需要封面、正文插图、艺术图解，或用户觉得配图太规整、缺少美感时读取。这里只定义文章的视觉设计与验收；实际生成遵循当前图片工具的 Skill。只整理 Skill 或找工具时，不顺便生成图片或替换旧稿。

用户选真实视频截图或文章需要真实资料图时，走[真实视频截图配图](real-video-stills.md)，不套本页的生图提示词与画风审批。两种图片可按用途并用，身份分别写清。

只要方案/提示词时，以计划和提示词文件为出口，记录图片、视觉验收和上传均未执行，不扩展成实际生图。此类交付由主笔核对文案与正文即可；完整图文稿才按现有审稿流程安排角色。用户禁止子代理时按既有单模型检查分支处理，不因配图要求另派代理。

## 先定图的用途，再定画风

先读成熟正文，找出哪些关系用画面更容易理解。每张图承担一个主要作用：封面吸引并交代主题、场景呈现生活处境、图解解释关系、流程展示顺序、对照展示有依据的差别。无需每节一图；只有文字摘要作用的图可以省掉。全套数量按文章和已有约定决定，不机械按字数配额。

内容形式、画风、配色分别选择。例如“场景＋水彩＋暖灰绿”适合生活文章，“关系图解＋纸雕拼贴＋米白赭红”适合知识文章。科技题材可以选深色光影与空间装置，健康题材不自动套霓虹或冷蓝医疗模板。正文有专业内容也不意味着所有图都要做成医学示意图。

已有确认的风格、人物和配图数量先沿用，读取上一版视觉记录及实际图片。已有授权就直接完成正常设计，不每图重问。全新方向可以先做一张代表图检验再扩展；只有需要用户选择的实质分歧才提问，不把探索做成固定三套审批。

## 可用的艺术方向

以下是可扩展的选项，不是全部文章的固定模板，也不以换色冒充换风格。

| 方向 | 画面做法 | 适用内容 |
| --- | --- | --- |
| 水彩与彩铅 | 纸张纹理、透明叠色、干笔边缘，人物和环境使用一致笔触 | 健康生活、家庭、情绪、日常场景 |
| 剪纸与纸雕拼贴 | 不规则纸边、纸层投影、大小错落的物件，有明确前后层次 | 生活知识、关系拆解、概念与流程 |
| 木刻与套色版画 | 刀痕、粗细线条、少量颜色、刻意留出的负形 | 文化、日常观察、有力度的封面 |
| 复古丝网印刷 | 网点颗粒、轻微套色错位、受控的大色块和斜向构图 | 评论、科技观察、文化封面 |
| 绘画式编辑插画 | 明确场景、侧光或窗光、冷暖色关系、富有分量的物件 | 健康生活、人物处境、长文封面 |
| 水墨与矿物色 | 飞白、墨晕、纸面或壁画纹理，少量矿物色强调主体 | 文化、自然、生活文章；医学结构不能随意变形 |
| 科技空间与装置 | 有用途的器件、半透明材质、空间层次、局部发光与暗面 | AI、工具、科技；装饰连线不伪装成真实架构 |
| 适度超现实拼贴 | 一个能解释正文的尺度变化或物件组合，其余保持可信 | 抽象概念、注意力、信息传播；健康图不暗示诊断或疗效 |

艺术感来自主体、空间、材质和构图的共同选择。装饰可以是纸张、器物、窗影、植物、织物、笔触等，必须与场景或主题有关。不只放圆角框、图标、分栏文字，不用无关几何、脑形电路、发光粒子作为所有题目的默认装饰。

人物年龄与文章一致，姿态自然，有尊严；不把中老年人画成统一佝偻、病弱或幼儿化形象。手、脚、器械与物件接触关系要可信。力量、平衡等画面只作示意，不能自行发明动作处方或添加医学结构、检测数值。

## 每张图先写清画面

在本篇目录写 `visual-plan.md`：统一画风、色板、材质、人物/道具设定、生成渠道及每图的正文位置、作用、具体场景、视角和文字。图中文字只从成熟正文取；先交给事实和行文角色核验，再开始生成。

每图在内部方案中标记“可独立解释”或“需相邻正文解释”，并保存对应正文位置。公开说明、必要身份与署名只按[交付规则](delivery.md#图片说明默认省略)安排，不自动生成图注；不能把氛围画面标为能独立解释关系的图解。

每张图另存 `prompts/NN-purpose.md`，提示词写具体的主体、动作、空间位置、光线、媒介质感、配色、构图与目标比例。没有固定语言或字数门槛；中文文章优先清楚的中文描述。别只写“高级、科技、艺术感”。可以使用经过理解的艺术流派或视觉参考，但要说明具体特征，不能只堆艺术家/品牌名字。

需要保持已有画风时，实际查看参考图并按工具能力传入参考；文字描述不冒充已传图。新角色先稳定形象，再生成系列图。整套共享人物、色板、材质和笔触；各图可以变化视角、景别、空间和构图，不能全部复制同一张卡片版式。不要生成现成媒体题头、品牌名、水印或作者签名，不加账号品牌。

画面以视觉解释为主。能靠场景说清的图可无文字，必要说明按交付规则放在相邻正文；关系图只保留读者理解所需的短说明，不把正文整段缩进图里。解释用自然叙述，功能标签可用名词；条件不能为少字而删，语言检查和修订只执行[统一审稿](review.md)。

封面单独设计，主题承诺与标题一致，不必把完整长标题塞进图里。横向裁切和方形裁切都要试看，主体与必要文字留在可保留的区域；尺寸依据当前工程要求，不把仓库示例比例当永远有效的平台规则。

本仓库查尺寸时，从 `wechat-mp-drafts/INDEX.md` 的工程入口定位当前上传/封面要求；中老年稿还可查 `wechat-mp-senior-health/references/draft-api.md`。只做方案、未核工程参数时写清“候选比例/尺寸”，实际生成和上传前再核对，不能把候选当已通过工程要求。

## 生成与验收

先执行用户指定渠道与专题边界；本仓库已有图片渠道要求优先。允许生成且无渠道约定时，位图用当前可用的内置 `imagegen` Skill；需要精确关系或可编辑原生图形时，可用合适的 SVG/HTML/Canvas 绘制，不把代码卡片当作艺术位图生成的替代品。现有生成位图的编辑仍走图片编辑工具；文字错漏用纠正提示词重新生成或改成少文字图，不用代码覆盖错误文字。

不能假设仓库所称模型、CLI、Gemini密钥、作者私有图库或图床在当前环境可用。工具不可用时保留已完成的方案和提示词，说明缺失，不声称已出图，也不未经授权切换付费API、其他渠道或上传。

生成后逐张打开实际文件，再检查整组及约390px手机展示：

- 主题与正文位置对应；视觉比喻不变成健康因果或伪造证据。
- 主体和动作看得清，人物、器械、手脚和接触关系合理；装饰不抢解释内容。
- 整组画风与材质一致，人物与背景不仿佛两套风格拼接；图片之间有适当变化。
- 中文、标点、数字与条件正确，缩到手机宽度仍清楚，不以大尺寸打开可读代替手机可读。
- 裁切不损伤主体和文字，比例、清晰度和正文图片加载正常。

发现问题先判断原因：文字多则减少图内说明并把必要解释留在相邻正文；画面空泛则重新落实场景、构图与材质；事实误导则改画面关系，不只美化颜色。每张图最多两次针对性视觉修正，合格图不重复生成；文字变化并入文章的[统一审稿](review.md)。仍不合格就记录问题保留较好版本，不无限抽图，也不将其标为通过。

保存成图、提示词、视觉记录和真实参考的来源/许可。生成图标记为艺术示意，不伪装成病例或现场。图片上传、推草稿及公开发表继续执行原授权边界；真实图限定的稿型不能被本流程覆盖。

每图来源记录至少包含：图号、用途及正文位置、文件路径、实际生成/绘制渠道、时间、提示词路径、参考图及来源/许可（无则写无）、是否实际传入参考、艺术示意说明、实图/手机验收状态。方案阶段的未执行字段明确写未执行，不凭空补作者、模型、许可或成功状态。
