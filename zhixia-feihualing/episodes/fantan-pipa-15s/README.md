> 总是关山旧别情。
>
> 撩乱边愁听不尽，

> 高高秋月照长城。

## 三次同强度高潮

1. 0.000—1.800 秒：低位反弹琵琶转纵向蹬地提展。
2. 4.800—7.000 秒：横跨宽弓急停与横向反向持琴发力。
3. 10.000—13.000 秒：向镜头急沉后沿长城纵深沉提远展。

三次高潮分别使用纵向、横向和纵深剪影；全片只有一次不超过 90 度的改面，7 秒后零完整旋转。13—15 秒保持高能量余势并在运动中结束。

- 场景：秋夜边塞城关、冷灰石砖、低矮垛口、深蓝夜空、后上方秋月和少量远处烽火。
