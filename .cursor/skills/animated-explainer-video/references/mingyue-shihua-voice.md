# 明月体史话口播

2026-10-14 用户确认：清末民初与「那年今天」的历史故事，以明月体的幽默解构为风格内核，以网络拟讲史的娱乐化叙事为文本策略，借用单口相声的表演节奏，最终写成短视频上的通俗史话。

本文件只约束这类口播。儿童拆解、新闻背景和机制科普不自动套用。已定稿不因本文件自动重写。

## 取舍

查阅日期：2026-10-14。

- 当年明月 2008 年接受中新网采访时说，历史可以用更通俗、更现代的语言写得好看；他称书中约九成有史书记载，虚构限于一部分场景和细节。2009 年央视《面对面》中他说：写得幽默的不是历史，幽默的只是讲述者；史书常把一生收成一句，讲述要把那一句还原成能听懂的场面，沉重由讲述者承担，不用沉重的腔调压给观众。
- 语言研究把这类白话归纳为短句、降用、跌衬、易色、反语和比喻。本系列只用前四类里能核对的说法，不仿写《明朝那些事儿》的原句，也不搬过期网络流行语。
- 相声创作把包袱概括为铺平垫稳、三翻四抖：先让听众按常情往下听，同类信息加码两到三次，最后一句打破这个预期。抖是停顿和语气，不是再解释一遍。单口不靠捧哏。
- 光明网等对《明朝那些事儿》的评论还肯定了补写心理、渲染场面。本系列不采用这一条。动机、对白和没有出处的现场保持不写。幽默只改叙述者怎么说，不改发生了什么。

## 四层怎么叠

1. **明月体**：把官职、礼仪、公文译成今天听得懂的处境，紧接着给回原名和原文。庄重的一句后面跟一句白话，拆架子，不拆事实。评语短，贴在刚发生的动作上。
2. **拟讲史**：口气像把材料讲给熟人，信息仍能回到日记、报纸、信函或档案。一条线只跟一个物件走，例如一张启事、一封信、一声枪。娱乐来自说法和顺序，不来自戏说。
3. **单口节奏**：一个讲述人。顶门进入当天的事，入活用一句拉回起因，正活里加码，抖包袱的那句单独成段，结底停在最后一份公开文书或人离开的动作。
4. **史话成片**：标题可以是这件事的俗名。正文第一句仍是日期、地点和正在做的事。字幕跟口播，不加弹幕式吐槽。

## 编辑动作

- **降用**：头衔先说成人话，再落回头衔。副林长可以说成居士林里管事的，下一句必须回到「副林长」。不用「打工人」「社畜」这类会过期、也会改写身份的词。
- **跌衬**：先引文件里的正经话，下一句只说这句话办成了什么。办成的事要有出处。不接「这说明」。
- **易色**：换一个生活里的动词，不换事实。登报、取枪、换座，比「实施」「进行」优先。
- **加码**：同一方向说两到三次，一次比一次更具体。第三次之后用一句短句落地，然后停。不把短句再翻译成主题。
- **疏密**：铺陈用完整句。包袱和结果用短句，单独成段。禁止通篇碎句，也禁止连续三段都在找笑点。
- **翻译一次**：同一个制度或官职，全篇只用一句白话对上原名。后面直接用原名。

## 仍然不许

- 不用「提出问题—给出判断—总结道理」组织段落或结尾。包袱不是道理，结底不是教训。
- 不设问，不自问自答，不写成甲乙对口。
- 不补人物心理、内心戏和对白。当年明月允许的那部分场景虚构，这里不跟着做。
- 反语后面必须接可核对的动作。反语不能变成对私生活的定论。
- 一方的指控保持「启事里写」「诗注里写」。不把传闻说成当场看见。
- 不工整对仗，不贯口堆名字，不把第二人称拿来教训观众。
- 网络词全篇至多一处，不能代替专名，也不能改变事件性质。

## 民国八卦的写稿程序

2026-10-14 用郁达夫样稿校准。只用于文人、名伶、报人的婚事、饭局、绝交、钱账和登报。工程、疫情、制度沿革不做人物长编。

一句话：主线用叙事把事情讲清楚。损友吐槽不铺满全篇，只在关键处加一两句。

本段覆盖上文这几条：开场回到日期、地点和正在做的事；网络词随那一两句吐槽出现，不连着堆。其他题材仍按上文。

样稿里的错误不跟着学：年龄、已经离婚、接吻次数、假托的鲁迅评语、「差几天没看到胜利」、把诗注写成已经坐实的出轨。类比只翻译已经发生的事，不能把事件换成另一件事。细节必须来自这一集的事实卡。样稿用来示范的钻戒、接吻次数、一块七、五块钱、棉裤、四百多篇，卡上没有的不搬。

### 写法

1. **主线是叙事**。按行动、回应和局面变化讲。一份文书改变一次局面。听众要听得清谁在什么时候做了什么。
2. **吐槽只加一两句**。挑字面上最拧的那一处，用损友的口气点一句，说完就回到叙事。全篇这种句子一两句，不每段都吐，不越吐越狠，不用「你敢信」开场。
3. **收尾停在这件事的结果上**。可以是最后那份文书。不把全篇收成吐槽金句，不写成「历史是个轮回」，不写成「不建议学」。
4. **句子**。口语，能读出声。不对仗，不自问自答。不为了好笑编对白、心理和场面。
5. **安全**。一方的指控仍写「诗注里写」「她在文章里否认」。不下道德死判。牺牲、遇害、战争从严写，不拿伤亡开玩笑。

动笔前在 `prompt-brief.md` 写明：叙事从哪一件事进入，哪一处加那一两句吐槽，吐槽指回哪条文书。文书清单只核对，不代替正文。

编剧、逐句语法、承接检查仍然要做。损友口气不免除主语、指代和事实卡。

这一页只加史话口气和事实卡，不替换已经定过的编剧、句法和承接。写民国八卦按这个顺序，缺一步不算写完：

1. 用 [非虚构视频的编剧方法](screenwriting-for-nonfiction.md) 安排行动、回应和局面变化。一件文书改变一次局面。不为了好笑编对白、心理和场面。
2. 先写事实卡，再按叙事主线写口播。损友吐槽只在关键处加一两句。
3. 成稿后按 [中文句法与病句审校](chinese-sentence-review.md) 逐句查六类病句、指代和问答语气。用户要求严格逐句时，在单集目录留下修改记录。
4. 再按 [中文承接与段落推进](chinese-writing-coherence.md) 连读。吐槽点完就回到下一件事，不把同一句再解释一遍。

### 用 DeepSeek 写稿

用户要求用 DeepSeek 起稿时，旧提示词和旧口播不作为输入。顺序固定为三步，缺一步不算写完：

1. 技能侧整理两样东西，写入单集 `prompt-brief.md`。事实只来自这份 `fact-card.md` 和 `research.md` 里已采用的文书、生平切片，文书是参考，不是逐条念的正文。期望按本段写法写：叙事从哪件事进入，哪一处加那一两句吐槽。不把上一版提示词或上一版稿子贴进去。
2. 用 `deepseek-v4-flash` 读这份 brief，只生成下一轮写稿用的提示词，存为 `deepseek-prompt.txt`。这一步不写口播。请求里关闭思考模式（`thinking.type = disabled`）。不关的话，额度会耗在推理上，返回的正文是空的。
3. 把 `deepseek-prompt.txt` 原样交给另一次 `deepseek-v4-flash`，同样关闭思考模式，生成口播。句法检查和连读仍在模型稿之后做，模型稿不直接当定稿。

工整对仗仍然禁止。民国八卦按上面的损友模板写。其他题材仍禁止「提出问题—给出判断—总结道理」。

### 事实卡

动笔前在单集目录写 `fact-card.md`，只收这一件事用得着的材料。三层分开：

1. **文书**：启事、信、协议、刊物目录、日记里的那一行。这是参考和核对底线，不是口播正文。日期、动作和原文从这里核对，不能写反，也不能把事实卡逐条念成稿。
2. **生平切片**：只留能把文书放回当时生活的几句，例如人在哪、和谁有婚姻、差事是什么。不写整本传记。来源要打开。
3. **评论**：别人在哪个物件上停住、那一句多长、是白话还是训诫。至少三篇不同来源，其中一篇是研究、前言、笺注或当事人后来的说明。断言了动机、私德或道理的，写进「不采用」。

每条短评在事实卡上注明它指着哪一条文书。指不回去的句子不写。

### 短评

短评是叙事里偶尔插入的一两句人话，指着刚讲过的那份文书。说完就回到事情本身。不解释为什么好笑，也不把人物收成一个鉴定。

寻人启事写「都不成问题」，同一则启事却把这些事印出来，这句可以有。不要写成「他这个人就是多疑」，也不要拿「真性情」给诗注开脱。一方的指控仍写「诗注里写」「她在文章里否认」。

### 审稿

三遍都要做，不能只用事实卡代替句法：

- 事实：时间、人物、因果是否都在事实卡上。生平切片有没有被说成文书。争议有没有被说死。样稿里的错细节有没有混进来。
- 弧线：主线是不是在讲事情的先后和局面变化。吐槽是不是只有关键处的一两句。有没有整篇都在骂。
- 句子：逐句过后，主语、搭配、指代和否定范围还在不在。吐槽之后有没有把同一句又解释一遍。结尾是不是停在这件事的结果上。滑成「历史是个轮回」「不建议学」或劝观众，重写结尾。
- 安全：有没有攻击民族、宗教、地域、性别，有没有拿灾难和牺牲开玩笑，有没有把暴行写得好玩。

### 《毁家诗纪》试点里定下的取舍

这一集的取舍只约束《毁家诗纪》，不取消上面的损友模板。

写进这一集的生平只有两刀：1928 年与王映霞结婚时，和原配孙荃没有办成离婚；诗注自己写到 1936 年风雨茅庐落成后他去福建、家在杭州。1927 年《日记九种》只放在诗稿寄出之后，说明他把家里的事送去印过，不再解释。

不写进这一集的：创造社、《沉沦》、接济沈从文、南洋再恋、化名赵廉、遇害日期。许绍棣和巨款只留在「注里写」。营销文里的「旷世姻缘」「人间怨偶」不进正文。这一集的事实卡里没有沈从文、棉裤和遇害，找补和肃然不能从样稿把这些情节搬进来。

## 写完后连读

按句听一遍：听众能否指出日期、人物、物件和结果。再听包袱和短评：落地之后有没有又解释了一遍。最后听结尾：是不是停在这件事的结果上。收成人生体会、轮回或不建议学，重写结尾及其上一句。
