# 《白帝城》15秒诗句诗境

## 取句

李白《早发白帝城》：

> 两岸猿声啼不住，轻舟已过万重山。

字幕出处：`唐·李白《早发白帝城》`。

## 内容定位

本集是15秒诗句诗境。它通过轻舟顺流穿行、阿砚数山和两人回望完成一个小事件，不是整首诗的30秒完整诗境，也不是逐句换景的静态配画。

关闭字幕后应能读懂：轻舟行得极快，阿砚来不及数完两岸青山，回头时已经越过层层峡谷。

## 对白与目标时间轴

| 时间 | 角色与内容 | 画面任务 |
| --- | --- | --- |
| 0.0—1.5秒 | 阿砚：“栀夏，船在飞！” | 建立轻舟高速顺流和阿砚的兴奋 |
| 1.6—3.5秒 | 栀夏：“坐稳，山要追不上了。” | 栀夏坐稳回应，近岸开始产生明显视差 |
| 3.6—5.8秒 | 阿砚：“一座、两座、三座——” | 阿砚不换座，只转头数岸边山峰 |
| 5.9—7.3秒 | 栀夏：“别数了，回头。” | 栀夏看向阿砚，两人准备回望 |
| 7.3—10.0秒 | 无对白 | 人物回头，镜头揭示身后层层远山 |
| 10.0—约14.7秒 | 阿砚朗诵取句 | 略高宽景跟随轻舟，万重山成为主体 |
| 14.7—15.0秒 | 无人声 | 保留江水、破水和远处猿声收尾 |

正式TTS生成后按真实时长微调。不得为了维持上述估算明显加速对白或朗诗；时间不足时优先压缩7.3—10.0秒的无对白揭示段。

## 固定角色与船上位置

- 栀夏始终坐在船后半部，面向船头，不站立、不换座、不触水。
- 阿砚始终位于船头附近，可以压低身体、看向栀夏、转头数山和自然回望，不跳船、不落水。
- 一条深棕色修长中式木船，两端微翘，三道横向木座板；船头较窄、船尾略宽。
- 无船桨、竹篙、船帆、桅杆、船篷、发动机、船夫和其他乘客。轻舟只依靠江流自然顺流前进。

## 四张卡

1. 小船结构卡：锁定船体完整轮廓、三道座板、船头船尾和人物座位。
2. 开场卡：侧前方中远景，建立真实破水、人物迎风和峡谷前进方向。
3. 中段卡：同侧侧面中景，锁定阿砚原地转头数山和栀夏坐稳回应。
4. 结尾卡：船后上方宽景，锁定人物自然回望和身后近中远三层“万重山”。
