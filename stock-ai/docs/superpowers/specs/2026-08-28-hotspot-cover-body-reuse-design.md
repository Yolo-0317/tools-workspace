# 热点深评封面按需复用于正文设计

## 背景

当前热点深评配图策略会从已核验的真实图片中选择封面，并在正文图片列表中强制排除该封面。因此，即使封面本身适合承接正文内容，也不能再次插入正文。

本次调整允许 Agent 根据稿件内容和素材质量，显式决定是否把封面复用于正文。该能力必须按单篇稿件开启，默认行为保持不变。

## 目标

- 封面可以按需复用于正文，且不视为图片冲突。
- 是否复用由 Agent 根据内容和素材决定，不机械地对每篇稿件启用。
- 复用的封面计入正文 `0–3` 张图片上限。
- 保持现有抖音优先、只用真实可追溯图片、禁止自动生成图片等规则不变。

## 配置约定

沿用每个选题图片目录中的 `cover_source.json`，增加可选布尔字段 `reuse_in_body`：

```json
{
  "source_filename": "still-01.jpg",
  "reuse_in_body": true
}
```

- `reuse_in_body: true`：允许已选封面进入正文图片序列。
- 字段缺失、值为 `false`、配置文件缺失或格式无效：保持旧行为，封面不进入正文。
- `source_filename` 的既有封面指定逻辑不变。

## 图片选择逻辑

1. 按现有规则完成图片核验并选择封面。
2. 读取 `cover_source.json` 中的 `reuse_in_body`。
3. 若启用复用，正文图片序列以已选封面开头，再追加其余已核验图片。
4. 若未启用复用，正文图片序列继续排除封面。
5. 无论是否复用，正文图片总数均不得超过 `max_body`，默认上限仍为 3；当 `max_body=0` 时正文不插图。

把复用封面放在正文图片序列首位，是为了让后续排版逻辑仍可自行决定具体插入位置，同时保证选择结果稳定、可测试。

## Skill 文案调整

在公众号草稿总流程和热点深评专题规则中统一补充：

> 封面可按需复用于正文，不视为重复冲突；复用后计入正文 0–3 张上限。是否复用由 Agent 根据内容与素材决定，不要求每篇复用。

其他图片约束不变，尤其包括：

- 优先从抖音获取封面或公开视频帧，不打开或播放视频，只获取可见封面图。
- 不足 3 张时有几张用几张，允许少图或正文无图。
- 禁止为了凑数自动生成图片。

## 兼容性与异常处理

- 这是可选配置，现有未声明 `reuse_in_body` 的选题不受影响。
- 配置读取失败时采用保守默认值 `false`，不因配图偏好阻断整篇稿件。
- 不改变现有图片真实性、来源记录、封面必需性和正文图片数量校验。

## 测试与验证

先补充失败测试，再修改实现，覆盖以下场景：

- 未配置或配置为 `false` 时，封面仍从正文图片中排除。
- 配置为 `true` 时，封面进入正文图片序列首位。
- 启用复用后，正文图片总数仍不超过 3 张。
- `max_body=0` 时，即使启用复用也不返回正文图片。
- 无效配置继续回退到默认行为。

实现后运行热点图片策略单元测试、相关公众号单元测试及文档一致性检查，并检查最终差异只包含本次约定的文件。
