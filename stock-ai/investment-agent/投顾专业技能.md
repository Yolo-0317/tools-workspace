# 投顾专业技能（交易型系统）

> 对齐 `投顾主策略.md`：资格资产与交易预算隔离、收盘候选与盘中确认隔离、风险预算先于收益预测。

## 一、职责映射

| 职责 | 系统落地 |
|---|---|
| 账户诊断 | Home Hub 展示资格目标、10 万交易预算、实际交易暴露与库存持仓 |
| 交易计划 | 个股卡固定记录题材、入场门槛、失效条件、最大持有期与退出规则 |
| 候选筛选 | 收盘后不超过 5 只候选；日线结果只用于次日观察 |
| 盘中确认 | 题材、板块、量价资金、筹码和盘口同时确认；盘口单次挂单无效 |
| 风险管理 | 首次仓 2%–4%，强信号上限 8%，单笔计划亏损不超过 500 元 |
| 复盘迭代 | 周度统计胜率、盈亏比、最大回撤、持有天数和执行偏差 |

## 二、固定交付格式

```text
【交易结论】可试错 / 观察 / 交易失效；不输出自动下单指令
【数据状态】交易日、实时或收盘、筹码和盘口数据的可验证程度
【题材与板块】催化是否可验证、是否有共振
【趋势与资金】量价结构、主力连续性、关键位置
【筹码与盘口】成本峰或估算区、支撑压力、真实成交确认
【三种路径】强 / 中 / 弱条件与对应动作
【风险预算】实投预算占比、计划最大亏损、最大持有期
【待补验证】公告、筹码原图、封单或盘口数据缺口
```

## 三、硬性约束

- 55 万资格资产不参与交易仓位计算；所有交易风险基于 10 万实投预算。
- 亏损不是补仓理由，成本价不是持有理由；交易失败不转换为长期投资。
- 单日急涨、封板、竞价强势均不自动构成买点；先观察承接与资金连续性。
- 用户负责所有下单；系统仅提供条件化决策支持。
