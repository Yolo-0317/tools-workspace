# 微信公众号 API 固定出口设计

## 背景

公众号脚本访问 `api.weixin.qq.com` 时，阿里云 SASE 会按目标地址或连接策略选择出口。2026-08-13 实测，同一域名的 token 请求与素材上传分别被微信识别为 `140.206.121.26` 和 `223.167.74.160`。昨天可用，是因为当时复用了已获取的 token，且请求未触发本次出口漂移组合；这不代表当前链路仍稳定。

## 目标与边界

- 只影响 `stock-ai` 的微信公众号 API 客户端。
- 让 token、素材、草稿等所有 `api.weixin.qq.com` 请求固定到同一目标节点，期望微信看到的源出口为 `140.206.121.26`。
- 不修改 macOS 全局代理、`/etc/hosts`、Clash 或 SASE 配置。
- 不记录或输出 AppSecret、完整 access token。
- 若无法确认出口为目标 IP，则停止上传，不自动切换到其他节点。

## 方案

### 节点探测

解析 `api.weixin.qq.com` 的全部 IPv4 地址，逐个以原域名作为 TLS SNI 和 HTTP Host 发起 token 请求。根据微信的 `40164 invalid ip` 返回，建立“目标节点 → 微信看到的源出口”映射。

探测只读取现有公众号凭证，不写草稿。日志仅保留目标节点、错误码和微信返回的源出口，不输出 secret 或 token。

### 应用内固定解析

为微信客户端增加可选环境变量 `WECHAT_MP_API_RESOLVE_IP`。配置后：

1. URL 和 Host 仍使用 `api.weixin.qq.com`；
2. TCP 连接固定到指定 IPv4；
3. TLS 仍校验 `api.weixin.qq.com` 证书；
4. token、素材上传、草稿读写统一复用该连接策略。

未配置时保持现有行为，避免影响其他使用者。

### 出口门禁

增加 `WECHAT_MP_REQUIRED_EGRESS_IP=140.206.121.26`。正式上传前强制刷新 token：

- 返回 `40164` 且源 IP 等于目标值：说明路由已固定但后台尚未放行，停止并提示加白名单；
- 返回 `40164` 且源 IP 不等于目标值：说明固定失效，停止；
- token 获取成功：继续素材与草稿操作；
- 任一后续接口再次出现不同出口的 `40164`：停止，不尝试其他节点。

## 验证

1. 单元测试覆盖未配置时兼容、固定解析、TLS 主机名保留、错误信息脱敏和出口门禁。
2. 逐节点真实探测，选出映射到 `140.206.121.26` 的目标地址。
3. 强制刷新 token，确认成功或只返回目标出口。
4. 上传一张测试图；成功后推送《功夫女足》完整 6 图草稿。
5. 远端回读核对标题、正文与图片数。

## 回滚

删除 `WECHAT_MP_API_RESOLVE_IP` 与 `WECHAT_MP_REQUIRED_EGRESS_IP` 即恢复系统 DNS 行为；代码路径保留为未启用状态，不修改系统网络。

## 风险

- 微信 CDN 目标地址可能变化，因此固定节点是短期稳定措施，不是永久网络承诺。
- 若 SASE 的出口选择不由目标地址稳定决定，应用内固定无法满足要求，应停止并改由 SASE 管理员配置域名出口策略。
