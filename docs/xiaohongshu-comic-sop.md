# 视频小人书复用为小红书图文 SOP

更新：2026-10-16。适用于复用视频端已确认的小人书图文原图。

2026-10-17 画风补充：新绘或用户指定重绘的正文遵循[小人书主 SOP 的“清爽写实线描＋薄淡彩”规则](lianhuanhua-video-sop.md#正文默认画风清爽写实线描薄淡彩)，以其中链接的《席间的“玩笑”》试稿为标准样张。仅复用、拼接已有确认图时，仍完整保留原图，不为套用新画风擅自重绘。

## 素材与顺序

- 先核对用户指定聊天、最终原图目录和页序，不混用旧样张、视频截图或其他故事。
- 每三张原图按故事顺序上下拼成一张正文图，从上往下阅读。
- 完整保留单张的画面、配文、标题、页码、纸感及排版。只做拼接，不裁切、拉伸、重绘、改字或重复画面凑数。

## 固定画布与不足三张的处理

- 同一期全部正文拼图使用相同宽高，画布按完整三张的尺寸确定。原图等宽等高为 W×H 时，正文画布固定为 W×3H。
- 不足三张时，画布尺寸和已有单张图片尺寸均不变。原图依序靠上排列，缺少的格位留在下方，用与纸底接近的纯色留白。
- 剩两张：占上、中两个格位，底部一个格位留白。剩一张：占顶部格位，下面两个格位留白。
- 不因尾页张数减少而缩短画布、放大现有图片、居中分散图片或另加内容。
- 原图尺寸不一致时，先核对视频端的最终导出规格；不得擅自缩放原图以凑齐格位。
- 本规则覆盖此前“剩两张做两格短尾页、剩一张单图收尾”的方案。

例：《阎王不收礼》8张原图均为1672×941，按3＋3＋2分成三张正文；三张正文均为1672×2823，最后一张底部留白1672×941。

## 检查与交付

1. 检查页序、数量，确认无漏页、重复和错序。
2. 检查所有正文拼图宽高一致，包括不足三张的尾页。
3. 将每个已填格位与对应原图逐块比较，确认像素一致；检查留白格位没有附加图文。
4. 查看实际拼图，检查文字、边框、页码完整；核对红衣女生封面与标题，并检查固定标识“小人书·民国历史连环画”逐字正确，标识及画册图文特征在缩略图下可辨认。
5. 按“00封面、01正文、02正文……”命名，附素材对应表、检查记录与压缩包。更新图片时同步更新交付包。不自动发布。
