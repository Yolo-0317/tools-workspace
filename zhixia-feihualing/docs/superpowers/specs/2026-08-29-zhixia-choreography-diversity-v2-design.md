# 栀夏诗境编舞多样性 v2 设计

## 目标

解决连续诗境虽然更换场景和动作名称，实际成片却反复出现“展臂—沉身—旋转—双袖画圆—镜头拉远”的视觉定式。新规则继续使用栀夏与阿砚两张角色母版加纯文字场景提示词，不增加状态卡、舞蹈分镜或参考视频；通过主高潮动作家族和视觉指纹去重，让后续诗境持续生成高冲击力、可辨别但允许 Seedance 自由变化的国风舞蹈。

本设计覆盖旧规则中“每支新诗境必须完成一次完整旋转”的要求。《惊涛》和《黄河》已经确认，不返工；新规则从下一首诗境开始生效。

## 主高潮动作家族

每集只选择一个主高潮动作家族，不再把旋转等同于舞蹈高潮：

1. **行进旋转**：在连续移动中完成一次转体，离开旋转后仍沿原路线推进。
2. **腾跃展开**：通过清楚助力步、短暂离地和稳定落脚形成开放身体线条；不与完整旋转叠加。
3. **低位扫展**：降低重心，以侧向或斜向扫臂、扫袖带动身体从低位打开，再稳定提起。
4. **倾身穿行**：以大幅倾身、穿臂或穿袖经过真实前景，在持续移动中形成长线条；不画完整袖圆。
5. **回身展臂**：先改变面向，再以腰身和目光带动大幅回身展开；转角服务方向变化，不完成整圈旋转。
6. **道具牵引**：由纸伞、团扇、剑、花枝或灯笼中的单一道具引导身体方向和空间揭示；道具不换手、不复制。
7. **纵向提沉**：以明显的沉、提、冲、靠或由低到高身体层次建立高潮，手臂与衣料只反馈纵向发力，不形成环形主轮廓。

旋转只是七种家族之一。每集仍须具有清楚空间移动、至少两次重心或高低层次变化、连续自然的中国古典舞身韵和一个视觉高潮，但不再强制完整旋转。

## 去重规则

- 连续两集禁止使用同一主高潮动作家族。
- 最近五集内，同一主高潮动作家族最多出现两次。
- 每次设计在写最终提示词前，与最近一集比较九项视觉指纹：开场轮廓、移动路线、主高潮动作、手臂轨迹、腿部剪影、衣料或道具轨迹、特效形状、高潮时间窗、摄影机高潮反应。
- 九项中有三项或以上相同，视为观众可感知的重复，当前组合不得进入 Seedance 提示词，必须至少替换主高潮动作、身体轮廓或镜头高潮中的一项，并重新比较。
- 去重检查比较最终可见结果，不以“沉身提转”和“跨步翻身”等文字标签不同作为通过依据。

## 水景解耦

水景不得默认选择“旋转＋双袖圆弧＋环形水特效”。水的运动结果从以下形状中按诗意选择，并受同一去重规则约束：

- 沿移动方向形成的直线破浪。
- 脚下落点产生的局部迸溅与回落。
- 由纵向提沉带出的短时水幕或水雾上升。
- 由倾身穿行带出的侧向水雾带。
- 动作落点向外扩散的非环形水纹。
- 不依附身体轮廓、由摄影机揭示的远景浪涌或河势增强。

所有水特效仍须具有真实来源、动作触发、跟随方向、前中后景层次和自然归宿；不得生成无来源光环、水环或图形化魔法圆。

## 组合器流程

自动编舞顺序调整为：诗意分析 → 角色与景物关系 → 开场轮廓 → 空间移动路线 → 主高潮动作家族 → 重心与身体层次 → 手臂及腿部剪影 → 衣料或道具反馈 → 特效形状 → 摄影机主路径及高潮反应 → 结束方式 → 视觉指纹比较 → 输出自然语言提示词。

第一秒强起势和结尾不提前定式的规则保持不变。摄影机仍只使用一条主路径，但动作触发反应不再固定绑定“旋转和高潮”；改为在开场进入与主高潮动作处分别产生最多两次有原因的反应。

## 台账结构

`operations/dance-design-history.csv` 在既有诗意、移动、载体、特效和镜头字段基础上，增加以下可观察字段：

- `climax_family`：七种主高潮动作家族之一。
- `opening_silhouette`：首秒人物可见轮廓。
- `arm_path`：主要手臂轨迹，如纵向上挑、侧向扫展、单臂穿行或非闭合弧线。
- `leg_silhouette`：主要腿部动作，如连续跨步、短暂离地、低位弓步或交叉换重。
- `carrier_shape`：衣料或道具形成的主要视觉形状。
- `effect_shape`：特效的主要视觉形状。
- `climax_window`：高潮所在宽时间窗。
- `camera_climax`：摄影机在高潮处的单一主要反应。

既有《惊涛》和《黄河》记录补齐能够从已确认提示词和成片中确定的视觉指纹，仅用于后续去重，不改变既有视频。

## 提示词输出边界

- 最终 Seedance 提示词只写身体部位、落脚、方向、重心、空间路线、动作结果和环境因果，不出现动作家族名称、内部编号、字段名、文件名或测试名。
- 不写“具体动作完全自由发挥”；允许 Seedance 只在明确的可观察动作边界内自然连接。
- 不复制现成剧目、网络舞蹈或具体舞者动作；保持原创虚构角色和原创变化定位。
- 复杂指定舞蹈仍需升级到动作分镜或自有、已授权参考视频，本设计不承诺纯文字逐拍复刻。

## 验收标准

1. 组合器、全局视觉规范和生产流程不再要求每集完整旋转。
2. 生效规则明确列出七种主高潮动作家族，旋转只占其中一种。
3. 连续两集同家族和最近五集超过两次均被明确禁止。
4. 九项视觉指纹中三项以上相同时，必须重新编排而不能直接出提示词。
5. 水景规则明确拆除“水景必然生成环形袖弧”的绑定。
6. 台账能够保存主高潮家族和八项细化视觉字段，并补齐《惊涛》《黄河》已有记录。
7. 最终提示词继续清除全部内部代码和动作家族名称。
