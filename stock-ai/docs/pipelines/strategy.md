# A股技术面五因子选股系统

## 文档版本：v1.0

## 更新日期：2026年3月25日

---

## 一、系统概述

本系统基于A股日线数据，通过**趋势、形态、动量、量能、支撑压力**五个维度对股票进行技术面量化评分，筛选出符合“筑底+放量突破”形态的优质标的。

### 1.1 五因子权重分配

| 因子 | 权重 | 满分 | 核心作用 |
| :--- | :--- | :--- | :--- |
| 趋势因子 | 25% | 25分 | 判断中长期方向 |
| 形态因子 | 25% | 25分 | 识别筑底+突破 |
| 动量因子 | 20% | 20分 | 确认启动信号 |
| 量能因子 | 15% | 15分 | 验证资金态度 |
| 支撑压力 | 15% | 15分 | 评估盈亏比 |

---

## 二、五因子详细条件

### 2.1 趋势因子（满分25分）

| 子项 | 条件 | 分值 | 判定逻辑 |
| :--- | :--- | :--- | :--- |
| **价格在MA60之上** | 收盘价 > 60日均线 | 5分 | 中长期趋势向上 |
| **价格在MA20之上** | 收盘价 > 20日均线 | 5分 | 短期趋势向上 |
| **MA20上翘** | 今日MA20 > 5日前MA20 × 1.01 | 5分 | 短期均线斜率>1% |
| **MA60走平或上翘** | 今日MA60 ≥ 10日前MA60 × 0.99 | 5分 | 长期均线不下降 |
| **均线多头排列** | MA5 > MA10 > MA20 > MA60 | 5分 | 完全多头排列 |

**加分项**：

- MA20斜率 > 2%：+2分
- 价格同时站在MA5、MA10、MA20、MA60之上：+3分

**扣分项**：

- 价格跌破MA20：-5分
- MA60斜率 < -1%：-3分
- 均线空头排列（MA5 < MA10 < MA20）：-5分

---

### 2.2 形态因子（满分25分）

| 子项 | 条件 | 分值 | 判定逻辑 |
| :--- | :--- | :--- | :--- |
| **筑底形态** | 近20日振幅 < 15% | 5分 | 窄幅震荡 |
| | 近20日均量 / 前60日均量 < 0.7 | 5分 | 缩量明显 |
| **放量突破** | 当日成交量 / 5日均量 ≥ 1.5 | 5分 | 放量1.5倍以上 |
| | 当日涨幅 ≥ 3% | 5分 | 中阳线以上 |
| **突破关键位** | 收盘价突破60日均线 | 3分 | 突破长期均线 |
| | 收盘价突破20日内最高点 | 2分 | 突破近期平台 |

**加分项**：

- 近20日振幅 < 10%：+2分
- 量比 ≥ 2.0：+2分
- 涨幅 ≥ 5%：+2分
- 涨停收盘：+3分

**扣分项**：

- 放量但涨幅 < 1%（放量滞涨）：-5分
- 缩量突破（量比 < 1.2）：-3分
- 突破后次日低开低走：-5分（需次日确认）

---

### 2.3 动量因子（满分20分）

| 子项 | 条件 | 分值 | 判定逻辑 |
| :--- | :--- | :--- | :--- |
| **MACD** | MACD线 > 信号线 | 4分 | MACD金叉状态 |
| | MACD红柱放大 | 4分 | 今日红柱 > 昨日红柱 |
| **RSI** | RSI在50-80之间 | 6分 | 强势非超买区 |
| | RSI在30-50之间 | 3分 | 弱势但未超卖 |
| **KDJ** | K线向上穿过D线 | 6分 | 当日金叉 |
| | K线 > D线（已金叉） | 3分 | 维持金叉状态 |

**加分项**：

- MACD零轴以上金叉：+2分
- RSI在60-75之间：+2分
- KDJ三线同时向上发散：+2分
- 出现MACD底背离：+5分

**扣分项**：

- MACD死叉：-5分
- RSI > 85：-3分
- RSI < 25：-2分
- KDJ死叉：-4分

---

### 2.4 量能因子（满分15分）

| 子项 | 条件 | 分值 | 判定逻辑 |
| :--- | :--- | :--- | :--- |
| **量比** | 量比 ≥ 2.0 | 5分 | 显著放量 |
| | 量比 ≥ 1.5 且 < 2.0 | 3分 | 温和放量 |
| **OBV趋势** | 今日OBV > 5日前OBV | 5分 | 能量潮向上 |
| **量价配合** | 今日上涨 + 今日放量 | 5分 | 健康的量价关系 |
| | 今日上涨 + 今日缩量 | 2分 | 缩量上涨（惜售） |

**加分项**：

- 量比 ≥ 3.0：+2分
- OBV创20日新高：+3分
- 连续3日放量上涨：+3分

**扣分项**：

- 上涨但缩量（量比 < 0.8）：-2分
- 下跌但放量：-5分
- OBV与价格顶背离：-5分
- 量比 < 0.5：-2分

---

### 2.5 支撑压力因子（满分15分）

| 子项 | 条件 | 分值 | 判定逻辑 |
| :--- | :--- | :--- | :--- |
| **距支撑距离** | (股价 - 支撑位) / 支撑位 ≤ 3% | 8分 | 极度靠近支撑 |
| | ≤ 5% | 5分 | 靠近支撑 |
| | ≤ 8% | 3分 | 接近支撑 |
| **距压力距离** | (压力位 - 股价) / 股价 ≥ 10% | 7分 | 上涨空间大 |
| | ≥ 5% | 4分 | 有一定空间 |
| | ≥ 3% | 2分 | 空间有限 |

**支撑位判定优先级**：

1. 近期低点（20日内最低价）
2. 60日均线
3. 20日均线
4. 筹码平均成本
5. 整数关口

**压力位判定优先级**：

1. 近期高点（20日内最高价）
2. 前高（60日内最高价）
3. 整数关口
4. 筹码密集区上沿

**加分项**：

- 支撑位为60日均线且已确认有效：+2分
- 多个支撑位重合：+3分
- 压力位为整数关口且有突破迹象：+2分

**扣分项**：

- 股价跌破关键支撑：-5分
- 距压力位 < 3%：-3分
- 上方获利盘 > 70%：-2分
