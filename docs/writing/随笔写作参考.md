## 本次采用与舍弃

采用的是具体用词与对象相合、常用词能承载完整想法、叙述中生发思考、抒情克制、字句要放回段落连读。公众号仍是有来源的非虚构文章，不能照搬文学作者的童年、故乡、家庭、采访或私人体会。

创作谈不全是随笔成品，也不代表作者只有一种文风。汪曾祺的小说谈只借语言和思索方法；王彬的访谈不迁入问答结构；张炜的植物命名不变成术语清单；署名周国平的转载只辅助比较，原书版本未核，不用作名人直接引语。不能把这些材料拼成一种作者人格或指定作家的仿写。

具体词语随语境判断，没有“随笔必用词”。倒、不过、还是等在基座中仅作为语义关系示例，不按次数添加；基座里的改句均为自拟编辑示例，不是上述文章的摘句或真实家庭案例。

## 规则调用

材料整合后，在已有参考环节按文章任务选取；词义和搭配拿不准时查既有语文知识库。结构、分段回读、事实与文体分查、独立审稿及有限修改沿用现有流程，不因本次研究增加新角色或新循环。

## 用户提供的去AI味教程取舍

2026-11-03用户贴入《如何消除文字的AI感（豆包篇）》全文及部分留言。未提供原文链接，以下只分析所贴文字，不核验其对具体模型生成习惯的概括；它是外部方法参考，不是用户认可的改稿正例，不加入文章卡片目录冒充已联网阅读。

| 材料中的做法或示例 | 本次取舍 |
| --- | --- |
| “积极组织活动”简化为“组织活动” | 若积极只有自夸作用，可去掉；活动做了什么仍须有内容，修饰词不能一律删除。 |
| 用“已梳理并调整……提质增效……稳步执行”改写流程汇报 | 改句仍有空泛目的和承诺，没有说明流程具体改了什么。只保留原材料确有的动作，不补造环节、效果或完成状态。 |
| “环境舒适”扩写成空间敞亮、紧绷情绪放松 | 新增空间与感受需有现场材料或真实体验；更长、更有情绪不等于更具体。 |
| 产品例子增加材质、尺寸、适用女性等内容 | 材质尺寸可核才写；跨产品大小比较和人群适用性另需依据，不能为自然感临时补出来。 |
| 加“其实、说白了、我发现”等衔接语 | 按实际转折和认识变化选择，不设必用词，不把观察或体验编给作者。 |
| 改用“大家、我们、不少人” | 涉及说话者和数量范围变化，不能把作者判断变成群体共识；例中“许多参与者都表示”也需有实际反馈支持。 |
| 长短句交错、弱化规整结构 | 取按意思组织句段的原则，不取固定长短配比或故意打乱因果、时间与指代的做法。 |
| 删除空格、引号、规整标点 | 只处理当前载体的无用途格式；不误伤英文、代码、URL、单位或必要引语，也不以格式推断文字是否由AI生成。 |
