# 牛马也智能 · 搜一搜数据怎么用（运营 SOP）

> **前提**：后台只能看 **汇总**，不能看「谁搜完哪篇才关注」。  
> 入口：`mp.weixin.qq.com` → **广告与服务** → **搜一搜** → **数据看板**；或小程序 **搜一搜数据助手**。  
> 代码对齐：`wechat_mp_seo.py`、`wechat_mp_traffic_checklist.py`、`stock-ai/docs/wechat_mp_seo_topics.md`。  
> 看板页 `pluginloginpage?pluginuin=10071` 内嵌 **「快速入门：在微信，如何优化你的搜索效果」** → 与 [微信开放社区 · 搜一搜优化教程](https://developers.weixin.qq.com/community/develop/doc/00080c559584e8578b312b8256bc09) 同源。

## 〇、官方「优化搜索效果」→ 牛马执行清单

微信搜一搜团队强调：**账号侧**（昵称/描述/菜单/认证/可搜）+ **内容侧**（稳定更新、标题摘要正文自然含词、体验好）。搜索引擎会索引这些信息；**堆砌同义词、菜单 SEO、通用词昵称**会被打压。

### 账号侧（改一次，季度复核）

| 官方建议 | 牛马也智能 | 动作 |
|----------|------------|------|
| 昵称有品牌、勿占通用词 | **牛马也智能** ✓ | 勿改名为「A股复盘」等纯通用词 |
| 描述写清服务与领域 | [account-packaging.md](account-packaging.md) 介绍定稿 | 含 A股、收盘复盘、产业链、龙头；勿荐股堆砌 |
| 菜单名具体可理解 | 更新节奏 / 近期文章 / 免责说明 | 勿再加第四个「A股」「龙头」同类菜单 |
| 鼓励认证 | 按主体能力 | 有企业/商标则做，提权威 |
| 允许昵称被搜 | 隐私设置 | **开启**「允许通过名称搜索到本账号」 |
| 稳定更新 | 交易日 evening 三篇 + 周日 news | 停更 &gt;3 天先看板会跌 |

### 内容侧（每篇自动 + 发布时人工）

| 官方建议 | 仓库已实现 | 你还须做 |
|----------|------------|----------|
| 标题/摘要含领域词，**勿堆砌**（约 1%～3%） | `enrich_title_for_search`（前 15 字）、`enrich_digest` | 看板 **文章搜索词** 微调 sector 主线名，勿一句塞 3 个热词 |
| 正文自然出现垂直词 | `wechat_mp_monetization` + `traffic` 清单 ≥2 词 | `wechat_mp_eval --kind * --traffic` 推稿前跑 |
| **停留、收藏** 利于排序 | 清单体、对照表、分节（evening 模板） | 发布勾 **原创·财经**；点 **#** 话题；可选文末 **推荐 ♡** |
| 持续原创 | LLM + humanize + 合规 | 禁止纯 AI 不审即发 |

### 三篇标题（对齐看板 + `title_sousou_hook_score`）

| kind | 前 15 字优先 | 搜一搜句式（有数据再强化） |
|------|--------------|---------------------------|
| `sector` | A股 / 行业 / **当日主线** | `产业链怎么拆` / `怎么跟` |
| `dragons` | A股 / 龙头 / 情绪 | `怎么玩` + `还在榜` |
| `top5` | A股 / 选股 | `领衔` + `收盘信号` + `明日盯` |
| `news`（周日） | A股 / 快讯 | 72h 要闻；摘要含 **财经快讯** |

**勿用**：私聊拉高阅读的篇（如极高阅读 outliers）当标题模板；看板 **热门搜索词** 里的荐股/代码不进标题。

### 每周闭环（看板 → 只改一类）

1. `pluginuin=10071` 看板抄四行指标 + 热门搜索词 Top5 + 热门文章 Top3。  
2. 点 Top 文看 **文章搜索词** → 下周同 kind **换主线、不换句式**。  
3. 只调一类 evening 标题/sector-discovery 权重（见 §四）。  
4. 推稿前：`wechat_mp_eval --kind sector|top5|dragons --traffic`。

## 一、两套数据，不要混口径

| 来源 | 路径 | 回答什么 | 和搜一搜看板关系 |
|------|------|----------|------------------|
| **搜一搜数据看板** | 广告与服务 → 搜一搜 | 用户在 **微信搜索** 里找到你后的阅读/关注/搜索词 | **本 SOP 主数据源** |
| **内容分析 · 流量来源** | 统计 → 内容分析 → 群发篇/日报 | 某篇阅读里 **搜一搜占比 %**（和推荐、朋友圈等并列） | 用来 **验算** 哪篇整体吃搜一搜 |
| **用户分析 · 增长来源** | 统计 → 用户分析 → 增长来源 | 「搜索公众号名称/微信号」等 **关注渠道** | **≠** 文章搜一搜；主页搜昵称才涨关注 |

**关键指标含义**（[掘金网对看板说明](http://jjsoho.com/syshtgx-2/) 等）：

| 指标 | 含义 | 牛马也智能怎么用 |
|------|------|------------------|
| **搜索后阅读（次）** | 在 **搜索结果页点击** 你文章的次数 | 内容是否 **可被搜到、标题有点击** |
| **搜索后关注（人）** | 因搜索路径 **新关注** 账号的人数 | 标题+简介+主页是否让人愿意点关注 |
| **热门文章** | 按 **搜索结果页展示次数** 排序 | 哪类稿 **占搜索曝光**（未必是推送阅读量最高） |
| **文章搜索词** | 用户 **通过哪些词** 找到某篇热门文 | 下篇标题/摘要 **用真实词**，别臆造 |
| **热门搜索词（约 20 个）** | 账号相关的 **高频搜索词** + 相关搜索词 | 全号 SEO 词表 **月度校准** |

## 二、用法 ① — 每周看一次看板（约 15 分钟）

### 何时

- **每周一**（或每月 1 号）看 **近 7 天**；大改标题策略后再看 **近 14 天**。
- 晚间三篇发布后 **至少等 3～7 天** 再评价该篇搜索表现（索引有延迟）。

### 记什么（建议一张表，四行就够）

落盘：`stock-ai/output/wechat_mp_weekly/YYYY-MM-DD.md`（周一更新）

| 字段 | 本周 | 上周 | 判断 |
|------|------|------|------|
| 搜索后阅读 | **444**（2026-06-07） | — | 升 → 标题/词有效；降 → 检查是否停更、节假日 |
| 搜索后关注 | **5** | — | 升 → 搜来的流量愿意关注 |
| **关注/阅读比** | **1.13%** | — | &lt;0.5% 常见：偏「看完就走」；持续 &lt;0.3% 要改 **简介/菜单/首篇体验** |
| 搜索后阅读占新增阅读体感 | 对照「内容分析」搜一搜% | | 单篇高、看板低 → 个别爆款；看板高、单篇低 → 多篇分散贡献 |

**2026-06-07 只调一类**：`sector`（标题加代表股名；`dragons`/`top5` 不动；非财经全周≤1 篇）→ 见当周周报。

### 决策树（看完板后只做一件事）

```
搜索后阅读 ↓ 且 搜索后关注 ↓
  → 先查：是否停更 &gt;3 天、合规限流、标题前 15 字是否还含 A股/行业/龙头
搜索后阅读 ↑ 但 搜索后关注 ─
  → 优化公众号「介绍」、菜单第一句、第一篇是否像广告；少改稿型
搜索后阅读 ↑ 且 搜索后关注 ↑
  → 保持 evening 三篇节奏；从「热门文章」复制成功标题结构
仅「用户分析-搜索公众号名称」高、看板低
  → 用户搜的是昵称；加强名称「牛马也智能」+ 简介含「A股复盘」
```

### 搜一搜看板（bind 已有 Chrome tab）

Chrome 打开 **数据看板** 并保持该 tab 前台（URL 含 `pluginloginpage?pluginuin=10071`），再：

```bash
cd stock-ai
uv run python -m scripts.tools.fetch_wechat_mp_sousou_opencli \
  --expect-url-substr 'pluginuin=10071' \
  -o output/wechat_mp_sousou_latest.json
```

勿对看板 URL 使用 `browser open`（易「遇到问题」）。详见 `.cursor/skills/stock-opencli/`。

### 可选：内容分析（非搜一搜看板口径）

```bash
cd stock-ai
uv run python -m scripts.tools.fetch_wechat_mp_analytics_opencli \
  --analytics-url 'https://mp.weixin.qq.com/misc/appmsganalysis?action=report&type=daily_v2&token=…' \
  --detail-top 3 -o output/wechat_mp_analytics_latest.json
```

## 三、用法 ② — 热门搜索词 → 改标题/摘要（与代码对齐）

### 流程

1. 看板 → **热门搜索词** → 筛 **文章板块**（不要只看公众号昵称板块）。
2. 把词分成三类（手写即可）：

| 类型 | 例 | 动作 |
|------|-----|------|
| **品牌** | 牛马也智能 | 简介、菜单一致；不必硬塞进每篇标题 |
| **大盘/稿型** | A股、收盘、复盘、龙头、情绪 | 已由 `TITLE_SEO_*` / `DIGEST_SEO_*` 覆盖；用 `wechat_mp_eval --traffic` 验 |
| **当日主线** | 半导体、电力、石油… | **优先写进 `sector` / `dragons` 标题前 15 字**；top5 慎用具体票名 |

3. 看 **相关搜索词**（每个主词旁 3 个）→ 选 **1 个** 自然并入下周 **sector** 标题，勿一句堆 3 个词。
4. 推稿前自检（自动）：

```bash
cd stock-ai
uv run python -m scripts.tools.wechat_mp_eval --kind sector --traffic
uv run python -m scripts.tools.wechat_mp_eval --kind top5 --traffic
uv run python -m scripts.tools.wechat_mp_eval --kind dragons --traffic
```

通过项应含：`title_search_seo`、`digest_seo`。

### 稿型 ↔ 代码词表（改词只改 `wechat_mp_seo.py`）

| kind | 标题前 15 字优先 | 摘要核心词 | 正文 #（发布再点） |
|------|------------------|------------|-------------------|
| `sector` | A股、行业、产业链 | A股、行业研究 | #A股 #行业研究 #产业链 |
| `top5` | A股、选股、收盘信号 | A股、选股观察 | #A股 #选股观察 #技术面 |
| `dragons` | A股、龙头、情绪 | A股、龙头复盘 | #A股 #收盘龙头 #连板梯队 + 可选主线 |
| `market`（手动） | A股、收盘复盘 | 按 edition | 见 `wechat_mp_seo_topics.md` |
| `news`（手动） | A股、快讯 | 财经快讯 | #A股 #财经快讯 |

**禁止**：把看板里偶发的 **荐股、牛股、代码** 写进标题（合规 + `HASHTAG_BANNED`）。

### 从「文章搜索词」反哺（比热门搜索词更准）

1. 打开 **热门文章** → 点进 Top1～3 → 看 **文章搜索词**。
2. 记下：**用户实际用来找到这篇的词**（往往比你想的更土、更具体）。
3. 下周同 kind 标题 **复用句式 + 替换主线词**，不要整句抄标题（降权）。

## 四、用法 ③ — 热门文章 → 调整 evening 三篇比重

### 怎么认 kind（对照草稿标题）

| 标题特征 | kind | 定时 |
|----------|------|------|
| 行业/产业链/板块 | `sector` | evening + weekend |
| 选股/5只/领衔 | `top5` | evening |
| 情绪/龙头/连板/怎么玩 | `dragons` | evening |
| 快讯/10条/要闻 | `news` | 仅手动 |
| 收盘/盘面/指数 | `market` | 仅手动 |

也可对照 `data/wechat_mp_draft_slots.json` 里近期标题。

### 月度复盘表（搜一搜热门文章 Top5）

| 排名 | 标题 | 推断 kind | 文章搜索词 Top1 | 下月动作 |
|------|------|-----------|-----------------|----------|
| 1 | | | | |
| … | | | | |

### 决策（只调一类，避免全改）

| 现象 | 动作 |
|------|------|
| **sector** 占 Top3 且搜索词偏行业 | `sector-discovery` 多给该行业权重；标题多用「产业链怎么拆」 |
| **top5** 搜索高、关注低 | 标题加强「观察/结构」弱化名单感；正文禁分数（已有） |
| **dragons** 搜索高 | 保留「情绪/怎么玩/还在榜」句式；`evening_align` 情绪前缀 |
| **news** 在休市日搜索仍高 | 周日/节假日定时 `weekend` → `news`（72h、个股优先）；周六 `weekend_skip` |
| 三篇都低、**market** 手动篇在「内容分析」搜一搜%高 | 考虑交易日 **手动加 1 篇 market(close)**，与 evening 错开发布时间 |
| 某 kind 从未进热门 | 查该篇 `title_search_seo` 是否未过；是否与另两篇标题雷同 |

### 和「推荐流」分工

- **搜一搜** 奖励：**关键词匹配 + 收藏 + 停留**（清单体、对照表）。
- **推荐** 奖励：完读、♡、留言（`wechat_mp_monetization` 问句）。
- 热门文章若 **推送阅读一般、搜索高** → 下月 **少改结构，多改标题/词**；反之则改开篇与完读。

## 五、发布闭环（搜一搜 × 仓库）

每个 **发布日**（人工点发送后）：

1. 草稿已由脚本：`enrich_title_for_search` + `enrich_digest` + 正文 `#` 行（`WECHAT_MP_HASHTAG_INLINE=1`）。
2. 后台再点 **原创** + 话题（与终端推荐一致，见 `wechat_mp_seo_topics.md`）。
3. 把 **发表标题** 记入周表，便于下週对「文章搜索词」。

每个 **推稿日**（19:00 批次后）：

```bash
uv run python -m scripts.tools.wechat_mp_draft_batch --batch evening --dry-run
# 通知里应有推荐 #话题；发布前可对单篇 eval --traffic
```

## 六、勿做清单

- 用看板词 **堆砌** 标题（密度约 1%～3% 即可，见 writing-guide）。
- 把「搜索公众号名称」当成「搜一搜读完文章关注」。
- 无数据时大改 prompt/版式（先查停更与合规）。
- 期待 API 拉搜一搜看板（目前无官方接口；`fetch_wechat_mp_analytics_opencli` 只抓 **内容分析** 流量来源）。
