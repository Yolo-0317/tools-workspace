# Seedance 人物与舞蹈句式库

本文件只提炼 A/B 级案例中有公开结果支撑的人物亮相、互动和舞蹈表达，不承诺复现结果。

每条句式将包含最小表达、必填槽位、适合时长与输入、不宜叠加目标、栀夏改写示例和来源案例编号。

## PHRASE-DANCE-01 脚步、重心与上肢并写

- **最小表达：** 舞者以明确步法移动，重心随每次落脚转移；上肢动作与脚步形成同一节拍，服装在踢、转或停时产生对应惯性。
- **必填槽位：** 步法、落脚方向、重心变化、上肢路径、服装反馈。
- **适合时长与输入：** 8–15 秒；纯文字可试，复杂组合建议分镜或动作视频。
- **不宜叠加：** 只写舞种和气质、完全自由发挥、持续遮脸的大袖动作。
- **栀夏改写示例：** 栀夏以两步轻圆场向侧前方移动，重心随落脚由右移左，双臂沿立圆展开；外衫在转身后稍迟回落，不遮住面部。
- **来源案例：** `CASE-015`

## PHRASE-DANCE-02 固定全身镜头优先动作准确

- **最小表达：** 全身始终完整入画，摄影机固定居中且不切镜；舞者连续完成动作，脚、膝、髋、躯干和手臂路径均可见。
- **必填槽位：** 全身边界、地面范围、动作顺序、固定机位、结束姿态。
- **适合时长与输入：** 10–15 秒；角色图加舞蹈分镜。
- **不宜叠加：** 环绕、快速推进、脚部特写切换和复杂场景变化。
- **栀夏改写示例：** 栀夏全身和脚下雪面始终完整入画，摄影机固定正面；她完成移步、转身、沉身和收势，动作连接不断裂。
- **来源案例：** `CASE-018`

## PHRASE-DANCE-03 按分镜顺序完成舞句

- **最小表达：** 参考动作分镜，严格按面板顺序从预备姿态经过若干中间姿态到最终定格，所有面板连接为一段连续动作。
- **必填槽位：** 分镜素材、面板顺序、总时长、连续要求、最终姿态。
- **适合时长与输入：** 10–15 秒；多格动作分镜图。
- **不宜叠加：** 让模型同时自由改编动作、复杂场景转场或多镜头切换。
- **栀夏改写示例：** 参考上传的六格古典舞分镜，按一至六顺序完成抬腕、移步、转身、沉势、展袖和收势，连成十秒连续舞句。
- **来源案例：** `CASE-017`

## PHRASE-DANCE-04 衣料的动作后效

- **最小表达：** 衣料受人物动作带动，在旋转时展开、移步时轻摆、停止后因惯性继续运动并逐渐回落。
- **必填槽位：** 衣料种类、重量感、触发动作、最大幅度、回落时间。
- **适合时长与输入：** 6–15 秒；角色图有助于固定服装结构。
- **不宜叠加：** 无风却持续飞扬、衣袖覆盖面部、衣料穿过身体。
- **栀夏改写示例：** 栀夏转身时半透明外衫向外展开半拍，停步后仍向前轻摆并自然贴回长裙，袖口始终低于面部。
- **来源案例：** `CASE-019`

## PHRASE-DANCE-05 分镜负责动作、音频负责节拍

- **最小表达：** 动作完全遵循分镜顺序；音乐只决定起势、重拍、旋转和最终停点的时间，不改变分镜中的人物身份和动作内容。
- **必填槽位：** 分镜、音频、节拍节点、对应动作、最终停点。
- **适合时长与输入：** 10–15 秒；分镜图 + 自有或授权音乐。
- **不宜叠加：** 逐拍再写另一套文字编舞、额外随机转场。
- **栀夏改写示例：** 六格分镜决定栀夏的古典舞顺序，古琴音频只控制第一次抬袖、转身重拍和结尾收势三处时间点。
- **来源案例：** `CASE-020`

## PHRASE-DANCE-06 合法动作视频的定向迁移

- **最小表达：** 严格参考已获授权视频的逐拍动作、位置、转身、跳跃、镜头和节拍；只替换主角外形、服装与环境，其他运动关系保持不变。
- **必填槽位：** 视频权利、保留项、替换项、角色图、环境目标、节拍来源。
- **适合时长与输入：** 与参考视频相同或更短；动作视频 + 角色图。
- **不宜叠加：** 同时要求另一套原创编舞、未授权网络视频或完全不同的身体结构。
- **栀夏改写示例：** 使用自录古典舞视频保留步法、重心、转身和镜头节奏，以栀夏母版替换舞者，并把摄影棚替换为雪林。
- **来源案例：** `CASE-022`

## PHRASE-CHAR-01 微表情引出动作

- **最小表达：** 人物先用一次视线或微表情确认环境，随后完成一个越界或取物动作，外部声音出现后立即做出反应并复位。
- **必填槽位：** 微表情、主动作、触发声音、反应动作、结束状态。
- **适合时长与输入：** 5–10 秒；角色图或场景图。
- **不宜叠加：** 多句对白、复杂舞蹈或连续换装。
- **栀夏改写示例：** 栀夏先侧目看见枝头新雪，抬袖轻触；远处一声枝响后她收袖回望阿砚，面部始终可见。
- **来源案例：** `CASE-002`

## PHRASE-CHAR-02 双角色的失误与修正

- **最小表达：** 角色 A 的动作出现明确偏差，角色 B 通过视线、重心或位置调整给予修正，二人重新同步并共同完成最后动作。
- **必填槽位：** 失误角色、可见偏差、修正角色、修正方式、共同结果。
- **适合时长与输入：** 8–15 秒；双角色参考图，复杂接触建议动作参考。
- **不宜叠加：** 两人同时自由表演、复杂口型或无关第三角色。
- **栀夏改写示例：** 阿砚先把落雪误认成梨花，栀夏以目光和手势引向枝头新雪；二者随后共同看向雪林，完成同一诗意揭示。
- **来源案例：** `CASE-009`
