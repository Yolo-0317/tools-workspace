## 一、原则（sector 模式仍适用）

| 项 | 股吧 | 公众号 |
|----|------|--------|
| 篇幅 | 800～1500 字（可更长，但首屏要抓人） | 2500～3200 字五节完整版 |
| 格式 | 纯文本；`【小标题】` 代替 `> 分节` | HTML + banner + 插图 |
| 个股 | **生成侧**每链 2 只、合计 3～4 只；**东财发帖**每帖 **≤3 个 `$话题$`**，双链时 **拆 2 帖**（见 §1.3） | 同上，可略展开 |
| 语气 | 讨论帖、留验证点 | 研究员手记 |
| 禁止 | CPS、#话题、荐股、目标价、外链轰炸 | — |
| 免责 | 文末 1 句 | 文末红框免责 |

**发布时间**：公众号**原创发表后 2～4 小时**再发股吧（避免同文同题被当 spam；也给搜一搜先收录）。

### 1.1 个股话题 `$简称(代码)$`（必带）

东财发帖支持 **个股话题**语法，帖子会 **自动同步到对应个股股吧** 的讨论流，不必同一内容多吧各发一遍。

**格式**

```text
$公司简称(SH六位代码)$   # 上交所
$公司简称(SZ六位代码)$   # 深交所
$公司简称(BJ六位代码)$   # 北交所（少用）
```

**示例**

```text
$山东玻纤(SH605006)$
$视觉中国(SZ000681)$
```

**规则**

| 项 | 说明 |
|----|------|
| 数量 | 生成 **3～4 只**（双主线每链 2 只）；**东财单帖上限 3 个 `$话题$`** → 双链 **发 2 帖**（每帖 2 只）；**禁止**单帖堆 4 只以上 |
| 选股来源 | 与公众号 sector 同源：`行业领涨` → `人气同行业` → `龙头池`（`collect_sector_sample_stocks`）；勿凭空凑票 |
| 位置 | **标题**放 2 个主 `$话题$`（≤36 字）；**首段**再补 1～2 个；**盘面样本**每只首次出现用 `$…$` |
| 与合规 | 话题 ≠ 推荐买入；正文仍只写量价事实、验证点；不写「建议关注 / 可埋伏」 |
| 交易所 | 60/68 开头 → `SH`；00/30 开头 → `SZ`；83/87/92 等 → `BJ` |
| 多股并列 | 标题示例：`…$视觉中国(SZ000681)$ $山东玻纤(SH605006)$`；第 3、4 只放正文首段或盘面节 |

### 1.3 东财单帖 ≤3 票 · 拆帖发帖

东财 App 发动态时，**单条最多约 3 个个股话题**；sector 成稿 4 只时 **按行业链拆 2 帖**（每帖 2 只 `$…$`）。

| 帖序 | 内容 | 话题数 |
|------|------|--------|
| 帖 1/2 | 榜一链（如磷肥及磷化工） | ≤3 |
| 帖 2/2 | 榜二链（如半导体材料） | ≤3 |

脚本：`wechat_mp_guba_sector.build_guba_split_posts()` · 备份 `output/wechat_mp_guba_latest.txt`（`=== 帖N/M · 主题 ===` 分块）。

**发帖位置**

1. **优先**：东财 App **发动态**，**每链 1 帖**（共 2 帖），间隔数分钟
2. 备选：当日 **概念/行业吧** 各发 1 条（仍带 `$…$`）
3. **不要**两链硬塞进 1 帖超过 3 个 `$…$`

### 1.2 为何多加股票命中（实证）

首帖 **600+ 阅读** 说明：`$话题$` 同步进个股吧是主要流量入口，不是行业吧本身。

| 做法 | 效果 |
|------|------|
| 只写 1～2 个 `$话题$` | 只进 1～2 只个股讨论流，曝光面窄 |
| **每链 2 只、共 3～4 个 `$话题$`** | 同步进 3～4 只个股吧 + 仍是一条动态，不刷屏 |
| 堆 5 只以上 | 像 top5 名单，合规与推荐流风险上升 |

**口诀**：行业逻辑写链，**流量靠票名命中**；每只 1 句量价事实即可，不必逐只长拆。

## 二、股吧帖骨架（从 sector 改写）

```
【标题】{数据日}收盘｜{榜一+榜二}：{机制问句} {$领涨1$} {$领涨2$}（≤36字，标题优先放两链各 1 只领涨）

【首段·钩子】首句列 **2～4 个 `$简称(SH/SZ代码)$`**（两链代表股）；接 2～3 句指数/广度 + 机制判断

【为什么现在看】80～120字：榜位、涨幅、与指数风格关系

【产业链怎么拆】150～220字：两链各 上中下游 各 1 句；交汇点 1 句

【盘面样本】180～280字：**3～4 只**，每链至少 2 只；**首次出现用 `$…$`** + 1 句量价事实（涨跌/换手/相对板块）；不写「建议关注」

【向后看·3个验证点】条列 3 条 + 1 句证伪；验证点里可再次 `$…$` 指代表股

【引流·软 CTA】1～2 句（见第四节）

【免责】个人观点，不构成投资建议；市场有风险，决策自负。
```

改写 checklist：

- [ ] 去掉 banner、slogan、CPS、微信 `#话题`、`「推荐 ♡」、留言互动句
- [ ] **全文含 3～4 个东财 `$简称(SH/SZ代码)$` 个股话题**（标题 2 + 正文至少再 1）
- [ ] 正文提及样本股时优先 `$…$`，勿只写裸代码
- [ ] 标题与公众号不同句式（可加 `$话题$`）
- [ ] 保留「M月D日收盘」，不用「今日」指代数据日
- [ ] 跑一遍合规：无「建议买入/建仓/目标价/强烈推荐」
- [ ] CTA 不超过 2 句，不带二维码图片（首期）

## 三、示例帖（2026-06-09 · 图片媒体+玻纤）

以下为可直接粘贴东财股吧的正文（标题在发帖框单独填）。

**标题**

```text
6月9日收盘｜图片媒体+玻纤共振 $视觉中国(SZ000681)$ $山东玻纤(SH605006)$
```

**正文**

```text
$视觉中国(SZ000681)$ 与 $山东玻纤(SH605006)$ 所在链条，6月9日收盘同日登上东财行业涨幅榜前列——图片媒体约+10%、玻纤约+9%。上证4010点（+1.28%），创业板+3.93%，全A上涨3264家、下跌1861家。深强沪弱、成长领跑，给「软内容+硬材料」提供了同一套流动性背景。

【为什么现在看】
图片媒体偏 AIGC/版权/视觉素材叙事，玻纤偏风电与电子基材材料逻辑。同一天上榜，更像主题扩散 + 材料补涨的风格互补，而不是单一宏观故事。

【产业链怎么拆】
图片媒体：内容生产 → 版权确权/API → 广告/传媒/游戏等变现。
玻纤：矿石能源 → 池窑拉丝/制品 → 风电叶片、PCB、建材等。
轻资产高弹性 vs 重资产顺周期——6月9日并列走强，尚不宜等同为同一景气拐点。

【盘面样本（仅结构观察）】
图片媒体链：
$视觉中国(SZ000681)$：板块约+10%，个股领涨约+10%，偏板块贝塔同步。
$昆仑万维(SZ300418)$：同链跟风，涨幅略低于领涨，看次日能否缩小差距。
玻纤链：
$山东玻纤(SH605006)$：玻纤板块约+9.7%，个股约+10%，略强于板块均值。
$中国巨石(SH600176)$：板块权重更大，涨幅与板块接近，偏稳态贝塔。
能否形成「龙头稳、跟风缩」梯队，要看后续换手，不能凭一日涨幅外推。

【向后看·3个验证点】
1. 东财行业榜：图片媒体、玻纤能否连续上榜。
2. $视觉中国(SZ000681)$、$山东玻纤(SH605006)$ 相对各自板块溢价是否收敛。
3. 若指数仍强但两板块跌出榜前五，则共振更偏短线定价。

本文为「收盘产业链笔记」系列摘要；五节完整版与验证清单在日常交流平台。当结构参考即可。

个人观点，不构成投资建议；市场有风险，决策自负。
```

**发帖**：东财 App **发动态** × **2 帖**（图片媒体链 1 帖 + 玻纤链 1 帖）；每帖 2 个 `$…$`，合计覆盖 4 只个股吧。

> 示例中第 3、4 只为结构示范；成稿时以 `collect_sector_sample_stocks` 当日样本为准，勿硬套历史票名。

## 四、引流到微信：怎么做得有效又不过线

### 4.1 东财对引流的实际限制

| 限制 | 应对 |
|------|------|
| 外链/二维码/微信/公众号词常被删 | **正文不写** 微信、公众号、谐音；用系列名 + 同名（见 §4.3） |
| 重复粘贴公众号全文 | 股吧只发 **70% 结构**；长表、五节完整版、插图留公众号 |
| 营销号嫌疑 | 同一吧 **≤1 帖/日**；CTA **隔篇轮换**，不是每帖都要关注 |
| 无投顾资质 | 只引「行业复盘/结构观察」，不引 top5 名单 |

### 4.2 内容漏斗（推荐）

```text
股吧个股吧（`$话题$` 命中）  →  价值够但不够全  →  读者自行搜同名  →  公众号（完读+推荐流）
```

**在股吧刻意「留白」、在公众号「补全」**——比硬广转化高：

| 留公众号的内容 | 股吧只给摘要 |
|----------------|--------------|
| 五节完整版 + 节间验证句 | 压缩成 3 个小标题 |
| 指数与广度联动专节 | 首段 1 句带过 |
| 证伪「若…则…露馅」完整句式 | 只列 3 个验证点 |
| 插图、banner 品牌识别 | 纯文字 |

### 4.3 CTA：固定方案（自动化与人工均用此句）

```text
本帖为东财人气榜收盘对照摘要（3只/帖，非荐股）。同一交易日快讯与验证清单在牛马也智能同步更新，搜「牛马也智能」看完整版。仅供结构参考。
```

**禁止**在正文写微信、公众号、谐音、回复关键词领资料。

**评论触发（不在主帖写死）**

- 有人问「有没有完整版 / 后面怎么跟踪」→ 评论回复：「同名牛马也智能有完整版，当参考即可」
- **不要**在评论写「微信」「公众号」；**不要**在每条评论都贴号名

**禁止**

- 首段就放「关注公众号领牛股」
- 带二维码图片（易被删）
- 把 top5/dragons 名单当引流钩子

### 4.4 公众号侧要配合的动作

| 动作 | 目的 |
|------|------|
| 功能介绍含「行业→产业链」关键词 | 微信搜一搜能搜到 |
| 菜单「近期文章」 | 从股吧来的新读者有落点 |
| 关键词「节奏」 | 股吧 CTA 可指向可核实的服务 |
| sector 文末保留 1 个**可回答的问题** | 股吧帖引用同一问题，两边评论氛围一致 |
| 发表后 2～4h 发股吧 | 公众号已收录，避免「空引流」 |

### 4.5 效果怎么量（简易）

| 信号 | 说明 |
|------|------|
| 股吧帖阅读/回复 | 东财个人中心 |
| 公众号「搜一搜」来源占比 | `output/wechat_mp_analytics_latest.json` |
| 关注新增时段 | 发表当晚 20:00～23:00 是否抬升（后台用户分析） |
| 无效信号 | 只看关注数不看完读——引流来的人完读低会伤推荐流 |

**节奏建议**：先 **4 周 × 每周 2 篇 sector 股吧帖**，对比「发股吧周 vs 不发」的搜一搜与关注增量，再决定是否加脚本自动化。

## 五、与 Agent 协作

用户说「写股吧版 / 东财引流」→ 读本文件 → 用 `--kind sector --dry-run` 或 `build_sector_article()` 取正文 → 从「代表股观察样本」取 **3～4 只** → 按 §二骨架改写 → **全部转为 `$简称(SH/SZ代码)$`** → 输出「标题 + 正文 + 建议关联话题列表（3～4 只）」。

**定时（交易日 15:15）**：`wechat_mp_guba_scheduled.sh` → `sync_guba_sector_delivery()`（`WECHAT_MP_GUBA_MODE=hot12`）→ **飞书 8 条**。手动：`uv run python -m scripts.tools.wechat_mp_guba_sector --feishu`。

**不做**：top5/dragons 股吧版、OpenCLI 自动发帖（东财无稳定发帖 API，且易触发风控）。
