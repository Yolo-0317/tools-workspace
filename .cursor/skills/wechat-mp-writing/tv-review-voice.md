## 真人剧评 vs 当前 AI 味

| AI 常犯 | 真人常写 |
|---------|----------|
| 每段先下结论再举例 | **先丢一个具体画面**，再补一句判断 |
| 「不是 A 而是 B」连用 | 顶多一两处；其余用「倒是」「说白了」转折 |
| 影评腔：戏眼、意象、正向反馈 | 大白话：重点、留到最后的、好处、窗户纸 |
| 半句话：「那种熟」 | 说完整：「再没有损友那种随口玩笑」 |
| 对称排比、破折号串联 | 长短句交错；一句短的，再接两句长的 |
| 百科复习：剧情承接、梗概也熟 | 「内地没上那部，这点挺要命」一句带过 |
| 介绍体/导购腔 | 「冲X来的会觉得」「拿不准值不值得：」「XX那场：」开段 |
| 压缩怪句 | 「脸上是信的」「表演上成立」「说得过去」——要么说完整人话，要么删掉 |
| 假共情：加班、票根、我哭了 | 写戏里：眼神、停顿、配乐、演员脸上 |

## 开篇三种真人入口（择一，禁止第一人称「我」）

1. **时间差**：「翻日历才会发现，上一部已是 X 年前……」
2. **一个画面**：散场后记得住的台灯/一句台词/一场戏，不是票房数字开头堆满
3. **内地语境**：没上前作、档期空窗、观众可能懵的一点——一句点破即可

## 中段写法

- 一场戏 = **发生了什么** + **演员/镜头哪一点成立**（一句就够）
- 引用外媒评分：嵌进判断里，不要「IGN 中国给了 8 分」单独成段念榜
- 缺点直说：公式化、挤、像《土拨鼠之日》——用比喻，不用「客观缺点」

## 朋友分享语气（可稍啰嗦）

- 像散场后顺嘴聊：**不怕多一两句过渡**，怕的是干巴巴下判断
- 可用：说穿了、可爱聊归爱聊、回头细想、有个段落特别好记、散场门口聊天、说到底、也别跟自己较劲
- 仍禁：第一人称「我」、百科复习体、导购分人群（「冲X来的会觉得」）
- 篇幅：院线单片 **1000–1400 字** 可接受，为语气多写几句过渡不算水

## 结尾

- 用**转述口吻**聊优缺点：「散场后吐槽也集中在这」「有人觉得…也有人嘀咕…」——像聊天，不像分人群导购
- 试看建议口语化：「先坐四十分钟试试」「别硬熬」
- 一句问句 + 点回开篇意象（「答案大概还在那盏台灯底下」）
- 末段锚点「台灯底下」对应第四张剧照
