# 中文口播逐句语法与病句修改

写稿、逐句修改、去问答语气或最终口播审校时读。先改句子，再按用户要求检查段落关系；承接、生硬说明腔与整段连贯另按 [中文承接与段落推进](chinese-writing-coherence.md) 检查。本规则由公开语文教学分类和编校案例改编为视频口播流程，属于本地审稿方法，不是国家统一的语法强制标准。

## 逐句检查：不能只凭“读着顺”

将完整口播按句编号；分号或逗号连接的多个分句也分别检查。标题、互动引导、直接引语与正文区分，不能用删除问号代替句式修改。

每句先抽出主干，再把修饰语放回：

1. 对象与动作：谁或什么发生了什么，必要的宾语、补语有没有缺失；多个动作是否确由同一主体承担。
2. 搭配与修饰：主谓、动宾、主宾是否成立；时间、地点、程度、数量和定语究竟修饰哪个词；比较的两项是否同类、同口径。
3. 结构与指代：前后分句有没有中途换主语、句式杂糅、指代多解；“这些、这、它、当时”是否有唯一可辨的对象。
4. 含义与范围：否定、可能性、数量、时间、因果与条件是否被改变；是否把先后发生写成因果，把部分写成全部。
5. 表达风格：是否有自问自答、预告答案、读者代言、重复解释或空泛评价；再读一次，判断能否自然说出来。

中文有无主句、存现句、判断句和可从语境恢复的省略句，不强迫每句补“主谓宾”，也不把所有承前省略判成主语残缺。长句、语气助词、“被”字句本身均不是错误。

用户说“忽略前后关联”时，不调整段落顺序、不添加过渡；仍检查句内关系及理解代词所需的最小语境。无法确认指代时标待确认，不能凭想象补一个人名。

## 六类病句的检查与修改

| 类别 | 检查位置 | 修改方式 |
|---|---|---|
| 语序不当 | 多项修饰语、关联词位置、并列动作次序 | 将修饰语放回准确对象旁边；按原有时间或逻辑关系调整，不能改事实顺序 |
| 搭配不当 | 主谓、动宾、主宾、修饰语与中心语；“能否”与单面结论 | 换准确动词或中心词；逐一试配并列项，不能只检第一个 |
| 成分残缺或赘余 | 介词使主语悬空、必要谓语或宾语缺失、同义成分叠加 | 补必要成分、删确属重复的词；保留可恢复省略和必要限定 |
| 结构混乱 | 两种句式拼在一起、句中换主体、前句尾兼充后句头 | 选择一种结构，明确各动作主体；必要时拆句，不靠标点掩盖错误 |
| 表意不明 | 指代、修饰范围、歧义、比较对象和省略项 | 明确对象和修饰关系；意义有两解时回源或待确认，不自行选一解 |
| 不合逻辑 | 否定叠加、集合包含与并列、条件和因果、前后矛盾 | 修正关系和范围；事实不够时核验，不为语法通顺补证据 |

修改优先保留原意，局部换词、调整顺序、补缺项或删赘余；只有原结构无法修复时才整句重写。没有明显语病的句子可以保留。别为了显示“优化”把每一句都换词。

### 动词要能支配这个名词

2026-10-15 用户指出「一个富商家里，生了徐志摩」不能用。先问谁在做这个动作，这个动词能不能拿后面的名词当对象。

「生了」的对象是婴儿，做这个动作的是母亲。已经用来称呼这个人的名字，不能放在「生了」后面。人物作主语，写成「徐志摩出生在浙江海宁一个富商家里。」家里、时代、一段历史，也不能「生出」一个叫这个名字的人。

同一类搭配都要拦：动作和对象对不上，就不靠换个近义词放过去。2026-10-14 公众号单句语法里的两条，口播同样执行：「一边……一边……」的两个动作须是同一个主体；没有原话，不把看见的事写成「他在意、她担心」。

## 去问答语气：修改表达，不抹去信息

当前介绍型口播不设置观众提问、角色提问、自问自答、反问或“答案在后面”的预告。直接叙述已核实的行动、原因或过程。

- “为什么他还能住在宫里？原来……” → 直接交代优待条件允许暂居宫中；保留决定这件事的原因。
- “你可能会问……” → 删除代言和提问，保留有信息的解释部分。
- “那么，这说明了什么？” → 直接写证据支持的具体含义，证据不足则不补结论。
- “并非……而是……”或“看似……其实……”属于陈述句，不冒称语法错误；本系列按用户偏好改成直接陈述，保留必要的事实区别。
- 标题允许疑问形式时不随正文一起改；史料直接引语不为消问答语气而篡改，需要时改为准确转述。

不能把“是否、能否、何时”等词一律删除，它们也能表达真实的不确定性。词语搜索只能提示复核，不能作为通过审稿的证据。

## 自拟例句与既有反馈

以下仅说明语言修改，不为例句中的历史、科学或医学内容提供事实背书。

- 病句：“通过这份文件，使他可以继续住在宫中。” → “这份文件允许他继续住在宫中。” 删除使主语悬空的结构；若“允许”不符合文件内容，应核实后换词。
- 病句：“婚礼用品包括号牌和参加婚礼的宾客。” → “婚礼用品中，有供宾客佩戴的号牌。” 人不能与物品并列归入用品；改写仍需符合原文事实。
- 用词笨重：“花朵所处的开放阶段，也会影响这些物质的释放。” → “花朵的开放阶段也会影响这些物质的释放。” 优化定语表达；“这些物质”仍需可辨的上文，不能假称已解决所有指代。
- 比较表达：“同一棵桂花树，在远处随风飘来的香气，与靠近花朵时闻到的香味，也可能有所不同。” → “同一棵桂花树的香味，随风飘到远处后，可能与靠近花朵时闻到的有所不同。” 明确比较对象，保留同一棵树、风与可能性，不擅自加“街口”等场景。

## 审校记录与交付

用户要求严格逐句检查时，在已有单集目录记录“句号编号｜原句｜问题类别或保留｜修改后｜修改理由｜事实待核项”；每句都覆盖，不能抽查。默认给用户修改后的全文，不把内部表格混入口播；用户要求分析时再展示。

分别记录：语法错误、表达优化、用户风格要求、事实待核。不要将“有点拗口”全部叫病句，也不能将删除信息包装成语法优化。

修改后逐句复核原意、指代、搭配和限定是否保留。再按请求范围连读，检查句内和相邻句的重复、读音与停顿。全文有标点；最终无标点字幕在制作阶段另行处理，不能因此删掉口播稿的标点。
