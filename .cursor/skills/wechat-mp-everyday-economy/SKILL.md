# 普通人的经济生活

本 Skill 负责选题与研究，随后把核实过的事实交给现有公众号写稿、质检和草稿流程。它不是财经行情工作台，也不自动调用 DeepSeek、写入草稿或发布。

## 路由

- 用户要“选一组”“看看近期热点”：先读 [hotspot-selection.md](hotspot-selection.md)，只做候选和推荐。用户已点名题目则跳过候选，直接研究。
- 用户要“查清这笔钱”“研究这个事件”或已选题：读 [evidence-and-accounting.md](evidence-and-accounting.md)，建立证据账本与适用人群明确的测算。
- 用户确认进入写稿：读 [writer-handoff.md](writer-handoff.md)，把研究包交给 [公众号写稿 Skill](../wechat-mp-writing/SKILL.md)。沿用原有两次确认、事实门禁、配图和草稿安全规则。

经济生活题的研究包需把关键数字、企业动作、页面价格分别标注发布日期、数据或页面所属时间和适用范围；不把报道时的在售价格写成现在仍可买到。研究 Skill 不替正文做最终措辞，也不负责 `editorial_handoff.json` 的图片与草稿字段；后两项由写作和草稿 Skill 接续完成。

## 编辑边界

从一个有日期、地点、来源的真实新变化出发，写它如何改变普通人的收入、支出、时间或选择。不要用全国平均数冒充一户人家的账单，不把个别经历写成普遍结果，不为戏剧性虚构人物、对话或成本。

候选少而精：最多三项，推荐一项。热点热度要有可见讨论信号，不能把搜索结果数量、转载数量或 A 股板块热度直接当成公众讨论热度。来源和适用范围不足时明确说缺口，暂停结论。

未经用户确认，不进入正式写稿；未经草稿操作确认，不触碰公众号已有草稿。本 Skill 的检索、核对和演练均为只读。
